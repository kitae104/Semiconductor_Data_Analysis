# week09_pass_fail_train.csv / week09_new_lots_to_predict.csv 데이터 설명서

## 목적
scikit-learn으로 첫 머신러닝 분류 모델(의사결정나무)을 직접 만들어 보는 실습 데이터다.
학습용 데이터(`week09_pass_fail_train.csv`)와, 정답 없이 예측만 해볼 신규 로트 데이터
(`week09_new_lots_to_predict.csv`, 10차시에서 사용)로 구성된다.

## 가상 상황
여러 공정·설비에서 측정한 공정 조건과 최종 검사 결과를 모아, "공정 조건만으로 합격/불합격을
미리 예측할 수 있을까?"를 실험하는 데이터다.

## 행 하나의 의미
한 행 = 로트 1건의 공정 조건 측정값과 최종 검사 결과.

## week09_pass_fail_train.csv 열 설명

| 열 이름 | 쉬운 설명 | 데이터 형식 | 단위 | 결측값 가능 여부 |
| --- | --- | --- | --- | --- |
| 공정명 | 어떤 작업(식각·포토 등)을 했는지 | 문자열 | - | 없음 |
| 설비번호 | 어느 기계에서 작업했는지 | 문자열 | - | 없음 |

| 압력_Pa | 설비(챔버) 안의 압력(아래 "압력_Pa 값의 한계" 참고) | 실수 | Pa | 있음 |
| 가스유량_slm | 설비에 흘려 넣은 가스의 양 | 실수 | slm(1분에 흐른 양) | 있음 |
| 두께_nm | 작업 뒤 웨이퍼 위에 남은 막의 두께 | 실수 | nm(10억분의 1미터) | 있음 |

전체 750행이며, 결측값이 포함된 행을 `dropna()`로 제거하면 735행이 남는다(모델 학습에는
735행 사용). 정답(`합격여부`) 분포는 합격(1) 582건, 불합격(-1) 153건으로 **불균형** 데이터다(원본 750행 기준 합격 595, 불합격 155).

## 부호 — 1~8차시와 같은 표기

`합격여부`는 1~8차시와 같이 **1 = 합격, -1 = 불합격**이다. 합격 비율은 `(y_test == 1).mean()`으로 구한다.
scikit-learn의 혼동행렬은 기본으로 숫자가 작은 쪽(-1 = 불합격)을 첫 줄·첫 칸에 두므로, 강의에서는
`confusion_matrix(y_test, pred, labels=[1, -1])`로 합격을 먼저 놓아 "윗줄 = 실제 합격, 왼쪽 칸 = 합격으로 예측"이 되게 한다.

## week09_new_lots_to_predict.csv 열 설명
`week09_pass_fail_train.csv`와 같은 8개 열(공정명, 설비번호와 공정 조건 6개: 온도_섭씨, 압력_Pa,
가스유량_slm, 두께_nm, 진공도_mTorr, 습도_pct)만 있고 `합격여부`는 없다. 아직 검사하지 않은
신규 로트 9건이며, 10차시에서 학습된 모델로 이 로트들의 합격/불합격을 예측한다.

## 압력_Pa 값의 한계 (교육용 가상 데이터)

`압력_Pa`는 교육용으로 생성한 가상 값이며 실제 측정값이 아니다. 이번 차시의 실측 범위는 학습용
데이터가 약 982.9~1,041.8 Pa(평균 약 1,011.9 Pa), 신규 로트 데이터가 약 989.2~1,031.7 Pa(평균
약 1,013.3 Pa)인데, 이 자릿수는 Pa로 읽은 챔버 압력보다 hPa로 읽었을 때의 자릿수에
가깝다(대기압이 약 1,013 hPa = 101,325 Pa다). **단위 라벨과 값의 자릿수가 서로 맞지 않는다.**
같은 행의 `진공도_mTorr`와도 맞지 않는다. 진공도 평균 약 5.01 mTorr는 약 0.67 Pa인데(1 mTorr ≈
0.133 Pa) 같은 행의 `압력_Pa`는 평균 약 1,011.9 Pa여서 약 1,510배 차이가 난다 — 한 챔버가 같은
시각에 두 압력일 수는 없다. 신규 로트 데이터도 같다(진공도 평균 약 4.79 mTorr ≈ 0.64 Pa, 압력
평균 약 1,013.3 Pa, 약 1,590배). 이 값이 실제로 어떤 공정 조건을 나타내는지는 단정할 수
없으므로, 실습에서는 `압력_Pa`의 절대값을 물리적으로 해석하지 않고 **수치 열 하나**로만
다룬다.

**학생이 물어보면**: "교육용으로 만든 가상 값이라 단위와 자릿수가 실제 공정과 맞지 않습니다.
이번 실습에서는 압력의 절대값을 해석하지 않고 값들 사이의 상대적인 차이만 봅니다"라고 답한다.

데이터를 다시 만들면 1~10차시의 실습 결과 수치와 강의 자료가 모두 함께 바뀌므로, 현재 버전은
값을 그대로 두고 이 한계를 여기에 명시하는 쪽을 택했다.

## 이번 차시 핵심 수치(실제 실행 결과, `max_depth=4`, `random_state=42`)
- 학습/평가 데이터 분할: `train_test_split(test_size=0.2, random_state=42, stratify=y)` → 588행 / 147행
  (모의고사 실제 합격 116건, 불합격 31건)
- 모델 정확도: 80.3%(147건 중 118건)
- "무조건 합격으로 예측" 기준선 정확도: 78.9%(116건) (**모델과 2건 차이** — 정확도 하나로는 판단하기 어렵다는 것이 이번 차시의 핵심 교훈)
- 혼동행렬(`labels=[1, -1]`): `[[109, 7], [22, 9]]` — 실제 불합격 31건 중 모델이 잡은 것은 9건, 놓친 것은 22건
  (모델이 불합격으로 예측한 것은 16건 = 헛경보 7건 + 잡아낸 불량 9건). `labels`를 빼면 `[[9, 22], [7, 109]]`.
- 가스유량_slm(비교용 열)을 47~53 slm 범위로 나누면 불합격 비율은 밖 20.3%(241건), 안 21.1%(494건)로 차이가 없다.
  그런데도 중요도는 9.2%다(모델이 우연한 패턴도 배울 수 있다).
- 특성 중요도: 온도_섭씨 48.8%, 진공도_mTorr 21.1%, 압력_Pa 16.7%, 가스유량_slm 9.2%,
  두께_nm 4.2%, 습도_pct 0.0%. 중요도는 "모델이 질문에 많이 쓴 열"이며 원인이라는 뜻이 아니다(원인 후보).
- 트리 위쪽 질문(학습용 588건): "온도 ≤ 293.95℃?" → "온도 ≤ 306.05℃?" → "진공도 ≤ 5.49 mTorr?".
  세 질문을 모두 안전한 쪽으로 통과한 406건의 불합격 비율은 9.4%.
- 온도(295~305℃)×진공도(4.5~5.5 mTorr) 범위별 불합격 비율(735건): 둘 다 안 8.0%, 온도만 밖 33.2%,
  진공도만 밖 32.6%, 둘 다 밖 56.5%.
- 같은 분할에서 Feature를 바꾼 결과(`max_depth=4`, `labels=[1, -1]`): 진공도 하나만 76.9% `[[110, 6], [28, 3]]`,
  온도 하나만 78.2% `[[103, 13], [19, 12]]`(불합격 12건을 잡지만 헛경보 13건), 온도·진공도 두 개 80.3% `[[110, 6], [23, 8]]`.
  모의고사가 147건뿐이라 몇 건 차이는 나누는 방식에 따라 바뀔 수 있다.
- `max_depth=8`: 연습문제(train) 94.2% / 모의고사(test) 78.9%(과대적합 신호). `max_depth=4`는 84.7% / 80.3%.
- `dropna()`를 건너뛰면(750행) 정확도 79.3%.

## 실제 현업 데이터와 다른 점
완전한 가상 데이터다. 클래스 불균형과 "정확도의 함정"(기준선과 거의 같은 정확도)을 직접 관찰하도록 구성했다.
