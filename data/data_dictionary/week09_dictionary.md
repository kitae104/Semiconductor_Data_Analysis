# week09_pass_fail_train.csv / week09_new_lots_to_predict.csv 데이터 설명서

## 목적
scikit-learn으로 첫 머신러닝 분류 모델(의사결정나무)을 직접 만들어 보는 실습 데이터다.
학습용 데이터(`week09_pass_fail_train.csv`)와, 정답 없이 예측만 해볼 신규 로트 데이터
(`week09_new_lots_to_predict.csv`, 10차시에서 사용)로 구성된다.

## 가상 상황
여러 공정·설비에서 측정한 공정 조건과 최종 검사 결과를 모아, "공정 조건만으로 합격/불합격을
미리 예측할 수 있을까?"를 실험하는 데이터다.

## 행 하나의 의미
한 행 = 로트 1건의 공정 조건 측정값과 최종 검사 결과.

## week09_pass_fail_train.csv 열 설명

| 열 이름 | 쉬운 설명 | 데이터 형식 | 단위 | 결측값 가능 여부 |
| --- | --- | --- | --- | --- |
| 공정명 | 공정 종류 | 문자열 | - | 없음 |
| 설비번호 | 공정 설비 | 문자열 | - | 없음 |
| 온도_섭씨 | 챔버 온도 | 실수 | ℃ | 있음 |
| 압력_Pa | 챔버 압력 | 실수 | Pa | 있음 |
| 가스유량_slm | 가스 유량 | 실수 | slm | 있음 |
| 두께_nm | 증착/식각 후 막 두께 | 실수 | nm | 있음 |
| 진공도_mTorr | 챔버 진공도 | 실수 | mTorr | 있음 |
| 습도_pct | 클린룸 습도 | 실수 | % | 있음 |
| 검사결과 | 최종 검사 결과 | 정수 | - | 없음(0=합격, 1=불합격) |

전체 750행이며, 결측값이 포함된 행을 `dropna()`로 제거하면 735행이 남는다(모델 학습에는
735행 사용). 정답(`검사결과`) 분포는 합격(0) 582건, 불합격(1) 153건으로 **불균형** 데이터다.

## week09_new_lots_to_predict.csv 열 설명
`week09_pass_fail_train.csv`와 동일한 6개 공정 조건 열(공정명, 설비번호, 온도_섭씨, 압력_Pa,
가스유량_slm, 두께_nm, 진공도_mTorr, 습도_pct)만 있고 `검사결과`는 없다. 아직 검사하지 않은
신규 로트 9건이며, 10차시에서 학습된 모델로 이 로트들의 합격/불합격을 예측한다.

## 이번 차시 핵심 수치(실제 실행 결과, `max_depth=4`, `random_state=42`)
- 학습/평가 데이터 분할: `train_test_split(test_size=0.2, random_state=42, stratify=y)`
- 모델 정확도: 78.2%
- "무조건 합격으로 예측" 기준선 정확도: 78.9% (**모델이 기준선보다 낮다** — 이번 차시의 핵심 교훈)
- 혼동행렬: `[[109, 7], [25, 6]]` — 실제 불합격 31건 중 모델이 맞춘 것은 6건뿐
- 특성 중요도: 온도_섭씨 51.7%, 진공도_mTorr 20.8%, 가스유량_slm 10.7%, 두께_nm 9.8%,
  습도_pct 4.4%, 압력_Pa 2.6% (8차시의 상관관계 분석 결과와 연결됨)

## 이번 차시 분석 질문
- "정확도"만 보고 좋은 모델이라고 판단해도 될까? (기준선과 비교)
- 혼동행렬에서 실제로 놓친 불합격은 몇 건인가?
- 어떤 공정 조건이 판정에 가장 큰 영향을 미쳤는가?

## 실제 현업 데이터와 다른 점
완전한 가상 데이터다. 정확도가 기준선보다 낮게 나오도록 설계하지는 않았지만(실제 계산
결과가 그렇게 나왔다), 클래스 불균형과 "정확도의 함정"을 직접 관찰하도록 구성했다.
