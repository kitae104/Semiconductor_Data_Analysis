# week09 데이터 설명서 — `week09_fab_selected_sensors.csv` / `week09_fab_beginner.csv`

## 목적
590개 센서를 가진 `fab.csv`를 초보자가 직접 다루기는 어렵기 때문에, 대표 센서만 골라낸
두 가지 축소 버전을 제공한다. 이 두 파일은 **실제 `fab.csv`에서 파생된 실제 값**을 담고 있다
(가상으로 새로 만든 데이터가 아니다). 원본 `fab.csv`는 절대 수정하지 않았다.

## 두 파일의 관계
1. `week09_fab_selected_sensors.csv`: 아래 "센서 선정 기준"으로 고른 15개 센서의
   **원본 값 그대로**(반올림만 적용) + `SensorTime` + 원본 `Pass_Fail`(부호 원본 유지: -1=정상, 1=이상).
2. `week09_fab_beginner.csv`: 위 15개 중 10개를 골라 **교육용 별칭**을 붙이고, 소수점을
   더 단순화했으며, `합격여부` 표기를 이 교육과정의 통일 기준인 `검사결과`(0=정상, 1=이상)로 변환한 파일.
   즉 `beginner` 파일은 `selected` 파일의 "쉬운 버전"이다.

## 센서 선정 기준(원본 fab.csv 분석 결과)
1. 결측률 5% 미만
2. 표준편차 > 0 (값이 실제로 변함)
3. 고유값 10개 초과
4. 위 조건을 만족하는 415개 센서 중 `Pass_Fail`과의 단순 상관계수 절댓값 상위 15개

## ⚠️ 매우 중요 — 센서 이름의 의미
`fab.csv`에는 Sensor0~Sensor589가 실제로 어떤 장비·물리량을 측정하는지에 대한 정보가 없다.
**`week09_fab_beginner.csv`의 별칭(Chamber_Temperature_edu 등)은 실제 장비 의미를 나타내는
것이 아니라, 학습자가 개념(챔버 온도, RF 전력 등)과 코드를 연결해 이해하도록 돕기 위해
임의로 붙인 교육용 가상 명칭이다.** 상관계수 상위 센서 중 의미를 추정할 근거가 전혀 없는
2개는 `주요센서_A`, `주요센서_B`로 표기해 "이름을 안다고 해서 실제 의미를 아는 것은 아니다"를
직접 보여준다.

## week09_fab_selected_sensors.csv 열 설명

| 열 이름 | 쉬운 설명 | 데이터 형식 | 결측값 가능 여부 |
| --- | --- | --- | --- |
| SensorTime | 센서 측정 시각(원본 그대로) | 문자열 | 없음 |
| Sensor59, Sensor103, Sensor510, Sensor348, Sensor431, Sensor434, Sensor430, Sensor435, Sensor21, Sensor28, Sensor436, Sensor129, Sensor210, Sensor298, Sensor163 | 선별된 15개 센서의 실제 측정값 | 실수 | 있음(원본 결측 그대로, 대부분 5% 미만) |
| Pass_Fail | 원본 판정 결과 | 정수 | 없음 |

**주의**: `Pass_Fail`은 원본 그대로 `-1`=정상/합격, `1`=이상/불합격이다. 이는 `반도체_공정_샘플.csv`의
`합격여부`(1=합격, -1=불합격)와 **부호가 반대**이므로 반드시 주의해서 다뤄야 한다.

## 핵심 발견(9차시 수업에서 강조)
상관계수가 가장 높은 센서(Sensor59)조차 `Pass_Fail`과의 상관계수 절댓값이 약 0.16에
불과하다. **어떤 센서 하나만으로는 합격/불합격을 명확히 구분할 수 없다.** 이는 "예측
모델이 불량 원인을 자동으로 증명하지 않는다"는 메시지의 실제 근거다.

## 실제 현업 데이터와 다른 점
센서 측정값 자체는 실제 `fab.csv`에서 가져온 값이지만, 별칭과 "교육용 재구성"이라는
틀은 이 과정에서 추가한 것이다. 센서의 실제 물리적 의미는 확인할 수 없으므로 단정하지 않는다.
