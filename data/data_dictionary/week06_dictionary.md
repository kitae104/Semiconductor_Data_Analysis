# week06_equipment_comparison.csv 데이터 설명서

## 목적
`groupby`를 이용해 설비별·공정별·작업조별 차이를 비교하는 실습 데이터다.

## 가상 상황
4대의 설비(EQ-01~EQ-04)가 3개 작업조(A/B/C조)로 운영되며 남긴 240건의 기록이다.

## 행 하나의 의미
한 행 = 특정 설비·작업조의 1건의 공정 기록.

## 열 설명

| 열 이름 | 쉬운 설명 | 데이터 형식 | 단위 | 예시 | 결측값 가능 여부 |
| --- | --- | --- | --- | --- | --- |
| 로트번호 | 로트 식별 번호 | 문자열 | - | LOT-0087 | 없음 |
| 설비번호 | 공정 설비 | 문자열 | - | EQ-04 | 없음 |
| 공정명 | 공정 종류 | 문자열 | - | 포토 | 없음 |
| 작업조 | 근무 조 | 문자열 | - | C조(야간) | 없음 |
| 온도_섭씨 | 챔버 온도 | 실수 | ℃ | 300.1 | **있음(야간조 일부)** |
| 압력_Pa | 챔버 압력 | 실수 | Pa | 1027.4 | 없음 |
| 진공도_mTorr | 챔버 진공도 | 실수 | mTorr | 5.02 | 없음 |
| 처리시간_sec | 처리 소요 시간 | 실수 | sec | 118.9 | 없음 |
| 합격여부 | 검사 결과 | 정수 | - | 1(합격) / -1(불합격) | 없음 |

## 정상 범위 (교육용 예시)
온도 295~305℃, 압력 995~1025 Pa, 진공도 4.5~5.5 mTorr.

## 설비별 설계 특성
| 설비 | 특징 | 불량률(설계값) |
| --- | --- | --- |
| EQ-01 | 대체로 안정 | 약 5% |
| EQ-02 | 온도 변동이 큼 | 약 10% |
| EQ-03 | 압력이 다소 높음 | 약 8% |
| EQ-04 | 불량률이 상대적으로 높음(원인 미상, 이후 차시에서 탐색) | 약 20% |

야간 근무(C조)에는 온도 열에 결측값이 조금 더 많이 섞여 있다(현장에서 야간에 기록이
누락되기 쉽다는 상황을 재현).

## 이번 차시 분석 질문

## 실제 현업 데이터와 다른 점
완전한 가상 데이터다. 설비별 특성은 "그룹 비교" 학습을 위해 의도적으로 다르게 설계했다.
