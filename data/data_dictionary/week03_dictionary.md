# week03_python_basics_2.csv 데이터 설명서

## 목적
리스트·딕셔너리를 조건문·반복문·함수로 다루는 실습을 위한 데이터다(2차시와 동일 계열,
다른 행으로 별도 생성). 이 CSV도 Pandas로 읽지 않고 리스트/딕셔너리 리터럴로 옮겨 적어 쓴다.

## 가상 상황
설비 여러 대에서 각각 측정한 온도 기록이다(2차시보다 행 수가 조금 더 많다).

## 행 하나의 의미
한 행 = 특정 로트·설비의 온도 측정 기록 1건.

## 열 설명

| 열 이름 | 쉬운 설명 | 데이터 형식 | 단위 | 예시 | 결측값 가능 여부 |
| --- | --- | --- | --- | --- | --- |
| 로트번호 | 로트 식별 번호 | 문자열 | - | LOT-0027 | 없음 |
| 공정명 | 공정 종류 | 문자열 | - | 세정 | 없음 |
| 설비번호 | 공정 설비 | 문자열 | - | EQ-02 | 없음 |

## 정상 범위 (교육용 예시)
온도 295~305℃.

## 의도적으로 포함된 패턴
30행 중 정상범위(295~305℃)를 벗어나는 온도 값을 12건 포함해(2차시보다 조금 더 많이),
`for`+`if`로 하나씩 판정하며 걸러내는 실습량을 확보했다.
