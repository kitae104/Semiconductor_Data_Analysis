# week03_process_filtering.csv 데이터 설명서

## 목적
Pandas로 CSV를 읽고, 열을 선택하고, 조건에 맞는 행을 찾고, 정렬하는 실습용 데이터다.

## 가상 상황
여러 설비에서 진행된 100건의 공정 기록이다.

## 행 하나의 의미
한 행 = 특정 설비·공정에서 이뤄진 1건의 공정 기록.

## 열 설명

| 열 이름 | 쉬운 설명 | 데이터 형식 | 단위 | 예시 | 결측값 가능 여부 |
| --- | --- | --- | --- | --- | --- |
| 측정시간 | 측정 시각 | 문자열(날짜시간) | - | 2024-03-10 14:00 | 없음 |
| 로트번호 | 로트 식별 번호 | 문자열 | - | LOT-0300 | 없음 |
| 설비번호 | 공정 설비 | 문자열 | - | EQ-02 | 없음 |
| 공정명 | 공정 종류 | 문자열 | - | 세정 | 없음 |
| 온도_섭씨 | 챔버 온도 | 실수 | ℃ | 299.4 | 없음 |
| 압력_Pa | 챔버 압력 | 실수 | Pa | 1015.2 | 없음 |
| 가스유량_slm | 공정 가스 유량 | 실수 | slm | 50.1 | 없음 |
| 합격여부 | 검사 결과 | 정수 | - | 1(합격) / -1(불합격) | 없음 |

## 정상 범위 (교육용 예시)
온도 295~305℃, 압력 995~1025 Pa, 가스유량 47~53 slm.

## 의도적으로 포함된 패턴
`EQ-02` 설비에 불합격 비율을 다른 설비보다 높게(약 28% vs 약 9%) 설계했다.
조건 검색(`df[df['설비번호']=='EQ-02']`)으로 학습자가 이 사실을 직접 "발견"하도록 만든 장치다.

## 이번 주 분석 질문
- `EQ-02`에서 발생한 불합격은 몇 건인가?
- 온도가 가장 높았던 상위 5건은 어떤 조건인가?

## 실제 현업 데이터와 다른 점
완전한 가상 데이터다. 결측값은 아직 넣지 않았다(결측값 처리는 4주차 주제).
