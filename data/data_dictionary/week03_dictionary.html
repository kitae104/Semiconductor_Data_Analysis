3차시 실습 데이터 설명서

대상 파일: week03_python_basics_2.csv

목적

리스트·딕셔너리를 조건문·반복문·함수로 다루는 실습을 위한 데이터다(2차시와 같은 계열, 다른 행으로 따로 생성). 3차시에는 이 CSV를 Pandas로 읽지 않고, 30행 중 4개 열(로트번호·공정명·온도_섭씨·합격여부)을 records라는 "딕셔너리의 리스트"로 옮겨 적어 쓴다. CSV를 코드로 읽는 방법은 4차시에 배운다.

가상 상황

여러 로트가 여러 공정을 거치며 남긴 온도 기록이다(2차시보다 행 수가 조금 더 많다).

행 하나의 의미

한 행 = 로트 하나가 공정 하나를 거친 기록 1건. 그래서 같은 로트번호가 다른 공정에서 한 번 더 나올 수 있다 (예: LOT-0186은 식각과 증착에서 각각 기록되었다).

열 설명

열 이름 쉬운 설명 데이터 형식 단위 예시 결측값 가능 여부
로트번호함께 이동하는 웨이퍼 묶음(상자)의 번호문자열-LOT-0049없음
공정명이 기록이 나온 작업 종류(산화·포토·식각·증착·세정)문자열-세정없음
설비번호작업한 기계의 번호문자열-EQ-02없음
온도_섭씨작업할 때 설비 안에서 잰 온도(교육용 가상 값)실수℃304.4없음
합격여부그 뒤 검사에서 나온 실제 결과정수-1(합격) / -1(불합격)없음

정상 범위 (교육용 예시)

온도 295~305℃. 1차시부터 쓰는 이 과정의 학습용 기준이며, 실제 공정의 기준이 아니다.

의도적으로 포함된 패턴

  • 30행 중 정상 범위(295~305℃)를 벗어나는 온도 값이 12건(높은 쪽 8건, 낮은 쪽 4건) 들어 있어, for+if로 하나씩 판정하며 걸러내는 실습량을 확보했다.
  • 합격여부는 온도만으로 정해진 값이 아니다. 합격 27건, 불합격 3건이고, 범위 밖 12건 중 9건은 합격이다. 그래서 온도 판정 함수(judge_pass)의 결과와 실제 검사 결과가 다르다. 3차시는 이 차이로 "규칙 하나로 합격·불합격이 다 설명되지 않는다"를 보여준다.

이번 차시 분석 질문

  • 내가 만든 판정 함수(judge_pass)로 걸러낸 불합격(범위 밖) 기록은 몇 건인가? → 12건
  • 그중 실제 검사(합격여부)에서 불합격(-1)한 기록은 몇 건인가? → 3건

실제 현업 데이터와 다른 점

완전한 가상 데이터다. 가상 데이터라 설비와 공정이 무작위로 짝지어져 있다. 실제 공장에서는 설비마다 맡는 공정이 정해져 있다. 온도 값은 공정 구분 없이 300℃ 근처로 만들어 실제 공정 조건과 다르다. 결측값은 아직 넣지 않았다(결측값 처리는 5차시 주제).
