# week02_python_basics_1.csv 데이터 설명서

## 목적
리스트와 딕셔너리를 처음 배울 때 참고할 소량의 예시 데이터다. 이 CSV는 Pandas로 읽지 않고,
강의 중 리스트/딕셔너리 리터럴로 직접 옮겨 적어 사용한다(Pandas는 4차시부터 배운다).

## 가상 상황
설비 여러 대에서 각각 측정한 온도 기록이다.

## 행 하나의 의미
한 행 = 특정 로트·설비의 온도 측정 기록 1건.

## 열 설명

| 열 이름 | 쉬운 설명 | 데이터 형식 | 단위 | 예시 | 결측값 가능 여부 |
| --- | --- | --- | --- | --- | --- |
| 로트번호 | 로트 식별 번호 | 문자열 | - | LOT-0012 | 없음 |
| 공정명 | 공정 종류 | 문자열 | - | 식각 | 없음 |
| 설비번호 | 공정 설비 | 문자열 | - | EQ-01 | 없음 |
| 온도_섭씨 | 챔버 온도 | 실수 | ℃ | 298.1 | 없음 |
| 합격여부 | 검사 결과 | 정수 | - | 1(합격) / -1(불합격) | 없음 |

## 정상 범위 (교육용 예시)
온도 295~305℃.

## 의도적으로 포함된 패턴
20행 중 정상범위(295~305℃)를 벗어나는 온도 값을 9건 포함해, 리스트에서 최댓값·최솟값을
찾는 실습(`max()`, `min()`) 소재로 쓴다. 결측값은 없다(2차시는 리스트/딕셔너리 문법에 집중).

## 이번 차시 분석 질문
- 이 리스트에서 가장 높은 온도와 가장 낮은 온도는 몇 번째 값인가?
- 온도 값들의 평균은 얼마인가?

## 실제 현업 데이터와 다른 점
완전한 가상 데이터이며, 리스트/딕셔너리 문법 연습을 위해 아주 작은 규모로 만들었다.
