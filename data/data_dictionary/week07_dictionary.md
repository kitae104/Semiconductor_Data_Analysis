# week07_yield_defect_analysis.csv 데이터 설명서

## 목적
수율/불량률 계산과 불량 유형 파레토 분석을 위한 로트·웨이퍼 단위 검사 데이터다.

## 가상 상황
60개 로트, 각 로트마다 6~8장의 웨이퍼가 검사를 거친 결과다.

## 행 하나의 의미
한 행 = 특정 로트의 특정 웨이퍼 1장에 대한 검사 결과 요약(검사수량/양품수량/불량수량/수율).

## 열 설명

| 열 이름 | 쉬운 설명 | 데이터 형식 | 단위 | 예시 | 결측값 가능 여부 |
| --- | --- | --- | --- | --- | --- |
| 로트번호 | 로트 식별 번호 | 문자열 | - | LOT-0053 | 없음 |
| 웨이퍼번호 | 로트 내 웨이퍼 순번 | 정수 | - | 3 | 없음 |
| 설비번호 | 공정 설비 | 문자열 | - | EQ-04 | 없음 |
| 공정명 | 공정 종류 | 문자열 | - | 식각 | 없음 |
| 검사수량 | 검사한 다이(die) 개수 | 정수 | 개 | 24 | 없음 |
| 양품수량 | 정상 판정된 개수 | 정수 | 개 | 20 | 없음 |

| 수율_pct | 웨이퍼 단위 수율 | 실수 | % | 83.3 | 없음 |

## 정상 범위 (교육용 예시)
정상 로트의 웨이퍼 수율은 대체로 88~99%.

## 의도적으로 포함된 패턴
60개 로트 중 5개 로트(`LOT-0053`, `LOT-0050`, `LOT-0006`, `LOT-0037`, `LOT-0029`)를
저수율(웨이퍼 평균 수율 55~78%)로 설계했고, 이 저수율 로트들은 모두 `EQ-04` 설비에서
생산되도록 구성했다. 불량유형은 8종(두께 불량, 파티클, 패턴 불량, 식각 과다, 식각 부족,
오염, 정렬 불량, 전기적 특성 불량) 중에서 무작위로 배정된다.

## 이번 차시 분석 질문
- 전체 수율과 설비별 수율은 얼마인가?
- 수율이 가장 낮은 로트 5개는 어떤 설비에서 나왔는가?
- 가장 자주 발생한 불량 유형은 무엇인가?(파레토 분석)

## 실제 현업 데이터와 다른 점
완전한 가상 데이터다. 저수율 로트와 설비의 연결은 "공통점 찾기" 학습을 위해 의도적으로 설계했다.
