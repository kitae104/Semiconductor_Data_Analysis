# week07_equipment_yield.csv 데이터 설명서

## 목적
`groupby`를 이용한 설비별·작업조별 비교와, 로트 단위 합격률·불량유형 파레토 분석을 하나의
데이터셋에서 함께 연습하는 실습용 데이터다(v1의 "설비 비교"와 "수율·불량 분석" 두 데이터를
병합·압축했다).

## 가상 상황
**공정 지도 위치**: 공정 지도 **②~⑤(산화·포토·식각·증착/이온주입) + 세정**의 설비 기록과 **⑦ EDS(전기 검사)** 뒤 최종 합격 여부다.

75개 로트, 로트마다 웨이퍼 4장씩 검사한 결과로 4대의 설비(EQ-01~EQ-04)와 3개 작업조
(A/B/C조)가 함께 기록된 300건의 웨이퍼 단위 검사 기록이다.

## 행 하나의 의미
한 행 = 특정 로트의 특정 웨이퍼 1장에 대한 공정 측정값과 검사 결과.

**이 기록의 단순화**: 실제 웨이퍼는 ②~⑥ 공정을 모두(여러 번) 거치지만, 이 기록은 로트마다 설비 하나·공정 하나만 적어 둔 교육용 단순화다(실측: 로트마다 설비·공정·작업조가 하나씩). 설비 4대가 여러 공정 기록을 함께 남겼다(교육용 가상 기록). 그래서 공정 차이와 설비 차이(그리고 로트 차이)를 숫자로 떼어 볼 수 없다.

## 불량 유형 쉬운 뜻
| 불량 유형 | 쉬운 뜻 |
| --- | --- |
| 두께 불량 | 쌓은 막이 정해진 두께보다 너무 두껍거나 얇다 |
| 패턴 불량 | 새긴 회로 무늬의 모양이 틀어졌다 |
| 파티클 | 공정 중 들어온 아주 작은 이물 알갱이가 붙었다 |
| 오염 | 있으면 안 되는 물질이 표면에 묻었다 |
| 정렬 불량 | 위아래 층의 무늬 위치가 서로 어긋났다 |
| 식각 부족 | 깎아내야 할 부분이 덜 깎였다 |
| 식각 과다 | 필요한 것보다 더 깎였다(이번 데이터에는 나오지 않음) |
| 전기적 특성 불량 | 전기를 흘려 검사했더니 기준을 벗어났다 |

불량 유형 7종 중 6종(두께·패턴·파티클·오염·정렬·식각 부족)은 공정 중간의 두께 측정·표면 검사에서 찾는 물리적 불량이고, 전기적 특성 불량만 전기 검사(⑦ EDS)에서 찾는다. 이 열은 둘을 한 열에 모아 둔 교육용 설정이다.
불량 유형은 검사에서 발견된 불량의 종류일 뿐이다. 그 행의 `공정명`(예: 증착)에서 그 불량이 생겼다는 뜻은 아니다.

## 수업에서 새로 만드는 열
- `불합격` — "반도체 데이터로 확인하기"(노트북 4단계) 코드 `df["불합격"] = df["합격여부"] == -1`로 만드는 True/False 열.
  작업조별 불합격률과 로트별 불합격 비율에 쓴다.
- `합격` — 수업 코드 `df["합격"] = df["합격여부"] == 1`로 만드는 True/False 열이다(CSV에는 없다).
  `합격여부`가 1/-1이라 바로 평균을 내면 합격률이 되지 않으므로, True(1)/False(0) 열을 만들어 `sum()`은 합격 장수,
  `mean()`은 합격 비율로 쓴다.
- 이 과정에서는 웨이퍼 1장 = 검사 1건으로 단순화했다. 웨이퍼를 설비별·로트별로 센 비율은 모두 "합격률"이라
  부르고 수율 대신 쓴다(실제 공장의 수율은 웨이퍼 안의 다이 단위로 세는 경우가 많다 — 다이를 센 PART 2 워밍업만 수율이라 부른다).

## 연습용 기준 (교육용 예시, 실제 공정 규격 아님)
온도 295~305℃, 진공도 4.5~5.5 mTorr. 압력은 절대값을 해석하지 않으므로 기준을 두지 않는다(아래 절).

## 압력_Pa 값의 한계 (교육용 가상 데이터)

`압력_Pa`는 교육용으로 생성한 가상 값이며 실제 측정값이 아니다. 이번 차시의 실측 범위는 약
992.2~1,040.7 Pa(평균 약 1,013.6 Pa)인데, 이 자릿수는 Pa로 읽은 챔버 압력보다 hPa로 읽었을
때의 자릿수에 가깝다(대기압이 약 1,013 hPa = 101,325 Pa다). **단위 라벨과 값의 자릿수가 서로
맞지 않는다.** 같은 행의 `진공도_mTorr`와도 맞지 않는다. 진공도 평균 약 5.00 mTorr는 약 0.67
Pa인데(1 mTorr ≈ 0.133 Pa) 같은 행의 `압력_Pa`는 평균 약 1,013.6 Pa여서 약 1,520배 차이가 난다
— 한 챔버가 같은 시각에 두 압력일 수는 없다. 이 값이 실제로 어떤 공정 조건을 나타내는지는
단정할 수 없으므로, 실습에서는 `압력_Pa`의 절대값을 물리적으로 해석하지 않고 **수치 열
하나**로만 다룬다.

**학생이 물어보면**: "교육용으로 만든 가상 값이라 단위와 자릿수가 실제 공정과 맞지 않습니다.
이번 실습에서는 압력의 절대값을 해석하지 않고 값들 사이의 상대적인 차이만 봅니다"라고 답한다.

데이터를 다시 만들면 1~10차시의 실습 결과 수치와 강의 자료가 모두 함께 바뀌므로, 현재 버전은
값을 그대로 두고 이 한계를 여기에 명시하는 쪽을 택했다.

## 의도적으로 포함된 패턴
- 생성기가 **강제하는 것은 5개 로트뿐**이다(`scripts/generate_weekly_data.py:249`, 시드 107로
  고정). 이 5개는 EQ-04에 배정하고 웨이퍼 4장 중 2장을 강제 불합격시켜 로트 합격률 80% 미만을
  보장한다. 나머지 로트의 불합격은 설비별 `fail_prob`(EQ-01 0.05 / EQ-02 0.10 /
  EQ-03 0.08 / EQ-04 0.20)에서 나오는 난수 결과다.
- **실제 생성 결과**(시드 고정이므로 항상 동일): 로트 합격률 80% 미만 로트는 21개이고
  EQ-04 11개, EQ-03 5개, EQ-02 4개, EQ-01 1개로 나뉜다. EQ-04는 전체 22개 로트 중
  11개만 합격률이 낮고 나머지 11개는 100%다 — 설비 전체가 아니라 일부 로트가 문제였다는 것을
  발견하는 장치다.
- 로트당 웨이퍼가 4장이므로 로트 합격률은 0·25·50·75·100% 다섯 값만 가질 수 있다.
  그래서 **동점 로트가 많다** — 합격률 50%인 로트만 6개다. "합격률 하위 N개"처럼 순위로
  문제를 내면 동점 처리 방식(정렬 알고리즘)에 따라 답이 달라지므로, 이 데이터에서는
  **임계값 기준**으로 묻는다(강의 코드: `(lot_fail > 20).sum()` — 불합격 비율 20% 초과 = 합격률 80% 미만).
- 불량유형 후보는 8종(두께 불량, 파티클, 패턴 불량, 식각 과다, 식각 부족, 오염, 정렬 불량, 전기적
  특성 불량)이며, 이번 데이터에는 식각 과다를 제외한 7종이 실제로 나타난다. 그중 EQ-04에서는 두께 불량·파티클·패턴 불량이 더 자주 나오도록 편향 배치했다.
  실제 상위 3개 불량유형(두께 불량 11건, 패턴 불량 6건, 파티클 5건)이 전체 불량(36건)의
  약 61.1%를 차지한다.

## 7차시 수업에서 쓰는 값(노트북·Orange 실제 출력)
- "반도체 데이터로 확인하기"(노트북 4단계): `(300, 11)` / 작업조별 불합격률 A조 9.8 · B조 15.5 · C조 9.7 /
  로트별 불합격 비율이 20%를 넘는 로트 **21개**(= 로트 합격률 80% 미만, 웨이퍼 4장 중 1장 이상 불합격).
- 반도체 데이터 실습(노트북 5단계 = 실습지 문제 1~3): 전체 합격률 **88.0** / 설비별 합격률 EQ-01 98.1 · EQ-02 86.5 · EQ-03 91.1 · **EQ-04 75.0** /
  불량 유형 1위 **두께 불량 11건**(패턴 불량 6 · 파티클 5 · 오염 5 · 정렬 불량 4 · 식각 부족 4 · 전기적 특성 불량 1).
- `합격여부`(1/-1)를 그대로 평균 내면 0.76이 나온다(합격률이 아니다 — 1과 -1이 서로 지워진 값).
- Orange Pivot Table(`_2_yield_done.ows`, Rows 설비번호 · Columns 합격여부 · Count) 실측:
  EQ-01 102 / 2 · EQ-02 45 / 7 · EQ-03 51 / 5 · **EQ-04 66 / 22** · Total 264 / 36(합격 / 불합격, 웨이퍼 장수). EQ-04 66 ÷ 88 = 75.0%.
  같은 창에서 Rows만 `불량유형`으로 바꾸면(실습지 문제 4 ③, `불량유형`은 meta인데도 Rows 목록에 나온다): 두께 불량 0 / 11 / 11 · 식각 부족 0 / 4 / 4 ·
  오염 0 / 5 / 5 · 전기적 특성 불량 0 / 1 / 1 · 정렬 불량 0 / 4 / 4 · 파티클 0 / 5 / 5 · 패턴 불량 0 / 6 / 6 · Total 0 / 36 / 36(1 / -1 / Total, 가나다순).
  합격 웨이퍼는 불량유형이 빈칸이라 표에서 빠진다(Total 36).

## 이번 차시 분석 질문
- 전체 합격률(88.0%)과 설비별 합격률(EQ-01 98.1% ~ EQ-04 75.0%)은 어떻게 다른가?
- 가장 자주 발생한 불량 유형은 무엇인가?(많은 순으로 줄 세우기, 파레토)

## 생활 예제 데이터 — week07_easy_quiz_results.csv

### 목적
반도체 데이터(`week07_equipment_yield.csv`)로 설비별 합격률과 로트별 합격률을 구하기 전에, 반별 쪽지시험 기록으로
**같은 모양의 `groupby` 계산**(개수·합·평균, 그룹별 비율, 낮은 그룹 열어 보기, 파레토 `value_counts`)을 먼저 익히는
**생활 예제용 가상 데이터**다. 강의·노트북은 파이썬 개념을 이 데이터(쉬운 예제)로 설명하고, 반도체 데이터는 강의 "반도체 데이터로 확인하기"와
실습지·노트북 뒷부분(4~5단계)에서 같은 모양의 코드로 다룬다. 강의의 groupby 개념도(반별로 모아 정답 비율 계산)도 이 데이터의 실제 값이다.
수업 코드에서는 반도체 표 `df`와 섞이지 않도록 이 표의 이름을 `quiz`로 쓴다.

### 가상 상황
세 반(A반·B반·C반)에서 두 명씩, 모두 6명이 4문항짜리 쪽지시험을 봤다. 문항마다 맞았는지, 틀렸다면 왜 틀렸는지를 적었다.

### 행 하나의 의미
한 행 = 학생 1명이 푼 문항 1개. 학생 1명 = 4행(반도체 데이터에서 로트 1개 = 웨이퍼 4장과 같은 모양).

### 수업에서 새로 만드는 열
- `정답` — `quiz["정답"] = quiz["정답여부"] == 1`로 만드는 True/False 열(CSV에는 없다). 반도체 수업의
  `df["합격"] = df["합격여부"] == 1`과 같은 모양이다. `sum()`은 맞힌 문항 수, `mean() * 100`은 정답률(%)이 된다.

### 의도적으로 포함된 패턴(실제 값)
- 크기 24행 x 6열(3반 x 2명 x 4문항). 전체 24문항 중 18문항 정답, 전체 정답률 75.0%.
- **반별 정답률**(`groupby("반")["정답"]`): 문항 수(count) 각 8 / 정답 수(sum) A반 7, B반 5, C반 6 /
  정답률 A반 87.5%, B반 62.5%, C반 75.0%.
- 반별 평균 풀이시간(`groupby("반")["풀이시간_sec"].mean()`, v3 수업에서는 쓰지 않음): A반 61.2초, B반 76.9초, C반 67.8초.
- **학생별 정답률**(로트 합격률과 같은 계산): 지민 100.0, 서준 100.0, 하은 75.0, 도윤 75.0, 시우 75.0, 예린 25.0.
  80% 미만 4명, 최저는 예린 25.0% 하나뿐이다. 학생 한 명이 4문항이라 정답률은 0·25·50·75·100% 다섯 값만 나온다
  (반도체 로트 합격률과 같다).
- **B반을 따로 떼어 보면**: 서준 100.0%, 예린 25.0%. B반 전체가 아니라 한 학생이 낮았다.
  반도체 7차시의 "EQ-04 전체가 아니라 일부 로트가 문제였다"와 같은 발견 장치다.
- 예린의 문항 기록: 1번 문제 잘못 읽음(85초), 2번 계산 실수(110초), 3번 정답(95초), 4번 개념 부족(120초).
- **오답유형 파레토**(`quiz[quiz["정답여부"] == -1]["오답유형"].value_counts()`): 계산 실수 3, 문제 잘못 읽음 2, 개념 부족 1
  (비율 50.0%·33.3%·16.7%).

### 반도체 데이터와 짝이 되는 연산

| 생활 예제 | 반도체(week07_equipment_yield.csv) |

### 실제 데이터와 다른 점

## Orange 워밍업 데이터 — week07_orange_wafer_lots.csv

### 목적
7차시 PART 2 Orange 워밍업용 데이터다. Pivot Table(피벗 표)로 설비별 합격·불합격 다이 수를 세어 수율이 낮은 설비를 찾고,
Select Rows로 그 설비의 웨이퍼만 골라 Scatter Plot으로 웨이퍼 맵을 그려 **불량 위치라는 단서**를 하나 더 본다.
Orange에서는 `orange/week07_orange_wafer_lots.tab`을 연다.

### 가상 상황
**공정 지도 위치**: 공정 지도 **④ 식각** 설비 3대(식각-1·식각-2·식각-3)를 거친 웨이퍼 12장의 **⑦ EDS(전기 검사)** 결과다.
설비 이름은 반도체 데이터의 EQ-0N과 헷갈리지 않게 따로 지었다.

### 행 하나의 의미
한 행 = 웨이퍼 한 장 위 다이 1개의 검사 결과(12장 × 317다이 = 3,804행). 이 가상 웨이퍼 한 장의 다이 317개는 교육용 가상 격자다 — 실제 다이 수는 칩 크기에 따라 다르다.
