1차시 실습 데이터 설명서

대상 파일: week01_semiconductor_process_overview.csv

목적

반도체 공정 데이터를 처음 관찰하는 1차시 실습용 데이터다. 어렵게 생각하지 말고 "공장에서 하루 동안 있었던 일을 적은 표"라고 생각하면 된다.

가상 상황

가상의 반도체 공장(FAB)에서 여러 설비(EQ-01~EQ-04)가 웨이퍼를 가공하며 남긴 기록이다.

공정 지도 위치공정 지도 ②~⑤(산화·포토·식각·증착/이온주입) + 세정의 설비 기록이다. 공정 지도는 1차시 그림 week01_process_flow.png의 ①~⑧ 번호를 말한다(세정은 단계 사이마다 하는 작업이라 번호가 없다).

행 하나의 의미

한 행 = 특정 시각에 특정 설비가 특정 웨이퍼를 특정 공정으로 처리한 뒤 남긴 기록 1건.

열 설명

열 이름 쉬운 설명 데이터 형식 단위 예시 결측값 가능 여부
측정시간기록이 저장된 시각문자열(날짜시간)-2024-03-01 08:00없음
로트번호웨이퍼 묶음(로트) 식별 번호문자열-LOT-0398없음
웨이퍼번호로트 안에서 웨이퍼 순번정수-4없음

설비번호공정을 수행한 설비문자열-EQ-03없음

단위 읽는 법

열 이름 끝의 _C, _Pa처럼 밑줄(_) 뒤는 그 열 숫자의 단위다. 처음 보는 단위는 아래처럼 읽는다.

표기 읽는 법 뜻
C (온도_C)섭씨 몇 도(℃). Celsius(섭씨)의 첫 글자온도 단위. 얼음이 어는 물 0℃, 끓는 물 100℃ 기준
Pa (압력_Pa)파스칼압력 단위. 넓이를 누르는 힘의 세기. 숫자가 클수록 세게 누른다

정상 범위 (교육용 예시)

온도 295~305℃, 압력 995~1025 Pa. 실제 공정의 절대 기준이 아니라 이 과정에서 사용하는 학습용 기준이다.

온도_C 값의 한계 (교육용 가상 데이터)

온도_C는 공정 종류와 관계없이 약 300℃ 근처(293.6~305.5℃)로 만든 가상 값이다. 실제 공장에서는 작업마다 온도가 크게 다르다(예: 포토는 실내 온도 근처, 산화는 수백~천 도 이상). 실습에서는 온도의 절대값을 실제 공정 조건으로 해석하지 않고, 기록끼리 비교하는 수치 열 하나로만 다룬다.

압력_Pa 값의 한계 (교육용 가상 데이터)

압력_Pa는 교육용으로 생성한 가상 값이며 실제 측정값이 아니다. 이번 차시의 실측 범위는 약 993.1~1,027.8 Pa(평균 약 1,009.1 Pa)인데, 이 자릿수는 Pa로 읽은 챔버 압력보다 hPa로 읽었을 때의 자릿수에 가깝다(대기압이 약 1,013 hPa = 101,325 Pa다). 단위 라벨과 값의 자릿수가 서로 맞지 않는다. 이 값이 실제로 어떤 공정 조건을 나타내는지는 단정할 수 없으므로, 실습에서는 압력_Pa의 절대값을 물리적으로 해석하지 않고 수치 열 하나로만 다룬다.

학생이 물어보면"교육용으로 만든 가상 값이라 단위와 자릿수가 실제 공정과 맞지 않습니다. 이번 실습에서는 압력의 절대값을 해석하지 않고 값들 사이의 상대적인 차이만 봅니다"라고 답한다.

데이터를 다시 만들면 1~10차시의 실습 결과 수치와 강의 자료가 모두 함께 바뀌므로, 현재 버전은 값을 그대로 두고 이 한계를 여기에 명시하는 쪽을 택했다.

의도적으로 포함된 패턴

1차시는 "관찰"이 목표이므로 결측값이나 극단적 이상값을 넣지 않았다. 합격 확률 85%로 생성해 현실적인 비율만 반영했다(실제 생성 결과: 합격 32건 80% / 불합격 8건 20%).

실제 생성 결과(강의 PART 2 Orange Distributions "Split by 공정명"과 실습지 문제 1~4 "설비 EQ-03 / Split by 설비번호"에서 쓰는 값):

  • 공정명별 기록/불합격: 세정 10/5, 포토 9/2, 산화 6/1, 증착 8/0, 식각 7/0.
  • 설비번호별 기록/불합격: EQ-01 13/2, EQ-02 9/1, EQ-03 12/3, EQ-04 6/2(EQ-03 불합격률 25.0%).
  • 학습용 정상 온도 범위(295~305℃) 밖 2건(305.5℃ 불합격, 293.6℃ 합격). 불합격 8건 중 7건은 범위 안.
  • 합격여부는 공정·온도와 무관하게 무작위로 만들었다. "세정에 불합격이 몰린 것"은 우연이므로 강의에서도 "원인"이 아니라 "원인 후보"로만 다룬다.

실제 현업 데이터와 다른 점

완전한 가상 데이터이며 실제 반도체 기업의 생산 데이터가 아니다. 설비와 공정도 무작위로 짝지어져 있어 설비 한 대가 여러 공정에 등장한다(실제 공장에서는 설비마다 맡는 공정이 정해져 있다). 열 이름과 값의 범위는 첨부된 반도체_공정_샘플.csv의 구조를 참고해 교육 목적으로 재구성했다.

Orange 워밍업 데이터 — week01_orange_town_population.csv

목적

Orange3 캔버스를 처음 만나는 1차시 PART 2 워밍업용 데이터다. 반도체 데이터를 열기 전에, 누구나 아는 "우리 동네" 표로 File → Data Table(행·열 세기) → Distributions(가장 흔한 값 찾기)를 먼저 해 본다. Orange에서는 같은 이름의 orange/week01_orange_town_population.tab을 연다.

가상 상황

가상의 도시에 있는 5개 구(햇살구·바람구·강변구·숲속구·새빛구), 구마다 6개 동의 인구 기록이다. 구·동 이름과 숫자는 모두 지어낸 것이며 실제 지역 통계가 아니다.

행 하나의 의미

한 행 = 동 하나(30개 동).

열 설명

열 이름 쉬운 설명 데이터 형식 단위 예시 결측값 가능 여부
구동이 속한 구(5개)문자열(범주)-햇살구없음
동동 이름(30개, 모두 다름). Orange에서는 표에만 보이는 이름 열(meta)문자열-햇살1동없음
인구_count그 동에 사는 사람 수정수명(count)29903없음
면적_km2동의 넓이실수km²(제곱킬로미터)4.7없음
주요연령대그 동에서 가장 많은 나이대문자열(범주)-40~50대없음

단위 읽는 법

표기 읽는 법 뜻
count (인구_count)개수(명)세어서 나온 수
km2 (면적_km2)제곱킬로미터가로 1km × 세로 1km 넓이가 1km²

의도적으로 포함된 패턴(실제 생성 결과)

  • 30행 × 5열. 인구 8,646~43,066명(평균 약 26,499명), 면적 0.8~6.3km².
  • 주요연령대 개수를 고정했다: 40~50대 12 · 20~30대 9 · 60대이상 6 · 10대이하 3. Distributions에서 가장 높은 막대는 40~50대(12)다.
  • 새빛구(새로 지은 아파트가 많은 동네라는 설정)는 6개 동 중 5개 동이 20~30대다. 다른 4개 구는 20~30대가 1개 동씩이다. Distributions의 Split by에서 구를 고르면 새빛구만 20~30대가 많다.
