1차시 실습 데이터 설명서

대상 파일: week01_semiconductor_process_overview.csv

목적

반도체 공정 데이터를 처음 관찰하는 1차시 실습용 데이터다. 어렵게 생각하지 말고 "공장에서 하루 동안 있었던 일을 적은 표"라고 생각하면 된다.

가상 상황

가상의 반도체 공장(FAB)에서 여러 설비(EQ-01~EQ-04)가 웨이퍼를 가공하며 남긴 기록이다.

행 하나의 의미

한 행 = 특정 시각에 특정 설비가 특정 웨이퍼를 특정 공정으로 처리한 뒤 남긴 기록 1건.

정상 범위 (교육용 예시)

온도 295~305℃, 압력 995~1025 Pa. 실제 공정의 절대 기준이 아니라 이 과정에서 사용하는 학습용 기준이다.

온도_섭씨 값의 한계 (교육용 가상 데이터)

온도_섭씨는 공정 종류와 관계없이 약 300℃ 근처(293.6~305.5℃)로 만든 가상 값이다. 실제 공장에서는 작업마다 온도가 크게 다르다(예: 포토는 실내 온도 근처, 산화는 수백~천 도 이상). 실습에서는 온도의 절대값을 실제 공정 조건으로 해석하지 않고, 기록끼리 비교하는 수치 열 하나로만 다룬다.

압력_Pa 값의 한계 (교육용 가상 데이터)

압력_Pa는 교육용으로 생성한 가상 값이며 실제 측정값이 아니다. 이번 차시의 실측 범위는 약 993.1~1,027.8 Pa(평균 약 1,009.1 Pa)인데, 이 자릿수는 Pa로 읽은 챔버 압력보다 hPa로 읽었을 때의 자릿수에 가깝다(대기압이 약 1,013 hPa = 101,325 Pa다). 단위 라벨과 값의 자릿수가 서로 맞지 않는다. 이 값이 실제로 어떤 공정 조건을 나타내는지는 단정할 수 없으므로, 실습에서는 압력_Pa의 절대값을 물리적으로 해석하지 않고 수치 열 하나로만 다룬다.

학생이 물어보면"교육용으로 만든 가상 값이라 단위와 자릿수가 실제 공정과 맞지 않습니다. 이번 실습에서는 압력의 절대값을 해석하지 않고 값들 사이의 상대적인 차이만 봅니다"라고 답한다.

데이터를 다시 만들면 1~10차시의 실습 결과 수치와 강의 자료가 모두 함께 바뀌므로, 현재 버전은 값을 그대로 두고 이 한계를 여기에 명시하는 쪽을 택했다.

의도적으로 포함된 패턴

1차시는 "관찰"이 목표이므로 결측값이나 극단적 이상값을 넣지 않았다. 합격 확률 85%로 생성해 현실적인 비율만 반영했다(실제 생성 결과: 합격 32건 80% / 불합격 8건 20%).

이번 차시 분석 질문

  • 데이터에는 몇 개의 행과 열이 있는가?
  • 합격과 불합격은 각각 몇 건인가?
  • 어떤 설비들이 등장하는가?

실제 현업 데이터와 다른 점

완전한 가상 데이터이며 실제 반도체 기업의 생산 데이터가 아니다. 설비와 공정도 무작위로 짝지어져 있어 설비 한 대가 여러 공정에 등장한다(실제 공장에서는 설비마다 맡는 공정이 정해져 있다). 열 이름과 값의 범위는 첨부된 반도체_공정_샘플.csv의 구조를 참고해 교육 목적으로 재구성했다.
