4차시 실습 데이터 설명서

대상 파일: week04_process_filtering.csv

목적

Pandas로 CSV를 읽고, 열을 선택하고, 조건에 맞는 행을 찾고, 정렬하는 실습용 데이터다.

가상 상황

공정 지도 위치공정 지도 ②~⑤(산화·포토·식각·증착/이온주입) + 세정 공정 중 설비 기록이다. 세정은 공정 지도의 한 단계가 아니라 단계 사이마다 하는 씻기다. 설비 4대가 여러 공정 기록을 함께 남겼다(교육용 가상 기록).

여러 설비에서 진행된 100건의 공정 기록이다.

행 하나의 의미

한 행 = 특정 설비·공정에서 이뤄진 1건의 공정 기록.

연습용 기준 (교육용 예시, 실제 공정 규격 아님)

온도 295~305℃, 압력 995~1025 Pa(절대값 해석 안 함), 가스유량 47~53 slm.

압력_Pa 값의 한계 (교육용 가상 데이터)

압력_Pa는 교육용으로 생성한 가상 값이며 실제 측정값이 아니다. 이번 차시의 실측 범위는 약 995.1~1,033.0 Pa(평균 약 1,012.2 Pa)인데, 이 자릿수는 Pa로 읽은 챔버 압력보다 hPa로 읽었을 때의 자릿수에 가깝다(대기압이 약 1,013 hPa = 101,325 Pa다). 단위 라벨과 값의 자릿수가 서로 맞지 않는다. 이 값이 실제로 어떤 공정 조건을 나타내는지는 단정할 수 없으므로, 실습에서는 압력_Pa의 절대값을 물리적으로 해석하지 않고 수치 열 하나로만 다룬다.

학생이 물어보면"교육용으로 만든 가상 값이라 단위와 자릿수가 실제 공정과 맞지 않습니다. 이번 실습에서는 압력의 절대값을 해석하지 않고 값들 사이의 상대적인 차이만 봅니다"라고 답한다.

데이터를 다시 만들면 1~10차시의 실습 결과 수치와 강의 자료가 모두 함께 바뀌므로, 현재 버전은 값을 그대로 두고 이 한계를 여기에 명시하는 쪽을 택했다.

의도적으로 포함된 패턴

EQ-02 설비에 불합격이 상대적으로 몰리도록 설계했다(실제 생성 결과: EQ-02 25건 중 5건 불합격, 약 20.0%). 조건 검색(df[df['설비번호']=='EQ-02'])으로 학습자가 이 사실을 직접 "발견"하도록 만든 장치다.

다만 실제 생성 결과에서 불합격 비율 1위는 EQ-04(22건 중 5건, 약 22.7%)다. 건수는 EQ-02와 같고 비율은 EQ-04가 높다(EQ-01 31건 중 2건 6.5%, EQ-03 22건 중 1건 4.5%). "어느 설비의 불합격 비율이 가장 높은가"를 묻는 과제에서는 두 답이 모두 성립하므로, 강사는 세는 기준(건수 vs 비율)을 함께 짚는다.

  • 온도가 가장 높았던 상위 5건은 어떤 조건인가? → 310.1~308.2℃, 그중 불합격은 1건

4차시 수업에서 쓰는 값(노트북·Orange 실제 출력)

  • "반도체 데이터로 확인하기"(노트북 7단계): df.shape → (100, 8), EQ-01 31건 중 불합격 2건, 전체 불합격률 13.0.
  • 반도체 데이터 실습(노트북 8단계 = 실습지 문제 1~3): 세 열 고르기 (100, 3) / EQ-02 25건 → 불합격 5건 → 20.0% / 온도 상위 5건 310.1 · 308.6 · 308.4 · 308.4 · 308.2(그중 불합격 1건, LOT-0192). 308.4가 두 건이라 두 행의 순서는 pandas 버전에 따라 바뀔 수 있다.
  • Orange 실측(_2_filtering_done.ows): File 100행 → Select Columns(설비번호·온도_C + Target 합격여부) → Select Rows 설비번호 is EQ-02 25행, 합격여부 is -1을 더하면 5행(온도 307.8 · 304.9 · 301.4 · 299.3 · 296.9).

실제 현업 데이터와 다른 점

완전한 가상 데이터다. 결측값은 아직 넣지 않았다(결측값 처리는 5차시 주제). 가상 데이터라 설비와 공정이 무작위로 짝지어져 있다. 실제 공장에서는 설비마다 맡는 공정이 정해져 있다.

생활 예제 데이터 — week04_easy_cafe_orders.csv

목적

반도체 데이터(week04_process_filtering.csv)에 쓰기 전에, 누구나 아는 카페 주문 기록으로 같은 Pandas 연산 (read_csv, shape·columns, 열 선택, 조건 검색, 한 번 더 고르기, 정렬)을 먼저 익히는 생활 예제용 가상 데이터다. 읽는 코드도 반도체 데이터와 같은 모양이다: pd.read_csv("../../data/weekly/week04/week04_easy_cafe_orders.csv", encoding="utf-8-sig").

가상 상황

  • 크기 12행 x 7열. 종류별 기록: 커피 5건, 차 3건, 디저트 4건.
  • 디저트에 "별로예요"가 몰린다: 커피 5건 중 1건(20.0%), 차 3건 중 1건(33.3%), 디저트 4건 중 2건(50.0%). 반도체 4차시의 "EQ-02에 불합격이 몰린다"와 같은 장치다. 매장별로는 강남점 6건 중 2건, 홍대점 6건 중 2건으로 같다.
  • 가격 5000원 초과 5건, 별로예요 4건, 둘 다 해당 3건(치즈케이크·바닐라라테·초코케이크). "비싼 주문과 별로예요 주문은 같은 기록일까"를 반도체의 "고온 기록과 불합격 기록"처럼 확인한다.
  • 가격 상위 5건(sort_values("가격_KRW", ascending=False).head(5)): 초코케이크 6800, 치즈케이크 6500, 바닐라라테 5500, 카페모카 5500, 유자차 5200.
  • 결측값·중복은 없다(5차시 주제).

Orange 워밍업 데이터 — week04_orange_process_flow.csv

목적

4차시 PART 2 Orange 워밍업용 데이터다. 1차시에 그림으로 본 공정 지도(반도체 8대 공정)를 표로 열어, Select Columns(열 고르기)와 Select Rows(행 고르기)로 "층마다 되풀이되는 공정"만 골라 본다. 1차시 그림 week01_process_flow.png의 원천 데이터다. Orange에서는 orange/week04_orange_process_flow.tab을 연다.

가상 상황

공정 지도 위치공정 지도 전체(①~⑧)를 표로 만든 것이다. 한 행이 공정 지도의 한 단계다. 반도체 공정을 처음 배우는 사람을 위해 단계마다 하는 일과 생활 비유(피자)를 한 줄씩 적어 둔 교육용 정리표다.

행 하나의 의미

한 행 = 반도체 8대 공정 중 한 단계(8행).

열 설명

열 이름 쉬운 설명 데이터 형식 단위 예시 결측값 가능 여부

  • 8행, 반복여부 = 여러 번은 5행(②산화 · ③포토 · ④식각 · ⑤증착/이온주입 · ⑥금속 배선).
  • 세정은 이 흐름표의 단계가 아니다. 오늘 반도체 데이터(week04_process_filtering.csv)의 공정명 다섯 가지(산화·포토·식각·증착·세정) 중 산화·포토·식각·증착은 이 표의 ②~⑤에 해당하고, 세정은 단계 사이마다 하는 씻기다.

이번 차시 분석 질문

  • 8대 공정 중 층마다 되풀이되는 단계는 몇 개이고 무엇인가? → 5개(②~⑥). 그래서 같은 공정 기록이 수없이 쌓인다.

실제 데이터와 다른 점
