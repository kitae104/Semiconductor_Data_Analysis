7차시 실습 데이터 설명서

대상 파일: week07_equipment_yield.csv

목적

groupby를 이용한 설비별·작업조별 비교와, 로트 단위 수율·불량유형 파레토 분석을 하나의 데이터셋에서 함께 연습하는 실습용 데이터다(v1의 "설비 비교"와 "수율·불량 분석" 두 데이터를 병합·압축했다).

가상 상황

75개 로트, 로트마다 웨이퍼 4장씩 검사한 결과로 4대의 설비(EQ-01~EQ-04)와 3개 작업조 (A/B/C조)가 함께 기록된 300건의 웨이퍼 단위 검사 기록이다.

행 하나의 의미

한 행 = 특정 로트의 특정 웨이퍼 1장에 대한 공정 측정값과 검사 결과.

수업에서 새로 만드는 열

  • 합격 — 수업 코드 df["합격"] = df["합격여부"] == 1로 만드는 True/False 열이다(CSV에는 없다). 합격여부가 1/-1이라 바로 평균을 내면 합격률이 되지 않으므로, True(1)/False(0) 열을 만들어 sum()은 합격 장수, mean()은 합격 비율로 쓴다.
  • 이 과정에서는 웨이퍼 1장 = 검사 1건으로 단순화했다. 웨이퍼를 설비별로 센 비율은 "합격률", 로트별로 센 비율은 "로트 수율"이라고 부른다(실제 공장의 수율은 웨이퍼 안의 칩 단위로 세는 경우가 많다).

정상 범위 (교육용 예시)

온도 295~305℃, 압력 995~1025 Pa, 진공도 4.5~5.5 mTorr.

압력_Pa 값의 한계 (교육용 가상 데이터)

압력_Pa는 교육용으로 생성한 가상 값이며 실제 측정값이 아니다. 이번 차시의 실측 범위는 약 992.2~1,040.7 Pa(평균 약 1,013.6 Pa)인데, 이 자릿수는 Pa로 읽은 챔버 압력보다 hPa로 읽었을 때의 자릿수에 가깝다(대기압이 약 1,013 hPa = 101,325 Pa다). 단위 라벨과 값의 자릿수가 서로 맞지 않는다. 같은 행의 진공도_mTorr와도 맞지 않는다. 진공도 평균 약 5.00 mTorr는 약 0.67 Pa인데(1 mTorr ≈ 0.133 Pa) 같은 행의 압력_Pa는 평균 약 1,013.6 Pa여서 약 1,520배 차이가 난다 — 한 챔버가 같은 시각에 두 압력일 수는 없다. 이 값이 실제로 어떤 공정 조건을 나타내는지는 단정할 수 없으므로, 실습에서는 압력_Pa의 절대값을 물리적으로 해석하지 않고 수치 열 하나로만 다룬다.

학생이 물어보면"교육용으로 만든 가상 값이라 단위와 자릿수가 실제 공정과 맞지 않습니다. 이번 실습에서는 압력의 절대값을 해석하지 않고 값들 사이의 상대적인 차이만 봅니다"라고 답한다.

데이터를 다시 만들면 1~10차시의 실습 결과 수치와 강의 자료가 모두 함께 바뀌므로, 현재 버전은 값을 그대로 두고 이 한계를 여기에 명시하는 쪽을 택했다.

의도적으로 포함된 패턴

  • 생성기가 강제하는 것은 5개 로트뿐이다(scripts/generate_weekly_data.py:249, 시드 107로 고정). 이 5개는 EQ-04에 배정하고 웨이퍼 4장 중 2장을 강제 불합격시켜 수율 80% 미만을 보장한다. 나머지 로트의 불합격은 설비별 fail_prob(EQ-01 0.05 / EQ-02 0.10 / EQ-03 0.08 / EQ-04 0.20)에서 나오는 난수 결과다.
  • 실제 생성 결과(시드 고정이므로 항상 동일): 저수율(80% 미만) 로트는 21개이고 EQ-04 11개, EQ-03 5개, EQ-02 4개, EQ-01 1개로 나뉜다. EQ-04는 전체 22개 로트 중 11개만 저조하고 나머지 11개는 100%다 — 설비 전체가 아니라 일부 로트가 문제였다는 것을 발견하는 장치다.
  • 로트당 웨이퍼가 4장이므로 로트 수율은 0·25·50·75·100% 다섯 값만 가질 수 있다. 그래서 동점 로트가 많다 — 수율 50%인 로트만 6개다. "수율 하위 N개"처럼 순위로 문제를 내면 동점 처리 방식(정렬 알고리즘)에 따라 답이 달라지므로, 이 데이터에서는 "로트 수율 80% 미만" 같은 임계값 기준으로 묻는다(강의 코드: (lot_yield < 80).sum()). 최저 수율 로트는 0%인 LOT-0008 하나뿐이라 sort_values().head(1)로 찾아도 답이 하나로 정해진다.
  • 불량유형 후보는 8종(두께 불량, 파티클, 패턴 불량, 식각 과다, 식각 부족, 오염, 정렬 불량, 전기적 특성 불량)이며, 이번 데이터에는 식각 과다를 제외한 7종이 실제로 나타난다. 그중 EQ-04에서는 두께 불량·파티클·패턴 불량이 더 자주 나오도록 편향 배치했다. 실제 상위 3개 불량유형(두께 불량 11건, 패턴 불량 6건, 파티클 5건)이 전체 불량(36건)의 약 61.1%를 차지한다.

이번 차시 분석 질문

  • 전체 합격률(88.0%)과 설비별 합격률(EQ-01 98.1% ~ EQ-04 75.0%)은 어떻게 다른가? 설비별 처리 장수는 몇 장인가?
  • 설비별 평균 온도는 합격률만큼 차이가 나는가?
  • 로트별 수율(로트 안 웨이퍼 4장 중 합격 비율)이 80% 미만인 로트는 몇 개이고, EQ-04의 로트는 어떻게 나뉘는가?
  • 수율이 가장 낮은 로트는 어느 설비·공정·작업조에서 나왔는가?
  • 가장 자주 발생한 불량 유형은 무엇인가?(많은 순으로 줄 세우기, 파레토)

실제 현업 데이터와 다른 점

완전한 가상 데이터다. 설비별 특성과 저수율 로트의 연결은 "그룹 비교"와 "공통점 찾기" 학습을 위해 의도적으로 설계했다.
