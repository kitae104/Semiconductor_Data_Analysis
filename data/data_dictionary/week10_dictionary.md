# week10_capstone_lots.csv 데이터 설명서 (10차시 종합 실습)

> **공정 지도 위치**: `week10_capstone_lots.csv` = 공정 지도 **②~⑤(산화·포토·식각·증착/이온주입) + 세정** 설비가 남긴 기록 값(센서·측정값) → **⑦ EDS(전기 검사)** 결과(합격여부·불량유형) /
> `week10_capstone_new_lots.csv` = ②~⑤ + 세정을 마쳤지만 아직 **⑦ 검사 전**인 새 로트 10개.
> 이 기록은 교육용으로 만든 **가상 데이터**이며 실제 공장의 기록이 아니다.
> 설비 4대가 여러 공정 기록을 함께 남겼다. 로트마다 설비 하나·공정 하나만 적어 둔 교육용 단순화다.

## 목적
10차시 종합 실습(캡스톤)용 데이터다. 1~9차시에서 배운 것 — 빈칸·튀는 값 점검(4·5차시), 그림(6차시), 무리별 합격률 비교(7차시),
상관과 연습용 기준 밖 비교(8차시), 결정 트리 예측과 기준선(9차시) — 을 모두 한 표에서 쓸 수 있게 만들었다.
수업에서는 "새 로트 10개 중 어느 것부터 점검할까?" 한 문제를 AI(ChatGPT)로 계획 → Orange3로 점검·비교·예측 → AI 해석 초안 → 직접 확인 순서로 풀어 본다.
**ChatGPT에는 이 CSV 파일을 올리지 않는다.** 아래 "열 설명"만 붙여 넣는다.

## 가상 상황
신입 데이터 담당자가 마지막 날 팀장에게서 받은 공정 기록 한 묶음이다. 2024-06-03부터 2024-06-30까지 4주 동안 로트 480개가 ②~⑤ + 세정 설비를 거쳤고,
⑦ 검사 결과가 함께 적혀 있다. 그와 별도로 아직 검사하지 않은 새 로트 10개(NEW-01~NEW-10)의 공정 기록이 있다.

## 행 하나의 의미
- `week10_capstone_lots.csv`: 한 행 = 로트 하나의 공정 기록(언제, 어느 설비에서, 어떤 작업을, 어느 작업조가, 어떤 조건에서 했고, 검사 결과는 어땠는지). 480행 13열, 로트번호는 모두 다르다.
- `week10_capstone_new_lots.csv`: 한 행 = 검사 전 새 로트 하나의 공정 기록. 10행 11열(결과 열 `불량유형`·`합격여부` 없음), 빈칸·입력 실수 없음.

## 연습용 기준 (교육용 예시)
이 과정에서 연습용으로 정한 범위이며 실제 공정 규격이 아니다. 범위 밖이라고 곧 불합격인 것은 아니다.
진공도 4.5~5.5 mTorr, 진동 0.64 mm/s 이하. 온도·진공도·두께 값은 다섯 공정 모두 비슷한 크기로 만든 교육용 값이라 실제 공정 조건(공정마다 크게 다르다)으로 해석하지 않는다.

## 데이터 점검에서 만날 것
- **빈칸 14칸(14행)**: 온도_C 5 · 진공도_mTorr 5 · 습도_pct 4. 14행 모두 합격 행이다.
- **입력 실수 3건**: 온도_C에 소수점이 빠진 값 3006.0(LOT-0017) · 3028.0(LOT-0616) · 2980.0(LOT-0534). Column Statistics의 온도 Max 3028, Mean 317.27이 단서다.
- **중복 행 없음**(Orange에서 중복을 지우려면 배우지 않은 위젯이 필요해 넣지 않았다).
- Orange Select Rows로 `온도_C` is below 1000을 걸면 472행이 남는다. 입력 실수 3행과 함께 온도가 빈 5행도 빠진다(숫자 조건은 빈칸 행을 통과시키지 않는다). 이어서 Impute(Average/Most frequent)로 진공도·습도 빈칸 9칸을 채운다.

## 실제 현업 데이터와 다른 점
완전한 가상 데이터다. 아래 패턴은 "함께 나타난 것"과 "원인"을 구분하는 연습을 위해 의도적으로 심어 둔 것이며, 실제 반도체 공정의 물리적 인과관계를 보증하지 않는다.
실제 공장에서는 한 로트가 여러 설비·여러 공정을 거치지만, 여기서는 로트마다 설비 하나·공정 하나만 적었다. 설비별 값의 퍼짐을 실제 측정 변동의 근거로 해석하지 않는다.
