# week10_mini_project_dataset.csv 데이터 설명서

## 목적
1~9주차에서 배운 모든 기법(조회, 정제, 시각화, 그룹 비교, 수율, 이상탐지, 예측적 사고)을
한 데이터셋 위에서 종합 적용해보는 미니 프로젝트용 데이터다.

## 가상 상황
600건의 공정 기록으로, 여러 주차의 패턴(설비별 차이, 이상값, 불량유형 등)이 옅게 섞여 있다.

## 행 하나의 의미
한 행 = 특정 로트·웨이퍼의 공정 측정 및 검사 기록.

## 열 설명

| 열 이름 | 쉬운 설명 | 데이터 형식 | 단위 | 결측값 가능 여부 |
| --- | --- | --- | --- | --- |
| 측정시간 | 측정 시각 | 문자열(날짜시간) | - | 없음 |
| 로트번호 | 로트 식별 번호 | 문자열 | - | 없음 |
| 웨이퍼번호 | 웨이퍼 순번 | 정수 | - | 없음 |
| 설비번호 | 공정 설비 | 문자열 | - | 없음 |
| 공정명 | 공정 종류 | 문자열 | - | 없음 |
| 작업조 | 근무 조 | 문자열 | - | 없음 |
| 온도_섭씨 | 챔버 온도 | 실수 | ℃ | 없음 |
| 압력_Pa | 챔버 압력 | 실수 | Pa | 없음 |
| 진공도_mTorr | 챔버 진공도 | 실수 | mTorr | 없음 |
| 두께_nm | 막 두께 | 실수 | nm | 없음 |

| 습도_pct | 클린룸 습도 | 실수 | % | 없음 |
| 불량유형 | 불량 시 유형(정상이면 빈 값) | 문자열 | - | 있음(정상일 때) |
| 검사결과 | 최종 판정 | 정수 | - | 없음(0=정상/합격, 1=이상/불합격) |

## 정상 범위 (교육용 예시)
docs/data-design.md의 공통 정상 범위표를 참고한다.

## 의도적으로 포함된 패턴
6~8주차에서 사용한 설비별 차이(EQ-04 불량률 높음 등) 패턴을 노이즈를 늘려 옅게 재현했다.
어떤 프로젝트 주제를 선택해도(설비 비교, 저수율 로트, 온도 이상, 진공도-불량 관계 등)
분석이 가능하도록 여러 열을 폭넓게 포함했다.

## 이번 주 분석 질문(자유 선택)
1. 설비별 불량률 비교 5. 냉각수온도-공정온도 관계
2. 수율이 낮은 로트 찾기 6. 막 두께 불량 원인 후보 분석
3. 온도 이상 구간 탐지 7. 주요 센서를 이용한 불량 예측(9주차 방식 응용)
4. 진공도 변화와 불량 관계 8. 설비의 시간대별 공정 변화 분석

## 실제 현업 데이터와 다른 점
완전한 가상 데이터다. 여러 패턴이 동시에 섞여 있어 실제 데이터처럼 "완벽하게 명확하지 않은"
상태로 설계했다 — 분석 결과에 항상 불확실성이 남는다는 점을 경험하게 하기 위함이다.
