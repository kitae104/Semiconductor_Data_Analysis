# week10_mini_project_dataset.csv 데이터 설명서 (선택 심화용)

> **참고**: v2 커리큘럼(`docs/curriculum.md`)에서 10차시의 핵심 데이터는 9차시에서 학습한
> 모델로 예측을 수행하는 `week09_new_lots_to_predict.csv`다(설명은
> `week09_dictionary.md` 참고). 이 파일(`week10_mini_project_dataset.csv`)은 8개 프로젝트
> 주제 중 하나를 골라 더 깊이 파보고 싶은 학습자를 위한 **선택 심화 자료**로 남겨둔 것이며,
> 10차시 core 진행에는 사용하지 않는다.

## 목적
1~9차시에서 배운 모든 기법(조회, 정제, 시각화, 그룹 비교, 수율, 이상탐지, 예측적 사고)을
한 데이터셋 위에서 종합 적용해보는 미니 프로젝트용 데이터다.

## 가상 상황
600건의 공정 기록으로, 여러 차시의 패턴(설비별 차이, 이상값, 불량유형 등)이 옅게 섞여 있다.

## 행 하나의 의미
한 행 = 특정 로트·웨이퍼의 공정 측정 및 검사 기록.

## 압력_Pa 값의 한계 (교육용 가상 데이터)

`압력_Pa`는 교육용으로 생성한 가상 값이며 실제 측정값이 아니다. 이번 차시의 실측 범위는 약
989.5~1,046.0 Pa(평균 약 1,013.9 Pa)인데, 이 자릿수는 Pa로 읽은 챔버 압력보다 hPa로 읽었을
때의 자릿수에 가깝다(대기압이 약 1,013 hPa = 101,325 Pa다). **단위 라벨과 값의 자릿수가 서로
맞지 않는다.** 같은 행의 `진공도_mTorr`와도 맞지 않는다. 진공도 평균 약 4.98 mTorr는 약 0.66
Pa인데(1 mTorr ≈ 0.133 Pa) 같은 행의 `압력_Pa`는 평균 약 1,013.9 Pa여서 약 1,530배 차이가 난다
— 한 챔버가 같은 시각에 두 압력일 수는 없다. 이 값이 실제로 어떤 공정 조건을 나타내는지는
단정할 수 없으므로, 실습에서는 `압력_Pa`의 절대값을 물리적으로 해석하지 않고 **수치 열
하나**로만 다룬다.

**학생이 물어보면**: "교육용으로 만든 가상 값이라 단위와 자릿수가 실제 공정과 맞지 않습니다.
이번 실습에서는 압력의 절대값을 해석하지 않고 값들 사이의 상대적인 차이만 봅니다"라고 답한다.

데이터를 다시 만들면 1~10차시의 실습 결과 수치와 강의 자료가 모두 함께 바뀌므로, 현재 버전은
값을 그대로 두고 이 한계를 여기에 명시하는 쪽을 택했다.

## 의도적으로 포함된 패턴
6~8차시에서 사용한 설비별 차이(EQ-04 불량률 높음 등) 패턴을 노이즈를 늘려 옅게 재현했다.
어떤 프로젝트 주제를 선택해도(설비 비교, 저수율 로트, 온도 이상, 관계없게 만든 열 확인 등)
분석이 가능하도록 여러 열을 폭넓게 포함했다.

## 강사용 주석 — 불량은 설비로만 만들어졌다

`scripts/generate_weekly_data.py`의 `gen_week10()`은 `합격여부`(1=합격, -1=불합격)를 **설비번호에 따라 정한 확률로만** 만든다.
온도·압력 분포도 설비마다 조금씩 다르게 만들었고, 두께는 온도에서 계산했으며, 진동은 EQ-02만 높게 만들었다.
진공도·처리시간·냉각수온도·습도는 설비·불량과 무관한 무작위 값이다.
실제 집계(600행, 불합격 59건):

- 설비별 불합격: EQ-01 166건 중 4건(2.4%), EQ-02 150건 중 17건(11.3%), EQ-03 142건 중 11건(7.7%), EQ-04 142건 중 27건(19.0%)
- 진공도 4.5~5.5 mTorr 안: 517건 중 54건(10.4%) / 밖: 83건 중 5건(6.0%) — **범위를 벗어난 쪽이 오히려 불합격이 적다.**
  9차시 데이터처럼 "진공도 이탈 → 불합격 증가" 패턴을 기대하면 반대 결과가 나온다.
- 온도·두께와 불합격의 관계가 보인다면 **설비라는 제3의 요인을 거친 간접 관계**다(EQ-04가 온도 평균이 약간 높고 불합격도 많다).
  학생이 "온도/두께가 불량의 원인 후보"라고 결론 내리면, 설비별로 나눠 다시 보게 해 제3의 요인을 확인하게 한다.

아래 분석 질문 4(관계없게 만든 열 확인)와 6(막 두께 불량 원인 후보)은 위 사실을 알고 지도한다. 관계가 없거나 간접적이라는 결론도 올바른 분석 결과다.

## 이번 차시 분석 질문(자유 선택)
1. 설비별 불량률 비교
2. 수율이 낮은 로트 찾기
3. 온도 이상 구간 탐지
4. 대조 연습 — 관계없게 만든 열 확인하기: 진공도·습도·처리시간이 정상 범위 안/밖일 때 불합격 비율을 비교해, 관계가 없어 보이는 열도 "관계없음"으로 결론 내려 보기(진공도는 범위 밖 6.0%, 안 10.4%로 오히려 반대 방향이다)
5. 냉각수온도-공정온도 관계
6. 막 두께 불량 원인 후보 분석
7. 주요 센서를 이용한 불량 예측(9차시 방식 응용)
8. 설비의 시간대별 공정 변화 분석

## 실제 현업 데이터와 다른 점
완전한 가상 데이터다. 여러 패턴이 동시에 섞여 있어 실제 데이터처럼 "완벽하게 명확하지 않은"
상태로 설계했다 — 분석 결과에 항상 불확실성이 남는다는 점을 경험하게 하기 위함이다.
