# week01_semiconductor_process_overview.csv 데이터 설명서

## 목적
반도체 공정 데이터를 처음 관찰하는 1차시 실습용 데이터다. 어렵게 생각하지 말고
"공장에서 하루 동안 있었던 일을 적은 표"라고 생각하면 된다.

## 가상 상황
가상의 반도체 공장(FAB)에서 여러 설비(EQ-01~EQ-04)가 웨이퍼를 가공하며 남긴 기록이다.

## 행 하나의 의미
한 행 = 특정 시각에 특정 설비가 특정 웨이퍼를 특정 공정으로 처리한 뒤 남긴 기록 1건.

## 열 설명

| 열 이름 | 쉬운 설명 | 데이터 형식 | 단위 | 예시 | 결측값 가능 여부 |
| --- | --- | --- | --- | --- | --- |
| 측정시간 | 기록이 저장된 시각 | 문자열(날짜시간) | - | 2024-03-05 10:00 | 없음 |
| 로트번호 | 웨이퍼 묶음(로트) 식별 번호 | 문자열 | - | LOT-0231 | 없음 |
| 웨이퍼번호 | 로트 안에서 웨이퍼 순번 | 정수 | - | 7 | 없음 |
| 공정명 | 수행한 공정 종류 | 문자열 | - | 식각 | 없음 |
| 설비번호 | 공정을 수행한 설비 | 문자열 | - | EQ-02 | 없음 |
| 온도_섭씨 | 공정 진행 중 챔버 온도 | 실수 | ℃ | 300.2 | 없음 |
| 압력_Pa | 공정 진행 중 챔버 압력 | 실수 | Pa | 1010.5 | 없음 |
| 합격여부 | 검사 결과 | 정수 | - | 1(합격) / -1(불합격) | 없음 |

## 정상 범위 (교육용 예시)
온도 295~305℃, 압력 995~1025 Pa. 실제 공정의 절대 기준이 아니라 이 과정에서 사용하는 학습용 기준이다.

## 의도적으로 포함된 패턴
1차시는 "관찰"이 목표이므로 결측값이나 극단적 이상값을 넣지 않았다. 합격 확률 85%로 생성해
현실적인 비율만 반영했다(실제 생성 결과: 합격 32건 80% / 불합격 8건 20%).

## 이번 차시 분석 질문
- 데이터에는 몇 개의 행과 열이 있는가?
- 합격과 불합격은 각각 몇 건인가?
- 어떤 설비들이 등장하는가?

## 실제 현업 데이터와 다른 점
완전한 가상 데이터이며 실제 반도체 기업의 생산 데이터가 아니다. 열 이름과 값의 범위는
첨부된 `반도체_공정_샘플.csv`의 구조를 참고해 교육 목적으로 재구성했다.
