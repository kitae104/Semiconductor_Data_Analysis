2차시 실습 데이터 설명서

대상 파일: week02_python_basics_1.csv

목적

리스트와 딕셔너리를 처음 배울 때 참고할 소량의 예시 데이터다. 이 CSV는 코드로 읽지 않고, 강의에 필요한 값만 리스트/딕셔너리로 직접 옮겨 적어 사용한다(파일을 코드로 여는 것은 4차시 Pandas부터).

가상 상황

가상의 반도체 공장(FAB)에서 여러 설비(EQ-01~EQ-04)가 로트를 처리하며 잰 온도와, 그 뒤 검사 결과를 적은 기록이다.

행 하나의 의미

한 행 = 로트 하나가 어떤 설비에서 어떤 공정으로 처리될 때 잰 온도와 검사 결과 1건. 2차시에서는 이 한 행을 딕셔너리 하나로 옮겨 적는다(열 이름 = 키). 여러 행을 담으면 "딕셔너리의 리스트"가 된다.

열 설명

열 이름 쉬운 설명 데이터 형식 단위 예시 결측값 가능 여부
로트번호함께 이동하는 웨이퍼 묶음(로트)의 번호. 택배 상자의 송장 번호와 비슷하다문자열-LOT-0122없음
공정명웨이퍼에 한 작업 종류(식각·포토·산화·증착·세정)문자열-식각없음
설비번호그 작업을 한 기계의 번호문자열-EQ-02없음
온도_섭씨작업 중 설비 안(챔버: 웨이퍼를 넣고 작업하는 밀폐된 방)에서 센서가 잰 온도실수℃302.5없음
합격여부검사 결과정수-1(합격) / -1(불합격)없음

정상 범위 (교육용 예시)

온도 295~305℃. 실제 공정의 기준이 아니라 이 과정에서 사용하는 학습용 기준이다.

온도_섭씨 값의 한계 (교육용 가상 데이터)

온도_섭씨는 공정 종류와 관계없이 약 300℃ 근처(292.2~317.9℃)로 만든 가상 값이다. 실제 공장에서는 작업마다 온도가 크게 다르다. 실습에서는 온도의 절대값을 실제 공정 조건으로 해석하지 않고, 기록끼리 비교하는 숫자로만 다룬다.

의도적으로 포함된 패턴

20행 중 정상범위(295~305℃)를 벗어나는 온도 값을 9건 포함해, 최댓값·최솟값을 찾는 실습(max(), min())과 "평균만 보면 튀는 값을 놓친다"는 해석 연습 소재로 쓴다. 불합격(-1)은 1건(LOT-0184, 312.4℃)이고, 정상 범위를 벗어났지만 합격(1)인 기록도 여러 건 있다(예: LOT-0097, 308.7℃). 결측값은 없다(2차시는 리스트/딕셔너리 문법에 집중).

2차시 강의에서 옮겨 쓴 값

  • 종합 실습: 앞 3행(LOT-0122, LOT-0097, LOT-0026)을 딕셔너리의 리스트 records로, 도전 문제에서 4번째 행(LOT-0160)을 추가
  • 연습문제: EQ-02 설비 기록 4건의 온도 [302.5, 299.8, 298.8, 305.6](평균 301.7℃, 최고 305.6℃)
  • 실습지: EQ-03 설비 기록 7건의 온도(평균 302.6℃, 최고 308.5℃, 최저 292.2℃), 실습지 7번의 LOT-0184(불합격 -1)와 LOT-0015(합격 1) 두 행
  • 강의 맨 앞의 하루 온도 다섯 개 [295.4, 298.1, 312.6, 301.0, 296.8]는 이 파일이 아니라 설명용으로 만든 값이다.

이번 차시 분석 질문

  • 이 리스트에서 가장 높은 온도와 가장 낮은 온도는 몇 번째 값인가?
  • 온도 값들의 평균은 얼마이고, 평균만 볼 때 무엇을 놓치는가?

실제 현업 데이터와 다른 점

완전한 가상 데이터이며 실제 반도체 기업의 생산 데이터가 아니다. 리스트/딕셔너리 문법 연습을 위해 아주 작은 규모로 만들었다. 가상 데이터라 설비와 공정이 무작위로 짝지어져 있다(예: EQ-04 한 대가 포토·식각·산화·증착 기록에 모두 나온다). 실제 공장에서는 설비마다 맡는 공정이 정해져 있다. 강의의 equipment_list(EQ-02 = 증착 등)도 설명용 값이라 이 파일의 짝과 다르다.
