반도체 및 반도체 공정 데이터 분석 10주 과정

프로그래밍 경험이 거의 없는 일반인을 위한, 반도체 공정과 데이터 분석을 함께 배우는 과정입니다.

📘 교육과정 설계 문서 🗂️ 전체 용어집 📄 README 📊 원본 데이터 분석 리포트

🎯 이 과정을 마치면 할 수 있는 것

  • 반도체와 웨이퍼의 기본 개념을 설명하고, 공정 데이터를 스스로 열어볼 수 있다.
  • 변수·리스트·딕셔너리·조건문·반복문·함수 등 파이썬 기초를 직접 짤 수 있다.
  • Pandas로 데이터를 조회·정리하고, 결측값·중복값·이상값을 찾을 수 있다.
  • 그래프로 공정 상태를 확인하고, 설비별·공정별 차이를 비교할 수 있다.
  • 수율과 불량률을 계산하고, 공정 이상의 원인 후보를 데이터로 탐색할 수 있다.
  • 합격/불합격을 예측하는 머신러닝 모델을 직접 만들고, 새 데이터를 예측해볼 수 있다.
  • Orange3로 같은 분석을 코드 없이 다시 확인하며 개념을 다질 수 있다.
진행 안내 이 커리큘럼은 파이썬 기초(2·3주차)와 Orange3 노코드 실습(5·6·8·9주차)을 추가하고, 9주차 예측 실습을 fab.csv 대신 반도체_공정_샘플.csv 기반으로 바꾼 v2 구성입니다(배경: docs/restructure-plan.md). 아래 주차 카드는 v2 목차를 반영했지만, 각 주차의 상세 강의 자료(HTML·노트북·데이터)는 아직 v1 내용일 수 있어 순서대로 다시 작성 중입니다.

📅 10주 커리큘럼

1부 · 첫걸음 — 개념과 파이썬 기초 (1~3주차)
WEEK 01

반도체 공정과 데이터 처음 만나기

반도체·웨이퍼·칩·FAB 개념, Colab에서 CSV 열기, Pandas 첫 조회.
WEEK 02

파이썬 기초 Ⅰ — 변수·리스트·딕셔너리

변수와 자료형, 리스트로 여러 값 담기, 딕셔너리로 이름표 붙이기.
WEEK 03

파이썬 기초 Ⅱ — 조건문·반복문·함수

if로 판정하기, for로 반복 처리하기, 함수로 재사용 가능한 코드 만들기.
2부 · 데이터 다루기 (4~6주차)
WEEK 04

Pandas로 공정 데이터 읽고 선택하기

read_csv, 열 선택, 조건 검색, 정렬로 원하는 데이터 찾기.
WEEK 05

결측값과 이상한 데이터 정리하기

결측값·중복값·이상값 찾기, 제거와 대체 + Orange3로 같은 데이터 훑어보기.
WEEK 06

그래프로 공정 상태 이해하기

선·막대·히스토그램·산점도·박스플롯 + Orange3 위젯으로 다시 그려보기.
3부 · 비교와 원인 탐색 (7~8주차)
WEEK 07

설비·공정 비교와 수율·불량 분석

groupby 집계로 설비 간 차이 비교, 수율·불량률 계산, 파레토 분석.
WEEK 08

공정 이상과 원인 후보 찾기

임계값 이상탐지, 상관관계 읽기 + Orange3 Correlations로 재확인하기.
4부 · 예측과 종합 (9~10주차)
WEEK 09

머신러닝으로 합격/불합격 예측하기

반도체_공정_샘플.csv로 분류 모델 만들고 새 데이터 예측 + Orange3로 비교.
WEEK 10

반도체 공정 데이터 분석 미니 프로젝트

질문 설정부터 결과 해석·개선 제안까지, 배운 내용을 종합하는 캡스톤 프로젝트.

🧭 이 과정 사용 방법

학습자용 매주 위 카드를 눌러 강의 자료를 먼저 읽고, notebooks/student/의 학생용 Notebook을 Google Colab이나 Jupyter에서 열어 실습하세요. 막히면 각 주차의 실습지(worksheet)와 퀴즈로 이해도를 점검할 수 있습니다.
강사용 각 주차 폴더의 instructor-guide.md에 2시간 수업 시간표와 진행 팁이 있습니다. notebooks/instructor/는 시연용, notebooks/solutions/는 정답입니다.
