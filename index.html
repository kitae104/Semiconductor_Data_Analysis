반도체 및 반도체 공정 데이터 분석 10차시 과정

프로그래밍 경험이 거의 없는 일반인을 위한, 반도체 공정과 데이터 분석을 함께 배우는 과정입니다.

📘 교육과정 설계 문서 🗂️ 전체 용어집 📄 README 📊 원본 데이터 분석 리포트

🎯 이 과정을 마치면 할 수 있는 것

  • 반도체와 웨이퍼의 기본 개념을 설명하고, 공정 데이터를 스스로 열어볼 수 있다.
  • 변수·리스트·딕셔너리·조건문·반복문·함수 등 파이썬 기초를 직접 짤 수 있다.
  • Pandas로 데이터를 조회·정리하고, 결측값·중복값·이상값을 찾을 수 있다.
  • 그래프로 공정 상태를 확인하고, 설비별·공정별 차이를 비교할 수 있다.
  • 수율과 불량률을 계산하고, 공정 이상의 원인 후보를 데이터로 탐색할 수 있다.
  • 합격/불합격을 예측하는 머신러닝 모델을 직접 만들고, 새 데이터를 예측해볼 수 있다.
  • Orange3로 같은 분석을 코드 없이 다시 확인하며 개념을 다질 수 있다.
진행 안내 이 커리큘럼은 파이썬 기초(1~3차시)와 Orange3 노코드 실습(5~10차시)을 추가하고, 9~10차시 예측 실습을 fab.csv 대신 반도체_공정_샘플.csv 기반으로 바꾼 v2 구성입니다(배경: docs/restructure-plan.md). 5~10차시는 모두 "① Orange3로 먼저 훑어보기 → ② 파이썬 코드로 확인하기" 순서로 진행하며, 10차시는 별도 미니 프로젝트 없이 9차시 예측 실습을 이어받아 모델 평가와 새 데이터 예측으로 마무리합니다. 실습 데이터(data/weekly/)는 v2 스펙으로 재생성되었고, 1~10차시 강의 자료·워크시트·퀴즈·노트북·강사 가이드가 모두 상세 콘텐츠로 완성된 상태입니다.

📅 10차시 커리큘럼

1부 · 첫걸음 — 개념과 파이썬 기초 (1~3차시)
1차시

반도체 공정과 데이터 처음 만나기 + 변수·출력

반도체·웨이퍼·칩·FAB 개념, Colab에서 CSV 열기, Pandas 첫 조회 + 파이썬 변수와 print() 출력.
2차시

리스트와 딕셔너리

리스트로 여러 값 담고 인덱싱하기, 딕셔너리로 이름표 붙이기, 두 가지를 충분히 연습.
3차시

리스트·딕셔너리로 배우는 조건문·반복문·함수

if로 판정하기, for로 리스트/딕셔너리 순회하기, 함수로 재사용 가능한 코드 만들기.
2부 · 데이터 다루기 (4~6차시)
4차시

Pandas 가장 기본적인 부분

read_csv, 열 선택, 조건 검색, 정렬로 원하는 데이터 찾기(가장 기본만).
5차시

데이터 훑어보기와 정리(EDA)

Orange3로 먼저 결측값·이상값을 훑어본 뒤, Pandas로 직접 찾아 정제하기.
6차시

그래프로 공정 상태 이해하기

Orange3로 먼저 그래프를 그려본 뒤, 선·막대·히스토그램·산점도·박스플롯을 코드로 재현하기.
3부 · 비교와 원인 탐색 (7~8차시)
7차시

설비·공정 비교와 수율·불량 분석

Orange3로 먼저 설비별 차이를 훑어본 뒤, groupby로 수율·불량률·파레토를 직접 계산하기.
8차시

공정 이상과 원인 후보 찾기

Orange3 Correlations로 먼저 관계를 훑어본 뒤, 상관관계를 직접 계산해 원인 후보 찾기.
4부 · 예측 (9~10차시)
9차시

머신러닝 예측 모델 만들기

Orange3로 먼저 예측 정확도를 훑어본 뒤, scikit-learn으로 분류 모델을 직접 학습시키기.
10차시

모델 평가와 새 데이터 예측

학습한 모델로 새 로트를 predict()하고, Orange3 Predictions로 재확인하며 전체 과정 정리.

🧭 이 과정 사용 방법

학습자용 매 차시 위 카드를 눌러 강의 자료를 먼저 읽고, notebooks/student/의 학생용 Notebook을 Google Colab이나 Jupyter에서 열어 실습하세요. 막히면 각 차시의 실습지(worksheet)와 퀴즈로 이해도를 점검할 수 있습니다.
강사용 각 차시 폴더의 instructor-guide.md에 수업 흐름과 진행 팁이 있습니다. notebooks/instructor/는 시연용, notebooks/solutions/는 정답입니다.
