9차시 · 개요(skeleton)

머신러닝 예측 모델 만들기

💬 오늘의 질문: "코드를 쓰기 전에, Orange3로 먼저 이 데이터가 얼마나 잘 예측되는지 확인해볼 수 있을까?"

작성 상태 이 페이지는 v2 커리큘럼 구성이 확정된 직후 작성된 개요(skeleton)입니다. 제목·학습 목표·다룰 내용·데이터까지는 확정되었지만, 상세 설명·예제 코드·단계별 실습·퀴즈는 아직 채워지지 않았습니다. 구성이 최종 확정되면 이어서 상세 내용을 작성합니다. 배경은 docs/restructure-plan.md 참고.

🎯 학습 목표

  • Orange3로 먼저 이 데이터가 얼마나 잘 예측되는지 확인할 수 있다.
  • Feature(특징)와 Label(정답)의 의미를 설명할 수 있다.
  • train/test로 데이터를 나누고 분류 모델을 학습시킬 수 있다.
  • 정확도·혼동행렬로 모델 성능을 확인할 수 있다.

선수 지식: 1~8차시 전체 — 특히 3차시(직접 판정)와 8차시(원인 후보)

🟠 ① Orange3로 먼저 훑어보기

위젯 File → Tree → Test and Score

scikit-learn 코드를 쓰기 전에 Orange3 File → Tree → Test and Score 위젯으로 코드 없이 모델을 먼저 만들어보고 정확도를 확인한다. 이어서 같은 데이터를 scikit-learn 코드로 직접 학습시켜 비교한다.

📚 ② 파이썬으로 확인하기 — 다룰 이론 주제(초안)

  • Feature(특징)와 Label(정답)
  • train/test 분리
  • 분류(classification), 정확도, 혼동행렬
  • '정상이 대부분인 데이터'에서 정확도만 보면 안 되는 이유

🐍 다룰 실습 흐름(초안)

  1. week09_pass_fail_train.csv 불러오기 → 결측치 처리(4~5차시 복습)
  2. Feature/Label 나누기
  3. train_test_split으로 학습/평가 데이터 나누기
  4. DecisionTreeClassifier 학습
  5. 정확도 · 혼동행렬 확인
