머신러닝으로 합격/불합격 예측하기

💬 오늘의 질문: "온도·압력 같은 측정값만 보고, 이 로트가 합격일지 불합격일지 미리 알 수 있을까?"

작성 상태 이 페이지는 v2 커리큘럼 구성이 확정된 직후 작성된 개요(skeleton)입니다. 제목·학습 목표·다룰 내용·데이터까지는 확정되었지만, 상세 설명·예제 코드·단계별 실습·퀴즈는 아직 채워지지 않았습니다. 구성이 최종 확정되면 이어서 상세 내용을 작성합니다. 배경은 docs/restructure-plan.md 참고.

🎯 학습 목표

  • Feature(특징)와 Label(정답)의 의미를 설명할 수 있다.
  • train/test로 데이터를 나누고 분류 모델을 학습시킬 수 있다.
  • 정확도·혼동행렬로 모델 성능을 확인할 수 있다.
  • 새 측정값을 입력해 predict()로 합격/불합격을 예측할 수 있다.
  • Orange3로 같은 데이터를 코드 없이 학습·예측해보고 결과를 비교할 수 있다.

선수 지식: 1~8주차 전체 — 특히 3주차(직접 판정)와 8주차(상관관계)

📚 다룰 이론 주제(초안)

  • Feature(특징)와 Label(정답)
  • train/test 분리
  • 분류(classification), 정확도, 혼동행렬
  • '정상이 대부분인 데이터'에서 정확도만 보면 안 되는 이유
  • 새 데이터에 대한 예측 — predict()

🧪 다룰 실습 흐름(초안)

  1. week09_pass_fail_train.csv 불러오기 → 결측치 처리(4~5주차 복습)
  2. Feature/Label 나누기
  3. train_test_split으로 학습/평가 데이터 나누기
  4. DecisionTreeClassifier 학습
  5. 정확도 · 혼동행렬 확인
  6. week09_new_lots_to_predict.csv의 새 로트에 대해 predict()로 예측

🟠 Orange3 실습(추가 예정)

위젯 File → Tree(또는 다른 분류기) → Test and Score → Predictions

동일한 학습/예측 데이터를 Orange3로 불러와 코드 없이 모델을 만들고, scikit-learn 결과와 정확도·예측을 비교한다.
