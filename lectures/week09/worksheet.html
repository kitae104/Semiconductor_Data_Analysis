머신러닝 예측 모델 만들기 — 실습지

🤔 왜 이걸 배워야 할까?

  • 지금까지는 이미 일어난 불량을 데이터로 "설명"했지만, 현장에서는 문제가 생기기 전에 "이 로트가 불합격할 것 같다"를 미리 알 수 있으면 훨씬 유용하다. 머신러닝은 과거 데이터의 패턴(온도·압력 등과 합격/불합격의 관계)을 학습해, 아직 결과를 모르는 새 데이터의 합격 여부를 예측하는 방법이다.
쉬운 예시 과거 1,000개 로트의 온도·압력과 합격/불합격 결과를 모델에 학습시키면, 아직 검사하지 않은 새 로트의 온도·압력 값만 보고도 "합격할 가능성이 높다/낮다"를 미리 계산해볼 수 있다 — 지난 시험 성적의 패턴으로 다음 시험 결과를 짐작하는 것과 비슷한 원리다.

1. 용어 연결 문제

왼쪽 용어와 오른쪽 설명을 알맞게 연결해보자.

용어설명 후보
① FeatureA. 예측에 쓰는 입력 값
B. 학습용과 평가용 데이터를 나누는 것
C. 예측 결과를 실제/예측 조합별로 정리한 표
D. 맞히고 싶은 정답 값
② Label
③ 혼동행렬
④ train/test 분리
① A ② D ③ C ④ B

model = ____________(max_depth=4, random_state=42)
model.fit(X_train, y_train)
순서대로 stratify, DecisionTreeClassifier

3. 정확도의 함정 문제

검사결과가 합격(0) 582건, 불합격(1) 153건(전체 735건)일 때, 모든 행을 무조건 "합격(0)"으로 예측하면 정확도는 몇 %가 될까? (소수 첫째 자리까지)

582 ÷ 735 × 100 ≈ 79.2%. 정확도는 높아 보이지만 불합격을 단 한 건도 찾아내지 못하는 예측이므로 실제로는 쓸모가 없다.

4. 혼동행렬 해석 문제

실습에서 얻은 실제 혼동행렬이다.

          예측:합격  예측:불합격
실제:합격    109        7
실제:불합격   25        6

이 표에서 "실제 불합격인데 모델이 합격으로 잘못 예측한 경우(FN, 놓친 불량)"는 몇 건인가?

정답: 25건. 실제 불합격 31건 중 25건을 놓치고 6건만 맞혔다(TP=6). 정확도 숫자만으로는 이 사실을 알 수 없다.

5. 분석 문장 작성 문제

아래 빈칸을 채워 이번 차시 분석 결과를 한 문장으로 요약해보자.

문장 작성 "test 데이터 ____건 중 모델은 정확도 약 ____%를 기록했으며, 이는 기준선(무조건 합격 예측) 정확도 약 ____%보다 (높다/낮다). 실제 불합격 ____건 중 ____건만 찾아냈다."

6. 도전 문제

도전 model.feature_importances_ 결과에서 가장 중요도가 높게 나온 특징을 적어보자. 그리고 이 결과가 "그 특징이 불량의 실제 원인이다"라는 뜻은 아닌 이유를 한 문장으로 설명해보자(8차시 "상관관계 ≠ 원인" 복습).

7. 심화 실습

심화 DecisionTreeClassifier(max_depth=2, ...)와 DecisionTreeClassifier(max_depth=10, ...)으로 각각 모델을 새로 학습시켜 test 정확도를 비교해보자. max_depth가 클수록 항상 test 정확도가 좋아지는지 확인하고, 만약 그렇지 않다면(과대적합, overfitting) 그 이유를 한 문장으로 설명해보자.
체크포인트 정확도는 반드시 X_test, y_test로 비교해야 한다. X_train 으로 정확도를 재면 max_depth가 클수록 항상 높게 나와서 과대적합을 발견할 수 없다. train 정확도와 test 정확도를 각각 따로 확인해 두 값의 차이가 커지는지 살펴보자.

8. AI 미니 프로젝트 도전 — 합격 예측 미니 데모

도전 AI 챗봇에게 "학습된 분류 모델(model)과 특징 이름 리스트(feature_cols)가 있을 때, 새로운 값 하나를 입력받아 데이터프레임 한 행으로 만들고 model.predict()로 합격/불합격을 재미있게 알려주는 파이썬 코드를 만들어줘"라고 요청해보자. 코드를 실습 노트북에 붙여넣어 실행하고, 입력값을 바꿔가며 예측이 어떻게 달라지는지 확인해보자.
