공정 이상과 원인 후보 찾기 — 실습지

모든 문제는 공정 센서 기록 week08_anomaly_root_cause.csv(450행 12열, 교육용 가상 데이터)로 푼다. 공정 지도 위치: ②~⑤ + 세정 설비의 센서 기록과 합격 여부(공정 중간 검사 + ⑦ EDS 결과를 모은 교육용 설정). 합격여부는 1 = 합격, -1 = 불합격이다. 설비 4대가 여러 공정 기록을 함께 남긴 교육용 가상 기록이다. 문제 1~3은 학생용 노트북 7단계와 같다 — 노트북 6단계 셀을 먼저 실행해 df를 만들어 둔다.

오늘의 미션 — 불합격과 관련 있어 보이는 공정 값을 찾아 '원인 후보' 보고서 한 줄을 쓰자.

문제 1 — 불합격 기준선 구하기 (노트북 7단계 문제 1)

전체 450건 중 불합격 기록의 비율(기준선)을 구하자. 힌트: 강의 "기준선" 절의 bad_all·base_rate와 같은 모양이다. 표 이름과 열 이름만 바뀐다.

Python — 노트북 7단계 문제 1
# TODO: 불합격을 뜻하는 숫자와, 나누는 표 이름을 채우세요.
fail_all = df[df["합격여부"] == ____]
base_rate = round(len(fail_all) / len(____) * 100, 1)
print(base_rate)

기준선은 몇 %인가?

주의 나누는 수는 공정 기록 전체 df의 행 수다. 가게 기록 shop과 헷갈리면 오류 없이 100%가 넘는 숫자가 나온다. 88.9가 나오면 불합격(-1) 대신 합격(1)을 센 것이다.
-1, df → 11.1. 450건 중 불합격 50건, 기준선 11.1%다. 문제 3에서 이 숫자와 비교한다.

문제 2 — 온도-두께와 습도-두께 상관계수 비교하기 (노트북 7단계 문제 2)

두께와 함께 움직이는 값이 있는지 보자. 습도는 관계없게 만든 비교용 열이다. 힌트: 강의 "산점도와 상관계수"의 shop["최고기온_C"].corr(shop["아이스크림판매량_count"])와 같은 모양이다. 두 번째 셀은 빈칸이 없다. 첫 셀과 같은 모양으로 습도_pct와 두께_nm의 상관계수를 직접 쓴다.

Python — 노트북 7단계 문제 2
# TODO: 상관계수를 구하는 함수 이름을 채우세요.
r_temp = df["온도_C"].____(df["두께_nm"])
print(round(r_temp, 2))

# TODO: 위 셀과 같은 모양으로, 습도_pct와 두께_nm의 상관계수를 r_humid에 담고 소수 둘째 자리로 출력하세요.
주의 두 열 모두 df에서 꺼낸다. 힌트의 shop이 남아 shop["습도_pct"].corr(df["두께_nm"])로 쓰면 오류 없이 0.29가 나온다. 가게 기록과 공장 기록을 행 번호끼리 짝지어 계산한 엉뚱한 값이다.

① 두 상관계수는 각각 얼마인가? ② 두께와 함께 움직이는 쪽은 어느 열인가? 그 열은 무엇의 원인 후보인가 — 두께인가, 불합격인가?

corr, 그리고 두 번째 셀에 직접 쓴 코드: 
r_humid = df["습도_pct"].corr(df["두께_nm"])
print(round(r_humid, 2))
출력: 0.71, -0.01. ① 온도–두께 0.71(강함), 습도–두께 -0.01(거의 관계없음). ② 온도다. 온도는 두께의 원인 후보다. 불합격에 대해서는 강의 확인 2에서 온도가 연습용 기준 밖일 때 불합격률이 9.8%로, 문제 1의 기준선 11.1%보다 높지 않았다(범위 안 11.5%보다도 낮다). 그래서 불합격의 원인 후보로 올리지 않는다.
체크포인트 KeyError: '습도'처럼 나오면 열 이름을 줄여 쓴 것이다. 정확한 이름은 습도_pct다. 열 이름은 따옴표 안에 쓴다. 따옴표 없이 df[습도_pct]로 쓰면 NameError: name '습도_pct' is not defined가 난다.

문제 3 — 진공도가 범위 밖일 때 불합격률 (노트북 7단계 문제 3)

진공도 연습용 기준은 4.5~5.5 mTorr다(실제 공정 규격이 아니다). 4.5보다 작거나 5.5보다 크면 범위 밖이다. 범위 밖 기록의 불합격률을 구해 문제 1의 기준선과 비교하자. |는 한국어 키보드에서 엔터 위 ₩ 키를 Shift와 함께 누른다. 힌트: 강의 "범위 밖 값 찾기"의 freezer_out, "반도체 데이터로 확인하기"의 temp_out과 같은 모양이다.

Python — 노트북 7단계 문제 3
# TODO: "또는"을 뜻하는 기호와 불합격을 뜻하는 숫자를 채우세요.
vac_out = df[(df["진공도_mTorr"] < 4.5) ____ (df["진공도_mTorr"] > 5.5)]
vac_out_fail = vac_out[vac_out["합격여부"] == ____]
print(len(vac_out), len(vac_out_fail))

# TODO: 범위 밖 불합격률 = 범위 밖 불합격 수 ÷ 범위 밖 기록 수 × 100. 나누는 표 이름을 채우세요.
vac_rate = round(len(vac_out_fail) / len(____) * 100, 1)
print(vac_rate, base_rate)

둘째 셀은 숫자 두 개(범위 밖 불합격률, 기준선)만 출력한다. 높은지 낮은지는 숫자를 보고 내가 판단한다.

① 범위 밖 기록은 몇 건이고, 그중 불합격은 몇 건인가? ② 범위 밖 불합격률은 기준선보다 높은가, 낮은가? 기준선의 약 몇 배인가?(소수 첫째 자리까지)

|, -1, vac_out 
78 20
25.6 11.1
① 범위 밖 78건 중 불합격 20건. ② 범위 밖 불합격률 25.6%는 기준선 11.1%보다 높다. 25.6 ÷ 11.1 ≈ 2.3배.

범위 밖을 낮은 쪽과 높은 쪽으로 나눠 보면 4.5 미만 39건 중 9건(23.1%), 5.5 초과 39건 중 11건(28.2%), 기준 안 372건 중 30건(8.1%)이다. 양쪽 끝이 모두 높다. 교육용 가상 데이터로 그린 그림, 연습용 기준.

체크포인트 TypeError: Cannot perform 'ror_' …가 나오면 두 조건 중 하나의 괄호 ( )가 빠진 것이다. | 자리에 or를 쓰면 ValueError가 난다. &를 쓰면 0 0이 나오고 둘째 셀에서 ZeroDivisionError가 난다. 첫 셀이 실패한 채 둘째 셀을 실행하면 NameError: name 'vac_out_fail' is not defined가 난다 — 첫 셀부터 고친다. 오류 없이 틀리는 경우: 78 58이면 합격(1)을 센 것이다. 불합격률이 4.4면 df로 나눈 것이다(범위 밖 표 vac_out으로 나눈다). 기준선이 26.7로 나오면 문제 1 셀을 실행하지 않아 1단계 가게 기록의 base_rate가 남아 있다 — 문제 1 셀부터 다시 실행한다.

문제 4 — Orange Correlations로 1위 쌍 찾고 파이썬과 비교하기

  1. 왼쪽 Unsupervised 묶음에서 Correlations를 끌어 와 File과 잇고 더블클릭한다.
  2. 맨 위 칸이 Pearson correlation, 그 아래 칸이 (All combinations)인지 확인한다.

  4. 목록 바로 위 Filter ... 칸에 진공도를 입력해, 진공도가 들어간 쌍 중 크기(부호를 뗀 값)가 가장 큰 값을 읽는다.

문제 3에서 진공도는 범위 밖 불합격률이 기준선보다 높았다. 그런데 Correlations 목록에서는 진공도가 어디쯤 보이는지, 왜 그런지 한 줄로 적자.

1위 +0.710 두께_nm–온도_C → 문제 2의 0.71과 같다(Orange는 소수 셋째 자리까지 보여 준다). 2위는 +0.093 두께_nm–압력_Pa로, 1위만 뚜렷하게 크다. 진공도 쌍 중 가장 큰 값은 -0.067(습도_pct–진공도_mTorr)로 0.1도 안 된다. 이유(예): "① Correlations 목록에는 합격여부가 없어 진공도–불합격 관계는 애초에 나오지 않는다. 진공도가 들어간 쌍은 다른 센서와의 관계라 모두 0에 가깝다. ② 파이썬으로 합격여부를 숫자로 넣어 계산해도 진공도–합격여부는 약 -0.02다. 문제 3 정답의 막대 그림처럼 범위 밖 양쪽(4.5 미만, 5.5 초과)에서 불합격이 늘어 한 방향 띠가 아니기 때문이다."
체크포인트 목록은 모두 28쌍이다. 측정시간이 들어간 쌍이 보이는 것은 정상이다(시간 열을 숫자로 바꿔 계산한다). 합격여부·설비번호·공정명은 목록에 없다. 값이 다르게 보이면 맨 위 칸이 Spearman correlation으로 바뀌지 않았는지 확인한다. 막히면 같은 폴더의 week08_2_anomaly_done.ows를 연다.

문제 5 — 해석 문장 쓰기

오늘의 질문 "여러 공정 값 중 불합격과 관련 있어 보이는 것을 어떻게 찾고, 그것을 '원인'이라고 불러도 될까?"에 문제 1·3의 숫자로 답하자.

문장 틀 "진공도가 연습용 기준 밖일 때 불합격률이 ______%로 기준선 ______%보다 (높아서 / 높지 않아서), 진공도는 불합격의 원인 후보(다 / 가 아니다). 원인이라고 말하려면 ______________이 필요하다."

이어서 판단해 보자: 이 숫자만으로 "진공도 때문에 불합격이 났다"고 보고해도 될까? 한 줄로 이유를 적는다.

"진공도가 연습용 기준 밖일 때 불합격률이 25.6%로 기준선 11.1%보다 높아서(약 2.3배), 진공도는 불합격의 원인 후보다. 원인이라고 말하려면 진공도만 바꿔 보는 실험이나 설비 점검 기록 같은 다른 근거가 필요하다."
판단(예): "아직 안 된다. 범위 밖 78건 중 58건은 합격이었고, 같은 때 다른 조건도 함께 달랐을 수 있다. 데이터로는 '함께 나타났다'까지만 말할 수 있다."
