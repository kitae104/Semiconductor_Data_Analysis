# 8차시 강의 운영안 — 공정 이상과 원인 후보 찾기

## 수업 흐름

1. 복습: 7차시 수율·불량률·파레토 분석
2. 오늘의 질문 제시 — "온도가 이상했던 시점과 불량이 발생한 시점이 겹칠까?"
3. 개념 설명: 이상치, 관리 상/하한, 상관관계, 인과관계와의 차이, "원인 후보" 표현
4. 강사 코드 시연: 진공도 임계값 이상탐지 ~ 상관계수 계산
5. 휴식
6. 학생 실습: 정상 범위 설정 → 이탈 데이터 찾기 → 온도-두께 산점도/상관계수 → 습도 대조군 확인
7. 도전 실습: 냉각수온도-공정온도 시차 패턴 찾기
8. 정리 퀴즈 + 다음 차시 예고

## 준비물
- `data/weekly/week08/week08_anomaly_root_cause.csv`
- 발표용 산점도 이미지(강의 자료에 포함되어 있음)
- Orange3(Correlations 위젯 시연용, 설치·사용법은 `docs/orange3-guide.html` 참고)

## 강사 설명 포인트
- **상관관계 ≠ 인과관계**를 이번 시간의 핵심 메시지로 반복 강조한다. "상관계수가 높다 = 원인이다"라고
  성급하게 결론짓지 않도록 여러 차례 짚어준다.
- 습도(대조군) 사례를 반드시 다룬다 — "상관관계가 없다"는 결과도 유효한 분석 결과임을 보여준다.
- 실제 수치(진공도 이탈 78건, 이탈 시 불합격률 25.64% vs 정상 8.06%, 온도-두께 r=0.71,
  습도-불합격 r=-0.13)를 칠판에 적어두고 수업 내내 참조한다.

## 질문 예시
- "상관계수가 0.9로 매우 높게 나왔다면, 그것만으로 원인이라고 확신할 수 있을까요?"
- "습도처럼 '관계가 없다'는 결과를 얻었을 때, 이것도 의미 있는 발견일까요?"

## 예상 오개념
- 상관계수가 높으면 곧 원인이라고 오해하기 쉽다 → "제3의 변수가 두 변수를 동시에 움직였을 수도
  있다"는 예시(예: 아이스크림 판매량과 익사 사고 수가 모두 여름에 증가하는 것은 "더위"라는
  제3의 원인 때문)를 들어 설명한다.
- 상관계수가 0에 가까우면 "분석이 실패했다"고 오해하기 쉽다 → 오히려 유용한 정보임을 강조한다.

## 실습 중 오류 대응
- `corr()` 사용 시 문자열 열이 섞여 있으면 오류가 날 수 있다 → 숫자 열만 선택했는지 확인.
- 조건식에서 `&`, `|`를 `and`, `or`로 잘못 쓰는 실수가 흔하다 → 판다스 조건식은 `&`/`|`를
  사용해야 하며 각 조건을 괄호로 감싸야 함을 강조.

## 빠른 학습자용 추가 과제
- 압력_Pa와 불합격 여부의 관계도 같은 방식(정상 범위 안/밖 비교)으로 확인해보게 한다.
- 냉각수온도와 온도의 상관계수를 시차(lag)를 주지 않고 그냥 계산했을 때와, 몇 시간 뒤와
  비교했을 때 어떻게 달라지는지 생각해보게 한다(정답을 요구하지 않고 사고를 유도).

## 느린 학습자용 최소 과제
- 온도-두께 산점도만 그려보고, "점들이 오른쪽 위로 갈수록 흩어져 있는지"만 관찰하게 한다.
- 진공도 이탈 여부에 따른 불합격률 두 숫자(8.06% vs 25.64%)만 비교해 "어느 쪽이 더 높은가"를 말해보게 한다.
