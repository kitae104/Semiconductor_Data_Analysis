리스트·딕셔너리로 배우는 조건문·반복문·함수 — 실습지

설비 기록 30건(교육용 가상 데이터)의 온도가 연습용 기준 295~305도 안인지 판정한다. 우리 코드는 "범위 안"/"범위 밖"만 판정한다. 이것은 연습용 기준으로 본 판정이고, 실제 검사 결과(합격여부: 1 = 합격, -1 = 불합격)와는 다를 수 있다. 기준 밖 기록은 몇 건이고, 그중 실제 불합격은 몇 건일까?

문제 1. 온도 하나 판정하기 (노트북 7단계 문제 1)

온도가 295 이상 305 이하이면 범위 안입니다., 아니면 범위 밖입니다.를 출력하도록 빈칸을 채우자. 실행하기 전에 293.8이 어느 쪽일지 먼저 예측해 본다.

힌트: 강의 "if/else — 둘 중 하나 고르기"의 36.0 <= body_temp <= 37.5와 같은 모양이다.

Python
temperature = 293.8

# TODO: 범위의 아래 끝과 위 끝 숫자를 채우세요.
if ____ <= temperature <= ____:
    print("범위 안입니다.")
else:
    print("범위 밖입니다.")
빈칸은 순서대로 295, 305. 출력: 범위 밖입니다. — 293.8은 295보다 작다.

문제 2. EQ-03 온도 중 범위 안인 값 직접 세기 (노트북 7단계 문제 2)

설비 EQ-03의 온도 11개 가운데 295~305도 안인 값이 몇 개인지 센다. 이번에는 빈칸이 없다. 노트북 셀에 온도 리스트만 있고, 세는 코드는 그 아래에 직접 쓴다.

Python — 노트북에 주어진 셀
eq03_temps = [304.4, 304.3, 293.8, 296.7, 308.0, 298.8, 299.5, 297.8, 306.3, 301.1, 312.4]

# TODO: 여기에 직접 써 보세요 — in_count를 0으로 시작 → for → if → 1 늘리기 → print
  1. 세는 변수 in_count를 for 바깥에서 0으로 시작한다.
  2. for temp in eq03_temps:로 하나씩 꺼낸다.
  3. 꺼낸 값이 295 이상 305 이하이면 in_count를 1 늘린다.
  4. 다 센 뒤 EQ-03 온도 11개 중 범위 안은 ○개입니다.를 f-string으로 출력한다.

힌트: 강의 "for — 하나씩 꺼내 개수 세기"의 pass_count 코드와 같은 모양이다. 이름만 바꾼다.

주의 3단계 코드를 베끼다 pass_count가 섞이면 3단계에서 센 값이 더해져 오류 없이 엉뚱한 숫자가 나온다. 새 이름 in_count로 통일한다. 
eq03_temps = [304.4, 304.3, 293.8, 296.7, 308.0, 298.8, 299.5, 297.8, 306.3, 301.1, 312.4]

in_count = 0

for temp in eq03_temps:
    if 295 <= temp <= 305:
        in_count = in_count + 1

print(f"EQ-03 온도 {len(eq03_temps)}개 중 범위 안은 {in_count}개입니다.")
출력: EQ-03 온도 11개 중 범위 안은 7개입니다.
범위 밖 4개는 293.8 · 308.0 · 306.3 · 312.4다.

문제 3. check_range로 기록 30건 판정하기 (노트북 7단계 문제 3)

온도가 295~305이면 "범위 안", 아니면 "범위 밖"을 돌려주는 함수 check_range를 만들고, 기록 30건을 판정해 보자.

힌트: 강의 "함수 — 판정 규칙에 이름 붙이기"의 judge_score, "함수와 for 함께 쓰기"의 fail_count와 같은 모양이다. 기록에서 온도를 꺼내는 모양 record["온도_C"]는 강의 "반도체 데이터로 확인하기" 확인 2에 있다.

Python — 3-1 판정 함수
# TODO: 결과를 돌려주는 낱말을 채우세요.
def check_range(temp):
    if 295 <= temp <= 305:

    else:

print(check_range(301.0))

다음 노트북 셀에는 기록 30건이 딕셔너리의 리스트 records로 이미 적혀 있다. 그 셀은 고치지 않고 실행만 한다(30이 출력된다).

Python — 3-2 연습용 기준 밖 기록 세기
out_total = 0

# TODO: 함수에 넣을 온도 값(딕셔너리에서 꺼내기)과 비교할 글자를 채우세요.
for record in records:
    if check_range(____) == ____:
        out_total = out_total + 1

Python — 3-3 그중 실제 불합격 세기
real_fail = 0

# TODO: 실제 불합격을 뜻하는 숫자를 채우세요.
for record in records:
    if check_range(record["온도_C"]) == "범위 밖":
        if record["합격여부"] == ____:

print(f"그중 실제 검사에서 불합격(-1)인 기록: {real_fail}건")
주의
  • 함수에 넣을 것은 지금 꺼낸 기록의 온도 record["온도_C"]다. temp를 넣으면 문제 2의 마지막 값이 남아 있어 오류 없이 엉뚱한 숫자가 나온다. record를 통째로 넣으면 TypeError가 난다.
  • "범위 밖"의 따옴표를 빼먹으면 SyntaxError가 난다. 비교는 ==(등호 두 개)다.
  • 3-1 함수 셀을 먼저 채우고 실행하지 않으면 3-2에서 NameError: name 'check_range' is not defined가 난다.
3-1 빈칸은 return, return. 출력: 범위 안, 범위 밖.
3-2 빈칸은 record["온도_C"], "범위 밖". 출력: 연습용 기준 밖 기록: 12건
3-3 빈칸은 -1. 출력: 그중 실제 검사에서 불합격(-1)인 기록: 3건
3-3은 if 안에 if가 하나 더 들어 있다. 바깥 조건(연습용 기준 밖)과 안쪽 조건(실제 불합격)을 둘 다 만족해야 센다.

문제 4. Orange로 기준 밖 기록과 실제 불합격 고르기

Orange 3.35에서 week03_2_records_start.ows를 새로 연다. 강의 PART 2에서 설비번호 is EQ-04 조건을 걸었던 화면은 저장하지 않고 닫는다. 이번에는 기록 30건 전체에서 고른다.

  1. File에 Select Rows(Transform 묶음)를 잇고 더블클릭한다.
  2. 이미 있는 조건 한 줄을 온도_C · is outside · 왼쪽 칸 295, 오른쪽 칸 305로 바꾼다.
  3. Select Rows에 Data Table을 잇고, 왼쪽 Info 칸에서 행 수를 읽는다.
  4. Select Rows 창으로 돌아가 Add Condition으로 두 번째 줄을 만들고 합격여부 · is · -1로 정한다. Data Table의 행 수를 다시 읽는다.
적어 보기 온도 조건만: ____행 · 합격여부 조건까지: ____행
문제 3의 3-2, 3-3 결과와 비교하면 (같다 / 다르다).
마지막에 남은 기록의 로트번호: ________________
체크포인트 온도 조건만 걸면 12행, 합격여부 조건까지 걸면 3행이다. 문제 3의 12건·3건과 같다.
남은 3행: LOT-0186(EQ-03, 293.8) · LOT-0195(EQ-02, 293.8) · LOT-0085(EQ-04, 307.0).
30행이 그대로라면 is outside의 두 칸 순서가 바뀌었거나(왼쪽이 305) 한 칸이 비어 있다. 18행이면 is between을 고른 것이다(범위 안 18 + 범위 밖 12 = 30). 8행이나 4행이면 높은 쪽(is greater than 305)이나 낮은 쪽(is below 295)만 고른 것이다.

문제 5. 이 숫자로 말할 수 있을까?

팀장이 문제 3·4 결과를 보고 이렇게 말했다.

팀장의 말 "온도가 연습용 기준 밖인 기록은 전부 불량이니까, 그 로트들은 모두 버리자."

오늘 숫자로 볼 때 이 말에 동의할 수 있을까? (예 / 아니오)를 고르고, 이유를 숫자를 넣어 한두 문장으로 쓰자.

힌트: 기준 밖 기록 중 실제 검사(합격여부)에서 불합격인 것은 몇 건이었나? 나머지는?

아니오. "기준 밖 기록 12건 중 실제 불합격은 3건이고 9건은 합격이었습니다. 기준 밖은 불량이 아니라 살펴볼 후보이므로, 모두 버리기 전에 실제 검사 결과와 다른 정보를 함께 확인해야 합니다."
연습용 기준으로 본 판정과 실제 검사 결과는 다르다. 기준은 확인할 후보를 골라 주는 거름망이다.
