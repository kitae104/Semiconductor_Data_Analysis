왜 이걸 배워야 할까?

  • 모든 문제는 공정 온도·가상 공장 기록(반도체 데이터)으로 푼다. 힌트의 "○단계"는 같은 모양의 쉬운 예제가 있는 노트북 단계다.
  • 295~305℃는 이 과정의 학습용 기준이고, 공정 데이터는 교육용 가상 데이터다.

문제 1 — 공정 온도에 질문하기 (노트북 8단계)

할 일: 온도 312.6, 설비 EQ-03에 네 가지 질문을 던지고, 305보다 크면 경고를 출력한다.
힌트: 1단계(시험 점수)와 같은 모양. score → temperature, subject → equipment, 80 → 305.

Python
temperature = 312.6
equipment = "EQ-03"

print(temperature > 305)
print(temperature <= 305)
print(equipment ____ "EQ-03")
print(equipment != "EQ-03")

if temperature ____ 305:
    print("온도가 범위보다 높습니다!")
print("판정 끝")
빈칸: ==, >. 출력: True, False, True, False, 온도가 범위보다 높습니다!, 판정 끝.

문제 2 — 공정 온도를 범위로 판정하기 (노트북 8단계)

할 일: 301.0을 범위 안/밖으로, 293.8을 높음·정상·낮음으로 판정한다.
힌트: 2단계(체온)와 같은 모양. 36.0 → 295, 37.5 → 305.

Python
temperature = 301.0

if 295 <= temperature <= 305:
    print("정상 범위입니다.")
____:
    print("범위 밖입니다.")

temperature = 293.8

if temperature > 305:
    print("높음")
____ temperature >= 295:
    print("정상")
else:
    print("낮음")
빈칸: else, elif. 출력: 정상 범위입니다., 낮음(293.8은 범위 아래쪽).

오류 찾기 — 콜론과 들여쓰기 (노트북 8단계 아래 빈 셀에 붙여 넣어 실행)

Python — 오류 있는 코드
temperature = 301.0
if 295 <= temperature <= 305:
print("정상 범위입니다.")
else
    print("범위 밖입니다.")
① if 다음 줄에 스페이스 4칸(없으면 IndentationError: expected an indented block after 'if' statement on line 2). ② else → else:(없으면 SyntaxError: expected ':').

문제 3 — 정상 범위인 온도 세기 (노트북 9단계)

할 일: 온도 5개를 출력하고, 295~305 안인 값의 개수를 센다.
힌트: 3단계(80점 이상 세기)와 같은 모양. 조건 score >= 80 대신 295 <= temp <= 305.

Python
temperatures = [295.4, 298.1, 312.6, 301.0, 296.8]

for temp ____ temperatures:
    print(temp)

normal_count = 0

for temp in temperatures:
    ____ 295 <= temp <= 305:
        normal_count = normal_count ____ 1

print(f"정상 범위인 값은 {normal_count}개입니다.")
체크포인트 빈칸: in, if, +. 결과 정상 범위인 값은 4개입니다.(312.6만 범위 밖). normal_count = 0이 반복문 안에 있으면 틀린 숫자가 나온다.

문제 4 — 온도 5개의 합계와 평균 (노트북 9단계)

할 일: 문제 3의 온도 5개 합계와 평균을 소수 첫째 자리까지 출력한다.
힌트: 4단계(용돈 합계)와 같은 모양. money → temp.

Python
total = 0

for temp in temperatures:
    total ____ temp

average = total / len(temperatures)
print(f"합계 {total:.1f}, 평균 {average:.1f}")
빈칸: +=. 결과 합계 1503.9, 평균 300.8. 평균은 범위 안이어도 312.6이 섞여 있다.

문제 5 — 온도가 높은 설비 골라내기 (노트북 9단계)

할 일: 노트북 9단계의 equipment_list(설비 3대: EQ-01 301.2, EQ-02 308.7, EQ-03 297.5)에서 온도가 305도를 넘는 설비 번호만 담는다.
힌트: 5단계(80점 넘은 학생)와 같은 모양. "점수" → "온도_섭씨", "이름" → "설비번호".

    if eq["온도_섭씨"] ____ 305:
        hot_equipment.____(eq["설비번호"])

빈칸: >, append. 결과 온도가 305도를 넘는 설비: ['EQ-02'](308.7도).

문제 6 — 평균 함수와 judge_pass 만들기 (노트북 10단계)

할 일: 평균 함수에 온도 5개를 넣고, 온도 판정 함수 judge_pass로 온도 5개를 판정한다.
힌트: 6단계(calculate_average, judge_score)와 같은 모양. 빈칸은 6단계 평균 함수 이름, return, 판정 함수 이름이다.

    if 295 <= temp <= 305:
        ____ "합격"
    else:
        ____ "불합격"

print(judge_pass(301.0))
print(judge_pass(312.6))

빈칸: calculate_average, return, return, judge_pass. 결과 300.78(문제 4는 :.1f로 반올림해 300.8로 보였다), 합격, 불합격, 온도 5개 중 312.6만 "불합격". 이 판정은 실제 검사 결과(합격여부)와 다르다.

문제 7 — 기록 30건을 온도 규칙으로 걸러내기 (노트북 11단계)

할 일: 노트북의 records(30건, 합격여부 1 = 합격, -1 = 불합격)에서 judge_pass로 "불합격" 판정된 기록 수를 센다.
힌트: 7단계(학생 명단 불합격 세기)와 같은 모양. judge_score(student["점수"]) → judge_pass(record["온도_섭씨"]).

        rule_fail ____ 1

빈칸: judge_pass, +=. 결과 온도 규칙으로 걸러낸 기록: 12건.
