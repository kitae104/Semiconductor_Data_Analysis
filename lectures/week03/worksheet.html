리스트·딕셔너리로 배우는 조건문·반복문·함수 — 실습지

왜 이걸 배워야 할까?

  • "온도가 정상 범위 안이면 규칙상 통과(합격 판정)" 같은 판정을 사람이 수십만 줄에 하나씩 할 수는 없다. 규칙(if)을 알려주고 반복(for)을 시키면 컴퓨터가 같은 기준으로 끝까지 판정한다. 자주 쓰는 판정은 함수(def)로 저장해 둔다.
  • 이 실습지의 정상 범위 295~305℃는 이 과정의 학습용 기준이고, 데이터는 교육용 가상 데이터다.

1. 용어 연결 문제

왼쪽 용어와 오른쪽 설명을 알맞게 연결해보자.

용어설명 후보
① 비교 연산자A. 리스트의 값을 처음부터 하나씩 꺼내 같은 일을 반복하는 문장
B. 조건이 참일 때만 정해 둔 코드를 실행하게 하는 문장
C. 자주 쓰는 계산을 이름 붙여 저장해 둔 레시피
D. 함수가 만든 결과를 부른 쪽에 돌려주는 키워드
E. 두 값을 비교해 True/False로 답하는 기호
② 조건문(if)
③ 반복문(for)
④ 함수(def)
⑤ return
① E ② B ③ A ④ C ⑤ D

2. 비교 연산자 결과 예측 문제

temperature = 293.8, equipment = "EQ-02"일 때 각 줄의 결과가 True인지 False인지 적어보자.

코드결과
print(temperature > 305)( )
print(temperature < 295)( )
print(equipment == "EQ-02")( )
print(equipment != "EQ-02")( )
순서대로 False, True, True, False. ==는 "같은가?", !=는 "다른가?"를 묻는다. 값을 저장하는 =와 다르다.

3. 오류 찾기 문제 — 콜론과 들여쓰기

아래 코드는 실행하면 오류가 난다. 어디가 문제인지 찾아 고쳐보자.

Python — 오류 있는 코드
temperature = 301.0
if 295 <= temperature <= 305:
print("정상 범위입니다.")
else
    print("범위 밖입니다.")
문제 두 곳: ① if 다음 줄 print("정상 범위입니다.")가 들여쓰기 되어 있지 않다 → 앞에 스페이스 4칸. 파이썬은 이것부터 발견해 IndentationError: expected an indented block after 'if' statement on line 2를 낸다. ② else 끝에 콜론이 없다 → else:. 고치지 않으면 SyntaxError: expected ':'가 난다.

4. 코드 빈칸 문제 — 개수 세기

정상 범위(295~305) 안인 온도의 개수를 세는 코드다. 빈칸을 채우고 결과를 예측해보자.

Python
temperatures = [295.4, 298.1, 312.6, 301.0, 296.8]
normal_count = 0

____ temp in temperatures:
    ____ 295 <= temp <= 305:
        normal_count ____ 1

print(f"정상 범위인 값은 {normal_count}개입니다.")
순서대로 for, if, +=. 결과는 정상 범위인 값은 4개입니다. (312.6만 범위 밖이다). normal_count = 0은 반복문 밖에서 한 번만 쓴다.

5. 결과 예측 문제 — 세 갈래 판정

아래 코드에서 temperature에 세 값을 차례로 넣으면 각각 무엇이 출력될까?

Python
if temperature > 305:
    print("높음")
elif temperature >= 295:
    print("정상")
else:
    print("낮음")
temperature출력
308.0( )
300.0( )
290.0( )
순서대로 높음, 정상, 낮음. 위에서부터 묻다가 처음으로 참인 곳에서 멈춘다. 300.0은 첫 질문(305보다 큰가?)이 거짓, 둘째 질문(295 이상인가?)이 참이라 "정상"이다.

6. 함수 빈칸 문제 — judge_pass

Python
____ judge_pass(temp):
    if 295 <= temp <= 305:
        ____ "합격"
    else:
        ____ "불합격"

print(judge_pass(294.9))
  1. 빈칸 세 곳에 들어갈 키워드는?
  2. 마지막 줄은 무엇을 출력할까?
1) 순서대로 def, return, return. def는 레시피를 적는 것(정의), return은 결과를 돌려주는 것이다. 2) 불합격. 294.9는 295보다 작아 범위 밖이다.

7. 결과 해석과 문장 쓰기

오늘 종합 실습(가상 기록 30건)의 결과를 정리하면 아래와 같다.

온도 규칙의 판정기록 수실제 합격(1)실제 불합격(-1)
범위 안 → "합격"18건18건0건
범위 밖 → "불합격"12건9건3건
문장 작성 빈칸을 채워보자. "판정 함수로 기록 30건을 판정하니 ____건이 범위 밖으로 걸러졌다. 그러나 실제 검사 불합격은 ____건이고, 범위 밖 기록 중 ____건은 합격했다. 따라서 온도 규칙 하나로는 합격·불합격을 ____."
"판정 함수로 기록 30건을 판정하니 12건이 범위 밖으로 걸러졌다. 그러나 실제 검사 불합격은 3건이고, 범위 밖 기록 중 9건은 합격했다. 따라서 온도 규칙 하나로는 합격·불합격을 다 설명할 수 없다." 규칙은 "더 살펴볼 기록"을 골라 주는 첫 번째 거름망이고, 다른 열도 함께 봐야 한다.

8. 도전 — 합격률 구하기

도전 records를 한 번 돌면서 합격여부가 1이면 pass_count를, 아니면 fail_count를 1씩 늘리고, pass_count / len(records) * 100으로 합격률을 구해 출력해보자. (노트북 6단계 "도전 문제 1")
체크포인트 결과는 합격 27건, 불합격 3건, 합격률 90.0%다. 합격과 불합격을 더하면 30이어야 한다. 둘을 동시에 셀 때는 if / else로 나누고, 두 변수 모두 반복문 밖에서 0으로 시작한다.

9. 도전 — 범위 밖인데 합격한 기록 찾기

도전 judge_pass로는 "불합격"인데 실제 합격여부는 1인 기록의 로트번호만 surprise_list에 모아보자. if 안에 if를 한 번 더 쓴다. (노트북 6단계 "도전 문제 2")
체크포인트 len(surprise_list)는 9다. 안쪽 if는 8칸, 그 안의 append 줄은 12칸 들여쓴다. 칸 수가 어긋나면 IndentationError가 난다.
