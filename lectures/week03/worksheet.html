조건문, 반복문, 함수 — 실습지

🤔 왜 이걸 배워야 할까?

  • "불합격만 찾기", "이상 온도만 걸러내기" 같은 판단을 사람이 수천 줄을 눈으로 보며 할 수는 없다. if는 판정 규칙을, for는 그 규칙을 모든 데이터에 반복 적용하는 방법을, def는 그 로직을 재사용하는 방법을 알려주며, 이는 4차시부터 배우는 Pandas 조건 검색이 내부적으로 하는 일과 같다.
쉬운 예시 "온도가 305도를 넘으면 불합격"이라는 규칙 하나를 if로 만들고, for로 측정값 100개에 반복 적용하면, 사람이 100번 눈으로 비교하지 않고도 몇 건이 불합격인지 즉시 알 수 있다. 이 판정 로직을 함수로 만들어두면 내일 측정한 새 데이터에도 그대로 다시 쓸 수 있다.

④ return
① B ② A ③ C ④ D

2. 코드 빈칸 문제

Python
temperatures = [295.4, 298.1, 312.6, 301.0, 296.8]
count = 0

____ temp in temperatures:
    ____ 295 <= temp <= 305:
        count ____ 1

print(count)
순서대로 for, if, +=. 결과는 4다 (312.6만 정상범위를 벗어난다).

3. 결과 예측 문제

아래 코드를 실행하면 무엇이 출력될지 먼저 예측해보고 정답을 확인하자.

Python
def judge(temp):
    if temp > 305:
        return "고온"
    elif temp < 295:
        return "저온"
    else:
        return "정상"

print(judge(310.0))
print(judge(290.0))
print(judge(300.0))
정답: 고온, 저온, 정상. 위에서부터 순서대로 조건을 검사하다가 처음 참인 곳에서 멈춘다.

4. 오류 찾기 문제

아래 코드는 실행하면 오류가 난다. 어디가 문제인지 찾아 고쳐보자.

Python — 오류 있는 코드
temperature = 301.0
if temperature > 305:
print("고온입니다.")
else:
print("정상입니다.")
문제: if/else 다음 줄이 들여쓰기 되어 있지 않아 IndentationError가 발생한다. 수정: print(...) 앞에 공백 4칸을 추가해야 한다.

5. 계산 문제

설비 3대의 딕셔너리 리스트가 아래와 같다.

equipment_list = [
    {"설비번호": "EQ-01", "온도_섭씨": 301.2},
    {"설비번호": "EQ-02", "온도_섭씨": 308.7},
    {"설비번호": "EQ-03", "온도_섭씨": 297.5},
]

for와 if를 사용해 온도가 305도를 넘는 설비가 몇 대인지 세는 코드를 손으로 적어보자(직접 실행하지 않고 코드만 작성).

count = 0
for eq in equipment_list:
    if eq["온도_섭씨"] > 305:
        count += 1
print(count) → 결과는 1(EQ-02만 해당).

6. 도전 문제

도전 매개변수를 2개 받는 함수 judge_range(value, limit)를 만들어, value가 limit를 넘으면 "초과", 아니면 "정상"을 반환하도록 작성해보자. 그리고 이 함수를 온도 리스트와 압력 리스트 양쪽에 재사용해보자.

7. 심화 실습

심화 값 리스트와 기준값을 받아 기준을 초과하는 개수를 반환하는 함수 count_exceed(values, limit)를 만들어보자(함수 안에서 for와 if로 개수를 센 뒤 return한다). 이 함수를 아래 온도 리스트와 압력 리스트에 각각 적용해 초과 건수를 구하고, 두 리스트 중 어느 쪽의 "초과 비율(초과 건수 ÷ 전체 개수)"이 더 높은지 비교해보자. 
temperatures = [295.4, 298.1, 312.6, 301.0, 296.8]
pressures = [980, 1010, 1050, 995, 1120]
체크포인트 return count를 for 문 안쪽(들여쓰기 8칸)에 넣으면 첫 번째 값을 검사하자마자 함수가 끝나버려 잘못된 결과가 나온다. return은 for 문이 모두 끝난 뒤 실행되도록 for와 같은 들여쓰기 위치에 두어야 한다.
