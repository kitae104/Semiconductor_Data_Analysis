# 3차시 강의 운영안 — 리스트·딕셔너리로 배우는 조건문·반복문·함수

## 왜 이걸 배워야 할까? (학생에게 전달할 메시지)

공장에는 "온도가 정상 범위 안이면 통과" 같은 판정 규칙이 있다. 기록이 30줄이면 사람이 눈으로 확인할 수 있지만,
실제 공장은 하루에도 수십만 줄의 기록을 남긴다(1차시). 한 줄에 3초씩만 잡아도 30만 줄이면 약 250시간이다.
그래서 판정을 컴퓨터에게 맡긴다. `if`는 규칙을 알려주고, `for`는 그 규칙을 모든 기록에 반복하고, `def`는 자주 쓰는
판정에 이름을 붙여 저장한다.

**비유**: 정답표(규칙)를 한 번 넣어 주면 답안지 수천 장을 같은 기준으로 채점하는 시험 채점기.

## 수업 흐름

1. 복습: 1차시 `=`(저장하라), 2차시 리스트·딕셔너리와 `equipment_list[0]["온도_섭씨"]`. "설비가 300대라면 번호를 300번 바꿀까요?"
2. 왜 자동화가 필요한가: 30줄 vs 수십만 줄, 채점기 비유
3. 조건문(STEP 01): 비교 연산자(True/False) → `=`와 `==` → `if`와 들여쓰기(가장 흔한 오류) → `if`/`else`(정상 범위) → `if`/`elif`/`else`(높음·정상·낮음, 순서의 중요성)
4. 반복문(STEP 02): `for`로 하나씩 꺼내기(출석부 비유) → 개수 세기(손가락 접기) → 누적 합과 평균 → 딕셔너리의 리스트 → `append()`로 골라내기
5. 휴식
6. 함수(STEP 03): 레시피 비유(정의 = 적어 두기, 호출 = 요리하기, 매개변수 = 재료 칸, `return` = 완성된 요리) → `calculate_average` → `judge_pass` → 반복문 안에서 호출
7. 종합(STEP 04): 기록 30건의 열 의미 다시 짚기 → 온도 규칙으로 걸러내기(12건) → 걸러낸 기록의 실제 결과 보기 → 실제 불합격 세기(3건) → "규칙 하나로 다 설명되지 않는다"(발열 체크 비유, 1차시 관찰과 연결)
8. 학생 실습: 학생용 노트북 1~6단계. 먼저 끝난 학생은 6단계 끝 "도전 문제 1·2"
9. AI 활용(노트북 7·8단계) → 연습문제(9단계) → 온도 뽑기 심판 미니 프로그램(10단계)
10. 정리 퀴즈 + 과제 안내 + 4차시 예고(Pandas가 오늘 일을 한 줄로)

## 강사 설명 포인트
- **들여쓰기를 오늘의 1순위 오류로 다룬다.** `if` 다음 줄을 일부러 들여쓰지 않고 실행해 `IndentationError`를 화면에 띄운 뒤,
  스페이스 4칸을 넣어 고치는 과정을 보여준다. "들여쓰기는 장식이 아니라 '이 줄은 위 if에 속한다'는 표시"라고 말한다.
- `if` 예제의 `print("판정 끝")`은 일부러 들여쓰지 않았다. `temperature`를 301.0으로 바꿔 다시 실행하면 "판정 끝"만 나오는 것을
  보여주면 "들여쓴 줄만 조건에 따라 실행된다"가 바로 전달된다.
- `=`와 `==`: 1차시 "이름표 붙은 상자" 그림을 다시 띄우고 "`=`는 상자에 넣기, `==`는 상자 속 값이 같은지 묻기"로 구분한다.
- `elif`는 "위에서부터 묻다가 처음 참인 곳에서 멈춘다"를 강조한다. 두 조건의 순서를 바꿔 312.6이 "정상"으로 잘못 나오는 것을
  보여주면 효과가 크다.
- 누적 변수는 `normal_count = 0`을 반복문 **안**으로 옮겨 실행해 `1`이 나오는 것을 직접 보여준다. 오류 없이 틀린 숫자가 나와서 더 위험하다는 점을 말한다.
- 함수는 "레시피" 비유 하나로 끝까지 설명한다. 매개변수와 `return`은 "재료 칸"과 "완성된 요리" 정도로만 다룬다.
  `def` 셀을 실행해 아무것도 출력되지 않는 것을 보여주고 "오류가 아니라 레시피를 적어 둔 것"이라고 말한다.
- **판정 기준은 학습용이다.** 295~305℃는 이 과정에서 정한 연습용 범위이고 실제 공정의 기준이 아니다. 학생이 실제 기준을 물으면
  "공정마다 다르고 설계 단계에서 정한다. 이 데이터의 온도 값도 교육용으로 만든 숫자다"라고 답한다.
- **종합의 핵심 메시지는 "규칙 하나로 다 설명되지 않는다"이다.** 12건을 걸러냈는데 실제 불합격은 3건, 범위 밖인데 합격한 기록이 9건이다.
  1차시(불합격 8건 중 7건은 범위 안)와 나란히 놓고, 발열 체크 비유로 "규칙은 더 살펴볼 대상을 골라 주는 첫 번째 거름망"이라고 정리한다.
  7~8차시 "여러 열 함께 보기"로 이어진다고 예고한다.
- **강사만 알고 있을 것**: 이 데이터의 `합격여부`는 온도와 관계없이 무작위로 만들어졌다(`scripts/generate_weekly_data.py`의 `gen_week03`).
  불합격 3건이 모두 범위 밖에 있는 것은 우연이다. 학생이 "그럼 온도 때문에 불합격한 거네요"라고 하면 "범위 밖인데 합격한 기록이 9건이고,
  30건뿐이라 우연일 수도 있다"로 되묻는다. 온도를 불합격의 이유처럼 강조하지 않는다.
- 한 행은 "로트 하나가 공정 하나를 거친 기록"이다. LOT-0186과 LOT-0004는 서로 다른 공정에서 두 번 기록되어 있다. 학생이 같은 번호가 두 번
  나온다고 물으면 이렇게 설명한다.

## 예상 오개념
- 들여쓰기는 보기 좋게 하는 장식이라고 생각 → 들여쓰기가 "어느 묶음에 속하는지"를 정한다. 빠뜨리면 `IndentationError`.
- `=`와 `==`를 같은 것으로 생각 → `if temperature = 305:`가 `SyntaxError`를 내는 것을 보여준다.
- `elif`를 여러 개 쓰면 모두 검사한다고 생각 → 처음 참인 곳에서 멈춘다.
- `for temp in temperatures`의 `temp`가 미리 정해진 이름이라고 생각 → 내가 붙이는 이름이다.
- `def`만 실행하면 결과가 나온다고 생각 → 이름을 불러야(호출) 실행된다.
- 범위 밖 = 무조건 불량이라고 생각 → 범위 밖 12건 중 9건은 합격. 판정 기준은 학습용이고 규칙 하나로 다 설명되지 않는다.

## 실습 중 오류 대응
- `IndentationError: expected an indented block after 'if' statement on line 3`: 콜론 다음 줄을 들여쓰지 않았다.
  스페이스 4칸을 넣게 한다(`for` 안의 `if` 안이면 8칸). `for`·`def` 뒤에서는 메시지의 `'if' statement` 자리가 바뀐다.
- `IndentationError: unindent does not match any outer indentation level`: 같은 묶음 안에서 칸 수가 다르다(4칸과 2칸 등). 칸 수를 맞추게 한다.
- `SyntaxError: expected ':'`: `if`·`else`·`for`·`def` 줄 끝의 콜론이 빠졌다.
- `SyntaxError: invalid syntax. Maybe you meant '==' or ':=' instead of '='?`: 조건에 `=`를 하나만 썼다. `==`로 고치게 한다.
- `SyntaxError: invalid syntax`: 학생용 노트북의 빈칸 `____`을 채우지 않고 실행한 경우가 대부분이다(예: `if temperature ____ 305:`).
- `NameError: name '____' is not defined`: 값·이름 자리의 빈칸을 채우지 않고 실행했다(예: `temperature = ____`).
- `NameError: name 'judge_pass' is not defined`: 5단계 `judge_pass` 셀을 실행하지 않았거나, 그 셀의 빈칸을 못 채워 함수가 만들어지지 않았다.
  6단계 이후 셀이 연달아 이 오류를 내면 5단계로 돌아가게 한다.
- 오류는 없는데 개수가 0이나 1로 나옴: 세는 변수(`= 0` 줄)가 반복문 안에 들어가 있다.
- AI 코드를 붙여넣은 뒤 6단계 결과가 달라짐: AI 코드 안의 `records = [...]`가 30건을 덮어썼다. 6단계 첫 셀을 다시 실행하게 한다.

## 느린 학습자용 최소 과제
- 노트북 1단계 `if`/`else`(정상 범위 판정)와 3단계 `for temp in temperatures: print(temp)`까지만 성공해도 충분하다.
- 5단계 `judge_pass` 셀은 짝 활동으로 함께 채우고, 6단계는 정답을 보며 실행만 해도 된다. 대신 "12건을 걸러냈지만 실제 불합격은 3건"이라는
  해석 문장은 꼭 직접 말해 보게 한다.
