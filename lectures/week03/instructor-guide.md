# 3차시 강의 운영안 — 리스트·딕셔너리로 배우는 조건문·반복문·함수

## 왜 이걸 배워야 할까? (학생에게 전달할 메시지)

공장 기록은 하루 수십만 줄이라 사람이 판정할 수 없다. `if`는 규칙, `for`는 반복, `def`는 자주 쓰는 판정에 이름 붙이기다.
비유: 정답표를 한 번 넣으면 답안지 수천 장을 같은 기준으로 채점하는 채점기.

수업 방식: 개념은 **쉬운 예제**(시험 점수·체온·용돈·학생 명단, 코드 속 값)로 설명하고, STEP 04 **"반도체 데이터로 확인하기"**에서
핵심(기록 30건 판정)만 시연한다. 반도체 문제 1~8은 실습지·노트북 8~11단계에서 학생이 푼다.

## 수업 흐름

1. 복습: `=`(저장), 리스트·딕셔너리. "설비가 300대라면?"
2. STEP 01 조건문: 시험 점수(비교 연산자·`if`·들여쓰기), 체온(`else`·`elif`)
3. STEP 02 반복문: 점수 세기, 용돈 합계, 학생 명단 골라내기
4. 휴식
5. STEP 03 함수: 레시피 비유, `calculate_average`·`judge_score`, 함께 쓰기(학생 불합격 판정 1명)
6. STEP 04 반도체 데이터로 확인하기(강사 시연): 예제 1 `judge_pass` → 예제 2 걸러낸 기록 12건 → 예제 3 실제 불합격 3건(먼저 예상하게 한 뒤 "결과 보기") → 발열 체크 비유
7. 학생 실습: 노트북 1~7단계(쉬운 예제 실행) → 실습지 문제 1~8 = 노트북 8~11단계(반도체) → AI(12·13단계)
8. 퀴즈·과제·4차시 예고

## 강사 설명 포인트
- 실습지 문제마다 힌트가 "어느 단계의 쉬운 예제와 같은 모양인지"를 알려 준다. 막히면 그 단계 셀을 다시 보게 한다.
- 문제 3은 `if`·`+` 빈칸, 문제 6은 `return` 두 개에서 많이 멈춘다. 3단계 개수 세기와 6단계 `judge_score`를 다시 가리킨다.
- 들여쓰기가 1순위 오류다. `if` 다음 줄을 일부러 들여쓰지 않고 실행해 `IndentationError`를 보여 준다.
- `elif`는 처음 참인 곳에서 멈춘다. 체온 예제의 두 조건 순서를 바꿔 37.9가 "정상"으로 나오는 것을 보여 준다.
- `pass_count = 0`을 반복문 안으로 옮겨 틀린 숫자가 나오는 것을 보여 준다(오류가 없어 더 위험).
- STEP 04 예제 3은 결과를 열기 전에 "12건 중 실제 불합격은 몇 건일까?"를 먼저 묻는다.
- **강사만 알고 있을 것**: `합격여부`는 온도와 무관하게 무작위로 만들었다(`gen_week03`). 불합격 3건이 모두 범위 밖인 것은 우연이다.

## 예상 오개념
- 들여쓰기는 장식이다 → 어느 묶음에 속하는지를 정한다.
- `=`와 `==`는 같다 → `if score = 80:`은 `SyntaxError`.
- `elif`를 모두 검사한다 → 처음 참인 곳에서 멈춘다.
- 실습지 문제에 쉬운 예제의 기준값 80을 그대로 둔다 → `if temp >= 80:`은 오류 없이 모든 온도를 "합격"으로 만든다.
- `def`만 실행하면 결과가 나온다 → 불러야 실행된다.
- 범위 밖 = 불량 → 범위 밖 12건 중 9건은 합격.

## 실습 중 오류 대응
- `IndentationError: expected an indented block after 'if' statement on line 3`: 콜론 다음 줄에 4칸(`for` 안 `if` 안은 8칸).
- `IndentationError: unindent does not match any outer indentation level`: 같은 묶음의 칸 수를 맞춘다.
- `SyntaxError: expected ':'`: 줄 끝 콜론 누락.
- `SyntaxError: invalid syntax. Maybe you meant '==' or ':=' instead of '='?`: 조건에 `=` 하나 → `==`.
- `SyntaxError: invalid syntax`: 빈칸 `____`을 채우지 않고 실행(예: `if temperature ____ 305:`).
- `NameError: name '____' is not defined`: 이름 자리 빈칸 미입력(예: `print(____(temperatures))`).
- `NameError: name 'scores' is not defined` 등: 앞 단계 쉬운 예제 셀을 건너뜀(`scores` 3단계, `calculate_average` 6단계). 문제 6은 6단계의 평균 함수를 쓴다.
- `NameError: name 'judge_pass' is not defined`: 10단계 `judge_pass` 셀 미실행 또는 빈칸 미입력. 11단계가 연달아 이 오류를 내면 10단계로 돌아가게 한다.
- 오류 없이 개수가 0이나 1: 세는 변수(`= 0`)가 반복문 안에 있다.
- AI 코드 붙여넣은 뒤 11단계 결과가 달라짐: AI 코드의 `records = [...]`가 덮어썼다. 11단계 `records` 셀을 다시 실행.
