  • 그래서 컴퓨터에게 맡긴다. if는 규칙, for는 반복, def는 자주 쓰는 판정에 이름 붙이기다.

STEP 01

조건문 — 값에 따라 다르게 판단하기

비교 연산자와 if

비교 연산자로 질문하면 파이썬은 True(참) 또는 False(거짓)로 답한다. if 조건: 다음 줄을 4칸 들여쓰면 조건이 참일 때만 실행된다. Jupyter에서는 콜론 뒤에 Enter를 치면 4칸이 자동으로 들어가고, Tab 키 한 번도 4칸이다.

연산자묻는 내용
> / <큰가? / 작은가?
>= / <=크거나 같은가? / 작거나 같은가?
== / !=같은가? / 다른가?

쉬운 예제 — 시험 점수

Python — 비교 연산자로 질문하기
score = 85
subject = "수학"

print(score > 80)
print(score <= 80)
print(subject == "수학")
print(subject != "수학")
실행 결과 
True
False
True
False
Python — if
if score > 80:
    print("80점을 넘었습니다!")
print("채점 끝")
실행 결과(score = 85) 
80점을 넘었습니다!
채점 끝

들여쓰지 않은 print("채점 끝")은 조건과 상관없이 실행된다. score가 75였다면 "채점 끝"만 나온다.

가장 흔한 오류
  • if 줄 끝 콜론(:)을 빠뜨리면 SyntaxError: expected ':', 다음 줄을 들여쓰지 않으면 IndentationError.
  • 조건에 =를 하나만 쓰면 SyntaxError. "같은가?"는 ==다.

else와 elif

else:는 조건이 거짓일 때, elif(else if의 줄임말)는 두 번째 질문이다. 위에서부터 묻다가 처음 참인 곳에서 멈춘다. 36.0 <= body_temp <= 37.5는 "36.0 이상 37.5 이하인가?"라는 뜻이다.

쉬운 예제 — 체온 재기

Python — if / else
body_temp = 36.5

if 36.0 <= body_temp <= 37.5:
    print("정상 체온입니다.")
else:
    print("다시 재 보세요.")
실행 결과 
정상 체온입니다.
Python — if / elif / else
body_temp = 35.4

if body_temp > 37.5:
    print("높음")
elif body_temp >= 36.0:
    print("정상")
else:
    print("낮음")
실행 결과 
낮음

35.4는 두 질문이 모두 거짓이라 else로 내려왔다. 순서가 중요하다: 만약 body_temp >= 36.0을 맨 위에서 물으면, 37.9도 36.0 이상이라 첫 질문에서 "정상"으로 멈춘다. 그래서 큰 기준(37.5 초과)부터 묻는다.

STEP 02

반복문 — for로 하나씩 꺼내 세고 더하기

for — 하나씩 꺼내 개수 세기

for 꺼낸값 in 리스트:는 값을 하나씩 꺼내 꺼낸값에 담고 들여쓴 줄을 반복한다(출석부를 한 명씩 부르기). 개수는 0으로 시작한 변수에 조건이 맞을 때마다 1씩 더해 센다.

쉬운 예제 — 우리 반 시험 점수

Python — for로 하나씩 꺼내기
scores = [72, 85, 90, 64, 88]

for score in scores:
    print(score)
실행 결과 
72
85
90
64
88
Python — 80점 이상인 학생 수 세기
pass_count = 0

for score in scores:
    if score >= 80:
        pass_count = pass_count + 1

print(f"80점 이상인 학생은 {pass_count}명입니다.")
실행 결과 
80점 이상인 학생은 3명입니다.
주의 for 안의 if 안 줄은 8칸 들여쓴다. pass_count = 0은 반복문 밖에 둔다. 안에 넣으면 오류 없이 틀린 숫자(0 또는 1)가 나온다.

누적 합 — 하나씩 더해 합계 만들기

값 자체를 계속 더하면 합계, 합계를 len()으로 나누면 평균이다. total += money는 total = total + money의 줄임말이다.

쉬운 예제 — 이번 달 용돈

Python — 누적 합과 평균
allowance = [5000, 3000, 7000, 2000]

total = 0

for money in allowance:
    total += money

average = total / len(allowance)
print(f"합계 {total}원, 평균 {average}원")
실행 결과 
합계 17000원, 평균 4250.0원

zip — 두 목록을 짝지어 함께 꺼내기

이름 목록과 점수 목록처럼 순서가 서로 대응하는 목록 두 개를 같이 읽고 싶을 때가 있다. zip(A, B)는 지퍼가 양쪽 이빨을 한 칸씩 맞물리듯, 두 목록에서 같은 자리의 값을 한 쌍씩 묶어 준다. for 뒤에 변수 이름을 두 개 쓰면 한 쌍이 앞 변수, 뒤 변수에 하나씩 나뉘어 담긴다.

쉬운 예제 — 이름과 점수 짝짓기

Python — zip으로 두 목록 함께 꺼내기
names = ["민지", "준호", "서연"]
exam_scores = [85, 72, 93]

for name, score in zip(names, exam_scores):
    print(name, score)
실행 결과 
민지 85
준호 72
서연 93

첫 번째 반복에서는 "민지"와 85가 짝이 되어 name, score에 들어온다. 9차시에서 "열 이름 목록"과 "중요도 목록"을 짝지어 출력할 때 같은 방식을 다시 쓴다.

"딕셔너리의 리스트"에서 골라내기

꺼낼 때마다 딕셔너리 하나(사람 한 명, 설비 한 대)가 통째로 들어온다. 조건에 맞을 때만 append()(2차시)로 새 리스트에 담는다.

쉬운 예제 — 학생 명단

Python — 딕셔너리의 리스트에서 골라내기
students = [
    {"이름": "민지", "반": "1반", "점수": 85},
    {"이름": "준호", "반": "2반", "점수": 72},
    {"이름": "서연", "반": "1반", "점수": 93},
]

for student in students:
    print(student["이름"], student["점수"])

high_students = []

for student in students:
    if student["점수"] > 80:
        high_students.append(student["이름"])

print(f"80점을 넘은 학생: {high_students}")
실행 결과 
민지 85
준호 72
서연 93
80점을 넘은 학생: ['민지', '서연']
AI에게 물어보기 — 복사해서 AI 챗봇에 붙여넣기
파이썬을 처음 배우는 사람이야. for 반복문 안에서 count = count + 1로 개수를 세는 방법을 손가락 접기 같은 일상 비유로 설명해줘. count = 0을 왜 반복문 밖에 써야 하는지도 비유로 알려줘.
STEP 03

함수 — 자주 쓰는 계산에 이름 붙이기

함수는 이름 붙인 레시피다. def로 적어 두고(정의), 이름을 불러 요리한다(호출). 괄호 안은 재료 칸(매개변수), return은 완성된 요리를 돌려주는 자리다.

쉬운 예제 — 평균 점수와 합격 판정

Python — 함수 정의와 호출
def calculate_average(numbers):
    return sum(numbers) / len(numbers)

print(calculate_average(scores))

def judge_score(score):
    if score >= 80:
        return "합격"
    else:
        return "불합격"

print(judge_score(85))
print(judge_score(64))

for score in scores:
    result = judge_score(score)
    print(f"{score}점 → {result}")
실행 결과 
79.8
합격
불합격
72점 → 불합격
85점 → 합격
90점 → 합격
64점 → 불합격
88점 → 합격
  • calculate_average(scores)를 부르면 scores 리스트가 재료 칸 numbers에 들어가고, 함수 안에서는 numbers라는 이름으로 쓴다. judge_score(85)도 85가 재료 칸 score에 들어간다(반복문의 score와는 따로인 칸이다).
  • def만 실행하면 아무것도 출력되지 않는다. 정의 전에 부르면 NameError: name 'judge_score' is not defined.

함께 쓰기 — 함수 + 딕셔너리의 리스트 + 개수 세기

쉬운 예제 — 학생 명단에서 불합격 판정 세기

Python — 함수 + 딕셔너리의 리스트 + 개수 세기
fail_count = 0

for student in students:
    if judge_score(student["점수"]) == "불합격":
        fail_count += 1

print(f"불합격 판정을 받은 학생: {fail_count}명")
실행 결과 
불합격 판정을 받은 학생: 1명

예제 1 — 온도 판정 함수 judge_pass

질문: 온도가 295 이상 305 이하이면 "합격"으로 판정하는 함수는? judge_score에서 조건 줄만 바뀐다.

Python — judge_pass
def judge_pass(temp):
    if 295 <= temp <= 305:
        return "합격"
    else:
        return "불합격"

print(judge_pass(301.0))
print(judge_pass(312.6))

합격
불합격

공장 말로 읽기 — 이 "합격"/"불합격"은 온도 규칙의 판정일 뿐, 데이터의 합격여부(실제 검사 결과)와 다르다.

if 36.0 <= body_temp <= 37.5:

for loop
한 줄 설명
리스트의 값을 하나씩 꺼내 같은 일을 반복한다. 꺼낸 값의 이름은 내가 붙인다.
예
for score in scores:

누적 변수

Accumulator
한 줄 설명
반복하며 개수·합계를 쌓는 변수. 0으로 시작하는 줄은 반복문 밖에 둔다.

total += money

Function (def)

return

결과 정리 & 퀴즈

더 많은 문제는 실습지에 있다.

Q1. (객관식) if 줄을 이렇게 썼을 때 문법 오류가 나는 것은? (다음 줄은 올바르게 들여썼다고 가정)
  • A. if score > 80:
  • B. if score = 80:
  • C. if score == 80:
  • D. if score >= 80:
정답: B. "같은가?"는 ==다. =를 조건에 쓰면 SyntaxError.
Q2. (결과 예측) score = 75일 때 아래 코드의 출력은?
if score > 80:
    print("80점을 넘었습니다!")
print("채점 끝")
정답: 채점 끝 한 줄. 들여쓴 줄은 건너뛰고, 들여쓰지 않은 줄만 실행된다.
Q3. (참/거짓) 온도 규칙으로 "불합격"이 나온 12건은 실제 검사에서도 모두 불합격했다.
정답: 거짓. 실제 불합격(-1)은 3건, 9건은 합격(1)했다.
Q4. (서술) "반도체 데이터로 확인하기" 결과를 두 문장으로 설명해보자.
예시 답안: "기록 30건을 학습용 범위(295~305℃)로 판정하니 12건이 범위 밖이었다. 그러나 실제 불합격은 3건이고 범위 밖 12건 중 9건은 합격했으므로, 온도 규칙 하나로는 합격·불합격을 다 설명할 수 없다."
