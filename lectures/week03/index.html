  • 비교 연산자(>, == 등)와 if/elif/else로 온도가 정상 범위인지 판정할 수 있다.
  • for로 리스트와 "딕셔너리의 리스트"를 하나씩 꺼내 보고, 조건에 맞는 개수와 합계를 셀 수 있다.

왜 이걸 배워야 할까?

  • 공장에는 "온도가 정상 범위 안이면 통과"처럼 판정 규칙이 있다. 지금까지는 사람이 기록을 한 줄씩 보며 "이 값은 범위 안인가?"를 확인했다고 해보자.
  • 기록이 30줄이면 눈으로도 할 수 있다. 그런데 1차시에서 본 것처럼 실제 공장은 하루에도 수십만 줄의 기록을 남긴다.
    • 한 줄 확인에 3초씩만 잡아도 30만 줄이면 90만 초, 약 250시간이다. 쉬지 않고 열흘이 넘게 걸린다.
    • 사람은 지치면 실수도 한다. 299.5와 295.9를 헷갈리는 일이 생긴다.
  • 그래서 판정을 컴퓨터에게 맡긴다. 오늘 배우는 세 가지가 그 도구다.
    • if — 판정 규칙을 알려준다("범위 안이면 규칙상 통과, 즉 합격 판정").
    • for — 그 규칙을 모든 기록에 하나씩 반복한다.
    • def — 자주 쓰는 판정에 이름을 붙여 저장해 두고 언제든 다시 쓴다.
비유 — 시험 채점기 선생님이 정답표(규칙)를 한 번 넣어 주면, 채점 기계는 답안지 수천 장을 지치지 않고 똑같은 기준으로 채점한다. 오늘은 파이썬에게 "정답표를 주고 답안지를 한 장씩 넘기게" 하는 법을 배운다.

  • 2차시: temperatures = [295.4, 298.1, 312.6, 301.0, 296.8]처럼 값을 리스트에 담고, equipment_list[0]["온도_섭씨"]처럼 번호와 이름표로 값을 하나씩 꺼냈다.
  • 설비가 3대면 손으로 번호를 바꿔 가며 볼 수 있다. 300대라면? 오늘은 이 "하나씩 꺼내 보기"를 컴퓨터가 대신하게 만든다.
STEP 01

조건문 — 값에 따라 다르게 판단하기

비교 연산자 — 컴퓨터에게 질문하기

  • 판정하려면 먼저 "이 값이 305보다 큰가?" 같은 질문을 할 수 있어야 한다.
  • 비교 연산자로 질문하면 파이썬은 True(참) 또는 False(거짓)로 답한다. 1차시에 본 불리언(bool) 자료형이다.
연산자묻는 내용예시
> / <큰가? / 작은가?temperature > 305
>= / <=크거나 같은가? / 작거나 같은가?temperature <= 305
==같은가?equipment == "EQ-03"
!=다른가?equipment != "EQ-03"
Python — 비교 연산자로 질문하기
temperature = 312.6
equipment = "EQ-03"

print(temperature > 305)
print(temperature <= 305)
print(equipment == "EQ-03")
print(equipment != "EQ-03")
실행 결과 
True
False
True
False
1차시와 연결 — =와 ==는 다르다
  • = 하나: "저장하라" (temperature = 312.6)
  • == 두 개: "같은가?" (equipment == "EQ-03")
  • 조건 자리에 =를 하나만 쓰면 파이썬이 SyntaxError를 내며 "혹시 ==를 쓰려던 것 아니냐"고 알려준다.

if — 조건이 참일 때만 실행하기

  • 생활 속 예: "비가 오면 우산을 챙긴다." 비가 안 오면 우산 챙기기는 건너뛴다.
  • 파이썬에서는 if 조건:을 쓰고, 조건이 참일 때 할 일을 다음 줄에 4칸 들여써서 적는다.
Python — if
if temperature > 305:
    print("온도가 범위보다 높습니다!")
print("판정 끝")
실행 결과(temperature = 312.6) 
온도가 범위보다 높습니다!
판정 끝
  • 들여쓴 줄(print("온도가 범위보다 높습니다!"))은 조건이 참일 때만 실행된다.
  • 들여쓰지 않은 줄(print("판정 끝"))은 if와 상관없이 항상 실행된다. temperature가 301.0이었다면 "판정 끝"만 나온다.
가장 흔한 오류 — 콜론과 들여쓰기
  • if 줄 끝에는 콜론(:)을 붙인다. 빠뜨리면 SyntaxError: expected ':'.
  • 콜론 다음 줄은 스페이스 4칸(또는 Tab 1번) 들여쓴다. 들여쓰기가 "이 줄은 if에 속한다"는 표시다.
  • 들여쓰기를 빠뜨리면 아래처럼 IndentationError가 난다.
temperature = 312.6

if temperature > 305:
print("온도가 범위보다 높습니다!")      ← 들여쓰기 없음

IndentationError: expected an indented block after 'if' statement on line 3

if / else — 두 갈래로 나누기

  • else:를 붙이면 조건이 거짓일 때 할 일도 정할 수 있다. else 뒤에는 조건 없이 콜론만 쓴다.
  • 295 <= temperature <= 305는 수학 시간의 부등식과 같다. "295 이상 305 이하인가?"라는 질문이다.
Python — if / else
temperature = 301.0

if 295 <= temperature <= 305:
    print("정상 범위입니다.")
else:
    print("범위 밖입니다.")
실행 결과 
정상 범위입니다.

조건문은 갈림길이다. 질문의 답이 참이면 왼쪽 길로, 거짓이면 오른쪽 길로 간다.

295~305℃는 학습용 기준이다 이 범위는 1차시부터 쓰고 있는 이 과정의 학습용 정상 범위다. 실제 공장의 기준은 공정마다 다르고, 설계 단계에서 따로 정한다. 오늘은 "규칙을 코드로 옮기는 연습"에만 쓴다.

if / elif / else — 여러 갈래로 나누기

  • "높음 / 정상 / 낮음"처럼 갈래가 셋 이상이면 중간에 elif(else if의 줄임말)를 넣는다.
  • 파이썬은 위에서부터 차례로 묻다가, 처음으로 참인 곳의 일만 하고 나머지는 건너뛴다.
Python — if / elif / else
temperature = 293.8

if temperature > 305:
    print("높음")
elif temperature >= 295:
    print("정상")
else:
    print("낮음")
실행 결과 
낮음
  • 293.8은 첫 질문(305보다 큰가?)도 거짓, 둘째 질문(295 이상인가?)도 거짓이라 else로 내려왔다.
  • 둘째 줄에 temperature <= 305를 따로 쓰지 않아도 되는 이유: 305보다 큰 값은 첫 줄에서 이미 걸러졌기 때문이다. 그래서 순서가 중요하다. 두 줄의 순서를 바꾸면 312.6도 "정상"으로 먼저 걸린다.
직접 해보기 temperature를 308.0으로 바꿔 다시 실행해보자. 실행하기 전에 결과를 먼저 예측한다. 다음으로 300.0도 넣어 보자. (노트북 2단계 "직접 해보기" 셀)
STEP 02

반복문 — for로 하나씩 꺼내 세고 더하기

for — 리스트에서 하나씩 꺼내기

  • 생활 속 예: 출석부를 위에서부터 한 명씩 부른다. 부르는 방법은 같고, 이름만 바뀐다.
  • for 이름 in 리스트:는 리스트의 값을 처음부터 하나씩 꺼내 이름에 담고, 들여쓴 줄을 값마다 한 번씩 실행한다.
Python — for
temperatures = [295.4, 298.1, 312.6, 301.0, 296.8]

for temp in temperatures:
    print(temp)
실행 결과 
295.4
298.1
312.6
301.0
296.8

보라색 화살표가 temp다. 한 칸씩 옮겨 가며 그 자리의 값을 담고, 들여쓴 줄을 실행한다. 다섯 칸이면 다섯 번 반복한다.

주의 for 줄 끝에도 콜론, 다음 줄은 4칸 들여쓰기다. if와 같은 규칙이다. temp는 내가 붙인 이름이라 t나 value로 바꿔도 동작은 같다.

개수 세기 — 조건에 맞는 것만 세기

  • for 안에 if를 넣으면 "하나씩 꺼내서, 조건에 맞을 때만" 무언가를 한다.
  • 개수를 세려면 숫자를 기억해 둘 변수를 0으로 만들어 두고, 조건에 맞을 때마다 1씩 더한다. 손가락을 하나씩 접으며 세는 것과 같다.
Python — 정상 범위인 값 개수 세기
normal_count = 0

for temp in temperatures:
    if 295 <= temp <= 305:
        normal_count = normal_count + 1

print(f"정상 범위인 값은 {normal_count}개입니다.")
실행 결과 
정상 범위인 값은 4개입니다.
  • normal_count = normal_count + 1은 "지금 개수에 1을 더해서 다시 저장하라"는 뜻이다. =가 "저장하라"라는 1차시 설명을 떠올리면 읽힌다.
  • if 안의 줄은 8칸 들여썼다. for 안(4칸)의 if 안(4칸 더)이기 때문이다.
  • 같은 뜻을 줄여서 normal_count += 1로도 쓴다. 이 줄임말을 아래부터 쓴다.
세는 변수는 반복문 "밖"에서 0으로 normal_count = 0을 for 안에 넣으면 값을 꺼낼 때마다 0으로 돌아간다. 그러면 마지막 값 하나만 센 1이 나온다. 오류는 나지 않아서 더 알아채기 어렵다.

누적 합 — 하나씩 더해 합계 만들기

  • 개수 대신 값 자체를 계속 더하면 합계가 된다. 장바구니에 물건을 하나 넣을 때마다 계산기에 가격을 더하는 것과 같다.
  • 합계를 개수로 나누면 평균이다. 2차시에 sum()으로 한 번에 구했던 것을 직접 만들어 보는 셈이다.
Python — 누적 합과 평균
total = 0

for temp in temperatures:
    total += temp

average = total / len(temperatures)
print(f"합계 {total:.1f}, 평균 {average:.1f}")
실행 결과 
합계 1503.9, 평균 300.8

"딕셔너리의 리스트"를 하나씩 꺼내기

  • 2차시에 만든 equipment_list도 리스트라서 for로 꺼낼 수 있다.
  • 이번에는 꺼낼 때마다 eq에 딕셔너리(설비 1대의 정보) 하나가 통째로 들어온다. 그래서 eq["온도_섭씨"]처럼 이름표로 값을 꺼낸다.
Python — 딕셔너리의 리스트 순회
equipment_list = [
    {"설비번호": "EQ-01", "공정명": "식각", "온도_섭씨": 301.2},
    {"설비번호": "EQ-02", "공정명": "증착", "온도_섭씨": 308.7},
    {"설비번호": "EQ-03", "공정명": "포토", "온도_섭씨": 297.5},
]

for eq in equipment_list:
    print(eq["설비번호"], eq["온도_섭씨"])
실행 결과 
EQ-01 301.2
EQ-02 308.7
EQ-03 297.5

조건에 맞는 것만 새 리스트에 담기

빈 리스트를 만들어 두고, 조건에 맞을 때만 append()(2차시: 리스트 끝에 추가)로 담는다.

Python — 골라내기
hot_equipment = []

for eq in equipment_list:
    if eq["온도_섭씨"] > 305:
        hot_equipment.append(eq["설비번호"])

print(f"온도가 305도를 넘는 설비: {hot_equipment}")
실행 결과 
온도가 305도를 넘는 설비: ['EQ-02']
직접 해보기 조건을 eq["온도_섭씨"] < 300으로 바꾸고, 담을 리스트 이름을 cold_equipment로 바꿔 온도가 300도 미만인 설비 목록을 만들어보자. (노트북 4단계 "직접 해보기" 셀)
AI에게 물어보기 — 복사해서 AI 챗봇에 붙여넣기
파이썬을 처음 배우는 사람이야. for 반복문 안에서 count = count + 1로 개수를 세는 방법을 손가락 접기 같은 일상 비유로 설명해줘. count = 0을 왜 반복문 밖에 써야 하는지도 비유로 알려줘.

이렇게 확인해보자: 비유 속에서 "0으로 시작하는 순간"이 반복을 시작하기 전에 딱 한 번만 나오는지 확인하자.

STEP 03

함수 — 자주 쓰는 계산에 이름 붙이기

  • "295 이상 305 이하면 합격으로 판정"하는 규칙을 앞으로 여러 번 쓴다. 쓸 때마다 같은 if를 다시 적으면 길고, 틀리기도 쉽다.
  • 함수(Function)는 자주 쓰는 계산을 이름을 붙여 저장해 둔 레시피다.
    • def로 레시피를 적어 두는 것 = 정의. 이때는 아직 요리하지 않는다.
    • 이름을 불러 그 레시피대로 요리하는 것 = 호출. 예: calculate_average(temperatures)
    • 괄호 안 이름(numbers, temp)은 재료를 넣는 칸(매개변수)이다.
    • return은 완성된 요리를 돌려주는 자리다. return 뒤의 값이 함수의 결과가 된다.

가장 단순한 레시피 — 평균 함수

Python — 함수 정의와 호출
def calculate_average(numbers):
    return sum(numbers) / len(numbers)

print(calculate_average(temperatures))
print(calculate_average([23.5, 24.1]))
실행 결과 
300.78
23.8
  • 같은 레시피에 재료만 바꿔 넣었다. 두 번째는 1차시 연습문제의 클린룸 온도 두 개(23.5, 24.1)다.
  • def 줄 끝에도 콜론, 다음 줄은 4칸 들여쓰기다.

합격 판정 함수 — judge_pass

앞에서 만든 범위 판정을 레시피로 저장한다. 온도 하나를 넣으면 "합격" 또는 "불합격"을 돌려준다.

Python — 판정 함수 만들기
def judge_pass(temp):
    if 295 <= temp <= 305:
        return "합격"
    else:
        return "불합격"

print(judge_pass(301.0))
print(judge_pass(312.6))
실행 결과 
합격
불합격

연습문제 — 온도 등급 함수 만들기

STEP 01의 세 갈래 판정을 함수로 만들고, 기록 30건에 적용해 높음·낮음이 각각 몇 건인지 센다.

조건돌려줄 값
305 초과"높음"
295 이상 305 이하"정상"
295 미만"낮음"
직접 해보기 (노트북 9단계)
  • classify_temp(temp) 함수를 만든다. if/elif/else 안에서 print 대신 return을 쓴다.
  • high_count, low_count를 0으로 시작해, records를 돌며 등급이 "높음"·"낮음"일 때 각각 1씩 늘린다.
  • 확인: 높음과 낮음을 더하면 종합 실습에서 걸러낸 기록 수와 같아야 한다.
def classify_temp(temp):
    if temp > 305:
        return "높음"
    elif temp >= 295:
        return "정상"
    else:
        return "낮음"

high_count = 0
low_count = 0

for record in records:
    grade = classify_temp(record["온도_섭씨"])
    if grade == "높음":
        high_count += 1
    elif grade == "낮음":
        low_count += 1

print(f"높음 {high_count}건, 낮음 {low_count}건")
실행 결과: 높음 8건, 낮음 4건 — 8 + 4 = 12건으로, 온도 규칙으로 걸러낸 기록 수와 같다.

AI로 재미있는 미니 프로그램 만들기 — 온도 뽑기 심판 프로그램

오늘의 미니 프로젝트 (노트북 10단계) 오늘 만든 judge_pass 함수를 그대로 다시 쓰는 재미있는 프로그램을 AI에게 만들어달라고 해보자. 함수를 한 번 만들어 두면 다른 프로그램에서도 이름만 불러 쓸 수 있다는 것을 확인하는 것이 목표다.
프롬프트 예시 — 그대로 물어보기 "290부터 320 사이의 임의의 온도를 5번 뽑아서, judge_pass 함수로 합격/불합격을 판정하고 합격이면 ✅, 불합격이면 ❌를 붙여 심판처럼 발표하는 파이썬 코드를 만들어줘. random 모듈을 사용하고, if/else와 for만 써줘."
Python — AI가 만들어줄 수 있는 코드 예시
import random

random.seed(3)  # 실행할 때마다 같은 결과가 나오도록 고정

print("오늘의 온도 뽑기 심판 프로그램")
for i in [1, 2, 3, 4, 5]:
    temp = round(random.uniform(290, 320), 1)
    result = judge_pass(temp)
    if result == "합격":
        mark = "✅"
    else:
        mark = "❌"
    print(f"{i}번째 측정: {temp}도 → {result} {mark}")
실행 결과(seed 3으로 고정) 
오늘의 온도 뽑기 심판 프로그램
1번째 측정: 297.1도 → 합격 ✅
2번째 측정: 306.3도 → 불합격 ❌
3번째 측정: 301.1도 → 합격 ✅
4번째 측정: 308.1도 → 불합격 ❌
5번째 측정: 308.8도 → 불합격 ❌
더 놀아보기
  • import random과 random.uniform()(두 수 사이의 값을 무작위로 뽑기)은 아직 배우지 않았다. 지금은 구경만 하자. round()는 2차시 AI 예시에서 본 반올림이다.
  • random.seed(3) 줄을 지우고 여러 번 실행해보자. 실행할 때마다 다른 온도가 나온다.
  • 뽑는 횟수를 늘리거나, judge_pass 대신 연습문제의 classify_temp로 심판하게 바꿔 달라고 AI에게 요청해보자.
