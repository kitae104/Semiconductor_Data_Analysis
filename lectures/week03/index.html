2주차 복습 2주차에서는 변수와 리스트에 숫자 여러 개를 담고, 평균·최댓값·최솟값·수율을 직접 계산했다. 리스트 하나가 "숫자 여러 개의 모음"이었다면, DataFrame의 열(column) 하나도 사실 "값 여러 개의 모음"이라는 점에서 리스트와 비슷하다. 오늘은 리스트 여러 개를 표로 합쳐 놓은 DataFrame에서, 원하는 열과 원하는 행만 골라내는 방법을 배운다.

📚 오늘의 개념: CSV와 DataFrame

CSV란 무엇인가

CSV(Comma-Separated Values)는 값을 쉼표(,)로 구분해 저장한 순수 텍스트 표 파일이다. 엑셀로도 열 수 있지만, Pandas로 읽으면 코드로 다루기 훨씬 편한 DataFrame이라는 표 형태의 자료구조가 된다.

DataFrame의 구조

DataFrame은 행(row)과 열(column)로 이루어진 표다. 이번 주 데이터 week03_process_filtering.csv는 100행(공정 기록 100건) × 8열(측정시간, 로트번호, 설비번호, 공정명, 온도_섭씨, 압력_Pa, 가스유량_slm, 합격여부)로 구성되어 있다.

데이터 형식(dtype)

DataFrame의 각 열은 저마다의 데이터 형식(dtype)을 가진다. 글자로 된 값은 object(문자열), 소수점이 있는 숫자는 float64(실수), 소수점이 없는 숫자는 int64(정수)로 표시된다. df.dtypes로 확인할 수 있다.

개념 온도_섭씨, 압력_Pa, 가스유량_slm은 float64, 합격여부는 int64, 나머지 문자열 열들은 object다.

📊 열 선택 · 조건 검색 · 정렬 이해하기

열 선택(Column Selection)

열 하나만 보려면 df['열이름'], 여러 열을 함께 보려면 df[['열이름1', '열이름2']]처럼 대괄호 안에 리스트를 넣는다. (대괄호가 두 번 겹치는 것을 헷갈리지 않도록 주의!)

조건 검색(불리언 인덱싱)

df['설비번호'] == 'EQ-02'처럼 조건식을 쓰면, 각 행에 대해 True/False 값이 만들어진다. 이것을 다시 df[...] 안에 넣으면 True인 행만 골라낸 새로운 표가 만들어진다. 이 방식을 불리언 인덱싱이라 부른다.

주의 값을 "저장"할 때는 =(등호 하나), 값이 "같은지 비교"할 때는 ==(등호 둘)를 쓴다. 문자열을 비교할 때는 'EQ-02'처럼 따옴표를 꼭 붙여야 한다.

정렬(Sorting)

df.sort_values('열이름')은 오름차순(작은 값→큰 값) 정렬이고, df.sort_values('열이름', ascending=False)는 내림차순(큰 값→작은 값) 정렬이다.

👩‍🏫 강사 코드 시연

Python — Colab / Jupyter
# 1. Pandas를 불러오고 CSV를 읽습니다.
import pandas as pd
df = pd.read_csv("week03_process_filtering.csv")

# 2. 열 하나만 선택해서 봅니다.
df["온도_섭씨"]

# 3. 열 여러 개를 함께 선택해서 봅니다. (대괄호 두 번!)
df[["온도_섭씨", "압력_Pa"]]

# 4. 설비번호가 EQ-02인 행만 골라냅니다.
eq02 = df[df["설비번호"] == "EQ-02"]
print(eq02.shape)

# 5. EQ-02 중에서 불합격(-1)만 골라 몇 건인지 셉니다.
print((eq02["합격여부"] == -1).sum())

# 6. 온도가 높은 순서로 정렬해 상위 5건을 봅니다.
df.sort_values("온도_섭씨", ascending=False).head(5)
코드 한 줄씩 설명
  • df["온도_섭씨"]: 온도 열 하나만 Series(1개 열짜리 값 모음) 형태로 꺼낸다.
  • df[["온도_섭씨", "압력_Pa"]]: 두 열을 리스트로 묶어 함께 꺼낸다. 결과는 여전히 DataFrame이다.
  • df["설비번호"] == "EQ-02": 각 행이 EQ-02인지 아닌지 True/False로 판단한다.
  • df[df["설비번호"] == "EQ-02"]: True인 행만 남긴 새 DataFrame을 만든다.
  • (eq02["합격여부"] == -1).sum(): 조건이 True인 개수를 더해서(True=1로 취급) 합계를 구한다.
  • df.sort_values("온도_섭씨", ascending=False): 온도 열을 기준으로 큰 값이 먼저 오도록 정렬한다.
  • .head(5): 정렬된 결과 중 위에서 5개만 본다.
실행 결과 예시 
eq02.shape → (32, 8)
(eq02["합격여부"] == -1).sum() → 8

정렬 상위 5건 (로트번호, 설비번호, 공정명, 온도_섭씨):

LOT-0338  EQ-03  산화  308.9

결과 해석 EQ-02 설비의 공정 기록은 32건이고, 이 중 8건(25.0%)이 불합격이다. 반면 나머지 설비 (EQ-01·EQ-03·EQ-04)를 합친 68건 중 불합격은 4건(5.9%)뿐이다. 즉 EQ-02는 다른 설비보다 불합격 비율이 눈에 띄게 높다 — 조건 검색으로 "직접 발견한" 사실이다. 또한 온도가 가장 높았던 상위 5건은 모두 합격 처리되어 있어, "온도가 높다고 무조건 불합격은 아니다"라는 점도 함께 확인할 수 있다.

🙋 실생활 비유로 정리하기

열 선택과 조건 검색은 엑셀의 "필터" 기능과 비슷하다. 엑셀에서 특정 열만 보이게 숨기거나, "설비번호가 EQ-02인 행만" 필터를 걸어본 적이 있다면 이미 오늘 배운 개념을 경험한 것이다. 정렬은 엑셀의 "정렬" 버튼과 똑같은 역할을 한다. 다만 Pandas에서는 이 모든 작업을 코드 한 줄로 빠르게 반복할 수 있다는 점이 다르다.

🟣 단계별 따라 하기 실습

데이터 읽기 — week03_process_filtering.csv를 업로드하고 pd.read_csv()로 읽어 df에 저장한다.

열 하나 선택 — df["온도_섭씨"]를 실행해 온도 값만 확인한다.
3
열 여러 개 선택 — df[["온도_섭씨", "압력_Pa"]]를 실행해 두 열을 함께 확인한다.

6
온도 내림차순 정렬 — df.sort_values("온도_섭씨", ascending=False)를 실행해 온도가 가장 높은 상위 5건을 확인한다. (학생용 Notebook의 TODO로 이어짐)

⚠️ 주의할 점 & 자주 발생하는 오류

오류 1 KeyError: '설비번호 ' — 열 이름에 공백이나 오타가 있는 경우다. df.columns로 정확한 열 이름을 먼저 확인한다.
오류 2 조건식에서 =과 ==을 혼동하는 경우다. df[df["설비번호"] = "EQ-02"]는 문법 오류(SyntaxError)를 낸다. 비교에는 반드시 ==을 쓴다.
주의 여러 열을 선택할 때 df["온도_섭씨", "압력_Pa"]처럼 대괄호를 한 번만 쓰면 오류가 난다. df[["온도_섭씨", "압력_Pa"]]처럼 안쪽에 리스트(대괄호)를 한 번 더 감싸야 한다.
