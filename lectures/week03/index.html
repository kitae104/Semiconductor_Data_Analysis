리스트·딕셔너리로 배우는 조건문, 반복문, 함수

💬 오늘의 질문: "리스트에 담긴 여러 설비 정보를 하나씩 살펴보며, 조건에 맞는 것만 컴퓨터가 골라내게 할 수 있을까?"

🎯 학습 목표

  • 비교 연산자와 if/elif/else로 조건에 따라 다르게 판단할 수 있다.
  • for로 리스트와 딕셔너리의 리스트를 순회할 수 있다.
  • for와 if를 함께 써서 조건에 맞는 값만 골라낼 수 있다.
  • def로 반복되는 계산을 함수로 만들어 재사용할 수 있다.
  • 함수와 반복문을 결합해 여러 로트를 한 번에 판정할 수 있다.

선수 지식: 2차시 — 리스트·딕셔너리

⏮️ 지난 시간 복습

2차시 연결 2차시에서는 equipment_list[0]["온도_섭씨"], equipment_list[1]["온도_섭씨"]처럼 인덱스를 손으로 하나씩 바꿔가며 값을 확인했다. 설비가 3대면 그럭저럭 할 만하지만, 300대라면 어떨까? 오늘은 이 반복적인 "하나씩 확인하기"를 컴퓨터가 대신하게 만드는 법( 반복문)과, 값에 따라 다르게 판단하는 법(조건문), 반복되는 코드를 이름 붙여 재사용하는 법 (함수)을 배운다.

📚 조건문 — 값에 따라 다르게 판단하기

비교 연산자

조건문을 만들려면 먼저 값을 비교하는 방법이 필요하다.

연산자의미예시
> / <크다 / 작다temp > 305
>= / <=크거나 같다 / 작거나 같다temp <= 305
==같다(비교)equipment == "EQ-01"
!=같지 않다equipment != "EQ-01"
1차시 복습 + 주의 =는 "저장하라"(대입), ==는 "같은가?"(비교)다. 조건문에서 if temp = 305:처럼 등호를 하나만 쓰면 SyntaxError가 난다.

if — 조건에 맞을 때만 실행하기

먼저 아주 간단한 예로 감을 잡자 반도체 데이터로 들어가기 전에, 누구나 익숙한 "나이로 성인 여부 판단하기"로 조건문의 기본 형태를 먼저 익혀보자.
Python — 아주 간단한 if
age = 20

if age >= 18:
    print("성인입니다.")
실행 결과 
성인입니다.

이제 같은 방식을 오늘 다룰 반도체 데이터의 온도 판정에 적용해보자.

Python
temperature = 312.6

if temperature > 305:
    print("온도가 너무 높습니다!")
실행 결과 
온도가 너무 높습니다!
들여쓰기(indentation) 규칙 if 다음 줄부터, 조건이 참일 때 실행할 코드는 4칸(또는 Tab 1번) 들여써야 한다. 들여쓰기가 다르면 IndentationError가 발생한다.

if / else — 두 갈래로 나누기

방금 만든 나이 예제에 else를 붙이면, 조건이 거짓일 때 실행할 코드도 함께 정할 수 있다.

Python — 아주 간단한 if/else
age = 15

if age >= 18:
    print("성인입니다.")
else:
    print("미성년자입니다.")
실행 결과 
미성년자입니다.

같은 구조를 온도 판정에도 적용해보자.

Python
temperature = 301.0

if temperature > 305 or temperature < 295:
    print("비정상 범위입니다.")
else:
    print("정상 범위입니다.")
실행 결과 
정상 범위입니다.

조건문은 갈림길과 같다 — 조건이 참이면 왼쪽 길로, 거짓이면 오른쪽 길로 간다.

if / elif / else — 여러 갈래로 나누기

조건이 셋 이상일 때는 elif(else if의 줄임말)를 추가로 쓴다. 위에서부터 순서대로 조건을 검사하다가 처음으로 참인 곳에서 멈춘다.

Python
score = 75

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "D"

print(f"점수 {score}는 {grade}등급입니다.")
실행 결과 
점수 75는 C등급입니다.
체크포인트 — elif 순서가 중요하다 if/elif는 위에서부터 검사하다가 처음으로 참인 곳에서 멈춘다. 만약 elif score >= 70:을 elif score >= 80:보다 먼저 쓰면, 점수 85도 "C등급"으로 먼저 걸려버려 "B등급"까지 도달하지 못한다. 조건은 항상 "가장 까다로운(높은) 조건 → 가장 느슨한(낮은) 조건" 순서로 써야 한다.
🙋 직접 해보기 score를 65로 바꿔서 다시 실행해보자. 어떤 등급이 나오는가?

📚 반복문 — for로 여러 값을 한 번에 처리하기

for로 리스트 순회하기

for 변수 in 리스트: 형태로 쓰면, 리스트의 값을 처음부터 끝까지 하나씩 꺼내 변수에 담아 반복 실행한다.

먼저 아주 간단한 예로 감을 잡자 2차시에서 만든 과일 리스트로 for의 기본 동작부터 확인해보자.
Python — 아주 간단한 for
fruits = ["사과", "바나나", "포도"]

for fruit in fruits:
    print(fruit)
실행 결과 
사과
바나나
포도

이제 같은 방식을 온도 리스트에 적용해보자.

Python
temperatures = [295.4, 298.1, 312.6, 301.0, 296.8]

for temp in temperatures:
    print(temp)
실행 결과 
295.4
298.1
312.6
301.0
296.8

보라색 화살표(temp)가 리스트를 왼쪽부터 한 칸씩 이동하며, 매번 그 자리의 값을 꺼내 코드 블록을 실행한다.

for + if — 조건에 맞는 것만 세기

반복문 안에 조건문을 넣으면, 조건에 맞을 때만 특정 동작을 하게 만들 수 있다.

Python
normal_count = 0

for temp in temperatures:
    if 295 <= temp <= 305:
        normal_count += 1     # normal_count = normal_count + 1 과 같은 뜻

print(f"정상 범위인 값은 {normal_count}개입니다.")
실행 결과 
정상 범위인 값은 4개입니다.
누적 변수는 반복문 "밖"에서 0으로 시작한다 normal_count = 0을 for 안에 넣으면 매번 0으로 초기화되어 항상 0 또는 1만 나온다. 누적할 변수는 반드시 반복문 시작 전에 한 번만 만든다.

for로 "딕셔너리의 리스트" 순회하기

2차시에서 만든 equipment_list처럼 딕셔너리가 담긴 리스트도 for로 순회할 수 있다. 매 반복마다 변수에는 딕셔너리 하나가 통째로 들어온다.

Python
equipment_list = [
    {"설비번호": "EQ-01", "공정명": "식각", "온도_섭씨": 301.2},
    {"설비번호": "EQ-02", "공정명": "증착", "온도_섭씨": 308.7},
    {"설비번호": "EQ-03", "공정명": "포토", "온도_섭씨": 297.5},
]

for eq in equipment_list:
    print(eq["설비번호"], eq["온도_섭씨"])
실행 결과 
EQ-01 301.2
EQ-02 308.7
EQ-03 297.5

조건에 맞는 것만 새 리스트로 골라내기

Python
hot_equipment = []   # 2차시에서 배운 빈 리스트 + append() 조합

for eq in equipment_list:
    if eq["온도_섭씨"] > 305:
        hot_equipment.append(eq["설비번호"])

print(f"온도가 305도를 넘는 설비: {hot_equipment}")
실행 결과 
온도가 305도를 넘는 설비: ['EQ-02']
🙋 직접 해보기 조건을 eq["온도_섭씨"] < 300으로 바꿔서, 온도가 300도 미만인 설비 목록을 만들어보자.

📚 함수 — 반복되는 계산에 이름 붙이기

지금까지 평균을 구할 때마다 sum(...) / len(...)을 매번 새로 썼다. 자주 쓰는 계산은 함수(Function)로 한 번 만들어두면, 이름만 불러서 재사용할 수 있다.

먼저 아주 간단한 예로 감을 잡자 숫자 두 개를 더하는 가장 단순한 함수로 "정의"와 "호출"이 무엇인지 먼저 익혀보자.
Python — 아주 간단한 함수
def add_numbers(a, b):
    return a + b

result = add_numbers(3, 5)
print(result)
실행 결과 
8

이제 같은 방식으로, 리스트 전체의 평균을 구하는 좀 더 쓸모 있는 함수를 만들어보자.

Python — 함수 정의와 호출
def calculate_average(numbers):
    return sum(numbers) / len(numbers)

avg1 = calculate_average(temperatures)
avg2 = calculate_average([1000.0, 1010.0, 1020.0, 990.0])

print(avg1)
print(avg2)
실행 결과 
300.78
1005.0
코드 한 줄씩 설명
  • def 함수이름(매개변수):: 함수를 "정의"하는 문장. 아직 실행되지 않는다.
  • numbers: 매개변수(parameter) — 함수를 호출할 때 전달받는 값의 이름표.
  • return: 함수의 결과값을 돌려준다. return을 만나면 함수가 즉시 끝난다.
  • calculate_average(temperatures): 함수 "호출" — 이때 비로소 코드가 실행된다.
주의 — 정의만 하고 호출을 잊는 실수 def로 함수를 만들기만 하고 calculate_average(...)처럼 괄호를 붙여 호출하지 않으면 아무 일도 일어나지 않는다. 함수는 "레시피를 적어두는 것"이고, 호출은 "그 레시피대로 요리하는 것"이다.

조건문 + 함수 — 판정 함수 만들기

Python
def judge_pass(temp):
    if 295 <= temp <= 305:
        return "합격"
    else:
        return "불합격"

for temp in temperatures:
    result = judge_pass(temp)
    print(f"{temp}도 → {result}")
실행 결과 
295.4도 → 합격
298.1도 → 합격
312.6도 → 불합격
301.0도 → 합격
296.8도 → 합격

종합 실습 — 함수로 여러 로트 한 번에 판정하기

Python — 종합 실습
lots = [
    {"로트번호": "LOT-0101", "온도_섭씨": 299.5},
    {"로트번호": "LOT-0102", "온도_섭씨": 306.2},
    {"로트번호": "LOT-0103", "온도_섭씨": 301.0},
]

fail_count = 0
for lot in lots:
    result = judge_pass(lot["온도_섭씨"])
    print(f"{lot['로트번호']}: {result}")
    if result == "불합격":
        fail_count += 1

print(f"불합격 로트 수: {fail_count}개")
실행 결과 
LOT-0101: 합격
LOT-0102: 불합격
LOT-0103: 합격
불합격 로트 수: 1개
4차시 예고 오늘 for와 if로 한 줄씩 직접 짠 이 판정 로직을, 4차시부터는 Pandas가 df[df["온도_섭씨"] > 305] 같은 한 줄로 대신 처리해준다. 오늘 만든 judge_pass 함수가 왜 필요했는지 그때 다시 비교해본다.

🗂️ 핵심 용어 카드

조건문

if statement
한 줄 설명
조건이 참(True)일 때만 특정 코드를 실행하게 만드는 구문.
쉬운 비유
갈림길에서 표지판을 보고 방향을 정하는 것.
데이터에서의 예
if temp > 305: print("고온")
자주 하는 오해
if 다음 줄의 들여쓰기를 생략해도 된다고 착각하기 쉽다.

비교 연산자

Comparison Operator
한 줄 설명
두 값을 비교해 참/거짓을 돌려주는 기호(>, <, == 등).
쉬운 비유
저울에 두 값을 올려 어느 쪽이 무거운지 재는 것.
데이터에서의 예
equipment == "EQ-01"
자주 하는 오해
=(대입)과 ==(비교)를 혼동하기 쉽다.

반복문

for loop
한 줄 설명
리스트의 값을 처음부터 끝까지 하나씩 꺼내 반복 실행하는 구문.
쉬운 비유
줄지어 선 사람들을 한 명씩 순서대로 호명하는 것.
데이터에서의 예
for temp in temperatures: ...
자주 하는 오해
반복 변수(temp)의 이름이 리스트 이름과 같아야 한다고 착각하기 쉽다(아무 이름이나 가능).

함수

Function
한 줄 설명
def로 정의해 이름을 붙여 재사용하는 코드 묶음.
쉬운 비유
레시피 — 정의는 "레시피 적기", 호출은 "그대로 요리하기".
데이터에서의 예
def judge_pass(temp): ...
자주 하는 오해
함수를 정의만 하고 호출(괄호로 실행)하는 것을 잊기 쉽다.

return

Return Value
한 줄 설명
함수가 계산한 결과값을 호출한 쪽으로 돌려주는 키워드.
쉬운 비유
자판기에 돈을 넣으면(호출) 물건이 나오는 것(return 값).
데이터에서의 예
return sum(numbers) / len(numbers)
자주 하는 오해
print()와 return을 혼동하기 쉽다. print는 "보여주기", return은 "값을 돌려주기"다.

⚠️ 주의할 점 & 자주 발생하는 오류

오류 1 IndentationError: expected an indented block — if나 for 다음 줄을 들여쓰지 않은 경우다. 콜론(:) 다음 줄은 반드시 들여써야 한다.
오류 2 SyntaxError — 조건문에서 =을 == 대신 쓴 경우다. "비교"는 항상 등호 두 개다.
주의 — 함수는 정의와 호출이 다르다 def judge_pass(temp): ...만 실행하면 함수가 "준비"만 될 뿐, 실제로 판정하려면 judge_pass(295.4)처럼 괄호를 붙여 "호출"해야 한다.

✅ 결과 정리 & 퀴즈

퀴즈는 실습지와 아래 정리 문제로 확인한다.

Q1. (객관식) 다음 중 문법 오류가 있는 코드는?
  • A. if temp > 305:
  • B. if temp = 305:
  • C. if temp == 305:
  • D. if temp >= 305:
정답: B. 조건문에서 비교는 ==를 써야 한다. =는 대입 연산자라서 조건 자리에 그대로 쓰면 SyntaxError가 난다.
Q2. (참/거짓) for temp in temperatures:에서 temp라는 이름은 반드시 temperatures와 관련된 이름이어야 한다.
정답: 거짓. temp는 그냥 변수 이름이므로 x, t 등 어떤 이름을 써도 동작은 같다. 다만 읽기 쉬운 이름을 쓰는 것이 좋은 습관이다.
Q3. (빈칸) 누적 변수 count를 1씩 늘리는 코드를 완성해보자: count ______ 1
정답: += → count += 1. count = count + 1과 완전히 같은 뜻이다.
Q4. (객관식) def로 함수를 정의만 하고 호출하지 않으면 어떻게 되는가?
  • A. 자동으로 한 번 실행된다
  • B. 오류가 난다
  • C. 아무 일도 일어나지 않는다(함수가 "준비"만 된다)
  • D. 파이썬이 알아서 매개변수를 채워 실행한다
정답: C. 함수는 정의만으로는 실행되지 않는다. 괄호를 붙여 함수이름(값)처럼 호출해야 실제로 코드가 실행된다.
Q5. (서술) print()와 return의 차이를 한 문장으로 설명해보자.
예시 답안: "print()는 화면에 값을 보여주기만 하고, return은 함수의 결과값을 호출한 곳으로 돌려줘서 다른 변수에 저장하거나 다시 계산에 쓸 수 있게 한다."
