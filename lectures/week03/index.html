3차시 · 2시간 수업 · 개요(skeleton)

리스트·딕셔너리로 배우는 조건문, 반복문, 함수

💬 오늘의 질문: "리스트에 담긴 여러 설비 정보를 하나씩 살펴보며, 조건에 맞는 것만 컴퓨터가 골라내게 할 수 있을까?"

작성 상태 이 페이지는 v2 커리큘럼 구성이 확정된 직후 작성된 개요(skeleton)입니다. 제목·학습 목표·다룰 내용·데이터까지는 확정되었지만, 상세 설명·예제 코드·단계별 실습·퀴즈는 아직 채워지지 않았습니다. 구성이 최종 확정되면 이어서 상세 내용을 작성합니다. 배경은 docs/restructure-plan.md 참고.

🎯 학습 목표

  • if/elif/else로 조건에 따라 다르게 판단하는 코드를 작성할 수 있다.
  • for로 리스트와 딕셔너리를 순회할 수 있다.
  • def로 반복되는 계산을 함수로 만들어 재사용할 수 있다.
  • 2차시에서 만든 리스트·딕셔너리 예제로 합격/불합격을 직접 판정할 수 있다.

선수 지식: 2차시 — 리스트·딕셔너리

📚 다룰 이론 주제(초안)

  • 비교 연산자(>, <, ==)
  • if / elif / else
  • for로 리스트·딕셔너리 순회하기
  • 누적 합·개수 세기
  • 함수 정의와 호출, 매개변수와 반환값

🐍 다룰 실습 흐름(초안)

  1. 온도 하나를 조건문으로 정상/비정상 판정하기
  2. for로 리스트 전체를 순회하며 정상 개수 세기
  3. '딕셔너리의 리스트'를 순회하며 조건에 맞는 설비만 골라내기
  4. 평균 계산을 함수로 만들기
  5. 합격/불합격 판정을 함수로 만들어 여러 로트에 반복 적용하기
