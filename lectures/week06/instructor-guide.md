# 6차시 강의 운영안 — 그래프로 공정 상태 이해하기

## 왜 이걸 배워야 할까? (학생에게 전달할 메시지)

평균은 "얼마인가", 그래프는 "어떤 모양인가"를 알려준다. 설비 4대의 평균 온도는 302.8 / 303.7 / 302.2 / 302.7℃로 거의 같지만,
박스플롯에서는 EQ-02만 293.7~314.7℃로 길게 퍼져 있다(정상 범위 295~305℃ 밖 37건 중 14건, 약 38%). 출근길 비유(평균 30분이 같아도
28~32분인 길과 15~50분인 길은 다르다)로 잡아준다.

## 수업 흐름

개념은 **쉬운 예제(`ice`)로만** 설명하고, 반도체 데이터(`df`)는 "반도체 데이터로 확인하기"에서 핵심 세 가지만 시연한다. 나머지는 실습지 문제 1~8(노트북 8~11단계)에서 학생이 푼다.

1. 지난 시간 연결 + 오늘 쓰는 표 두 개 소개(둘 다 가상 데이터, 합격여부 1 = 합격, -1 = 불합격).
2. "왜 이걸 배워야 할까?": 평균 표 → "네 설비 상태가 같을까요?" → 박스플롯 공개.
3. 그래프 읽기 순서(축 이름 → 하나가 무엇인지 → 전체 모양)와 "질문 → 그래프" 표.
4. Orange3 시연(Scatter Plot·Box Plot·Distributions). 학생이 답을 적어 두게 한다.
5. 휴식
6. 쉬운 예제로 개념: 준비·`pd.to_datetime` → 선 → 막대 → 히스토그램 → 산점도 → 박스플롯 → 숫자 요약(흐린 날 함정). (노트북 1~7단계)
7. 반도체 데이터로 확인하기(강사 시연): 확인 1 드리프트(선), 확인 2 온도-두께/압력(산점도, 원인 후보), 확인 3 설비별 퍼짐(박스플롯·숫자 요약).
8. 학생 실습: 실습지 문제 1~8 = 노트북 8~11단계.
9. AI 활용(노트북 12·13단계).
10. 정리 퀴즈 + 과제 + 7차시 예고(기록 수가 다르면 비율로 비교).

## 강사 설명 포인트
- **개념은 쉬운 예제로, 반도체는 핵심만.** "반도체 데이터로 확인하기"에서 코드가 쉬운 예제와 같은 모양(표 이름 `ice` → `df`, 열 이름만 바뀜)임을 나란히 보여준다.
- 그래프마다 "가로축은 ○○, 세로축은 ○○, 하나는 ○○, 전체 모양은 ○○"를 소리 내어 읽는다.
- 박스플롯은 학생 몇 명을 키 순서로 세워 "한가운데 = 가운데 선, 가운데 절반 = 상자"로 보여준다.
- `value_counts()`는 사실상 처음이다. `print(counts)` 결과를 먼저 보여주고 "그 숫자가 막대 높이"라고 짚는다.
- 히스토그램은 21일 → `bins=5`, 180건 → `bins=10`.
- 산점도는 8차시 예고편이다. 상관계수는 계산하지 않고 "함께 움직여도 원인은 아니다"만 남긴다. 확인 2에서 온도-압력 대비를 꼭 보여준다.
- 흐린 날 함정은 "여러 열 함께 보기"의 생활판이다. 반도체에서도 열 하나만 보지 않는 이유와 연결한다.
- `groupby().describe()`는 구경만(실습지 문제 8도 빈칸 없이 그대로 실행). `std`는 "퍼짐의 크기"까지만.
- **강사만 알고 있을 것**: 패턴은 생성 때 일부러 넣었다. "EQ-02 히터 고장" 같은 해석으로 넘어가지 않고 "EQ-02를 먼저 더 살펴볼 만하다"에서 끊는다.
  "원인 후보"는 무엇의 후보인지 분명할 때만(온도 → 두께).
- `압력_Pa`는 단위·자릿수가 실제와 맞지 않는 가상 값이다. "크기를 해석하지 않고 비교만 한다"고 답한다.

## 예상 오개념
- 평균이 같으면 상태도 같다 → 퍼짐이 다르면 다른 상태다.
- 히스토그램 = 막대그래프 → 가로축이 숫자 구간 vs 이름이다.
- 박스플롯 가운데 선 = 평균 → 중앙값이다(맑음·흐림 가운데 선은 둘 다 99.0, 평균은 101.5와 109.3).
- 동그라미 점 = 잘못된 값 → 멀리 떨어졌다는 표시일 뿐이다.
- 그룹 이름 하나로 차이를 설명(흐리면 더 팔린다) → 기온을 함께 본다.
- 산점도가 기울면 원인이다 → 함께 움직이는 것과 원인은 다르다.
- 건수가 적은 EQ-02는 문제없는 설비 → 건수는 사용 횟수일 뿐이다.

## 실습 중 오류 대응
아래는 이 차시 코드를 실제로 실행해 확인한 오류다.
- 한글 네모(□) + `UserWarning: Glyph 50728 (\N{HANGUL SYLLABLE ON}) missing from font(s) DejaVu Sans.`: 1단계 글꼴 두 줄 미실행. Mac은 `"AppleGothic"`.
- `KeyError: '날짜'`: 실습지 문제에서 쉬운 예제를 바꿔 쓰며 표 이름만 `df`로 바꾸고 열 이름은 그대로 뒀다.
- `KeyError: 'Column not found: 온도'` / `KeyError: '설비'`: 열 이름을 줄여 썼다(`온도_섭씨`, `설비번호`).
- `TypeError: scatter() missing 1 required positional argument: 'y'` / `TypeError: bar() missing 1 required positional argument: 'height'`: 값을 하나만 넣었다.
- `NameError: name 'df' is not defined`: 8단계의 읽기 셀을 건너뛰었다. 위부터 다시 실행.
- 오류 없이 이상한 그래프: 가로축 글자 겹침(`pd.to_datetime`·`xticks` 확인), 그림 겹침(셀 나누기), 엉뚱한 축 이름(`xlabel`/`ylabel` 미수정).
- 빈칸 미입력: 함수 빈칸은 `AttributeError: module 'pandas' has no attribute '____'`(또는 `'matplotlib.pyplot'`, `'Series' object`, `'DataFrame' object`),
  열 이름 빈칸(문제 6·7)은 `KeyError: '____'`.
