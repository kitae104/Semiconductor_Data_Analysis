# 6차시 강의 운영안 — 그래프로 공정 상태 이해하기

## 왜 이걸 배워야 할까? (학생에게 전달할 메시지)

숫자 표는 한 줄씩 읽어야 하지만 그래프는 전체 모양을 한 번에 보여 준다.
웨이퍼 다이 317줄짜리 표로는 불합격 다이가 어디에 몰렸는지 모르지만, 점으로 찍으면 가장자리 고리가 바로 보인다(64개 중 60개).
그리고 평균이 비슷한 설비 네 대도 상자 그림으로 보면 퍼짐이 다르다 — 평균만 보면 놓치는 것을 그래프가 보여 준다.

## 수업 흐름

PART 1 파이썬 → PART 2 Orange3 → PART 3 실습지 순서다. 노트북은 단계 번호로 지시한다.

1. 오늘의 질문·오늘의 미션(입사 여섯째 날, 회의용 그래프 3장) → 지난 시간 복습 2문항(`dropna()` 미저장, Missing 3)
2. PART 1 시작: 학생용 노트북 "막혔을 때" 셀 읽기
3. 노트북 1단계: `plt` 불러오기·한글 설정 두 줄·가게 기록 읽기 → 4줄 틀 표와 "질문 → 그래프" 표
4. 노트북 2단계: `value_counts()` → `plt.bar`(맑음 12 · 흐림 6 · 비 3) → **직접 해 보기** 빈칸 `ice["요일"]`(월~일 막대 7개 모두 3)
5. 노트북 3~4단계: 판매량 히스토그램(`bins=5`) → **직접 해 보기** 빈칸 `bins=10`(구간별 2 1 1 3 5 1 2 2 1 3, 최고 5일) → 기온-판매량 산점도(오른쪽 위로)
6. **여기서 쉬기**
7. 노트북 5단계 "반도체 데이터로 확인하기": 정답 노트북으로 시연 — `(180, 10)`, 공정명별 막대, 두께 히스토그램, 온도-압력 산점도(흩어진 구름)
8. PART 2 Orange: 말 사전·위젯 이름표(묶음 열 포함)·Box Plot 창 읽는 법 → 공정 지도 위치 두 줄 → 워밍업 `week06_1_wafermap_start.ows`(학생이 직접, 웨이퍼 맵 장면) → 웨이퍼 맵은 생성 그림·캡처가 정답 접힘 안에 있으니 학생이 Scatter Plot을 띄우고 말해 본 뒤 연다 → 반도체 `week06_2_process_start.ows` 1~2단계는 **강사 시연**(Distributions, Scatter Plot — Scatter는 축 설정까지만 보여 주고 창을 닫는다. 점 모양은 실습지 문제 3 뒤에 다시 열어 비교), 3단계 Box Plot은 설정만 보여 주고 읽기는 실습지 문제 4로 넘긴다 → 파이썬 결과와 비교 한 문장
9. **여기서 쉬기**(필요하면)
10. PART 3 실습지: 문제 1~3(노트북 6단계, 오늘의 미션 그래프 3장) → 문제 4(Orange Box Plot) → 문제 5(해석 문장) → 정답 확인과 문장 발표
11. 결과 정리·반도체 이해 포인트 → AI로 한 걸음 더(노트북 7단계) → 과제·7차시 예고

## 강사 설명 포인트

- 개념은 가게 기록으로만 설명하고, 공정 기록은 5단계에서 "표 이름과 열 이름만 바뀐다"를 보여 준다. 실습지 힌트가 강의의 어느 확인과 같은 모양인지 짚어 준다(문제 1 ↔ 확인 1, 문제 2 ↔ 확인 2, 문제 3 ↔ 확인 3).
- 그래프는 질문이 고른다. "무엇을 알고 싶은가?"를 먼저 묻고 그래프를 고르게 한다.
- 4줄 틀을 칠판에 적어 두고 그래프마다 첫 줄만 바뀐다는 것을 반복한다. 막대만 앞에 `value_counts()` 한 줄이 붙는다.
- 산점도에서 "함께 움직인다"까지만 말한다. 온도가 두께를 바꾼다고 단정하지 않는다(상관과 원인 후보는 8차시).
- 오늘의 aha는 웨이퍼 맵이다. Scatter Plot을 연 뒤 강의의 "보이는 것 확인 보기"를 열기 전에 "무엇이 보이나요?"를 먼저 묻는다.
- 웨이퍼 가장자리 불량의 실제 이유는 단정하지 않는다. "어디를 먼저 살펴볼지 단서"까지만 말한다. 이 데이터는 가장자리형 패턴을 심은 가상 데이터다.
- 공정 기록은 설비 4대가 여러 공정 기록을 함께 남긴 교육용 가상 기록이다. "같은 작업을 하는 기계 네 대"라고 말하지 않는다. 설비별 상자 그림은 "그 설비 기록의 온도가 얼마나 퍼졌나"로만 읽는다.
- `압력_Pa`는 절대값을 해석하지 않는다(데이터 설명서 "압력_Pa 값의 한계").

## 학생들이 자주 찾아볼 질문과 보충 설명

- **막대그래프와 히스토그램 차이**: AI가 "히스토그램은 연속형, 막대는 범주형"처럼 용어만 늘어놓을 수 있다. "이름 붙은 무리를 세나(막대), 숫자 구간을 세나(히스토그램)"로 다시 말해 준다.
- **박막 두께가 중요한 이유**: AI가 구체적인 두께 규격(몇 nm ± 몇 %)을 단정하는 경우가 있다. 실제 범위는 막 종류·제품마다 다르고, 오늘 데이터 값은 교육용이라고 짚는다.
- **상자그림 읽는 법**: AI 답이 수염(whisker) 길이 규칙(1.5×IQR)이나 이상값 점을 길게 설명할 수 있다. Orange Box Plot은 상자 밖 선을 최솟값~최댓값까지 그리고 따로 찍힌 점이 없다. 오늘은 "상자 = 가운데 절반, 길이 = 퍼짐"까지만 쓴다.
- **웨이퍼 맵이란**: AI가 가장자리 불량의 이유를 하나로 단정(예: 특정 공정 탓)할 수 있다. 실제로는 여러 가능성이 있고 맵 모양은 "어디를 먼저 볼지" 단서라고 보충한다. 다이 수·배치는 제품마다 다르다.

## 예상 오개념

- 막대그래프와 히스토그램은 같은 그래프다 → 막대는 이름 붙은 무리, 히스토그램은 숫자 구간을 센다.
- `plt.bar(df["설비번호"])`로 개수가 그려진다 → 높이(개수)가 없어 TypeError. `value_counts()`로 먼저 센다.
- 산점도에서 점이 함께 올라가면 온도가 두께를 바꾼 것이다 → 함께 움직인다는 것까지만 보인다(8차시).
- 상자가 길면 온도가 높다 → 상자의 위치가 크기, 길이가 퍼짐이다.
- 기록 수가 많은 설비가 퍼짐도 크다 → EQ-02는 기록이 가장 적은데(37건) 상자가 가장 길다. 막대와 상자 그림은 다른 것을 보여 준다.
- 웨이퍼 맵의 가장자리 불량은 곧 특정 공정의 잘못이다 → 단서일 뿐 이유를 확정하지 않는다.

## 막히는 지점 TOP3와 대처

1. **한글이 네모로 깨지거나 Glyph 경고가 뜸** — 1단계 첫 셀(`plt.rcParams[…]` 두 줄)을 건너뛰고 그래프 셀부터 실행한 경우다. 첫 셀을 실행하고 그래프 셀을 다시 실행하게 한다. 커널을 다시 시작했다면 첫 셀부터 다시 실행해야 한다.
2. **Orange 반도체 Scatter Plot이 바둑판 모양** — 처음에 x 설비번호·y 공정명으로 잡혀서다. 왼쪽 Axis x·Axis y 칸을 `온도_C`·`두께_nm`로 바꾸게 한다. Box Plot도 Variable·Subgroups 두 칸을 모두 바꿔야 온도 상자 네 개가 나온다(Variable만 바꾸면 상자 두 개(1, -1), Subgroups만 바꾸면 온도가 아닌 측정시간 상자가 나온다).
3. **실습지 문제 2·3 빈칸에 따옴표 없이 열 이름을 씀** — `df[온도_C]`처럼 쓰면 `NameError: name '온도_C' is not defined`가 난다. 열 이름은 `"온도_C"`처럼 따옴표 안에 쓴다. 문제 3에서 x·y를 바꿔 넣으면 오류 없이 옆으로 누운 그림이 나온다 — 축 이름과 함께 확인시킨다.

## 실습 중 오류 대응

- `Glyph 44032 (\N{HANGUL SYLLABLE GA}) missing from font(s) DejaVu Sans.` 경고 + 글자가 네모: 1단계 첫 셀 미실행.
- `TypeError: bar() missing 1 required positional argument: 'height'`: `plt.bar`에 열을 바로 넣었다. `value_counts()`로 센 결과의 `.index`와 값을 넣는다.
- 그래프 위에 `Text(0, 0.5, '기록 건수')` 줄: `plt.show()`를 빠뜨렸다(오류는 아님).
- `KeyError: '온도_c'`: 열 이름 대소문자·철자가 다르다. 오늘 열 이름은 `온도_C`(대문자 C), `두께_nm`, `설비번호`다(`print(df.columns)`로 확인).
- `AttributeError: module 'matplotlib.pyplot' has no attribute 'Bar'`: 함수 이름을 대문자로 썼다. `plt.bar`처럼 소문자다.
- `____`를 채우지 않고 실행(실제 메시지): 문제 1 `AttributeError: 'Series' object has no attribute '____'`, 그리기 함수 자리 `AttributeError: module 'matplotlib.pyplot' has no attribute '____'`, 열 이름 자리 `NameError: name '____' is not defined`. 빈칸을 채운다.
- `NameError: name 'df' is not defined`: 5단계 셀을 실행하지 않고 6단계로 왔다. "막혔을 때" 셀대로 위에서부터 다시 실행한다.
- Orange File에 파일 이름이 빨갛게 보임: `.ows`를 원래 폴더 밖으로 옮겼거나 폴더 구조가 바뀌었다. 원래 폴더의 `_start.ows`를 다시 연다.

## 빨리 끝낸 학생용 과제

- Orange 웨이퍼 맵 Scatter Plot에서 Color를 `중심거리_mm`로 바꿔 보고, 색이 가운데에서 바깥으로 어떻게 변하는지 한 문장으로 적는다. 다시 `합격여부`로 돌려 불합격 점의 위치와 비교한다.
- 실습지 문제 3과 같은 모양으로 `plt.scatter(df["진동_mm_s"], df["두께_nm"])`를 그리고(x·y 축 이름도 바꾼다), 온도-두께 산점도와 모양이 어떻게 다른지 한 문장으로 적는다.
