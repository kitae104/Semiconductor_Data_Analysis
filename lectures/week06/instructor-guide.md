# 6차시 강의 운영안 — 그래프로 공정 상태 이해하기

## 왜 이걸 배워야 할까? (학생에게 전달할 메시지)

숫자 요약(평균)은 "얼마인가"를, 그래프는 "어떤 모양인가"를 알려준다. 숫자 하나로 줄이는 순간 사라지는 정보가 있어서,
둘을 함께 봐야 놓치지 않는다.

**예를 들면**: 오늘 데이터에서 설비 4대의 평균 온도는 302.8 / 303.7 / 302.2 / 302.7℃로 거의 같다. 그런데 박스플롯으로
그리면 EQ-02만 상자가 길게 늘어나 있다. EQ-02는 293.7℃부터 314.7℃까지 오르내렸고, 학습용 정상 범위(295~305℃) 밖 기록이
37건 중 14건이다(다른 설비는 46~50건 중 9~10건). 출근길 비유(평균 30분이 같아도 매일 28~32분인 길과 15~50분인 길은 다르다)로
"평균이 같아도 퍼짐이 다르면 다른 상태"를 먼저 잡아준다.

## 수업 흐름

1. 지난 시간 연결: 1차시 "여러 열 함께 보기", 4차시 열 선택·조건 검색, 5차시 `describe()`. 오늘 데이터의 열이
   공장에서 무엇을 뜻하는지 표로 한 번 짚는다(합격여부 1 = 합격, -1 = 불합격 포함).
2. "왜 이걸 배워야 할까?": 평균 표 → "그럼 네 설비 상태가 같을까요?" 질문 → 박스플롯 그림 공개 → 출근길 비유.
3. 그래프 읽기 첫걸음: 읽는 순서 3단계(축 이름 → 하나가 무엇인지 → 전체 모양)와 "질문 → 그래프" 표.
4. Orange3 시연: File → Scatter Plot·Box Plot·Distributions. 학생이 답(기운 방향, 가장 긴 상자, 가장 높은 막대 위치)을 적어 두게 한다.
5. 휴식
6. 파이썬 준비(글꼴 두 줄, `read_csv`, `pd.to_datetime`) → 그래프 코드의 공통 네 줄 틀.
7. 그래프 다섯 가지를 "읽는 법 → 코드 → 결과 → 해석" 순서로 시연: 선 → 막대 → 히스토그램 → 산점도 → 박스플롯.
   산점도에서 "함께 움직여도 원인은 아니다"를, 박스플롯에서 그림의 각 부분 이름을 꼭 짚는다.
8. 숫자로 다시 확인하기: `groupby().describe()`는 실행만(7차시 예고). 25%·50%·75%가 상자 아래 끝·가운데 선·위 끝과
   같은 숫자임을 박스플롯 옆에 놓고 보여준다.
9. 학생 실습: 학생용 노트북 1~7단계. 먼저 끝난 학생은 7단계 끝 "도전 문제"(진동 박스플롯).
10. AI 활용(노트북 8·9단계) → 연습문제(10단계, 불합격 막대그래프) → 글자 막대그래프 미니 프로그램(11단계).
11. 정리 퀴즈 + 과제 안내 + 7차시 예고(같은 불합격 8건, 다른 기록 수 → 비율).

## 강사 설명 포인트
- **"질문 먼저, 그래프는 나중"**을 반복한다. 그래프를 그리기 전에 학생에게 "지금 무엇이 궁금한가요?"를 한 문장으로 말하게 하고,
  "질문 → 그래프" 표에서 고르게 한다.
- **그래프마다 읽는 순서 3단계를 소리 내어 읽는다.** "가로축은 ○○, 세로축은 ○○, 점 하나는 ○○, 전체 모양은 ○○."
  처음 두 그래프는 강사가, 나머지는 학생이 말하게 한다.
- **박스플롯은 줄 세우기로 설명한다.** 학생 몇 명을 키 순서로 세우고 "한가운데 친구 = 가운데 선, 가운데 절반 = 상자"를
  보여주면 가장 빨리 이해한다. 1.5배 규칙은 "많이 멀리 떨어진 값은 따로 점으로 찍는다" 정도로 충분하다.
- `value_counts()`는 4차시 핵심 개념이 아니어서 대부분의 학생에게 사실상 처음이다. 막대그래프 앞에서 `print(counts)` 결과를
  먼저 보여주고 "값마다 몇 건인지 센다 → 그 숫자가 막대 높이가 된다"를 짚는다.
- 박스플롯 위의 영어 제목 "Boxplot grouped by 설비번호"는 pandas가 자동으로 붙이는 것이라고 미리 말해 둔다.
- **산점도는 8차시 상관관계의 예고편이다.** 이 차시에서는 상관계수를 계산하지 않는다. "오른쪽 위로 기울면 함께 커진다"는 그림 감각과
  "함께 움직여도 원인은 아니다"(아이스크림-물놀이 사고) 한 줄만 남긴다. 상관계수 질문이 나오면 "8차시에 숫자로 잰다"고 답한다.
- 온도-압력 "직접 해보기"는 꼭 시킨다. 같은 온도 열이라도 짝에 따라 모양이 다르다는 대비가 산점도 이해의 핵심이다.
- `groupby().describe()`는 **구경만**이다. 문법을 설명하지 말고 25%·50%·75% 세 열이 박스플롯 숫자라는 것만 짚는다.
  `std`는 "퍼짐의 크기를 숫자 하나로 잰 것"까지만.
- **강사만 알고 있을 것**: 드리프트·EQ-02 퍼짐·온도-두께 경향은 데이터 생성 때 일부러 넣었다. 실제 공장 해석(예: "EQ-02 히터가
  고장이다")으로 넘어가지 않게 한다. "이 그래프로 말할 수 있는 것은 EQ-02를 먼저 더 살펴볼 만하다까지"로 끊는다.
  "원인 후보"라는 말은 산점도(온도가 두께의 원인 후보)처럼 무엇의 후보인지가 분명할 때만 쓴다.
- `압력_Pa`는 단위와 자릿수가 실제 챔버 압력과 맞지 않는 가상 값이다. 학생이 물으면 "크기를 해석하지 않고 기록끼리 비교만 한다"고 답한다.

## 예상 오개념
- 평균이 같으면 상태도 같다 → 퍼짐(상자 길이)이 다르면 다른 상태다. 출근길 비유로 되돌아간다.
- 히스토그램과 막대그래프를 같은 것으로 생각 → 히스토그램 가로축은 숫자 구간, 막대그래프 가로축은 이름이다.
- 박스플롯 가운데 선을 평균으로 착각 → 중앙값이다. 평균은 박스플롯에 나오지 않는다(숫자 요약의 `mean`과 `50%`를 나란히 보여준다).
- 박스플롯 동그라미 점 = 잘못된 값 → 5차시의 "있을 수 없는 값"과 다르다. 멀리 떨어졌다는 표시일 뿐이다.
- 산점도가 기울면 원인이다 → 함께 움직이는 것과 원인은 다르다(8차시에서 숫자로, 9·10차시에서 예측으로 이어진다).
- 막대그래프에서 건수가 적은 EQ-02가 "문제없는 설비" → 건수는 사용 횟수일 뿐, 상태와는 다른 이야기다.

## 실습 중 오류 대응
아래는 이 차시 코드를 실제로 실행해 확인한 오류다.
- 한글이 네모(□)로 나오고 `UserWarning: Glyph 50728 (\N{HANGUL SYLLABLE ON}) missing from font(s) DejaVu Sans.` 같은 경고가 뜬다:
  1단계 첫 셀의 글꼴 설정 두 줄을 실행하지 않은 경우다(글자 번호와 이름은 그래프의 첫 한글 글자에 따라 다르다). 첫 셀부터 다시 실행.
  Mac이면 `"AppleGothic"`으로 바꾼다.
- `KeyError: 'Column not found: 온도'`: 박스플롯 `column=`에 열 이름을 줄여 썼다. `온도_섭씨`로 고친다.
- `KeyError: '설비'`: 박스플롯 `by=`에 그룹 열 이름을 틀렸다. `설비번호`로 고친다.
- `TypeError: scatter() missing 1 required positional argument: 'y'`: `plt.scatter()`에 열을 하나만 넣었다.
- `TypeError: bar() missing 1 required positional argument: 'height'`: `plt.bar(counts)`처럼 이름과 높이를 하나만 넣었다.
  `plt.bar(counts.index, counts)` 두 개를 넣게 한다.
- `NameError: name 'df' is not defined`: 1단계를 건너뛰었다. 맨 위 셀부터 다시 실행.
- 오류는 없지만 그래프가 이상한 경우:
  - 선 그래프 가로축 글자가 겹친다 → `pd.to_datetime()` 셀을 실행했는지, `plt.xticks(rotation=45)` 줄이 있는지 확인.
  - 그림 두 개가 한 장에 겹친다 → 한 셀에 그래프 코드를 두 개 썼다. 셀을 나눈다.
  - 연습문제 결과가 0건 → `== "-1"`처럼 따옴표를 붙였다. 이 열은 숫자다.
- 빈칸 `____`을 채우지 않고 실행한 경우(학생용 노트북을 그대로 실행해 확인): 대부분
  `AttributeError: module 'pandas' has no attribute '____'`(또는 `'matplotlib.pyplot'`, `'Series' object`, `'DataFrame' object`)이고,
  열 이름 빈칸은 `KeyError`(메시지 안에 `____`가 보인다), 연습문제 숫자 빈칸은 `NameError: name '____' is not defined`다.
  메시지에 `____`가 보이면 빈칸을 채우게 한다.

## 느린 학습자용 최소 과제
