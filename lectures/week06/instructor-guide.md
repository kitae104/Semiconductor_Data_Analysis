# 6차시 강의 운영안 — 그래프로 공정 상태 이해하기

## 🤔 왜 이걸 배워야 할까? (학생에게 전달할 메시지)

숫자로만 나열된 표는 수백 행만 넘어가도 패턴을 눈으로 알아채기 어렵다. 그래프는 온도·압력 같은 값의
변화와 설비 간 차이를 한눈에 보여줘서, 어디를 더 자세히 조사해야 할지 훨씬 빠르게 판단하게 해준다.

**쉬운 예시**: 설비 4대의 온도를 표로만 보면 숫자가 너무 많아 비교가 쉽지 않다. 하지만 박스플롯
하나로 그리면 "EQ-02만 유난히 온도가 들쭉날쭉하다"는 사실이 한눈에 보인다 — 표를 한 줄씩 읽지 않고도
문제 설비를 바로 짐작할 수 있다.

## 수업 흐름

1. 지난 시간(5차시 결측/이상값 정제) 복습 + 오늘의 질문 제시 — "표만 보고도 이상을 알 수 있을까?"
2. Orange3 시연: Scatter Plot·Box Plot 위젯으로 패턴 먼저 훑어보기
3. 그래프 5종 이론 설명(선/막대/히스토그램/산점도/박스플롯) — 그래프 선택 가이드 표로 정리
4. 강사 코드 시연: `read_csv` → `to_datetime` → 5개 그래프 순서대로 시연(실제 이미지로 결과 확인)
5. 휴식
6. 학생 실습(노트북 1~6단계): 에디터에서 5개 그래프 직접 그리기
7. 도전 실습: 진동_mm_s 박스플롯 그리기
8. 정리 퀴즈 + 과제 안내 + 다음 차시 예고

## 준비물
- 발표자용 에디터 실습 환경, 프로젝터, Orange3(실습 PC에 미리 설치, 위젯 사용법은 `docs/orange3-guide.html` 참고)
- `data/weekly/week06/week06_process_visualization.csv` (학생 각자 다운로드 준비)
- 5차시에서 정제한 데이터를 다시 띄워 "정제된 데이터라야 그래프도 왜곡 없이 보인다"는 연결고리로
  시작하면 좋다.

## 오늘 데이터 핵심 수치(실제 실행 결과, 강의 중 반드시 확인)
- 원본: **180행 10열**
- 설비별 온도 표준편차: EQ-01 3.22 / **EQ-02 5.37(가장 큼)** / EQ-03 3.05 / EQ-04 3.02
- 설비별 불합격률: EQ-01 4.3% / **EQ-02 21.6%(가장 높음)** / EQ-03 6.5% / EQ-04 16.0%
- 온도-두께 상관계수: **약 0.81**(비교적 강한 양의 상관)
- 두께-진동 상관계수: **약 0.12**(거의 관계 없음) — 실습지 7번 심화에서 학생이 계산하는 값이다.
- 온도 정상범위(295~305℃) **안** 138건 불합격률 **10.9%** / **밖** 42건 불합격률 **14.3%**
  → 차이 **3.4%p**뿐이다. **"온도가 불안정해서 불합격"이라고 정리하지 않는다.**
- 진동 상위 25%(약 0.55 이상) 45건 불합격률 **17.8%**(전체 11.7%) — 그런데 **EQ-02를 빼면 5.6%**로
  전체보다 낮아진다. EQ-02 진동 평균 **0.61** vs 나머지 약 **0.50**.
- 시간에 따른 온도는 완만한 상승(드리프트) 패턴을 보인다.

## 강사 설명 포인트
- Orange3 Box Plot을 먼저 보여줄 때, 학생들이 "어느 설비의 상자가 가장 넓은지" 스스로
  발견하도록 질문으로 유도한다.
- 그래프 선택은 "무엇이 알고 싶은가"에서 출발해야 한다는 점을 강조한다 — 강의 자료의
  "그래프 선택 가이드" 표(이제 예시 질문 열이 추가됨)를 칠판에도 옮겨 적어두면 좋다.
- 각 그래프마다 "언제 쓰는가"와 "지금 이 그래프가 무엇을 보여주는가"를 분리해서 설명한다.
  초보자는 "일단 막대그래프부터" 그리는 습관이 있으므로, 그래프를 그리기 전에 "나는 지금
  무엇이 궁금한가"를 말로 먼저 표현하게 한 뒤 그래프를 고르도록 유도한다.
- 산점도에서 상관계수 0.81을 보여줄 때, "관계가 있어 보인다"까지만 말하고 "온도가 두께의
  원인이다"라고 단정하지 않는다 — 8차시 예고로 자연스럽게 연결한다.
- **실습지 3번(박스플롯 해석)과 7번(두께-진동 산점도)은 이 차시에서 8차시로 넘어가는 다리다.**
  두 곳 모두 학생이 "온도가 불안정해서 불합격", "진동이 높아서 불합격"으로 결론 내기 쉽다.
  강사는 위 핵심 수치(정상범위 안 10.9% vs 밖 14.3%, 진동 상위 25%는 EQ-02를 빼면 5.6%)를 들어,
  **그렇게 보이는 이유가 EQ-02가 온도 퍼짐과 진동을 동시에 갖고 있기 때문**임을 짚어준다.
  "틀렸다"가 아니라 **"이 그래프만으로는 갈라낼 수 없다"**로 말하는 것이 핵심이고, 갈라내는
  방법이 8차시 주제임을 예고한다. 이 차시에서 "교란 요인"이라는 말을 외우게 할 필요는 없다.
- 박스플롯의 상자 위아래 점(이상치 표시)이 오류가 아니라 정상적인 통계 표시임을 짚어준다.

## 예상 오개념
- 히스토그램과 막대그래프를 혼동 → 히스토그램의 x축은 "구간(bin)"이고, 막대그래프의 x축은
  "범주(카테고리)"라는 차이를 강조한다.
- `측정시간`을 `pd.to_datetime()`으로 변환하지 않고 선 그래프를 그리면 **오류는 나지 않지만**
  x축에 날짜 글자 180개가 겹쳐 읽을 수 없고 측정 사이의 실제 시간 간격도 반영되지 않는다는
  것을 직접 보여준다. 이 데이터는 `2024-03-01 05:00` 같은 ISO 형식이라 **문자열 정렬 결과와
  날짜 정렬 결과가 180행 전부 같다** — "순서가 뒤엉킨다"는 시연은 이 데이터로는 되지 않으니
  축 가독성과 간격 반영을 근거로 설명한다.
- 상관계수가 높으면 곧 인과관계라고 오해 → "관계가 있어 보인다"는 표현만 쓰고, 원인 단정은
  8차시로 미룬다는 것을 명확히 한다.
- `df.boxplot(by=...)`가 자동으로 붙이는 부제목을 그대로 두어 제목이 두 줄로 겹치는 경우가
  많다 — `plt.suptitle("")`로 지워야 함을 짚어준다.

## 실습 중 오류 대응
- x축 날짜가 겹쳐 읽히지 않는 경우: `측정시간` 열을 `pd.to_datetime()`으로 변환했는지
  확인하게 한다(문자열 그대로 그려도 **오류는 나지 않는다** — 그림이 읽기 어려워질 뿐이다).
- 그래프가 안 뜨는 경우: `plt.show()`를 빼먹지 않았는지, 코드를 순서대로 실행했는지 확인.
- 박스플롯 제목이 겹쳐 보이는 경우: `plt.suptitle("")` 추가를 안내한다.

## 빠른 학습자용 추가 과제
- 강의 자료의 "도전 실습"(진동_mm_s 박스플롯)을 먼저 시도해보게 한다.
- `df.groupby("설비번호")["온도_섭씨"].std()`를 미리 실행해보고 박스플롯 결과와 비교해보게
  한다(7차시 groupby 예고).
- 강의 자료 "연습문제 — 설비별 평균 온도 막대그래프"(`groupby().mean()` + `.plot(kind="bar")`)로
  건수 대신 평균을 막대그래프로 그리는 연습을 추가로 시켜본다. 이어지는 "AI로 재미있는 미니
  프로그램 만들기"(이모지 막대그래프)는 정확한 코드보다 matplotlib 없이도 막대그래프의 원리를
  텍스트로 표현해보는 재미에 집중하도록 유도한다.

## 느린 학습자용 최소 과제
- 히스토그램과 산점도 두 가지만 성공해도 충분하다. 박스플롯은 강사·동료와 함께 짝 활동으로
  진행한다.
- `plt.scatter(...)`까지만 실행하고, 상관계수 계산은 강사가 함께 읽어주며 숫자의 의미만
  이해시킨다.
