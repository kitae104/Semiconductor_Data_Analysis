1. 용어 연결 문제

왼쪽 용어와 오른쪽 설명을 알맞게 연결해보자.

용어설명 후보
① 그룹화(groupby)A. 값들이 평균에서 얼마나 떨어져 있는지를 나타내는 수
B. 기준 열의 값에 따라 데이터를 여러 묶음으로 나누는 것
C. 크기순으로 줄 세웠을 때 정가운데 값
D. 여러 값을 하나의 요약값으로 계산하는 것
② 집계(aggregation)
③ 중앙값(median)
④ 표준편차(std)
① B ② D ③ C ④ A

2. 코드 빈칸 문제

Python
import pandas as pd
df = pd.read_csv("week06_equipment_comparison.csv")

# 설비별 평균 온도
print(df.____________("설비번호")["온도_섭씨"].mean())

# 설비별 온도 표준편차(들쭉날쭉한 정도)
print(df.groupby("설비번호")["온도_섭씨"].____________())

# 공정별 평균 처리시간
print(df.groupby("____________")["처리시간_sec"].mean())
순서대로 groupby, std, 공정명

3. 그래프 선택 문제

여러 설비의 온도 값이 "얼마나 넓게 퍼져 있는지(변동성)"를 한눈에 비교하려면 어떤 그래프가 가장 적합할까?

  • ① 선 그래프
  • ② 박스플롯
  • ③ 원그래프
정답: ② 박스플롯. 박스플롯은 값의 중앙값과 퍼짐 정도(사분위, 이상값)를 그룹별로 한눈에 비교할 수 있다(5주차에서 배운 내용과 연결된다).

4. 결과 해석 문제

실습에서 설비별 온도 mean()과 std() 결과가 아래와 같았다.

설비번호   평균     표준편차
EQ-01   299.78    2.39
EQ-02   299.08    7.16
EQ-03   299.75    2.67
EQ-04   301.14    4.12

평균만 보고 "EQ-02가 가장 정상적인 설비"라고 말할 수 있을까? 표준편차까지 고려하면 결론이 어떻게 달라지는지 적어보자.

평균만 보면 EQ-02(299.08℃)가 가장 낮아 정상적으로 보이지만, 표준편차가 7.16으로 다른 설비(2~4대)보다 훨씬 크다. 즉 EQ-02는 값이 넓게 흔들리는 가장 불안정한 설비이므로 "정상적"이라고 단정할 수 없다.

6. 도전 문제

도전 df.groupby("설비번호")["온도_섭씨"].median()을 실행해서 평균과 중앙값을 비교해보자. 그리고 df.groupby(["설비번호","작업조"])["합격여부"].count()처럼 기준을 2개 넣어 그룹화하면 결과가 어떻게 달라지는지 확인해보자.
