오늘의 질문: "숫자 표로는 안 보이던 공정의 모습을, 그래프 몇 장으로 볼 수 있을까?"

오늘의 미션 — 입사 여섯째 날, 다음 회의에서 쓸 그래프 3장을 만들자: 설비별 건수, 온도 분포, 온도와 두께의 관계. (신입 데이터 담당자의 10일 이야기와 공장·데이터는 모두 교육용 가상이다.)

학습 목표

  • 막대그래프·히스토그램·산점도가 각각 어떤 질문에 답하는 그래프인지 고를 수 있다.
  • "그리기 → x축 이름 → y축 이름 → plt.show()"의 4줄 틀로 세 그래프를 그릴 수 있다.
  • Orange3 Scatter Plot으로 웨이퍼 맵을 그리고, Box Plot으로 무리마다 값의 퍼짐을 비교할 수 있다.
  • 평균만 보면 놓치는 것(불량이 몰린 위치, 값의 퍼짐)을 그래프를 근거로 말할 수 있다.

선수 지식: 5차시 — 정리와 describe() / 4차시 — read_csv, 열 고르기, 조건 검색 / 1차시 — Orange Distributions

왜 이걸 배워야 할까?

숫자 표는 한 줄씩 읽어야 하지만, 그래프는 전체 모양을 한 번에 보여 준다. 오늘 Orange에서 여는 웨이퍼 검사 기록은 317줄이다. 표를 위에서부터 읽어서는 불합격 다이가 웨이퍼의 어디에 몰렸는지 알 수 없다. 점으로 찍으면 한눈에 보인다.

비유 — 피자 한 판 피자 한 판(웨이퍼)에서 탄 조각(불합격 다이)이 몇 개인지만 세면 "어디가" 탔는지는 모른다. 판 위에 표시해 보면 가장자리만 탔는지, 가운데가 탔는지가 보이고, 어디를 먼저 살펴볼지 단서가 된다.

막대그래프 — 무리마다 몇 개인가

막대를 그리려면 먼저 개수를 세야 한다. value_counts()는 한 열에서 값마다 몇 번 나왔는지 세어 많은 순으로 보여 준다. 센 결과를 counts에 담고, plt.bar(이름들, 개수들)로 그린다. counts.index는 센 결과의 이름표 칸(맑음·흐림·비), counts는 개수다. 막대는 많은 순으로 놓인다.

Python — 날씨별 날 수 세고 막대로 그리기 (노트북 2단계)
counts = ice["날씨"].value_counts()
print(counts)

plt.bar(counts.index, counts)
plt.xlabel("날씨")
plt.ylabel("날 수")
plt.show()

노트북 2단계 실행 결과 — 날씨별 날 수(생활 예제용 가상 데이터)

  • 출력 첫 줄 날씨는 센 열의 이름, 마지막 줄 Name: count, dtype: int64는 "개수를 센 정수 열"이라는 표시다.
  • 3주 중 맑은 날이 12일로 가장 많고, 비 온 날은 3일이다. 숫자 세 개를 막대 높이로 바꾸니 차이가 바로 보인다.
직접 해 보기 (노트북 2단계) 요일마다 며칠씩 기록됐는지 막대로 그려 보자. 노트북의 day_counts = ice[____].value_counts() 빈칸에 세는 열 이름을 따옴표와 함께 넣는다. 나머지 세 줄은 위 코드와 같은 4줄 틀이다.
ice["요일"]. 월~일 막대 7개가 모두 높이 3이다 — 3주 기록이라 요일마다 3일씩 있다. 막대 높이가 같으면 "무리마다 개수가 같다"고 읽는다.

히스토그램 — 값이 어디에 몰렸나

히스토그램은 숫자 열 하나를 몇 개의 구간으로 나눠, 구간마다 몇 개가 있는지 막대로 보여 준다. bins는 구간 수다. 이번에는 개수를 따로 세지 않는다 — plt.hist가 구간을 나누고 세는 일까지 한다.

Python — 하루 판매량 히스토그램 (노트북 3단계)
plt.hist(ice["판매량_count"], bins=5)
plt.xlabel("판매량_count")
plt.ylabel("날 수")
plt.show()

노트북 3단계 실행 결과 — 하루 판매량 히스토그램, 구간 5개(생활 예제용 가상 데이터)

판매량 46~147개를 다섯 구간으로 나눴다. 가운데 구간(약 86~107개)이 6일로 가장 높다. 평균 하나만으로는 "얼마나 고르게 팔렸나"를 알 수 없지만, 히스토그램은 값이 몰린 곳과 퍼진 정도를 보여 준다.

직접 해 보기 (노트북 3단계) 노트북의 plt.hist(ice["판매량_count"], bins=____) 빈칸에 10을 넣어 구간을 열 개로 나눠 다시 그려 보자. 구간을 잘게 나누면 그림이 어떻게 달라질까?
막대가 10개로 늘고 하나하나가 낮아진다(가장 높은 막대도 5일). 구간이 잘면 자세하지만 들쭉날쭉해 보이고, 구간이 크면 큰 모양이 잘 보인다. 21일처럼 기록이 적으면 bins=5가 모양을 읽기 쉽다.

산점도 — 두 값이 함께 움직이나

산점도는 숫자 열 두 개를 x(가로)와 y(세로)로 놓고, 행마다 점 하나를 찍는다. 21일이면 점 21개다. plt.scatter(x에 놓을 열, y에 놓을 열) 순서다.

Python — 기온과 판매량 산점도 (노트북 4단계)
plt.scatter(ice["최고기온_C"], ice["판매량_count"])

plt.show()

Box PlotVisualize상자 그림오늘 새 위젯. 숫자 열 하나가 무리마다 어디에, 얼마나 넓게 퍼져 있는지 상자로 보여 준다
Box Plot 창 읽는 법
  • 창 왼쪽 위 Variable 목록 = 볼 숫자 열, 그 아래 Subgroups 목록 = 나눌 기준 열. 둘 다 이름을 한 번 클릭해 고른다.
  • 가로로 누운 상자 하나가 무리 하나다. 상자에는 값을 작은 순으로 줄 세웠을 때 가운데 절반이 들어 있다. 상자가 길수록 값이 넓게 퍼진 것이다.
  • 상자 아래 숫자 세 개 = 상자 왼쪽 끝 · 중앙값(한가운데 값) · 상자 오른쪽 끝. 상자 위 숫자는 평균 ± 표준편차(퍼짐을 나타내는 값)다. 소수 자리 수는 숫자마다 다르게 보일 수 있다.
  • 상자 안 노란 선 = 중앙값, 파란 세로선 = 평균이다. 창 맨 위의 ANOVA·Student's t 줄, 상자를 가로지르는 회색 세로선, 양옆으로 뻗은 점선은 오늘 읽지 않는다.

주의할 점 & 자주 발생하는 오류

오류 1 — 한글이 네모(□)로 깨짐 1단계 첫 셀의 plt.rcParams[…] 두 줄을 실행하지 않으면 축 이름의 한글이 네모로 보이고, Glyph 44032 (\N{HANGUL SYLLABLE GA}) missing from font(s) DejaVu Sans. 같은 경고가 뜬다. 첫 셀을 실행한 뒤 그래프 셀을 다시 실행한다.
오류 2 — 개수를 세지 않고 막대 그리기 plt.bar(df["설비번호"])처럼 열을 바로 넣으면 TypeError: bar() missing 1 required positional argument: 'height'가 난다. 막대에는 이름과 높이(개수) 두 가지가 필요하다. value_counts()로 먼저 세고 plt.bar(이름들, 개수들)로 그린다.
오류 3 — plt.show() 빠뜨림 오류는 나지 않지만 그래프 위에 Text(0, 0.5, '기록 건수') 같은 글자 줄이 함께 나온다. 마지막 줄 plt.ylabel(…)의 결과가 찍힌 것이다. 4줄 틀의 마지막 plt.show()를 붙인다.
빈칸을 그대로 두고 실행하면 노트북의 ____를 채우지 않으면 AttributeError: module 'matplotlib.pyplot' has no attribute '____'(그리기 함수 이름 자리)나 AttributeError: 'Series' object has no attribute '____'(Series = 표의 열 하나), NameError: name '____' is not defined(열 이름 자리)가 난다. 빈칸을 아직 안 채웠다는 뜻이다. 열 이름은 따옴표 안에 쓴다 — df[온도_C]처럼 따옴표를 빠뜨리면 NameError: name '온도_C' is not defined가 난다. x와 y 열을 바꿔 넣으면 오류 없이 축 이름과 내용이 어긋난 그림이 나온다 — plt.scatter(x, y) 순서와 xlabel·ylabel을 함께 확인한다.

결과 정리 & 퀴즈

  • 질문이 그래프를 고른다: 무리마다 몇 개 → 막대, 어디에 몰렸나 → 히스토그램, 함께 움직이나 → 산점도, 무리마다 얼마나 퍼졌나 → 상자 그림(Orange).
  • 그래프는 "그리기 → x축 이름 → y축 이름 → plt.show()" 4줄 틀이다. 막대만 그 앞에 value_counts() 한 줄이 붙는다.
  • 공정 기록: 다섯 공정 기록이 31~39건으로 비슷하고, 두께는 약 101~103nm 근처에 가장 많으며, 온도와 압력은 함께 움직이는 모습이 안 보였다.
  • 웨이퍼 맵: 다이_X·다이_Y를 점으로 찍으니 둥근 웨이퍼가 나타났고, 불합격 다이 64개 중 60개가 가장자리에 몰려 있었다.
오늘의 반도체 이해 포인트
  • 웨이퍼 맵은 다이마다 전기 검사(⑦ EDS) 결과를 위치대로 찍은 지도다. 불량이 어디에 몰렸는지(오늘은 가장자리)가 어디를 먼저 살펴볼지 단서가 된다.
  • 평균이 비슷해도 설비마다 값의 퍼짐은 다를 수 있다. 그래서 평균과 함께 상자 그림으로 퍼짐을 본다. 퍼짐이 불량과 이어지는지는 7·8차시에 숫자로 확인한다.

pandas 표 df에 "온도_C", "두께_nm", "합격여부"(1 = 합격, -1 = 불합격) 열이 있어. 온도-두께 산점도를 그리는데 불합격 점만 빨간색으로 겹쳐 그리는 짧은 matplotlib 코드를 만들어 줘.
Python — AI가 만들어 준 코드 예시 (노트북 7단계)
fail = df[df["합격여부"] == -1]

plt.scatter(df["온도_C"], df["두께_nm"], label="전체")
plt.scatter(fail["온도_C"], fail["두께_nm"], color="red", label="불합격")
plt.xlabel("온도_C")
plt.ylabel("두께_nm")
plt.legend()
plt.show()

노트북 7단계 실행 결과 — 전체 180건 위에 불합격 21건을 빨간 점으로 겹침(교육용 가상 데이터)

  • color="red"는 점 색, label과 plt.legend()는 그림 구석의 이름표(범례)다. 처음 보는 옵션이라 구경만 한다.
  • Orange Scatter Plot은 Color 칸 하나로 같은 일을 한다. 빨간 점이 한곳에 몰렸는지, 여기저기 흩어졌는지 직접 보고 말해 보자.
AI 코드를 다룰 때 직접 실행해 그림을 확인하고, 열 이름과 경로가 내 표와 같은지 맞춘다. 회사의 실제 데이터는 AI에 붙여 넣지 않는다.
