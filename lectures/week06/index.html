6차시 · 개요(skeleton)

그래프로 공정 상태 이해하기

💬 오늘의 질문: "그림으로 미리 본 패턴을, 코드로 그대로 재현할 수 있을까?"

작성 상태 이 페이지는 v2 커리큘럼 구성이 확정된 직후 작성된 개요(skeleton)입니다. 제목·학습 목표·다룰 내용·데이터까지는 확정되었지만, 상세 설명·예제 코드·단계별 실습·퀴즈는 아직 채워지지 않았습니다. 구성이 최종 확정되면 이어서 상세 내용을 작성합니다. 배경은 docs/restructure-plan.md 참고.

🎯 학습 목표

  • Orange3 위젯으로 먼저 그래프를 그려 패턴을 확인할 수 있다.
  • 선/막대/히스토그램/산점도/박스플롯을 구분하고 해석할 수 있다.
  • Matplotlib 코드로 같은 그래프를 직접 그려 Orange3 결과와 비교할 수 있다.

선수 지식: 4~5차시 — 정제된 데이터

🟠 ① Orange3로 먼저 훑어보기

위젯 Scatter Plot · Box Plot · Distributions

Matplotlib 코드를 쓰기 전에 Orange3 위젯으로 온도-두께 산점도, 설비별 온도 박스플롯을 먼저 그려 패턴을 확인한다. 이어서 같은 그래프를 Matplotlib 코드로 그려 같은 결론이 나오는지 비교한다.

📚 ② 파이썬으로 확인하기 — 다룰 이론 주제(초안)

  • 선 그래프 — 시간에 따른 변화
  • 막대그래프 — 범주별 비교
  • 히스토그램 — 값의 분포
  • 산점도 — 두 변수의 관계
  • 박스플롯 — 그룹별 분포와 이상값

🐍 다룰 실습 흐름(초안)

  1. 시간-온도 선그래프 그리기
  2. 설비별 생산량 막대그래프 그리기
  3. 온도 히스토그램 그리기
  4. 온도-두께 산점도 그리기
  5. 설비별 온도 박스플롯 그리기
