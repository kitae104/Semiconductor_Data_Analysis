그래프로 공정 상태 이해하기

오늘의 질문: "그림으로 미리 본 패턴을, 코드로 그대로 재현할 수 있을까?"

학습 목표

  • 선·막대·히스토그램·산점도·박스플롯이 각각 어떤 질문에 답하는 그래프인지 고를 수 있다.
  • 아이스크림 가게 기록(쉬운 예제)으로 그려 본 그래프 코드를, 표 이름과 열 이름만 바꿔 반도체 데이터에 적용할 수 있다.
  • 그래프를 읽고, 평균 하나로는 놓치는 것(퍼짐, 시간에 따른 변화)을 한 문장으로 말할 수 있다.
  • Orange3로 먼저 본 그림을 Matplotlib 코드로 다시 그려, 같은 결론이 나오는지 확인할 수 있다.

선수 지식: 4차시(열 선택·조건 검색), 5차시(describe())

그래프 읽기 첫걸음 — 어떤 질문에 어떤 그래프?

읽는 순서는 늘 같다: 축 이름 → 점·막대·상자 하나가 무엇인지 → 전체 모양. 그래프는 질문에 맞춰 고른다.

알고 싶은 것(질문)그래프하나가 뜻하는 것쉬운 예제 → 반도체 적용
시간이 지나며 어떻게 변했나?선 그래프선 위 꺾이는 점 하나 = 그 시각의 기록 하나날짜별 판매량 → 시간에 따른 온도
그룹마다 몇 건인가?막대그래프막대 하나 = 그룹(날씨, 설비) 하나의 건수날씨별 날 수 → 설비별 기록 건수
값이 주로 어디에 몰려 있나?히스토그램막대 하나 = 숫자 구간 하나에 들어간 기록 수판매량 분포 → 온도 분포
두 값이 함께 움직이나?산점도점 하나 = 기록(행) 하나기온과 판매량 → 온도와 두께
그룹마다 얼마나 들쭉날쭉한가?박스플롯상자 하나 = 그룹 하나의 값 전체를 요약날씨별 판매량 → 설비별 온도
흔한 실수 — "일단 막대그래프" 그리기 전에 "무엇이 궁금한가?"를 한 문장으로 말하고, 위 표에서 가장 가까운 줄을 고르자.

datetime64가 "날짜로 알아본다"는 표시다. 뒤의 [us]는 저장 단위라 신경 쓰지 않아도 된다(버전에 따라 [ns]).

그래프 코드의 공통 틀

줄하는 일
plt.그리기명령(가로축 값, 세로축 값)그래프를 그린다(plot·bar·hist·scatter). 그래프마다 이 줄만 바뀐다. hist는 값 하나만 넣는다(세로축은 개수가 자동)

plt.show()그림을 화면에 보여주고 마무리. plt.show() 전에 다음 그래프를 이어 쓰면 그림이 겹치므로 그래프 하나는 셀 하나에서 그린다

그래프 1. 선 그래프 — 시간이 지나며 어떻게 변했나

읽는 법: 가로축 = 시간, 세로축 = 잰 값, 꺾이는 점 하나 = 기록 하나. 흔들림 전체가 조금씩 위(아래)로 가는지를 본다.

Python — 선 그래프
plt.plot(ice["날짜"], ice["판매량_개"])
plt.xticks(rotation=45)   # 날짜 글자를 45도 기울여 겹치지 않게
plt.xlabel("날짜")
plt.ylabel("판매량_개")
plt.show()

노트북 2단계 실행 결과.

  • 들쭉날쭉하면서도 올라간다. 첫 주 평균 85.7개 → 셋째 주 115.0개(강사 계산).
  • 뚝 떨어진 6월 13일·20일·22일은 날씨 열을 함께 보면 비 온 날이다. 다른 열을 함께 보면 이유의 실마리가 보인다.

그래프 2. 막대그래프 — 그룹마다 몇 건인가

읽는 법: 가로축 = 그룹 이름(순서 없음), 세로축 = 건수, 막대 하나 = 그룹 하나. 막대 높이를 그대로 비교한다.

Python — 막대그래프
counts = ice["날씨"].value_counts()
print(counts)

plt.bar(counts.index, counts)
plt.xlabel("날씨")
plt.ylabel("날 수")
plt.show()

노트북 3단계 실행 결과.

  • value_counts()는 값마다 몇 건인지 세어 많은 순서로 늘어놓는다.
  • plt.bar(이름들, 숫자들) — counts.index는 막대 이름표, counts는 막대 높이다.

그래프 3. 히스토그램 — 값이 주로 어디에 몰려 있나

읽는 법: 가로축 = 이어진 숫자 구간, 세로축 = 그 구간의 기록 수. bins=5는 최솟값~최댓값을 같은 폭 5칸으로 나누라는 뜻이다. 반 친구 키를 5cm 칸으로 나눠 칸마다 몇 명인지 센 것과 같다.

Python — 히스토그램
plt.hist(ice["판매량_개"], bins=5)
plt.xlabel("판매량_개")
plt.ylabel("날 수")
plt.show()

노트북 4단계 실행 결과. 46~147개를 한 칸 약 20개로 나눴다.

  • 가장 높은 막대는 약 86~107개 칸(6일), 나머지는 3~4일씩이다. 하루에 보통 100개 안팎이 팔렸다.
  • 막대그래프 가로축은 이름(순서 바꿔도 됨), 히스토그램 가로축은 숫자 구간(순서 고정)이다.

그래프 4. 산점도 — 두 값이 함께 움직이나

읽는 법: 점 하나 = 기록(행) 하나. 같은 행의 두 값을 가로·세로 위치로 찍고, 점들이 어느 방향으로 기울었는지 본다.

그래프 5. 박스플롯 — 그룹마다 얼마나 들쭉날쭉한가

한 그룹의 값을 작은 것부터 한 줄로 세운 뒤 네 토막으로 나눠 상자로 요약한 그림이다.

예시 일러스트레이션 · 실제 데이터 아님

박스플롯 한 개의 각 부분(예시 그림). 상자가 길수록 들쭉날쭉하다. 상자 끝에서 상자 길이의 1.5배보다 멀리 떨어진 값은 동그라미 점으로 따로 찍는다(잘못된 값이라는 뜻은 아니다).

Python — 박스플롯
ice.boxplot(column="판매량_개", by="날씨")
plt.show()

노트북 6단계 실행 결과. "Boxplot grouped by 날씨"는 자동으로 붙는 제목이다.

  • 표.boxplot(column="값을 볼 열", by="그룹을 나눌 열") — 그룹별로 나누는 일까지 한 줄로 한다.
  • 비 오는 날 상자가 가장 아래, 맑은 날 상자가 가장 길다(선선한 날과 더운 날이 섞임).

숫자로 다시 확인하기

5차시 describe()를 그룹별로 실행한다. groupby는 7차시에 배우므로 오늘은 코드를 그대로 실행하고 결과만 읽는다(반도체 데이터에서도 같다). round(1)은 소수 첫째 자리까지 반올림한다.

Python — 반도체 데이터 읽기

오류 1 — 그래프의 한글이 네모(□)로 나올 때 UserWarning: Glyph 50728 (\N{HANGUL SYLLABLE ON}) missing from font(s) DejaVu Sans. — 글꼴 설정 두 줄을 실행하지 않았다. 노트북 1단계 첫 셀을 다시 실행한다(Mac은 "AppleGothic").
오류 2 — 열 이름을 틀렸을 때
  • KeyError: 'Column not found: 온도', KeyError: '설비' — 열 이름을 줄여 썼다(온도_섭씨, 설비번호).

오류 3 — 가로·세로 값 중 하나를 빼먹었을 때 TypeError: scatter() missing 1 required positional argument: 'y', TypeError: bar() missing 1 required positional argument: 'height' — plt.scatter(df["온도_섭씨"], df["두께_nm"]), plt.bar(counts.index, counts)처럼 두 개를 넣는다.

  • pd.to_datetime()을 건너뛰면 가로축 날짜 글자가 겹친다. 한 셀에 그래프 두 개를 쓰면 그림이 겹친다.
