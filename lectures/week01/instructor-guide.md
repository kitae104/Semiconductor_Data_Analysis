# 1차시 강의 운영안 — 반도체 공정과 데이터 처음 만나기 + 변수·출력

## 🤔 왜 이걸 배워야 할까? (학생에게 전달할 메시지)

반도체 공정 데이터가 어디서, 왜 생기는지 모르면 앞으로 볼 숫자들이 그냥 "의미 없는 숫자 나열"일
뿐이다. 오늘 배우는 변수와 출력은 그 숫자를 코드 안에 기억해두고 다시 꺼내 쓰는 가장 작은 단위로,
앞으로 10차시 내내 쓰는 모든 코드가 결국 이 위에 쌓인다.

**쉬운 예시**: 매일 아침 "오늘 생산된 웨이퍼 중 합격/불합격이 몇 건인지" 확인해야 하는 담당자가
있다고 하자. "합격 34, 불합격 6"이라는 숫자를 `pass_count`, `fail_count`라는 변수에 담아두면, 매번
다시 세지 않고 `print()`로 바로 꺼내 볼 수 있다 — 이것이 데이터를 코드로 다루는 첫걸음이다.

## 수업 흐름

1. 오리엔테이션: 10차시 과정 전체 흐름 소개(복습할 이전 시간 없음)
2. 오늘의 질문 제시 — "반도체는 어떻게 만들어지고 어떤 기록을 남길까?" + 반도체 개념 설명(웨이퍼→칩, FAB)
3. 공정·설비·센서, 데이터의 행과 열, 합격/불합격 부호, "왜 데이터를 분석해야 하는가" + 용어 카드 훑어보기
4. 휴식
5. 파이썬이 어떤 언어이고 왜 배우는지 소개 + "앞으로 배우게 될 내용"(1~10차시 로드맵) 안내
6. 변수·자료형·print·f-string·input() 강의 + 강사 시연
7. 학생 직접 실습: 변수 만들기 → 자료형 확인 → f-string 문장 → input() → 자기소개 종합 실습
8. 정리 퀴즈 + 과제 안내 + 다음 차시 예고

## 강사 설명 포인트
- "반도체 = 제품 이름"이라는 흔한 오해를 초반에 바로잡는다. 반도체는 물질의 "성질"이다.
- 웨이퍼-다이-칩의 관계는 반드시 그림(피자 비유)으로 설명한다.
- `합격여부`의 부호(1=합격/-1=불합격)를 칠판에 크게 적어두고 수업 내내 언급한다.
- "왜 데이터를 분석해야 하는가"를 짚을 때는 "표를 눈으로 다 읽을 수 없으니 세고 요약한다"는
  감각을 먼저 심어준다 — 오늘 합격 34건/불합격 6건이라는 숫자 두 개가 40줄짜리 표를 요약한
  결과라는 점을 강조.
- 파이썬 코드를 처음 보여주기 전에 "파이썬이 뭔지, 왜 배우는지"부터 짚는다. 엑셀과 비교해
  "데이터가 많아지면 엑셀은 느려지고 실수하기 쉽지만, 파이썬은 코드 몇 줄로 똑같은 작업을 빠르고
  정확하게 반복할 수 있다"는 점을 강조한다.
- "앞으로 배우게 될 내용" 로드맵(강의 자료의 🔭 섹션)을 반드시 짚어준다 — 오늘은 그중 1단계의
  맨 처음(변수)이며, 표 전체를 다루는 Pandas는 4차시부터라는 것을 명확히 알려 학생들이 "오늘
  코드로 CSV를 못 열어봐서 뒤처진 건가" 하는 불안을 갖지 않도록 한다.
- 변수는 "이름표가 붙은 상자"라는 비유로 설명하고, `=`가 수학의 "같다"가 아니라
  "오른쪽 값을 왼쪽 이름에 저장하라"는 뜻임을 반드시 강조한다(강의 자료의 상자 그림 참고).
- f-string은 "문장의 빈칸에 값을 채워 넣는 것"이라는 비유로 소개하고, `f`를 빼먹었을 때
  중괄호가 그대로 출력되는 모습을 직접 실행해서 보여주면 효과가 크다.
- `input()`은 항상 문자열을 돌려준다는 점을 반드시 강조 — 이후 3~4차시(조건문, Pandas)에서
  숫자 비교를 할 때 반복적으로 등장하는 함정이므로 여기서 확실히 짚고 넘어간다.

## 예상 오개념
- FAB을 특정 회사 이름으로 오해 → "공장"이라는 일반 용어임을 강조.
- "데이터 분석 = 어려운 통계/수학"이라는 선입견 → 오늘 한 일(34건/6건을 세고 비율을 계산한 것)도
  이미 데이터 분석의 시작이라는 점을 짚어준다.
- `=`를 수학의 "같다"로 착각 → 비교에는 `==`를 쓴다는 것을 3차시 예고로 짧게 언급.
- `input()`의 결과가 자동으로 숫자가 될 거라고 오해 → 항상 문자열이며 `int()`/`float()`
  변환이 필요함을 실제 오류(`TypeError`)를 보여주며 각인시킨다.
- f-string과 일반 문자열의 차이를 몰라 `f`를 빼먹음 → 강의 자료의 "이렇게 하면 오류가
  난다" 콜아웃 예시를 함께 실행해본다.

## 실습 중 오류 대응
- Colab 런타임 연결 끊김: 맨 위 셀부터 순서대로 재실행.
- `NameError`: 문자열에 따옴표를 빼먹은 경우다(`equipment = EQ-03`). 따옴표를 채우게 한다.
- `TypeError: can only concatenate str (not "int") to str`: `input()` 결과를 변환 없이
  숫자와 더한 경우다. `int(input(...))`로 감싸도록 안내한다.

## 빠른 학습자용 추가 과제
- 강의 자료의 "과제 3(도전) — 온도 판정 문장 만들기"를 수업 중에 미리 시도해보게 한다.
- f-string의 `:.2f`, `:.0f` 등 다른 소수점 자리수 서식을 바꿔보며 결과 차이를 관찰하게 한다.
- 온도(`temperature`), 설비(`equipment`) 두 변수를 조합한 자신만의 f-string 문장을 2~3개
  더 만들어보게 한다.

## 느린 학습자용 최소 과제
- 강의 자료의 데이터 미리보기 표를 보고 "몇 행, 몇 열인지"만 말로 설명할 수 있으면 충분하다.
- `pass_count = 34`, `print(pass_count)`까지만 성공해도 충분하다. f-string과 input()은 짝
  활동으로 강사·동료가 함께 도와준다.
