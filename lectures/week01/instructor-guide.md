# 1차시 강의 운영안 — 반도체 공정과 데이터 처음 만나기 + 변수·출력

## 2시간 세부 시간표

| 시간 | 내용 |
| --- | --- |
| 0~8분 | 오리엔테이션: 10차시 과정 전체 흐름 소개(복습할 이전 시간 없음) |
| 8~20분 | 오늘의 질문 제시 — "반도체는 어떻게 만들어지고 어떤 기록을 남길까?" + 반도체 개념 설명(웨이퍼→칩, FAB) |
| 20~30분 | 공정·설비·센서, 데이터의 행과 열, 합격/불합격 부호 + 용어 카드 훑어보기 |
| 30~45분 | 강사 코드 시연(Colab 접속 ~ value_counts까지) |
| 45~50분 | 휴식 |
| 50~70분 | 학생 실습: Colab 접속 → CSV 업로드 → head/shape/columns/value_counts + 도전 실습(설비별·공정별 value_counts) |
| 70~95분 | **(신규)** 파이썬 변수·자료형·print·f-string·input() 강의 + 강사 시연 |
| 95~115분 | **(신규)** 학생 직접 실습: 변수 만들기 → f-string 문장 → input() → 자기소개 종합 실습 |
| 115~120분 | 정리 퀴즈 + 과제 안내 + 다음 차시 예고 |

> 시간이 부족하면 "50~70분" 구간의 도전 실습(설비별·공정별 value_counts)을 과제로 돌리고, 신규
> 파이썬 파트(70~115분)에 시간을 더 배분한다. 반대로 파이썬 진도가 빠르면 95~115분 구간의
> "종합 실습(자기소개)"을 짝 활동으로 확장해도 좋다.

## 강사 설명 포인트
- "반도체 = 제품 이름"이라는 흔한 오해를 초반에 바로잡는다. 반도체는 물질의 "성질"이다.
- 웨이퍼-다이-칩의 관계는 반드시 그림(피자 비유)으로 설명한다.
- `합격여부`의 부호(1=합격/-1=불합격)를 칠판에 크게 적어두고 수업 내내 언급한다.
- **(신규)** 변수는 "이름표가 붙은 상자"라는 비유로 설명하고, `=`가 수학의 "같다"가 아니라
  "오른쪽 값을 왼쪽 이름에 저장하라"는 뜻임을 반드시 강조한다(강의 자료의 상자 그림 참고).
- **(신규)** f-string은 "문장의 빈칸에 값을 채워 넣는 것"이라는 비유로 소개하고, `f`를 빼먹었을 때
  중괄호가 그대로 출력되는 모습을 직접 실행해서 보여주면 효과가 크다.
- **(신규)** `input()`은 항상 문자열을 돌려준다는 점을 반드시 강조 — 이후 3~4차시(조건문, Pandas)에서
  숫자 비교를 할 때 반복적으로 등장하는 함정이므로 여기서 확실히 짚고 넘어간다.

- "공정 데이터의 '행'과 '열'을 성적표에 비유하면 무엇에 해당할까요?"
- **(신규)** "`pass_count = 34`에서 `=`는 수학 시간에 배운 '같다'와 같은 뜻일까요, 다른 뜻일까요?"

## 예상 오개념
- FAB을 특정 회사 이름으로 오해 → "공장"이라는 일반 용어임을 강조.
- `1행 8열` 같은 표현을 "8행 1열"과 혼동 → `shape`의 출력 순서(행, 열)를 명확히 짚는다.
- `value_counts()`가 정렬 없이 출력된다고 오해 → 기본적으로 개수 많은 순으로 정렬됨을 설명.
- **(신규)** `=`를 수학의 "같다"로 착각 → 비교에는 `==`를 쓴다는 것을 3차시 예고로 짧게 언급.
- **(신규)** `input()`의 결과가 자동으로 숫자가 될 거라고 오해 → 항상 문자열이며 `int()`/`float()`
  변환이 필요함을 실제 오류(`TypeError`)를 보여주며 각인시킨다.
- **(신규)** f-string과 일반 문자열의 차이를 몰라 `f`를 빼먹음 → 강의 자료의 "이렇게 하면 오류가
  난다" 콜아웃 예시를 함께 실행해본다.

## 실습 중 오류 대응
- `FileNotFoundError`: 파일을 업로드했는지, 파일명 철자가 정확한지 확인.
- `KeyError: '합격여부'`: `df.columns`로 정확한 열 이름을 먼저 출력해보게 한다.
- Colab 런타임 연결 끊김: 파일 재업로드 후 위에서부터 재실행.
- **(신규)** `NameError`: 문자열에 따옴표를 빼먹은 경우다(`equipment = EQ-03`). 따옴표를 채우게 한다.
- **(신규)** `TypeError: can only concatenate str (not "int") to str`: `input()` 결과를 변환 없이
  숫자와 더한 경우다. `int(input(...))`로 감싸도록 안내한다.

## 빠른 학습자용 추가 과제
- `df.describe()`를 실행해 숫자 열의 평균값을 미리 살펴보게 한다(2차시 예고 겸용).
- 압력_Pa 열에서 가장 높은 값과 낮은 값을 가진 행을 `df.sort_values()`로 찾아보게 한다(3차시 예고).
- **(신규)** 강의 자료의 "과제 3(도전) — 온도 판정 문장 만들기"를 수업 중에 미리 시도해보게 한다.

## 느린 학습자용 최소 과제
- `df.head()`와 `df.shape`만 실행해보고, "행이 몇 개인지, 열이 몇 개인지"만 말로 설명할 수 있으면 충분하다.
- `value_counts()` 결과를 강사가 함께 읽어주며 숫자의 의미만 이해시킨다.
- **(신규)** f-string·input() 없이 `pass_count = 34`, `print(pass_count)`까지만 성공해도 충분하다.
  f-string과 input()은 짝 활동으로 강사·동료가 함께 도와준다.
