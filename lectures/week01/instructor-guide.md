# 1차시 강의 운영안 — 반도체 공정과 데이터 처음 만나기 + 변수·출력

## 왜 이걸 배워야 할까? (학생에게 전달할 메시지)

10차시 동안 공장 숫자를 다룬다. 숫자가 어디서 왜 생겼는지 알아야 표가 보인다. 오늘은 공장 이야기와,
그 숫자(합격 32, 불합격 8)를 `pass_count`, `fail_count`에 저장해 꺼내 쓰는 변수·출력을 배운다.

## 수업 흐름

1. 오리엔테이션: 과정 흐름 소개, "전공·코딩 경험 없어도 된다".
2. 반도체 개념: 스위치 비유 → 웨이퍼·다이·칩(쿠키 비유) → 만드는 흐름과 작업 6가지 표 → FAB·클린룸·로트·설비·센서
3. 휴식
4. 데이터 개념: 기록을 남기는 이유(블랙박스) → 행과 열 → 합격(1)/불합격(-1) → 표 한 행을 문장으로 읽기
5. "여러 열 함께 보기": 공정명별 불합격 표, 온도 범위 → "원인"이 아니라 "원인 후보"
6. Jupyter 사용법 시연: 노트북 파일 열기, 새 노트북 만들기·저장, 코드 셀/마크다운 셀(더블클릭해 글 쓰기), Shift+Enter, 실행 순서, 주석
7. 개념은 쉬운 예제(카페 주문)로만 설명: 변수 → 자료형 → f-string → 계산 → input()·int() (학생은 노트북 1~5단계 실행)
8. "반도체 데이터로 확인하기" 시연: 확인 1 합격·불합격 문장 → 확인 2 불합격률 20% → 확인 3 세정 50%(원인 후보)
9. 반도체 실습: 실습지 4~10번 = 노트북 6~8단계(`### 문제 4~10`)
10. AI 활용(노트북 9·10단계)
11. 정리 퀴즈, 과제, 다음 차시 예고

## 오늘 데이터 핵심 수치(실제 실행 결과, 강의 중 반드시 확인)
- 교육용 가상 데이터. 온도(약 300℃)·압력(약 1,000)은 실제 공정 조건과 다르며 값의 크기는 해석하지 않는다.
- 40행 8열. `합격여부` 1(합격) 32건, -1(불합격) 8건.
- 공정명별 기록/불합격: 세정 10건/5건, 포토 9건/2건, 산화 6건/1건, 증착 8건/0건, 식각 7건/0건.
- 학습용 정상 온도 범위(295~305℃) 밖 2건(305.5℃ 불합격, 293.6℃ 합격). 불합격 8건 중 7건은 범위 안.
- 반도체 실습 출력(실습지 번호): 5번 `오늘 합격은 32건, 불합격은 8건입니다.`, 7번 `EQ-04 설비의 온도는 300.1도입니다.`,
  8번 `40 20.0` → `전체 40건 중 불합격률은 20.0%입니다.`, 9번 `세정 기록 10건 중 불합격률은 50.0%입니다.`,
  10번(입력 2) `불합격은 모두 10건입니다.`, AI 예시 `합격률 80.0% → 점검 필요`.
- 쉬운 예제 출력: `아메리카노 3잔 주문이 들어왔습니다.`, `12 41.66666666666667` → `전체 12잔 중 아이스 비율은 41.7%입니다.`,
  추가 주문(입력 2) `주문은 모두 5잔입니다.`

## 강사 설명 포인트
- 공정은 이름보다 "하는 일"과 비유로. 한 바퀴가 아니라 층마다 수백 번 반복한다고 강조한다.
- `합격여부` 부호(1=합격, -1=불합격)를 칠판에 적어둔다.
- 공정명별 표는 강사가 미리 센 결과다. "세정이 원인일까요?"라고 되물어 "원인 후보"(용의자 ≠ 범인)를 소개한다.
- **강사만 알 것**: 합격여부는 공정과 무관하게 무작위로 만들었다. "세정 10건 중 5건"은 우연이므로 "우연일 수 있다"를 꼭 함께 말한다.
- 개념 설명은 카페 예제로만 한다. 반도체는 "확인하기" 3개에서 질문을 먼저 던지고 [코드와 결과 보기]를 연다.
- 확인 3에서 전체 20% vs 세정 50%를 대비해 "여러 열 함께 보기 → 원인 후보"를 다시 연결한다.
- 실습지 문항 힌트는 쉬운 예제의 같은 모양 코드를 가리킨다("`coffee_price` 자리에 `pass_count`").
- `f`를 빼먹으면 중괄호가 그대로 나오는 모습을 실행해 보여준다.
- 정답 노트북 5단계 주석 줄 `# print(more_text + cups)`를 풀면 `TypeError: can only concatenate str (not "int") to str`를 시연할 수 있다.

## 예상 오개념
- FAB을 회사 이름으로 오해 → 공장을 뜻하는 일반 용어.
- 작업 6가지를 한 번 거치면 칩 완성 → 층마다 반복, 수백 단계, 몇 주~몇 달.
- 눈에 띄는 것 = 원인 → 원인 후보와 원인은 다르다.
- `=`를 "같다"로 착각 → 비교는 `==`(3차시).
- `input()` 결과가 숫자일 거라는 오해 → 항상 문자열, `int()` 필요.

## 실습 중 오류 대응
- `NameError: name 'pass_count' is not defined`: 위 셀을 건너뜀 → 맨 위부터 차례로 실행.
- `NameError: name '____' is not defined`: 빈칸을 안 채움.
- `SyntaxError: leading zeros in decimal integer literals are not permitted`: `equipment = EQ-04`처럼 따옴표 누락.
- `TypeError: can only concatenate str (not "int") to str`: `more_text + cups`처럼 `int()` 없이 더함.
  `fail_count + more_text` 순서면 메시지가 `unsupported operand type(s) for +: 'int' and 'str'`로 바뀌지만 원인은 같다.
- 셀이 `[*]`로 멈춤: `input()` 입력칸에서 Enter를 누르지 않음.
- 커널 끊김: 커널 재시작 후 맨 위부터 재실행.
