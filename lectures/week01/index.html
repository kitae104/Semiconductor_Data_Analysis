📚 반도체 개념 이해하기

반도체란 무엇인가

반도체(Semiconductor)는 전기가 "잘 통하는 도체"와 "전혀 통하지 않는 부도체"의 중간 성질을 가진 물질이다. 이 성질 덕분에 전류를 켜고 끄는 스위치처럼 동작시킬 수 있고, 이 스위치를 수십억 개 모아 계산과 저장을 수행하는 칩을 만든다.

웨이퍼에서 칩이 만들어지는 과정

둥근 원판 모양의 웨이퍼(Wafer) 위에 여러 공정을 반복해서 회로를 새기면, 웨이퍼 하나에 작은 사각형 회로 조각인 다이(Die)가 수백~수천 개 만들어진다. 다이를 자르고 포장(패키징)하면 우리가 아는 칩(Chip)이 된다.

비유 웨이퍼는 커다란 피자 도우, 다이는 그 위에 자른 한 조각이라고 생각하면 된다. 도우(웨이퍼) 하나로 여러 조각(다이)을 만들지만, 조각마다 굽는 상태(품질)가 다를 수 있다.
🖼️ 이미지 자리 — 실제 웨이퍼·다이·칩 사진(둥근 원판 위에 사각형 칩이 촘촘히 배열된 모습)을 강사가 추가하면 좋다. 검색 키워드 예시: "silicon wafer die chip photo".

반도체 제조의 주요 공정

웨이퍼는 산화 → 포토(노광) → 식각 → 이온 주입 → 증착 → 세정 같은 공정을 수백 번 반복하며 회로가 완성된다. 각 공정은 서로 다른 설비(Equipment)에서 진행되며, 설비 안에는 온도·압력·가스유량 등을 측정하는 센서(Sensor)가 붙어 있다.

🖼️ 이미지 자리 — "산화 → 포토 → 식각 → 이온 주입 → 증착 → 세정" 공정 흐름을 화살표로 연결한 다이어그램이나 애니메이션(GIF)을 추가하면 순서를 기억하기 쉽다.

FAB의 의미

FAB(팹, Fabrication의 줄임말)은 반도체를 실제로 생산하는 공장을 말한다. 하나의 FAB 안에는 수백~수천 대의 설비가 24시간 돌아간다.

📊 데이터 분석 개념 이해하기

공정 데이터의 행과 열

설비의 센서는 몇 초~몇 시간 간격으로 값을 기록한다. 이 기록을 표로 정리하면, 한 행(row)은 "한 번의 측정 기록", 한 열(column)은 "측정한 항목(온도, 압력 등)"이 된다.

개념 표(table) = 여러 개의 행과 열로 이루어진 데이터. 오늘 우리가 열어볼 CSV 파일도 결국 엑셀처럼 행과 열로 이루어진 표다.

합격과 불합격 데이터

공정을 마친 웨이퍼는 검사를 거쳐 합격(양품)과 불합격(불량)으로 나뉜다. 이 과정에서는 합격여부 열의 값이 1이면 합격, -1이면 불합격을 의미하도록 정했다. (뒤에서 다룰 다른 원본 데이터인 fab.csv는 반대 부호를 쓰는데, 이는 9차시에서 자세히 설명한다.)

🐍 파이썬 시작하기 — 변수와 출력

변수란 무엇인가

오늘 value_counts()로 확인한 "합격 34건, 불합격 6건"이라는 숫자를, 매번 코드를 다시 실행하지 않고 기억해두고 싶다면 어떻게 해야 할까? 파이썬에서는 변수(Variable)를 써서 값에 이름을 붙여 저장해둔다. 변수는 "이름표가 붙은 상자"라고 생각하면 쉽다 — 상자 안에 값을 넣고, 이름표(변수 이름)로 그 상자를 다시 찾아 쓸 수 있다.

pass_count = 34 — 오른쪽 값(34)을 왼쪽 이름(pass_count)이라는 상자에 저장한다. 이때 =는 수학의 "같다"가 아니라 "오른쪽 값을 왼쪽 이름에 저장하라"는 뜻(대입 연산자)이다.

Python — 변수 만들기
# 값에 이름을 붙여 저장한다(대입).
pass_count = 34
fail_count = 6

# 이름(변수)만 적으면 그 안에 든 값을 다시 꺼내 쓸 수 있다.
print(pass_count)
print(fail_count)
실행 결과 
34
6
🙋 직접 해보기 Colab에 위 코드를 그대로 입력하고 실행해보자. 그다음 pass_count 값을 다른 숫자로 바꿔서 다시 실행하면 어떻게 되는지 확인해보자.

자료형 — 숫자형, 문자열형, 불리언

변수에는 숫자뿐 아니라 문자, 참/거짓 값도 담을 수 있다. 값의 "종류"를 자료형(Data Type)이라고 부른다. 이번 차시에서는 아래 세 가지만 기억해도 충분하다.

자료형예시설명
int (정수)6소수점 없는 숫자
float (실수)300.1소수점이 있는 숫자
str (문자열)"EQ-03"따옴표로 감싼 글자
bool (불리언)True / False참 또는 거짓
Python — 자료형 확인하기
temperature = 300.1        # 실수(float)
equipment = "EQ-03"        # 문자열(str) — 따옴표로 감싼다
is_pass = True              # 불리언(bool) — True/False만 가능

print(type(temperature))
print(type(equipment))
print(type(is_pass))
실행 결과 
<class 'float'>
<class 'str'>
<class 'bool'>
주의 문자열은 반드시 따옴표("..." 또는 '...')로 감싸야 한다. equipment = EQ-03처럼 따옴표 없이 쓰면 파이썬은 이를 "EQ-03이라는 변수를 찾아라"는 뜻으로 오해해 NameError가 발생한다.

print()로 여러 값 한 번에 출력하기

print() 안에 콤마(,)로 여러 값을 나열하면, 값 사이에 공백을 하나씩 넣어 순서대로 이어서 출력해준다.

Python
print("합격:", pass_count, "불합격:", fail_count)
실행 결과 
합격: 34 불합격: 6

f-string으로 문장 속에 값 끼워 넣기

콤마로 나열하면 값 사이에 원치 않는 공백이 생기고, 문장을 매끄럽게 쓰기 어렵다. f-string(포맷 문자열)을 쓰면 문장 안에서 원하는 위치에 변수 값을 자연스럽게 끼워 넣을 수 있다. 방법은 간단하다 — 문자열 앞에 f를 붙이고, 변수를 넣고 싶은 자리에 중괄호 { }로 감싼다.

Python — f-string 기본
print(f"오늘 합격은 {pass_count}건, 불합격은 {fail_count}건입니다.")
실행 결과 
오늘 합격은 34건, 불합격은 6건입니다.

중괄호 안에는 변수뿐 아니라 계산식도 바로 넣을 수 있다. 소수점 자리수를 정리하고 싶다면 :.1f처럼 콜론(:) 뒤에 서식을 적는다(.1f = 소수 첫째 자리까지).

Python — f-string 안에서 계산하기
total = pass_count + fail_count
fail_rate = fail_count / total * 100

print(f"전체 {total}건 중 불합격률은 {fail_rate:.1f}%입니다.")
실행 결과 
전체 40건 중 불합격률은 15.0%입니다.
🙋 직접 해보기 equipment 변수(EQ-03)와 temperature 변수(300.1)를 이용해 f"{equipment} 설비의 온도는 {temperature}도입니다." 같은 나만의 f-string 문장을 만들어 출력해보자.

input()으로 값 입력받기

지금까지는 값을 코드에 직접 적었지만, input()을 쓰면 사람이 키보드로 입력한 값을 받아 사용할 수 있다. input("질문")을 실행하면 화면에 질문이 뜨고, 사람이 입력한 내용이 input()의 결과값이 된다.

Python — input() 기본
name = input("이름을 입력하세요: ")
print(f"안녕하세요, {name}님! 반갑습니다.")
실행 결과 예시(입력값: 지민) 
이름을 입력하세요: 지민
안녕하세요, 지민님! 반갑습니다.
가장 중요한 주의사항 input()이 돌려주는 값은 항상 문자열(str)이다. 숫자를 입력받아도 파이썬은 이를 글자로 취급하므로, 계산에 쓰려면 int()(정수) 또는 float()(실수)로 바꿔줘야 한다.
Python — 입력값을 숫자로 바꾸기
age_text = input("나이를 입력하세요: ")   # age_text는 항상 문자열!
age = int(age_text)                        # 문자열 → 정수로 변환

print(f"내년이면 {age + 1}살이 되네요!")
실행 결과 예시(입력값: 24) 
나이를 입력하세요: 24
내년이면 25살이 되네요!
이렇게 하면 오류가 난다 age_text + 1처럼 변환 없이 문자열과 숫자를 바로 더하면 TypeError: can only concatenate str (not "int") to str 오류가 발생한다. "문자열끼리는 이어붙일 수 있지만, 문자열과 숫자는 더할 수 없다"는 규칙 때문이다.

오늘 배운 세 가지(input() → 변수 저장 → f-string 출력)는 앞으로 10차시 내내 반복해서 쓰는 기본 패턴이다.

지금까지 배운 변수·input()·f-string을 모두 합쳐 자기소개 문장을 만들어보자.

my_name = input("이름을 입력하세요: ")

반도체

Semiconductor
한 줄 설명

쉬운 비유
필요할 때만 문을 여닫는 스위치.
데이터에서의 예

웨이퍼

Wafer
한 줄 설명

여러 조각으로 자를 큰 피자 도우.

웨이퍼 1장 = 칩 1개가 아니다. 웨이퍼 1장에서 칩이 수백~수천 개 나온다.

FAB(팹)

Fabrication
한 줄 설명
반도체를 생산하는 공장.
쉬운 비유
수백 대의 기계가 쉬지 않고 돌아가는 초정밀 공장.
데이터에서의 예

자주 하는 오해
FAB은 회사 이름이 아니라 "생산 시설"을 뜻하는 일반 용어다.

로트

Lot
한 줄 설명
함께 관리되는 웨이퍼의 묶음(보통 25장 내외).
쉬운 비유
같은 상자에 담겨 함께 이동하는 물건 묶음.
데이터에서의 예
로트번호 열(예: LOT-0398).
자주 하는 오해
로트와 웨이퍼를 같은 것으로 착각하기 쉽다. 로트는 여러 웨이퍼의 묶음이다.

공정

Process
한 줄 설명
웨이퍼에 특정 처리를 하는 작업 단계(증착, 식각 등).
쉬운 비유
요리에서 "굽기", "볶기"처럼 각각의 조리 단계.
데이터에서의 예
공정명 열(예: 식각, 포토, 세정).
자주 하는 오해
하나의 공정만 거치면 칩이 완성된다고 오해하기 쉽지만, 실제로는 수백 번 반복된다.

설비

Equipment
한 줄 설명
공정을 실제로 수행하는 기계.
쉬운 비유
주방의 오븐, 가스레인지처럼 각 조리를 담당하는 기계.
데이터에서의 예
설비번호 열(예: EQ-01~EQ-04).
자주 하는 오해
설비 하나가 모든 공정을 다 한다고 생각하기 쉽지만, 설비마다 담당 공정이 다르다.

센서

# 1. 데이터 분석 도구인 Pandas를 불러옵니다.
import pandas as pd

# 2. CSV 파일을 읽어 표(DataFrame) 형태로 저장합니다.
df = pd.read_csv("week01_semiconductor_process_overview.csv")

# 3. 데이터의 앞부분 5개 행을 확인합니다.
df.head()

# 4. 행 개수와 열 개수를 확인합니다. (행, 열) 순서로 나옵니다.
print(df.shape)

# 5. 열 이름 목록을 확인합니다.
print(df.columns)

# 6. 합격(1)과 불합격(-1)이 각각 몇 건인지 세어봅니다.
print(df["합격여부"].value_counts())
코드 한 줄씩 설명
  • import pandas as pd: 표 형태의 데이터를 다루는 도구 Pandas를 pd라는 별명으로 불러온다.
  • pd.read_csv(...): CSV 파일을 읽어서 DataFrame이라는 표 형태로 만든다.
  • df: 읽어들인 데이터를 저장해두는 이름(변수)이다.
  • df.head(): 데이터의 맨 앞 5개 행만 보여준다(전체를 다 보면 복잡하기 때문).
  • df.shape: (행 개수, 열 개수)를 튜플로 알려준다.
  • df.columns: 모든 열의 이름을 알려준다.
  • df["합격여부"].value_counts(): 합격여부 열에서 값별 개수를 센다.

⚠️ 주의할 점 & 자주 발생하는 오류

오류 1 FileNotFoundError — CSV 파일 이름을 잘못 입력했거나 업로드하지 않은 경우다. 왼쪽 파일 목록에 파일이 보이는지, 이름의 대소문자·확장자가 정확한지 확인한다.
오류 2 KeyError: '합격여부' — 열 이름을 잘못 입력한 경우다. df.columns로 정확한 열 이름을 먼저 확인한다.
주의 Colab에서 런타임이 초기화되면(연결이 끊기면) 이전에 실행한 코드 결과가 사라진다. 파일을 다시 업로드하고 셀을 처음부터 다시 실행해야 한다.
오류 3 NameError: name 'EQ' is not defined — 문자열에 따옴표를 빼먹은 경우다 (equipment = EQ-03처럼). 문자열은 항상 "EQ-03"처럼 따옴표로 감싼다.
오류 4 TypeError: can only concatenate str (not "int") to str — input()으로 받은 문자열을 int()로 바꾸지 않고 바로 숫자와 더한 경우다. age = int(input(...))처럼 반드시 변환한다.
주의 — f-string 흔한 실수 문자열 앞의 f를 빼먹으면 {pass_count}가 계산되지 않고 글자 그대로 출력된다(예: "합격은 {pass_count}건" → 화면에 {pass_count}가 그대로 찍힘). 항상 f"..." 형태인지 확인한다.

Q1. (객관식) 다음 중 "웨이퍼"에 대한 설명으로 가장 알맞은 것은?
  • A. 반도체 칩을 만드는 둥근 원판 모양의 판
  • B. 반도체 공장의 다른 이름
  • C. 공정에서 사용하는 가스의 종류
  • D. 불량품을 검사하는 사람
정답: A. 웨이퍼는 칩을 만드는 원판이다. FAB은 공장, 다이는 웨이퍼를 잘라 만든 조각이다.
Q2. (참/거짓) df.shape는 데이터의 (행 개수, 열 개수)를 알려준다.
정답: 참. 예를 들어 (40, 8)은 40행 8열이라는 뜻이다.
Q3. (서술) 오늘 실습에서 계산한 합격/불합격 개수를 바탕으로, 이 데이터를 처음 보는 사람에게 한 문장으로 설명해보자.
예시 답안: "이번 공정 기록 40건 중 34건(85%)이 합격했고, 6건(15%)이 불합격했다. 대부분의 웨이퍼는 정상적으로 만들어졌지만, 일부는 원인을 더 살펴볼 필요가 있다."
Q4. (객관식) pass_count = 34를 실행했을 때 =의 의미로 가장 알맞은 것은?
  • A. 왼쪽과 오른쪽이 수학적으로 같다는 뜻
  • B. 오른쪽 값을 왼쪽 이름의 변수에 저장하라는 뜻
  • C. 왼쪽 값을 오른쪽으로 옮기라는 뜻
  • D. 두 값을 비교해 참/거짓을 반환하라는 뜻
정답: B. 파이썬의 =는 "대입 연산자"로, 오른쪽 값을 왼쪽 이름의 상자(변수)에 저장한다. (참고: "같다"를 비교할 때는 ==를 쓴다 — 3차시에서 배운다.)
Q5. (빈칸) name = "지민"일 때, "안녕하세요 지민님"을 출력하는 f-string을 완성해보자: print(f"안녕하세요 ______님")
정답: {name} → print(f"안녕하세요 {name}님"). f-string은 중괄호 { } 안에 변수를 넣으면 값이 그대로 문장 속에 끼워진다.
Q6. (참/거짓) age = input("나이를 입력하세요: ")를 실행하면 age는 항상 숫자(int)형으로 저장된다.
정답: 거짓. input()은 입력값을 항상 문자열(str)로 돌려준다. 숫자로 계산하려면 int(age) 또는 float(age)로 변환해야 한다.
