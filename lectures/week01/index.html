반도체 공정과 데이터 처음 만나기

💬 오늘의 질문: "반도체는 어떻게 만들어지고, 그 과정은 어떤 기록을 남길까?"

🎯 학습 목표

  • 반도체, 웨이퍼, 칩의 차이를 설명할 수 있다.
  • 반도체 제조 공정의 전체 흐름을 이해한다.
  • 공정에서 데이터가 왜 발생하는지 설명할 수 있다.
  • 파이썬이 어떤 언어이고, 이 과정에서 왜 필요한지 설명할 수 있다.
  • 데이터를 "분석"한다는 것이 무엇이고 왜 필요한지 설명할 수 있다.
  • 앞으로 10차시 동안 무엇을 배우게 되는지 전체 흐름을 그려볼 수 있다.
  • 파이썬 변수에 값을 저장하고 print()/f-string으로 출력할 수 있다.

🤔 왜 이걸 배워야 할까?

  • 반도체 공정 데이터가 어디서, 왜 생기는지 모르면 앞으로 볼 숫자들이 그냥 "의미 없는 숫자 나열"일 뿐이다. 오늘 배우는 변수와 출력은 그 숫자를 코드 안에 기억해두고 다시 꺼내 쓰는 가장 작은 단위로, 앞으로 10차시 내내 쓰는 모든 코드가 결국 이 위에 쌓인다.
쉬운 예시 매일 아침 "오늘 생산된 웨이퍼 중 합격/불합격이 몇 건인지" 확인해야 하는 담당자가 있다고 하자. "합격 34, 불합격 6"이라는 숫자를 pass_count, fail_count라는 변수에 담아두면, 매번 다시 세지 않고 print()로 바로 꺼내 볼 수 있다 — 이것이 데이터를 코드로 다루는 첫걸음이다.

첫 시간 안내
  • 1차시 — 복습할 이전 내용 없음. 대신 10차시 전체 흐름을 먼저 살펴본다.
    • 1~3차시: 데이터를 "보는" 법
    • 4~5차시: 데이터를 "정리하고 그리는" 법
    • 6~8차시: 데이터를 "비교하고 이상을 찾는" 법
    • 9~10차시: "예측하고 종합하는" 법

📚 반도체 개념 이해하기

반도체란 무엇인가

  • 반도체(Semiconductor) = 도체와 부도체의 중간 성질을 가진 물질
    • 전류를 켜고 끄는 스위치처럼 동작
    • 스위치 수십억 개를 모아 계산·저장을 수행하는 칩을 만듦

웨이퍼에서 칩이 만들어지는 과정

  • 웨이퍼(Wafer) — 둥근 원판, 여기에 공정을 반복해 회로를 새김
  • 다이(Die) — 웨이퍼 한 장에서 나오는 사각형 회로 조각 (수백~수천 개)
  • 칩(Chip) — 다이를 자르고 포장(패키징)한 결과물
비유
  • 웨이퍼 = 커다란 피자 도우 / 다이 = 도우를 자른 한 조각
  • 같은 도우(웨이퍼)라도 조각(다이)마다 굽는 상태(품질)가 다를 수 있음

웨이퍼(둥근 원판) 위에는 같은 회로가 새겨진 다이(Die)가 수백~수천 개 있다. 보라색으로 반짝이는 칸 하나를 잘라 패키징하면 우리가 아는 칩(Chip)이 된다. (실제 웨이퍼 사진을 구할 수 있다면 이 다이어그램과 나란히 추가해도 좋다.)

반도체 제조의 주요 공정

  • 산화 → 포토(노광) → 식각 → 이온 주입 → 증착 → 세정 순서를 수백 번 반복 → 회로 완성
  • 각 공정은 서로 다른 설비(Equipment)에서 진행
  • 설비마다 온도·압력·가스유량을 측정하는 센서(Sensor) 부착

이 6단계를 수백 번 반복하며 웨이퍼 위에 회로가 완성된다 — 순서를 "산-포-식-이-증-세"처럼 앞글자로 외워두면 기억하기 쉽다.

FAB의 의미

  • FAB(팹) = Fabrication의 줄임말 = 반도체를 생산하는 공장
  • 하나의 FAB 안에 수백~수천 대의 설비가 24시간 가동

📊 데이터 분석 개념 이해하기

공정 데이터의 행과 열

  • 학급 성적표로 "표(행과 열)" 개념부터 잡기
이름국어영어
지민9085
하은7892
서준8876
  • 한 행(row) = 학생 한 명의 기록 (예: 지민의 국어 90점, 영어 85점)
  • 한 열(column) = 같은 종류의 항목 (모든 학생의 국어 점수 등)
  • 반도체 공정 데이터도 같은 구조
    • 설비 센서가 몇 초~몇 시간 간격으로 값을 기록
    • 한 행 = 한 번의 측정 기록 (학생 대신 측정 1회)
    • 한 열 = 측정 항목 — 온도, 압력 등 (국어·영어 점수 대신)
개념 표(table) = 여러 개의 행과 열로 이루어진 데이터. 오늘 열어볼 CSV 파일도 성적표·엑셀처럼 행과 열로 이루어진 표다.

합격과 불합격 데이터

  • 검사를 마친 웨이퍼 → 합격(양품) / 불합격(불량)으로 분류
  • 합격여부 열 값: 1 = 합격, -1 = 불합격
    • 다른 원본 데이터 fab.csv는 반대 부호 사용 (9차시에서 설명)

왜 데이터를 "분석"해야 할까

  • 하나의 FAB에는 설비가 수백~수천 대 있고, 각 설비는 초 단위로 온도·압력 등을 기록
    • 하루치 기록만 모아도 수만~수십만 행 → 사람이 하나하나 눈으로 훑어보는 건 사실상 불가능
  • 그래서 데이터를 세고, 요약하고, 그림으로 그려서 한눈에 볼 수 있게 만드는 작업이 필요함
    • 예: "합격 34건, 불합격 6건" — 40줄짜리 표를 일일이 읽는 대신 숫자 두 개로 요약
    • 이렇게 요약하면 "오늘 상태가 괜찮은가?", "어디를 더 살펴봐야 하는가?"를 훨씬 빨리 판단할 수 있음
  • 이것이 바로 데이터 분석 — 많은 기록에서 의미 있는 패턴과 요약을 뽑아내는 과정
    • 이 과정 10차시 전체가 "반도체 공정 데이터를 요약 → 비교 → 예측"하는 순서로 진행됨

🐍 파이썬 시작하기 — 변수와 출력

파이썬이란 무엇인가

  • 파이썬(Python) = 사람이 읽고 쓰기 쉬운 문법으로 컴퓨터에게 일을 시키는 프로그래밍 언어
    • print, import처럼 영어 단어에 가까운 명령어로 이루어져 있어 처음 배우기 좋음
    • 웹 서비스, 인공지능, 데이터 분석 등 다양한 분야에서 가장 널리 쓰이는 언어 중 하나

왜 이 과정에서 파이썬을 배우는가

  • 엑셀로도 표를 다룰 수 있지만, 데이터가 많아지면 한계가 있음
    • 엑셀 — 마우스 클릭과 수식으로 작업 → 행이 수만 개가 넘어가면 느려지고, 사람이 실수하기도 쉬움
    • 파이썬 — 같은 작업을 코드 몇 줄로 만들어두면, 데이터가 아무리 많아도 똑같이 빠르고 정확하게 반복 가능
  • 반도체 공정은 설비마다 초 단위로 온도·압력 등을 기록 → 하루에도 수만~수십만 행이 쌓임
    • 이런 대용량 데이터를 정리·요약·시각화하려면 파이썬 같은 프로그래밍 언어가 사실상 필수
  • 이 과정에서는 파이썬 중에서도 표(행·열) 데이터를 다루는 데 특화된 Pandas라는 도구를 함께 사용
    • 비유: 파이썬이 "공구함"이라면, Pandas는 그 안에 든 "표 전용 공구"
오늘의 순서 표(데이터) 전체를 한 번에 다루는 도구인 Pandas는 4차시부터 배운다. 오늘은 그보다 먼저, 파이썬으로 값 하나를 다루는 가장 작은 단위인 변수부터 시작한다. "변수 → 자료형 → 출력(print, f-string) → 입력(input)" 순서로 기본기를 다진다.

변수란 무엇인가

  • 문제: "합격 34건, 불합격 6건"을 매번 다시 계산하지 않고 기억해두려면?
  • 해결: 변수(Variable) — 값에 이름을 붙여 저장
    • 비유: 이름표가 붙은 상자
    • 상자 안에 값을 넣고, 이름표(변수 이름)로 다시 꺼내 씀

pass_count = 34 — 오른쪽 값(34)을 왼쪽 이름(pass_count) 상자에 저장. =는 수학의 "같다"가 아니라 "오른쪽 값을 왼쪽 이름에 저장하라"(대입 연산자).

Python — 변수 만들기
# 값에 이름을 붙여 저장한다(대입).
pass_count = 34
fail_count = 6

# 이름(변수)만 적으면 그 안에 든 값을 다시 꺼내 쓸 수 있다.
print(pass_count)
print(fail_count)
실행 결과 
34
6
🙋 직접 해보기
  • Colab에 위 코드 입력 후 실행
  • pass_count 값을 다른 숫자로 바꿔 다시 실행 → 결과 변화 확인
체크포인트 — 변수 이름 규칙
  • 사용 가능: 영문자 · 숫자 · 밑줄(_) — 단, 숫자로 시작 불가
  • 사용 불가: 띄어쓰기, 하이픈(-)
    • 예: pass count, 1st_lot, my-name → 모두 오류
  • 대소문자 구분: Pass_Count ≠ pass_count (완전히 다른 변수)

자료형 — 숫자형, 문자열형, 불리언

  • 변수에는 숫자·문자·참거짓(참/거짓) 값을 담을 수 있음
  • 값의 "종류" = 자료형(Data Type) — 오늘은 아래 세 가지만 기억
자료형예시설명
int (정수)6소수점 없는 숫자
float (실수)300.1소수점이 있는 숫자
str (문자열)"EQ-03"따옴표로 감싼 글자
bool (불리언)True / False참 또는 거짓
Python — 자료형 확인하기
temperature = 300.1        # 실수(float)
equipment = "EQ-03"        # 문자열(str) — 따옴표로 감싼다
is_pass = True              # 불리언(bool) — True/False만 가능

print(type(temperature))
print(type(equipment))
print(type(is_pass))
실행 결과 
<class 'float'>
<class 'str'>
<class 'bool'>
주의
  • 문자열은 반드시 따옴표("..." 또는 '...')로 감싸기
  • equipment = EQ-03처럼 따옴표 없이 쓰면 "EQ-03 변수를 찾아라"로 오해 → NameError

print()로 여러 값 한 번에 출력하기

  • print() 안에 콤마(,)로 값을 나열
  • 값 사이에 공백을 하나씩 넣어 순서대로 출력
Python
print("합격:", pass_count, "불합격:", fail_count)
실행 결과 
합격: 34 불합격: 6

f-string으로 문장 속에 값 끼워 넣기

  • 콤마 나열의 문제 — 값 사이에 원치 않는 공백, 매끄러운 문장 쓰기 어려움
  • f-string(포맷 문자열) — 문장 안 원하는 위치에 변수 값을 끼워 넣음
    • 사용법: 문자열 앞에 f + 변수를 중괄호 { }로 감싸기
Python — f-string 기본
print(f"오늘 합격은 {pass_count}건, 불합격은 {fail_count}건입니다.")
실행 결과 
오늘 합격은 34건, 불합격은 6건입니다.
  • 중괄호 안에는 변수뿐 아니라 계산식도 바로 입력 가능
  • 소수점 자리수 지정: :.1f처럼 콜론(:) 뒤에 서식 (.1f = 소수 첫째 자리까지)
Python — f-string 안에서 계산하기
total = pass_count + fail_count
fail_rate = fail_count / total * 100

print(f"전체 {total}건 중 불합격률은 {fail_rate:.1f}%입니다.")
실행 결과 
전체 40건 중 불합격률은 15.0%입니다.
🙋 직접 해보기
  • equipment(EQ-03), temperature(300.1) 변수 활용
  • f"{equipment} 설비의 온도는 {temperature}도입니다." 같은 나만의 f-string 문장 출력

input()으로 값 입력받기

  • 지금까지: 값을 코드에 직접 작성
  • input(): 키보드로 입력한 값을 받아 사용
    • input("질문") 실행 → 화면에 질문 표시 → 입력 내용이 결과값
Python — input() 기본
name = input("이름을 입력하세요: ")
print(f"안녕하세요, {name}님! 반갑습니다.")
실행 결과 예시(입력값: 지민) 
이름을 입력하세요: 지민
안녕하세요, 지민님! 반갑습니다.
가장 중요한 주의사항
  • input()의 결과값은 항상 문자열(str)
  • 숫자를 입력해도 파이썬은 글자로 취급 → 계산하려면 int() 또는 float()로 변환 필요
Python — 입력값을 숫자로 바꾸기
age_text = input("나이를 입력하세요: ")   # age_text는 항상 문자열!
age = int(age_text)                        # 문자열 → 정수로 변환

print(f"내년이면 {age + 1}살이 되네요!")
실행 결과 예시(입력값: 24) 
나이를 입력하세요: 24
내년이면 25살이 되네요!
이렇게 하면 오류가 난다
  • age_text + 1처럼 변환 없이 문자열+숫자를 더하면 오류
  • TypeError: can only concatenate str (not "int") to str
  • 규칙: 문자열끼리는 이어붙이기 가능, 문자열+숫자는 불가

오늘 배운 세 가지(input() → 변수 저장 → f-string 출력)는 앞으로 10차시 내내 반복해서 쓰는 기본 패턴이다.

종합 실습 — 나만의 자기소개 만들기

  • 변수 · input() · f-string을 모두 합쳐 자기소개 문장 만들기
Python — 종합 실습
my_name = input("이름을 입력하세요: ")
favorite_process = input("좋아하는 공정을 입력하세요(증착/식각/포토/세정/산화 중 하나): ")

print(f"안녕하세요! 저는 {my_name}입니다.")

안녕하세요! 저는 하은입니다.

  • 단, 순서를 뒤섞어 실행하면 NameError나 예상과 다른 값 발생 가능
  • 결과가 이상하면 → "런타임 → 모두 실행"으로 맨 위부터 다시 실행
1
새 코드 셀 열기 — 오늘 쓰던 Colab 노트북에 새 코드 셀을 추가한다 (셀 왼쪽에 마우스를 올리면 나타나는 + 코드 버튼).
2
변수 만들기 — pass_count = 34, fail_count = 6을 입력하고 실행한 뒤, print(pass_count)로 값이 잘 저장됐는지 확인한다.
3
자료형 확인하기 — temperature = 300.1, equipment = "EQ-03"을 만들고 각각 type()으로 자료형을 확인한다.
4
f-string 문장 만들기 — print(f"합격 {pass_count}건, 불합격 {fail_count}건")처럼 나만의 문장을 f-string으로 만들어본다.
5
input()으로 입력받기 — name = input("이름을 입력하세요: ")를 실행하고, 화면에 뜬 입력창에 이름을 입력한 뒤 print(f"안녕, {name}!")로 확인한다.
6
종합 실습 완성하기 — 위 "나만의 자기소개 만들기" 코드를 그대로 실행해 자신의 이름과 좋아하는 공정으로 자기소개 문장을 완성한다. (학생용 Notebook의 TODO로 이어짐)

🗂️ 핵심 용어 카드

반도체

Semiconductor
한 줄 설명
전기가 잘 통하는 것과 안 통하는 것의 중간 성질을 가진 물질.
쉬운 비유
필요할 때만 문을 여닫는 스위치.
데이터에서의 예
이 과정에서 다루는 모든 공정 데이터는 반도체를 만드는 과정에서 나온다.
자주 하는 오해
반도체를 특정 "제품 이름"으로 오해하는 경우가 많다. 반도체는 재료의 성질을 말한다.

웨이퍼

Wafer
한 줄 설명
반도체 칩을 만드는 둥근 원판 모양의 얇은 판.
쉬운 비유
여러 조각으로 자를 큰 피자 도우.
데이터에서의 예
웨이퍼번호 열이 웨이퍼 한 장 한 장을 구분한다.
자주 하는 오해
웨이퍼 1장 = 칩 1개가 아니다. 웨이퍼 1장에서 칩이 수백~수천 개 나온다.

FAB(팹)

Fabrication
한 줄 설명
반도체를 생산하는 공장.
쉬운 비유
수백 대의 기계가 쉬지 않고 돌아가는 초정밀 공장.
데이터에서의 예
이 과정의 모든 실습 데이터는 가상의 FAB에서 나온 것으로 가정한다.
자주 하는 오해
FAB은 회사 이름이 아니라 "생산 시설"을 뜻하는 일반 용어다.

로트

Lot
한 줄 설명
함께 관리되는 웨이퍼의 묶음(보통 25장 내외).
쉬운 비유
같은 상자에 담겨 함께 이동하는 물건 묶음.
데이터에서의 예
로트번호 열(예: LOT-0398).
자주 하는 오해
로트와 웨이퍼를 같은 것으로 착각하기 쉽다. 로트는 여러 웨이퍼의 묶음이다.

공정

Process
한 줄 설명
웨이퍼에 특정 처리를 하는 작업 단계(증착, 식각 등).
쉬운 비유
요리에서 "굽기", "볶기"처럼 각각의 조리 단계.
데이터에서의 예
공정명 열(예: 식각, 포토, 세정).
자주 하는 오해
하나의 공정만 거치면 칩이 완성된다고 오해하기 쉽지만, 실제로는 수백 번 반복된다.

설비

Equipment
한 줄 설명
공정을 실제로 수행하는 기계.
쉬운 비유
주방의 오븐, 가스레인지처럼 각 조리를 담당하는 기계.
데이터에서의 예
설비번호 열(예: EQ-01~EQ-04).
자주 하는 오해
설비 하나가 모든 공정을 다 한다고 생각하기 쉽지만, 설비마다 담당 공정이 다르다.

센서

Sensor
한 줄 설명
온도, 압력 등 물리량을 측정해 숫자로 기록하는 장치.
쉬운 비유
체온계처럼 상태를 숫자로 알려주는 장치.
데이터에서의 예
온도_섭씨, 압력_Pa 열이 센서 측정값이다.
자주 하는 오해
센서 값은 항상 정확하다고 생각하기 쉽지만, 고장이나 노이즈로 이상값이 생길 수 있다.

수율

Yield
한 줄 설명
생산한 것 중 정상 제품이 차지하는 비율.
쉬운 비유
사과 100개 중 92개가 상품이면 수율은 92%.
데이터에서의 예
합격여부 열에서 1의 비율.
자주 하는 오해
수율이 낮다고 항상 설비 문제인 것은 아니다(7~8차시에서 자세히 다룬다).

변수

Variable
한 줄 설명
값에 이름을 붙여 저장해두는 공간.
쉬운 비유
이름표가 붙은 상자.
데이터에서의 예
pass_count = 34처럼 합격 건수를 이름 붙여 저장한다.
자주 하는 오해
=를 수학의 "같다"로 착각하기 쉽다. 파이썬에서는 "저장하라"는 뜻이다.

f-string

Formatted String
한 줄 설명
문자열 앞에 f를 붙이고 { } 안에 변수를 넣어 문장 속에 값을 끼워 넣는 방법.
쉬운 비유
편지의 빈칸에 이름을 채워 넣는 것처럼, 문장의 빈칸에 값을 채워 넣는다.
데이터에서의 예
f"합격은 {pass_count}건입니다"
자주 하는 오해
문자열 앞의 f를 빼먹으면 중괄호가 그대로 글자로 출력된다.

⚠️ 주의할 점 & 자주 발생하는 오류

주의
  • Colab 런타임 초기화(연결 끊김) → 이전 실행 결과 사라짐
  • 해결: 맨 위 셀부터 순서대로 다시 실행
오류 1
  • NameError: name 'EQ' is not defined — 문자열 따옴표 누락 (equipment = EQ-03)
  • 해결: 문자열은 항상 "EQ-03"처럼 따옴표로 감싸기
오류 2
  • TypeError: can only concatenate str (not "int") to str
  • 원인: input() 결과(문자열)를 int() 변환 없이 숫자와 더함
  • 해결: age = int(input(...))처럼 반드시 변환
주의 — f-string 흔한 실수
  • 문자열 앞 f 누락 → {pass_count}가 계산 안 되고 글자 그대로 출력
  • 예: "합격은 {pass_count}건" → 화면에 {pass_count} 그대로 표시
  • 항상 f"..." 형태인지 확인

✅ 결과 정리 & 퀴즈

퀴즈는 실습지와 아래 정리 문제로 확인한다.

Q1. (객관식) 다음 중 "웨이퍼"에 대한 설명으로 가장 알맞은 것은?
  • A. 반도체 칩을 만드는 둥근 원판 모양의 판
  • B. 반도체 공장의 다른 이름
  • C. 공정에서 사용하는 가스의 종류
  • D. 불량품을 검사하는 사람
정답: A. 웨이퍼는 칩을 만드는 원판이다. FAB은 공장, 다이는 웨이퍼를 잘라 만든 조각이다.
Q2. (참/거짓) f-string을 쓰려면 문자열 앞에 반드시 f를 붙여야 한다.
정답: 참. f를 빼먹으면 중괄호 { } 안의 내용이 계산되지 않고 글자 그대로 출력된다.
Q3. (서술) 오늘 실습에서 계산한 합격/불합격 개수를 바탕으로, 이 데이터를 처음 보는 사람에게 한 문장으로 설명해보자.
예시 답안: "이번 공정 기록 40건 중 34건(85%)이 합격했고, 6건(15%)이 불합격했다. 대부분의 웨이퍼는 정상적으로 만들어졌지만, 일부는 원인을 더 살펴볼 필요가 있다."
Q4. (객관식) pass_count = 34를 실행했을 때 =의 의미로 가장 알맞은 것은?
  • A. 왼쪽과 오른쪽이 수학적으로 같다는 뜻
  • B. 오른쪽 값을 왼쪽 이름의 변수에 저장하라는 뜻
  • C. 왼쪽 값을 오른쪽으로 옮기라는 뜻
  • D. 두 값을 비교해 참/거짓을 반환하라는 뜻
정답: B. 파이썬의 =는 "대입 연산자"로, 오른쪽 값을 왼쪽 이름의 상자(변수)에 저장한다. (참고: "같다"를 비교할 때는 ==를 쓴다 — 3차시에서 배운다.)
Q5. (빈칸) name = "지민"일 때, "안녕하세요 지민님"을 출력하는 f-string을 완성해보자: print(f"안녕하세요 ______님")
정답: {name} → print(f"안녕하세요 {name}님"). f-string은 중괄호 { } 안에 변수를 넣으면 값이 그대로 문장 속에 끼워진다.
Q6. (참/거짓) age = input("나이를 입력하세요: ")를 실행하면 age는 항상 숫자(int)형으로 저장된다.
정답: 거짓. input()은 입력값을 항상 문자열(str)로 돌려준다. 숫자로 계산하려면 int(age) 또는 float(age)로 변환해야 한다.

🔍 AI에게 검색하며 이해도 높이기

  • "pass_count, fail_count 두 변수로 합격률을 계산해서, 90% 이상이면 '정상', 아니면 '점검 필요'라고 출력하는 파이썬 코드를 만들어줘."
  • "설비 이름과 온도 값을 변수로 받아서, 온도가 295~305도 범위를 벗어나면 경고 문구를 출력하는 코드를 만들어줘."
  • "pass_count, fail_count로 합격률을 계산해 소수 첫째 자리까지 보기 좋게 출력하는 코드를 만들어줘."
Python — AI가 만들어줄 수 있는 코드 예시
pass_count = 34
fail_count = 6
total = pass_count + fail_count
pass_rate = pass_count / total * 100

if pass_rate >= 90:
    print(f"합격률 {pass_rate:.1f}% → 정상")
else:
    print(f"합격률 {pass_rate:.1f}% → 점검 필요")
실행 결과 
합격률 85.0% → 점검 필요
AI 코드를 다룰 때 꼭 지킬 점
  • AI가 만든 코드를 그대로 믿지 말고 직접 Colab/Jupyter에 붙여넣어 실행해 결과를 확인한다.
  • 위 예시의 if/else처럼 아직 배우지 않은 문법이 나올 수 있다 — 이해가 안 되면 그 부분만 다시 AI에게 "이 문법이 무슨 뜻이야?"라고 물어봐도 좋다 (조건문은 3차시에서 자세히 배운다).
  • 변수 이름이 오늘 쓴 것과 다르게 나올 수도 있다 — 그런 경우 코드를 읽으며 내 변수 이름으로 바꿔본다.
