📚 반도체 개념 이해하기

반도체란 무엇인가

반도체(Semiconductor)는 전기가 "잘 통하는 도체"와 "전혀 통하지 않는 부도체"의 중간 성질을 가진 물질이다. 이 성질 덕분에 전류를 켜고 끄는 스위치처럼 동작시킬 수 있고, 이 스위치를 수십억 개 모아 계산과 저장을 수행하는 칩을 만든다.

웨이퍼에서 칩이 만들어지는 과정

둥근 원판 모양의 웨이퍼(Wafer) 위에 여러 공정을 반복해서 회로를 새기면, 웨이퍼 하나에 작은 사각형 회로 조각인 다이(Die)가 수백~수천 개 만들어진다. 다이를 자르고 포장(패키징)하면 우리가 아는 칩(Chip)이 된다.

비유 웨이퍼는 커다란 피자 도우, 다이는 그 위에 자른 한 조각이라고 생각하면 된다. 도우(웨이퍼) 하나로 여러 조각(다이)을 만들지만, 조각마다 굽는 상태(품질)가 다를 수 있다.

반도체 제조의 주요 공정

웨이퍼는 산화 → 포토(노광) → 식각 → 이온 주입 → 증착 → 세정 같은 공정을 수백 번 반복하며 회로가 완성된다. 각 공정은 서로 다른 설비(Equipment)에서 진행되며, 설비 안에는 온도·압력·가스유량 등을 측정하는 센서(Sensor)가 붙어 있다.

FAB의 의미

FAB(팹, Fabrication의 줄임말)은 반도체를 실제로 생산하는 공장을 말한다. 하나의 FAB 안에는 수백~수천 대의 설비가 24시간 돌아간다.

📊 데이터 분석 개념 이해하기

공정 데이터의 행과 열

설비의 센서는 몇 초~몇 시간 간격으로 값을 기록한다. 이 기록을 표로 정리하면, 한 행(row)은 "한 번의 측정 기록", 한 열(column)은 "측정한 항목(온도, 압력 등)"이 된다.

개념 표(table) = 여러 개의 행과 열로 이루어진 데이터. 오늘 우리가 열어볼 CSV 파일도 결국 엑셀처럼 행과 열로 이루어진 표다.

합격과 불합격 데이터

공정을 마친 웨이퍼는 검사를 거쳐 합격(양품)과 불합격(불량)으로 나뉜다. 이 과정에서는 합격여부 열의 값이 1이면 합격, -1이면 불합격을 의미하도록 정했다. (뒤에서 다룰 다른 원본 데이터인 fab.csv는 반대 부호를 쓰는데, 이는 9차시에서 자세히 설명한다.)

👩‍🏫 강사 코드 시연

Python — Colab / Jupyter
# 1. 데이터 분석 도구인 Pandas를 불러옵니다.
import pandas as pd

# 2. CSV 파일을 읽어 표(DataFrame) 형태로 저장합니다.
df = pd.read_csv("week01_semiconductor_process_overview.csv")

# 3. 데이터의 앞부분 5개 행을 확인합니다.
df.head()

# 4. 행 개수와 열 개수를 확인합니다. (행, 열) 순서로 나옵니다.
print(df.shape)

# 5. 열 이름 목록을 확인합니다.
print(df.columns)

# 6. 합격(1)과 불합격(-1)이 각각 몇 건인지 세어봅니다.
print(df["합격여부"].value_counts())
코드 한 줄씩 설명
  • import pandas as pd: 표 형태의 데이터를 다루는 도구 Pandas를 pd라는 별명으로 불러온다.
  • pd.read_csv(...): CSV 파일을 읽어서 DataFrame이라는 표 형태로 만든다.
  • df: 읽어들인 데이터를 저장해두는 이름(변수)이다.
  • df.head(): 데이터의 맨 앞 5개 행만 보여준다(전체를 다 보면 복잡하기 때문).
  • df.shape: (행 개수, 열 개수)를 튜플로 알려준다.
  • df.columns: 모든 열의 이름을 알려준다.
  • df["합격여부"].value_counts(): 합격여부 열에서 값별 개수를 센다.
