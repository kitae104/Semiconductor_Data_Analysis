파이썬 변수와 출력

Variable & print()
  • 반도체·웨이퍼·칩과 칩을 만드는 큰 흐름을 내 말로 설명할 수 있다.
  • 공장이 기록(데이터)을 남기는 이유와, 여러 열을 함께 봐야 하는 이유를 말할 수 있다.
  • 변수에 값을 저장하고 print()와 f-string으로 문장을 출력할 수 있다.

왜 이걸 배워야 할까?

  • 10차시 동안 반도체 공장의 숫자를 다룬다. 숫자가 어디서 왜 생겼는지 알아야 표가 의미 있게 보인다.
  • 변수와 출력은 그 숫자를 코드에 저장하고 다시 꺼내 쓰는 가장 작은 단위다.

지난 시간 복습

첫 시간 안내 첫 시간이라 복습은 없다. 과정 흐름: 1~3차시 값 담기 → 4~6차시 표 정리·그래프 → 7~8차시 비교·단서 찾기 → 9~10차시 예측. 전공·코딩 경험이 없어도 괜찮다.

반도체 개념 이해하기

반도체란 무엇인가

  • 스마트폰·노트북·자동차처럼 "기억"하거나 "계산"하는 물건에는 반도체 칩이 들어 있다.
  • 반도체는 전기가 통하는 정도가 도체(구리)와 부도체(고무) 중간인 물질이다. 대표 재료는 실리콘이다.
  • 조건에 따라 전기를 켜고 끌 수 있어 아주 작은 스위치(켜짐 1, 꺼짐 0)를 만든다. 칩 하나에 수십억 개가 들어 있다.

웨이퍼에서 칩이 되기까지

  • 웨이퍼 — 실리콘을 얇고 둥글게 자른 원판(지름 약 30cm). 이 위에 회로를 새긴다.
  • 다이 — 웨이퍼 위에 바둑판처럼 새긴 회로 하나. 한 장에 수백~수천 개.
  • 칩 — 다이를 잘라 포장한 완성품.
비유 — 쿠키 굽기 웨이퍼 = 쿠키 반죽판, 다이 = 틀로 찍은 쿠키 한 개, 칩 = 하나씩 포장한 쿠키.

웨이퍼 위 다이(보라색 칸) 하나를 잘라 포장하면 칩이 된다.

회로 기판 사진. 검은 사각형이 포장을 마친 칩이다.

반도체는 어떻게 만들까

큰 흐름은 웨이퍼 준비 → 회로 새기기 → 검사(합격/불합격 결정) → 자르고 포장하기다. 회로 새기기에서는 아래 작업들을 순서를 바꿔 가며 수백 번 반복한다. 이름보다 하는 일을 기억하자.

작업(공정)하는 일생활 속 비유
산화표면에 얇은 보호막(산화막)을 만든다쇠 표면이 녹스는 것처럼 표면이 막으로 바뀌기
포토빛을 비춰 회로 무늬를 찍는다스텐실로 무늬 찍기
식각찍힌 무늬대로 필요 없는 부분을 깎아낸다판화에서 조각칼로 파내기
이온 주입정해진 자리에 원자(이온)를 넣어 전기 성질을 바꾼다고기 일부에만 양념 배게 하기
증착재료를 아주 얇은 막으로 한 겹 쌓는다페인트 한 겹 덧칠하기
세정작업 사이사이 찌꺼기와 먼지를 씻어낸다다음 조리 전에 재료 헹구기
오해하기 쉬운 점 위 작업을 한 바퀴 돈다고 칩이 완성되지 않는다. 층마다 반복해 수백 단계, 몇 주~몇 달이 걸린다.
"AI에게 물어보기" 상자 사용법 [복사]를 눌러 AI 챗봇에 붙여넣는다. AI 답은 틀릴 수 있으니 강의와 비교하고, 회사 데이터·개인정보는 붙여넣지 않는다.
AI에게 물어보기 — 복사해서 AI 챗봇에 붙여넣기
너는 반도체 공장에서 오래 일한 친절한 선배야. 반도체를 처음 배우는 사람에게 산화, 포토, 식각, 이온 주입, 증착, 세정 6가지 작업을 '케이크 만들기'에 비유해서 작업마다 한 줄씩 설명해줘.

FAB·클린룸, 로트·설비·센서

  • FAB(팹) — 반도체 공장. 먼지 한 톨도 회로를 망칠 수 있어 공장 안은 클린룸(먼지를 극도로 줄인 방)이다.
  • 로트 — 함께 이동하는 웨이퍼 묶음(보통 25장 내외). 택배 송장처럼 LOT-0398 같은 번호가 붙는다.
  • 설비 — 작업을 하는 기계(EQ-01 등). 센서 — 설비 안의 온도·압력을 재는 장치(체온계).

데이터 분석 개념 이해하기

공장은 왜 기록을 남길까

웨이퍼 한 장이 수백 단계를 거치므로, 불량이 나오면 기록을 거슬러 올라가 어디서 무엇이 달랐는지 찾는다. 자동차 블랙박스와 같다.

기록은 표(행과 열)로 쌓인다

이름국어영어
지민9085
하은7892
  • 행(가로줄) = 기록 1건(학생 한 명 → 공정 데이터에서는 작업 1건).
  • 열(세로줄) = 같은 종류의 항목(국어 점수 → 시간, 설비번호, 온도 등).
  • 검사 결과 합격여부 열은 1 = 합격, -1 = 불합격이다.

STEP 01

파이썬 시작하기 — 변수와 출력

파이썬과 Jupyter Notebook

  • 파이썬은 컴퓨터에 일을 시키는 언어다. 한 번 쓴 코드를 데이터가 많아도 똑같이 반복해준다.
  • 코드를 쓰는 칸이 셀이다. Shift + Enter로 실행하면 결과가 바로 아래 나온다. [1]은 실행 순서다.
  • 코드 셀은 파이썬을 실행하고, 마크다운 셀은 글을 적는 칸이다. 글 칸은 더블클릭해 고치고 Shift + Enter로 마친다.
  • 노트북 파일 열기·새 노트북 만들기·저장은 강사가 화면으로 보여준다(README 6절).
  • # 뒤의 글은 주석이다. 파이썬은 실행하지 않는다.
  • 개념은 카페 주문(연습용 가상 값)으로 배우고, 반도체 데이터는 뒤의 "반도체 데이터로 확인하기"와 실습지에서 다룬다.

변수 — 이름표가 붙은 상자

cups = 3 — 오른쪽 값(3)을 왼쪽 이름(cups) 상자에 저장한다. =는 "같다"가 아니라 "저장하라"는 뜻이다.

쉬운 예제 — 카페 주문

Python — 쉬운 예제: 변수 만들기
coffee_price = 4500
cups = 3

print(coffee_price)
print(cups)
실행 결과 
4500
3

print()는 괄호 안 값을 화면에 보여준다. 변수 이름을 넣으면 그 안의 값이 나온다.

변수 이름 규칙 영문자·숫자·밑줄(_)만 쓰고 숫자로 시작하지 않는다(pass count, 1st_lot, my-name은 오류). 대문자와 소문자는 다른 이름이다.

자료형 — 값의 종류

자료형예설명
int (정수)3소수점 없는 숫자
float (실수)4.5소수점 있는 숫자
str (문자열)"아메리카노"따옴표로 감싼 글자
bool (불리언)True참 또는 거짓

쉬운 예제 — 카페 주문

Python — 쉬운 예제: 자료형 확인하기
rating = 4.5               # 실수(float)
menu = "아메리카노"        # 문자열(str)
is_hot = True              # 불리언(bool)

print(type(cups))
print(type(rating))
print(type(menu))
print(type(is_hot))
실행 결과 
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>

type()은 값의 자료형을 알려준다.

주의 — 글자는 따옴표로 따옴표 없이 equipment = EQ-04처럼 쓰면 SyntaxError가 난다. 글자는 "EQ-04"처럼 감싼다.

print()와 f-string — 값을 문장으로 출력하기

  • print()에 콤마로 값을 나열하면 사이에 공백을 넣어 출력한다.
  • f-string: 따옴표 앞에 f, 값 자리에 {변수 이름}. 편지 양식 빈칸 채우기와 같다. 중괄호 안에는 {cups + 2} 같은 계산식도 넣을 수 있다.

쉬운 예제 — 주문 문장

Python — 쉬운 예제: 콤마 출력과 f-string
print("메뉴:", menu, "잔 수:", cups)
print(f"{menu} {cups}잔 주문이 들어왔습니다.")
실행 결과 
메뉴: 아메리카노 잔 수: 3
아메리카노 3잔 주문이 들어왔습니다.

계산한 값을 문장에 넣기

+ 더하기, / 나누기, * 곱하기. {ice_rate:.1f}의 :.1f는 "소수 첫째 자리까지"라는 뜻이다.

쉬운 예제 — 아이스 커피 비율

따뜻한 커피 7잔, 아이스 커피 5잔이 팔렸다.

Python — 쉬운 예제: 계산한 값 넣기
hot_count = 7
ice_count = 5

total = hot_count + ice_count
ice_rate = ice_count / total * 100
print(total, ice_rate)

print(f"전체 {total}잔 중 아이스 비율은 {ice_rate:.1f}%입니다.")
실행 결과 
12 41.66666666666667
전체 12잔 중 아이스 비율은 41.7%입니다.

그대로 출력하면 소수점이 길게 이어지고, :.1f를 쓰면 41.7로 반올림된다.

input() — 키보드로 값 입력받기

input("질문")을 실행하면 입력칸이 나타나고, 입력 후 Enter를 누르면 그 내용이 결과값이 된다.

쉬운 예제 — 이름 입력과 추가 주문

Python — 쉬운 예제: input() 기본
name = input("이름을 입력하세요: ")
print(f"안녕하세요, {name}님! 주문을 도와드릴게요.")

이름을 입력하세요: 지민
안녕하세요, 지민님! 주문을 도와드릴게요.
Python — 쉬운 예제: 입력값을 숫자로 바꾸기
more_text = input("몇 잔 더 주문하시겠어요? ")
print(type(more_text))

more_cups = int(more_text)
print(f"주문은 모두 {cups + more_cups}잔입니다.")
실행 결과 예시(입력값: 2) 
몇 잔 더 주문하시겠어요? 2
<class 'str'>

가장 중요한 주의사항 input()의 결과는 숫자를 입력해도 항상 문자열(str)이다. 계산하려면 int()(또는 float())로 바꾼다. 바꾸지 않고 more_text + cups를 하면 TypeError: can only concatenate str (not "int") to str가 난다.

AI로 한 걸음 더 — 질문하고 코드 받아보기

질문해보기 — 하나 이상 골라서 (노트북 9단계)
  • "파이썬에서 =와 ==는 어떻게 다른가요? 예시와 함께 설명해주세요."
  • "웨이퍼, 다이, 칩의 관계를 쿠키 말고 다른 비유로 설명해주세요."
  • "반도체 공장에서 클린룸이 왜 필요한지 초등학생도 알아듣게 설명해주세요."
코드 받아보기 (노트북 10단계) "pass_count, fail_count 두 변수로 합격률을 계산해서, 90% 이상이면 '정상', 아니면 '점검 필요'라고 출력하는 파이썬 코드를 만들어줘." (90%는 연습용 기준)
Python — AI가 만들어줄 수 있는 코드 예시
pass_count = 32
fail_count = 8
total = pass_count + fail_count
pass_rate = pass_count / total * 100

if pass_rate >= 90:
    print(f"합격률 {pass_rate:.1f}% → 정상")
else:
    print(f"합격률 {pass_rate:.1f}% → 점검 필요")
실행 결과 
합격률 80.0% → 점검 필요
AI 코드를 다룰 때 직접 실행해서 확인한다. if/else는 3차시에 배우니 지금은 "조건에 따라 다른 문장을 출력한다" 정도로 읽는다.
