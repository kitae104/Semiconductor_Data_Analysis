공정 지도 — 칩이 만들어지는 8단계

칩을 만드는 큰 단계는 여덟 개라서 흔히 "반도체 8대 공정"이라고 부른다. 이 과정에서는 아래 그림을 공정 지도라고 부른다.

앞으로 데이터를 볼 때마다 "공정 지도의 몇 번에서 나온 기록인가"를 이 번호로 알려 준다. 이름을 외울 필요는 없다.

반도체 8대 공정을 생활 비유로 본 흐름. ②~⑥ 단계는 층을 쌓을 때마다 여러 번 되풀이한다(교육용 단순화). 전공정·후공정 분류는 자료마다 조금 다를 수 있다.

번호하는 일피자 가게라면
① 웨이퍼 제조실리콘 덩어리를 얇고 둥글게 썰어 원판을 만든다피자 도우(웨이퍼) 만들기
② 산화웨이퍼 표면을 산소와 반응시켜 얇은 산화막(보호막)을 키운다철이 녹슬듯 표면에 얇은 막 키우기
③ 포토빛을 비춰 회로 그림을 웨이퍼에 옮긴다사진 인화처럼 도우 위에 회로 그림 찍기
④ 식각그림대로 필요 없는 부분을 깎아 낸다판화처럼 그림 밖 부분 깎아 내기
⑤ 증착/이온주입얇은 막을 한 겹 쌓는다(증착). 정해진 자리에 아주 작은 알갱이(이온)를 넣어 전기가 통하는 성질을 바꾼다(이온주입)토핑을 층층이 올리고 소스를 스며들게 하기
⑥ 금속 배선층마다 금속 선을 깔아 회로 사이를 이어 전기가 흐르게 한다층마다 재료 사이를 전선처럼 잇기
⑦ EDS(전기 검사)자르기 전 웨이퍼 상태에서 칩 하나하나에 전기를 넣어 제대로 동작하는지 검사한다자르기 전, 조각(칩)마다 전기로 검사
⑧ 패키징칩을 잘라 보호 껍데기에 담고 바깥과 연결한다조각을 하나씩 포장 상자에 담기
  • 칩은 회로를 여러 층으로 쌓는다. 그래서 ② 산화부터 ⑥ 금속 배선까지를 층마다 되풀이한다.
  • 세정(씻기)은 따로 번호가 없다. 단계 사이마다 웨이퍼를 씻는다. 오늘 데이터의 공정명에 나오는 세정이 이것이다.

측정시간로트번호웨이퍼번호공정명설비번호온도_C압력_Pa합격여부

  • 한 행 = 어느 로트의 몇 번 웨이퍼가 어느 설비에서 어떤 공정을 거친 기록 한 번. 둘째 행은 "LOT-0227의 4번 웨이퍼가 EQ-04에서 식각을 거쳤고 합격".

변수 — 이름표가 붙은 상자

cups = 3 — 오른쪽 값(3)을 왼쪽 이름(cups) 상자에 저장한다.

=는 "같다"가 아니라 "저장하라"는 뜻이다.

커피 한 잔 4,500원, 3잔 주문. 값을 상자에 담고, 담은 값끼리 곱한 결과도 새 상자에 담는다.

Python — 쉬운 예제: 변수 만들기 (노트북 2단계)
coffee_price = 4500
cups = 3

print(coffee_price)
print(cups)

total_price = coffee_price * cups
print(total_price)
실행 결과 
4500
3
13500

*는 곱하기다. total_price에는 계산 결과 13500이 저장된다.

변수 이름 규칙 영문자·숫자·밑줄(_)로 쓰고, 숫자로 시작하지 않는다. 대문자와 소문자는 다른 이름이다(cups와 Cups는 다르다).

자료형 — type()으로 값의 종류 보기

값에는 종류(자료형)가 있다. 종류에 따라 할 수 있는 일이 다르다 — 숫자는 계산하고, 글자는 문장에 넣는다.

자료형예뜻
int3정수(소수점 없는 수)
float4.5소수점이 있는 수
str"아메리카노"글자(문자열). 따옴표로 감싼다
Python — 쉬운 예제: 자료형 확인하기 (노트북 3단계)
rating = 4.5
menu = "아메리카노"

print(type(cups))
print(type(rating))
print(type(menu))
실행 결과 
<class 'int'>
<class 'float'>
<class 'str'>

type()은 괄호 안 값의 종류를 알려 준다. cups는 2단계에서 만든 상자라서 2단계를 먼저 실행해야 한다.

print()와 f-string — 값을 문장으로 출력하기

  • print()에 콤마로 값을 나열하면 사이에 빈칸을 넣어 출력한다.
  • f-string: 따옴표 앞에 f, 값이 들어갈 자리에 {변수 이름}을 쓴다. 문장 속 빈칸에 값을 채워 넣는 방법이다.
  • 콤마 출력은 값을 빈칸으로 띄워 늘어놓을 뿐이고, f-string은 값이 들어간 하나의 자연스러운 문장을 만든다. 보고 문장에는 f-string을 쓴다.
Python — 쉬운 예제: 콤마 출력과 f-string (노트북 4단계)
print("메뉴:", menu, "잔 수:", cups)

print(f"{menu} {cups}잔 주문이 들어왔습니다.")
실행 결과

계산한 값을 문장에 넣기

따뜻한 커피 6잔, 아이스 4잔이 팔렸다. 전체 잔 수와 아이스 비율을 구해 문장으로 만든다.

+는 더하기, /는 나누기, * 100은 백분율(%)로 바꾸기다.

Python — 쉬운 예제: 계산한 값 넣기 (노트북 5단계)
hot_count = 6
ice_count = 4

total = hot_count + ice_count
ice_rate = ice_count / total * 100
print(total, ice_rate)

print(f"전체 {total}잔 중 아이스는 {ice_rate}%입니다.")
실행 결과 
10 40.0
전체 10잔 중 아이스는 40.0%입니다.

나누기(/)의 결과는 늘 소수점이 있는 수(float)라서 40이 아니라 40.0으로 나온다.

구경만 — input() 강사가 화면에서 name = input("이름을 입력하세요: ") 한 줄을 보여 준다. 실행하면 입력칸이 나오고, 키보드로 친 글자가 name에 저장된다. 오늘 실습에는 쓰지 않는다.

반도체 데이터로 확인하기

카페 예제와 같은 모양으로, 오늘 받은 공장 기록표(교육용 가상 데이터)를 다룬다. 오늘 파이썬은 표 파일을 직접 읽지 않는다(그건 4차시에 배운다). 그래서 노트북에는 표에서 센 값(합격 32, 불합격 8)이 미리 적혀 있다. 이 숫자가 맞는지는 PART 2에서 Orange 막대로 직접 세어 확인한다. 질문을 먼저 생각해 본 뒤 열어 보자. (노트북 6단계)

확인 1 — 미션 보고 문장 만들기

합격 건수와 불합격 건수를 각각 상자에 담고, 둘을 더한 전체 건수와 함께 한 문장으로 보고하면?

Python — 확인 1
pass_count = 32
fail_count = 8
total_count = pass_count + fail_count

print(f"오늘 기록 {total_count}건 중 합격은 {pass_count}건, 불합격은 {fail_count}건입니다.")
실행 결과 
오늘 기록 40건 중 합격은 32건, 불합격은 8건입니다.

공장 말로 읽기: 40줄짜리 표가 이름 붙은 숫자 세 개와 보고 문장 하나로 줄었다. 이 문장이 오늘 미션의 보고 문장이다.

확인 2 — 불합격률은 몇 %일까

카페의 아이스 비율과 같은 모양으로 불합격률을 구하면?

Python — 확인 2
fail_rate = fail_count / total_count * 100
print(f"불합격률은 {fail_rate}%입니다.")
실행 결과 
불합격률은 20.0%입니다.

공장 말로 읽기: 기록 40건 중 20.0%가 불합격 기록이다. 거꾸로 합격 기록은 80.0%다.

공장에서는 생산한 것 중 정상 제품이 나온 비율을 수율이라고 부른다. 오늘 합격 비율은 "기록 40건 중 합격 기록"의 비율이라 계산 모양은 같지만, 수율 그 자체는 아니다.

숫자 하나로는 모르는 것 "불합격률 20.0%"만으로는 불합격이 어느 공정·설비에서 나왔는지 알 수 없다. 그러려면 공정명·설비번호 같은 다른 열도 함께 봐야 한다. PART 2에서 Orange로 공정별로, 실습지에서 설비별로 나눠 본다.

공장과 잇기 공장에서는 동네 표의 한 행이 동 하나이듯, 공장 기록표의 한 행은 기록 1건이다. 주요연령대 막대로 가장 흔한 값을 본 것처럼 합격여부 막대로 합격·불합격 수를 보고, Split by 구처럼 Split by 공정명·설비번호로 나눠 본다.

반도체 데이터 — 공장 기록표 40건

파이썬에서 다룬 그 공장 기록표다. 공정 지도 ②~⑤와 세정에서 남긴 설비 기록이다(교육용 가상 데이터).

1
File > Open으로 orange3/week01/week01_2_process_start.ows를 연다. File을 더블클릭해 week01_semiconductor_process_overview.tab이 들어왔는지 확인한다.
2
File에 Data Table을 잇고 Info 칸을 읽는다.
  • 40 instances = 기록 40건. 파이썬 확인 1의 total_count 40과 같다.
  • 4 features = 공정명·설비번호·온도_C·압력_Pa.
  • Target with 2 values = 결과 열 합격여부 1개(값 두 종류: 1, -1).
  • 3 meta attributes = 측정시간·로트번호·웨이퍼번호. 기록을 찾아가는 이름표 열이다.

불합격 8건 중 5건이 세정 기록이다(산화 1 · 포토 2 · 식각 0 · 증착 0). 세정 기록은 모두 10건이다. 공정명이라는 열을 함께 보니 "세정을 더 살펴볼까?"라는 질문이 생긴다.

원인이라고 말해도 될까? 아직 아니다. 기록이 적어 우연일 수 있다. 지금은 세정을 원인 후보(더 확인할 대상)까지만 말한다. 원인인지는 더 많은 기록으로 확인해야 한다.
파이썬 결과와 비교 파이썬 변수에 담은 합격 32 · 불합격 8이 Distributions 막대 높이와 같다. 파이썬의 불합격률 20.0%와 Orange 툴팁의 20.00 %도 같은 숫자다.
막혔을 때 같은 폴더의 week01_1_town_done.ows, week01_2_process_done.ows를 열면 완성된 연결을 볼 수 있다. File에 빨간 글씨가 보이면 키트 폴더 구조가 바뀌지 않았는지 확인한다.

주의할 점 & 자주 발생하는 오류

오류 1 — 글자에 따옴표를 빼먹었을 때 menu = 아메리카노라고 쓰면 NameError: name '아메리카노' is not defined가 난다. 따옴표가 없으면 파이썬이 글자를 변수 이름으로 읽는다. "아메리카노"처럼 감싼다.
오류 2 — 변수 이름의 대소문자·철자가 다를 때 cups를 만들고 print(Cups)라고 쓰면 NameError: name 'Cups' is not defined가 난다. 위 셀을 실행하지 않았을 때도 같은 오류가 난다. 이름을 그대로 베껴 쓰고, 위 셀부터 차례로 실행한다.
오류 3 — f-string의 f를 빼먹었을 때 오류 없이 합격은 {pass_count}건처럼 중괄호가 글자 그대로 나온다. 따옴표 바로 앞에 f가 있는지 확인한다.
주의 — 오류 없이 틀린 숫자가 나올 때 비율을 구할 때 나누는 수를 잘못 고르면 오류 없이 엉뚱한 숫자가 나온다. 카페의 total(10), 공장 전체의 total_count(40), EQ-03의 eq03_count(12)는 서로 다른 상자다. "무엇 중에서의 비율인가"를 먼저 정하고 그 상자를 쓴다.

결과 정리 & 퀴즈

오늘의 반도체 이해 포인트
  • 웨이퍼 한 장 위에 칩(다이) 수백 개 이상을 함께 만들고, ② 산화부터 ⑥ 금속 배선까지를 층마다 되풀이한다. 이 흐름이 공정 지도 ①~⑧이다.
  • 공장은 공정마다 온도·압력 같은 조건과 합격/불합격을 기록한다. 오늘 표의 한 행은 "어느 로트의 몇 번 웨이퍼가 어느 설비에서 어떤 공정을 거친 기록 한 번"이다.
  • 파이썬: 합격 32, 불합격 8을 변수에 담아 "오늘 기록 40건 중 합격은 32건, 불합격은 8건", "불합격률은 20.0%"로 보고했다.
  • Orange: Distributions 막대 높이 32와 8이 파이썬 숫자와 같았다. 공정명으로 나누면 불합격 8건 중 5건이 세정이었다(원인 후보).

나머지 문항은 실습지와 수업 뒤 퀴즈로 복습한다.

Q1. (객관식) 웨이퍼와 칩의 관계로 알맞은 것은?
  • A. 웨이퍼 한 장 위에 칩(다이) 여러 개를 함께 만든 뒤 잘라 낸다
  • B. 칩 하나를 크게 키우면 웨이퍼 한 장이 된다
  • C. 웨이퍼는 칩을 담아 옮기는 상자다
  • D. 웨이퍼와 칩은 같은 말이다
정답: A. 피자 도우(웨이퍼)를 조각(칩)으로 나누는 것과 비슷하다.
Q2. (객관식) print("합격은 {pass_count}건입니다.")를 실행하면 무엇이 나올까? (pass_count는 32)
  • A. 합격은 32건입니다.
  • B. 합격은 {pass_count}건입니다.
  • C. NameError
  • D. SyntaxError
정답: B. 따옴표 앞에 f가 없어서 중괄호가 글자 그대로 나온다.
Q3. (객관식) Orange Distributions에서 합격여부를 골랐을 때 막대 두 개가 보여 주는 것은?
  • A. 합격(1)과 불합격(-1)이 각각 몇 건인지 — 32건과 8건
  • B. 온도의 평균
  • C. 표의 행과 열 개수
  • D. 설비별 온도
정답: A. 파이썬 변수 pass_count, fail_count와 같은 숫자다.

AI로 한 걸음 더

ChatGPT에 이렇게 물어봤다. (노트북 8단계)

ChatGPT에 보낸 질문 — 복사해서 붙여 넣기
합격 32건, 불합격 8건일 때 합격률을 계산해서 90% 이상이면 "정상", 아니면 "점검 필요"라고 출력하는 짧은 파이썬 코드를 만들어 줘.

아래는 받은 코드의 예시다. if/else는 3차시에 배운다. 지금은 실행해서 결과만 확인한다.

Python — AI가 만든 코드 예시
pass_count = 32
fail_count = 8
total = pass_count + fail_count
pass_rate = pass_count / total * 100

if pass_rate >= 90:
    print(f"합격률 {pass_rate}% → 정상")
else:
    print(f"합격률 {pass_rate}% → 점검 필요")
실행 결과 
합격률 80.0% → 점검 필요
AI 코드를 다룰 때 AI가 준 코드와 숫자는 직접 실행해서 확인한다. 90%는 연습용 기준이다.
