4. 코드 빈칸 문제

Python
pass_count = 32
fail_count ____ 8

print(f"오늘 합격은 {pass_count}건, 불합격은 {____}건입니다.")
순서대로 =, fail_count. =는 오른쪽 값을 왼쪽 이름에 저장하라는 뜻이다.

5. 자료형 맞히기

각 값의 자료형을 int, float, str, bool 중에서 골라보자.

값자료형

순서대로 int(정수), float(실수), str(문자열), bool(불리언). 따옴표로 감싸면 숫자처럼 보여도 문자열이다.

6. f-string 결과 예측 문제

아래 코드를 실행하면 무엇이 출력될지 먼저 예측해보자.

Python
equipment = "EQ-02"
temperature = 301.46
print(f"{equipment} 설비의 온도는 {temperature:.1f}도입니다.")
정답: EQ-02 설비의 온도는 301.5도입니다. — :.1f는 소수 첫째 자리까지 반올림해 보여준다.

7. input() 오류 찾기 문제

아래 코드는 실행하면 오류가 난다. 어디가 문제인지 찾아 고쳐보자.

Python — 오류 있는 코드
age_text = input("나이를 입력하세요: ")
print(f"내년이면 {age_text + 1}살이 되네요!")
input()으로 받은 age_text는 문자열이라 숫자 1과 더할 수 없다(TypeError). age = int(age_text)로 바꾼 뒤 {age + 1}을 쓴다.

8. 결과 해석과 문장 쓰기

오늘 데이터의 합격여부 열을 세어 보니 아래와 같았다.

합격(1)      32건
불합격(-1)    8건
문장 작성 불합격률을 계산하고 빈칸을 채워보자. "이번 공정 기록 ____건 중 ____건이 불합격했으며, 이는 전체의 ____%에 해당한다."
8 ÷ 40 × 100 = 20. "이번 공정 기록 40건 중 8건이 불합격했으며, 이는 전체의 20%에 해당한다."

1) 세정(10건 중 5건). 2) "세정을 원인 후보로 더 살펴볼 만하지만, 아직 원인이라고 단정할 수는 없어. 기록이 40건뿐이라 우연일 수 있고, 앞 단계에서 생긴 문제가 세정 뒤 검사에서 드러났을 수도 있어."

10. 도전 — 합격률 문장 만들기

도전 pass_count = 32, fail_count = 8로 total(전체 건수)과 pass_rate(합격률)를 계산하고, 합격률은 80.0%입니다.를 f-string으로 출력해보자. (노트북 4단계 끝 "도전 문제")
체크포인트 pass_rate = pass_count / total * 100 순서로 계산한다. pass_count / (total * 100)처럼 괄호를 넣으면 0.008이라는 엉뚱한 값이 나온다. 출력에는 {pass_rate:.1f}를 쓴다.
