🤔 왜 이걸 배워야 할까?

  • 반도체 공정 데이터가 어디서, 왜 생기는지 모르면 앞으로 볼 숫자들이 그냥 "의미 없는 숫자 나열"일 뿐이다. 오늘 배운 변수와 출력은 그 숫자를 코드 안에 기억해두고 다시 꺼내 쓰는 가장 작은 단위로, 앞으로 10차시 내내 쓰는 모든 코드가 결국 이 위에 쌓인다.
쉬운 예시 매일 아침 "오늘 생산된 웨이퍼 중 합격/불합격이 몇 건인지" 확인해야 하는 담당자가 있다고 하자. "합격 32, 불합격 8"이라는 숫자를 pass_count, fail_count라는 변수에 담아두면, 매번 다시 세지 않고 print()로 바로 꺼내 볼 수 있다 — 이것이 데이터를 코드로 다루는 첫걸음이다.

1. 용어 연결 문제

B. 함께 관리되는 웨이퍼 묶음

D. 공정을 수행하는 기계
② FAB
③ 로트
④ 설비

2. 코드 빈칸 문제

Python
pass_count = 32
fail_count ____ 8   # 8을 fail_count라는 이름에 저장

print(f"합격 {pass_count}건, 불합격 {____}건")
순서대로 =, fail_count. =는 오른쪽 값을 왼쪽 이름에 저장하는 대입 연산자다.

3. 그래프 선택 문제

합격/불합격처럼 "범주별 개수"를 비교하려면 어떤 그래프가 가장 적합할까?

  • ① 선 그래프
  • ② 막대그래프
  • ③ 산점도
정답: ② 막대그래프. 막대그래프는 범주(카테고리)별 개수나 크기를 비교할 때 가장 알아보기 쉽다. (6차시에서 직접 그려본다.)

4. 결과 해석 문제

오늘 살펴본 데이터에서 합격/불합격 열을 정리한 결과가 아래와 같았다.

합격(1)      32
불합격(-1)    8

이 결과를 보고 불합격 비율(%)을 계산해보자.

8 ÷ (32+8) × 100 = 20%. 즉 40건 중 20%가 불합격이다.

5. 분석 문장 작성 문제

아래 빈칸을 채워 이번 차시 데이터를 한 문장으로 요약해보자.

문장 작성 "이번 공정 기록 ____건 중 ____건이 합격했으며, 이는 전체의 약 ____%에 해당한다."

6. 도전 문제

도전 오늘 데이터의 설비별 기록 건수는 EQ-01 13건, EQ-02 9건, EQ-03 12건, EQ-04 6건이다. 네 값을 각각 변수에 저장한 뒤, 가장 많이 등장한 설비와 건수를 f-string으로 "가장 많이 기록된 설비는 ___(___건)입니다." 형태의 문장으로 출력해보자.

7. 변수·자료형 빈칸 문제

Python
pass_count ____ 32        # 32를 pass_count라는 이름에 저장
equipment = "EQ-03"
print(____(equipment))    # equipment의 자료형을 확인
순서대로 =, type. equipment는 따옴표로 감싼 문자열(str)이므로 <class 'str'>이 출력된다.

8. f-string 결과 예측 문제

아래 코드를 실행하면 무엇이 출력될지 먼저 예측해보고 정답을 확인하자.

Python
name = "하은"
score = 92.345
print(f"{name}님의 점수는 {score:.1f}점입니다.")
정답: 하은님의 점수는 92.3점입니다. — {score:.1f}는 소수 첫째 자리까지만 반올림해 보여준다.

9. input() 오류 찾기 문제

아래 코드는 실행하면 오류가 난다. 어디가 문제인지 찾아 고쳐보자.

Python — 오류 있는 코드
age = input("나이를 입력하세요: ")
print(f"내년이면 {age + 1}살이 되네요!")
문제: age는 input()이 돌려준 문자열(str)이라 숫자 1과 바로 더할 수 없다(TypeError). 수정: age = int(input("나이를 입력하세요: "))처럼 int()로 변환해야 한다.

10. 심화 실습

심화 아래처럼 합격 건수와 불합격 건수를 변수에 저장했다. 
pass_count = 32
fail_count = 8
total(전체 건수)과 pass_rate(합격률) 변수를 직접 계산해서 만들고, f"전체 {total}건 중 합격 {pass_count}건, 합격률 {pass_rate:.1f}%" 형태의 문장을 출력하는 코드를 작성해보자. :.1f 형식을 잊지 말고 사용한다.
체크포인트 pass_rate는 pass_count / total * 100 순서로 계산해야 한다. pass_count / (total * 100)처럼 괄호 위치가 달라지면 결과가 크게 작아지니 계산 순서를 꼭 확인하자.
