문제 3. EQ-03 불합격률 계산하고 자료형 확인하기 (노트북 7단계 문제 3)

불합격률 = 불합격 건수 ÷ 전체 건수 × 100. 힌트: 강의 확인 2의 fail_rate 계산과 같은 모양이다.

문제 4. Orange로 불합격이 가장 많은 설비 찾기

Orange 3.35에서 week01_2_process_start.ows를 연다(강의 PART 2에서 이어 붙인 화면이 있으면 그대로 써도 된다).

  1. File 위젯에 Distributions(분포 막대)를 잇고 더블클릭한다.
  2. 왼쪽 Variable 목록에서 합격여부를 클릭한다.
  3. 왼쪽 아래 Columns 칸의 Split by를 설비번호로 바꾼다. 막대가 설비마다 다른 색으로 나뉜다.
  4. 불합격(-1) 막대에 마우스를 올리고 잠시 기다린다. 툴팁 표에서 설비마다 불합격이 몇 건인지 읽는다.
적어 보기 불합격 막대 안 설비별 개수: EQ-01 ____ · EQ-02 ____ · EQ-03 ____ · EQ-04 ____
불합격이 가장 많은 설비는 ______. 문제 1의 eq03_fail과 비교하면 (같다 / 다르다).
체크포인트 불합격 8건 중 EQ-01 2 · EQ-02 1 · EQ-03 3 · EQ-04 2. 불합격이 가장 많은 설비는 EQ-03이고, 문제 1의 eq03_fail 3과 같다.
툴팁 표의 맨 윗줄은 막대 전체(-1: 8, 20.00 %)이고, 아래 줄이 설비별 개수다.
막혔으면 같은 폴더의 week01_2_process_done.ows를 열고 Distributions에서 Split by만 바꾼다.

문제 5. 해석 문장 쓰기

EQ-03 결과를 팀장에게 보고하는 문장을 빈칸을 채워 완성하자.

문장 작성 "공장 기록 40건 중 ____건(____%)이 불합격이고, 설비 EQ-03은 12건 중 ____건(____%)이 불합격이다. 이 숫자만으로 알 수 없는 것은 ____________이다."

힌트: 강의 "반도체 데이터로 확인하기"의 "숫자 하나로는 모르는 것" 상자를 떠올려 보자.

"공장 기록 40건 중 8건(20.0%)이 불합격이고, 설비 EQ-03은 12건 중 3건(25.0%)이 불합격이다. 이 숫자만으로 알 수 없는 것은 EQ-03 때문에 불합격이 났는지이다."
EQ-03의 불합격률이 전체보다 높아 더 살펴볼 만하다. 하지만 기록이 12건뿐이라 우연일 수 있고, EQ-03 기록에는 여러 공정이 섞여 있다. 그래서 EQ-03은 원인이 아니라 원인 후보까지만 말한다.
