pass_count = ____

print(pass_count)

순서대로 32, 8. 출력도 32, 8.

5. 합격·불합격 문장 만들기 (노트북 6단계)

오늘 합격은 32건, 불합격은 8건입니다.가 나오도록 빈칸을 채워보자. 힌트: 쉬운 예제 f"{menu} {cups}잔 …"과 같은 모양.

Python
print(f"오늘 합격은 {____}건, 불합격은 {____}건입니다.")
순서대로 pass_count, fail_count.

6. 설비 값의 자료형 (노트북 6단계)

설비번호 EQ-04을 저장하도록 빈칸을 채우고, 출력될 자료형 네 줄을 예측해보자. 힌트: 쉬운 예제 menu = "아메리카노"와 같은 모양.

Python
temperature = 300.1        # 실수(float)
equipment = ____           # 문자열(str)
is_pass = True             # 불리언(bool)

print(type(pass_count))
print(type(temperature))
print(type(equipment))
print(type(is_pass))
빈칸은 "EQ-04"(따옴표를 빼면 SyntaxError). 출력은 순서대로 <class 'int'>, <class 'float'>, <class 'str'>, <class 'bool'>.

7. 설비 온도 문장 만들기 (노트북 6단계)

EQ-04 설비의 온도는 300.1도입니다.가 나오도록 빈칸을 채워보자. 힌트: f-string 글자 하나, 300.1이 든 변수 이름.

Python
print(____"{equipment} 설비의 온도는 {____}도입니다.")
순서대로 f, temperature. f를 빼면 중괄호가 글자 그대로 나온다.

8. 불합격률 계산하기 (노트북 7단계)

전체 건수와 불합격률을 구하고 빈칸을 채워보자. 힌트: 쉬운 예제 ice_count / total * 100, {ice_rate:.1f}와 같은 모양.

Python
total = pass_count ____ fail_count
fail_rate = ____ / total * 100
print(total, fail_rate)

print(f"전체 {total}건 중 불합격률은 {fail_rate:____}%입니다.")
문장 작성 "이번 공정 기록 ____건 중 ____건이 불합격했으며, 이는 전체의 ____%에 해당한다."
빈칸은 +, fail_count, .1f. 출력 40 20.0, 전체 40건 중 불합격률은 20.0%입니다.
"이번 공정 기록 40건 중 8건이 불합격했으며, 이는 전체의 20%에 해당한다."

9. 세정 공정만 따로 보기 (노트북 7단계)

공정명과 함께 세어 보니 세정 기록 10건 중 불합격이 5건이었다. 세정의 불합격률을 구해보자. 힌트: 8번과 같은 모양.

Python
clean_total = 10
clean_fail = 5
clean_rate = ____ / clean_total * 100
print(f"세정 기록 {clean_total}건 중 불합격률은 {clean_rate:.1f}%입니다.")

동료가 "그럼 세정이 불량의 원인이네!"라고 말했다. 어떻게 답하면 좋을까?

빈칸은 clean_fail. 출력 세정 기록 10건 중 불합격률은 50.0%입니다.(전체 20.0%).
예시 답: "세정은 원인 후보일 뿐 원인이라고 단정할 수 없어. 40건뿐이라 우연일 수 있어."

추가 불합격 건수를 입력받아 합계를 구한다(연습용 상황). 빈칸을 채우고 2를 입력했을 때의 출력을 적어보자. 힌트: 쉬운 예제 more_cups = int(more_text)와 같은 모양.

Python
more_text = input("추가로 나온 불합격 건수를 입력하세요: ")
print(type(more_text))

more_fail = ____(more_text)
print(f"불합격은 모두 {fail_count + more_fail}건입니다.")
체크포인트 빈칸은 int. 출력: <class 'str'>, 불합격은 모두 10건입니다. int()를 빼면 TypeError가 난다.
