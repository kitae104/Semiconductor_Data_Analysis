3. 열 선택 문제

온도(온도_섭씨)와 압력(압력_Pa) 두 열을 함께 선택하는 코드로 올바른 것은?

  • ① df["온도_섭씨", "압력_Pa"]
  • ② df[["온도_섭씨", "압력_Pa"]]
  • ③ df.온도_섭씨.압력_Pa
정답: ②. 여러 열을 선택할 때는 대괄호 안에 리스트를 한 번 더 감싸야 한다.

4. 결과 해석 문제

실습에서 EQ-02 설비의 기록은 25건이었고, 이 중 불합격은 5건이었다.

eq02.shape → (25, 8)
(eq02["합격여부"] == -1).sum() → 5

EQ-02의 불합격 비율(%)을 계산해보자.

5 ÷ 25 × 100 = 20.0%. 즉 EQ-02 기록 25건 중 20.0%가 불합격이다.

6. 도전 문제

도전 df[df["설비번호"] != "EQ-02"]로 EQ-02가 아닌 나머지 설비의 기록만 골라내고, 그 안에서 불합격 비율을 계산해서 EQ-02(20.0%)와 비교해보자. 그리고 df.sort_values("온도_섭씨")로 온도가 가장 낮았던 하위 5건도 확인해보자.

7. loc / iloc 연습 문제

아래 빈칸에 loc 또는 iloc 중 알맞은 것을 넣어보자.

Python
# ① 조건으로 행을 고르면서 열 두 개도 함께 지정하고 싶다
df.____________[df["합격여부"] == -1, ["로트번호", "온도_섭씨"]]

# ② 앞에서 3번째 행(위치 기준)만 보고 싶다
df.____________[2]

# ③ 앞에서 5개 행, 앞에서 2개 열만 잘라내고 싶다
df.____________[0:5, 0:2]
① loc(조건식은 loc 전용) ② iloc(위치 기준) ③ iloc(위치 기준 슬라이스)

다음 중 df.iloc[0:3]이 돌려주는 행의 개수로 올바른 것은?

  • ① 2개(위치 0, 1)
  • ② 3개(위치 0, 1, 2)
  • ③ 4개(위치 0, 1, 2, 3)
정답: ②. iloc의 슬라이스는 파이썬 리스트처럼 끝 번호(3)를 포함하지 않는다. 반면 df.loc[0:3]이었다면 끝 번호 3을 포함해 4개 행이 나왔을 것이다.
🙋 직접 해보기 df.loc[0:2]와 df.iloc[0:2]를 각각 실행해서 결과 행이 몇 개 나오는지 직접 세어 비교해보자. 예상과 같은가?

8. 심화 실습

심화 & 연산자로 두 조건을 동시에 만족하는 행을 찾아보자: df[(df["온도_섭씨"] > 305) & (df["합격여부"] == -1)]. 이 결과의 행 개수를 세어 "고온이면서 불합격인 건수"를 확인하고, 전체 불합격 건수 대비 비율(%)을 계산해보자. 그리고 이 조건으로 걸러낸 결과에 ["공정명"].value_counts()를 적용해 어떤 공정에서 많이 나타나는지도 확인해보자.
체크포인트 Pandas에서 여러 조건을 &(그리고)·|(또는)로 합칠 때는 각 조건을 반드시 괄호로 감싸야 한다. df["온도_섭씨"] > 305 & df["합격여부"] == -1처럼 괄호 없이 쓰면 연산 순서가 꼬여 오류가 나거나 엉뚱한 결과가 나온다.
