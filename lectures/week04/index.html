Pandas 가장 기본적인 부분

💬 오늘의 질문: "3차시에 반복문으로 한 줄씩 처리했던 일을, Pandas는 어떻게 한 번에 처리할까?"

작성 상태 이 페이지는 v2 커리큘럼 구성이 확정된 직후 작성된 개요(skeleton)입니다. 제목·학습 목표·다룰 내용·데이터까지는 확정되었지만, 상세 설명·예제 코드·단계별 실습·퀴즈는 아직 채워지지 않았습니다. 구성이 최종 확정되면 이어서 상세 내용을 작성합니다. 배경은 docs/restructure-plan.md 참고.

🎯 학습 목표

  • read_csv로 CSV 파일을 DataFrame으로 읽을 수 있다.
  • 원하는 열만 선택해서 볼 수 있다.
  • 조건 검색(불리언 인덱싱)으로 원하는 행만 골라낼 수 있다.
  • 정렬로 값이 높은/낮은 순서를 확인할 수 있다.

선수 지식: 3차시 — 반복문·함수

📚 다룰 이론 주제(초안)

  • CSV와 DataFrame
  • 열 선택
  • 조건 검색(불리언 인덱싱)
  • 정렬
  • head / shape / columns 로 기본 정보 확인하기

🐍 다룰 실습 흐름(초안)

  1. read_csv()로 데이터 읽기
  2. 온도 열만 보기, 온도+압력 함께 보기
  3. 특정 설비(EQ-02)만 찾기
  4. 불합격 데이터만 찾기
  5. 온도 내림차순 정렬
  6. 3차시 함수로 짠 결과와 Pandas 조건 검색 결과 개수 맞춰보기
