Pandas 가장 기본적인 부분

💬 오늘의 질문: "3차시에 반복문으로 한 줄씩 처리했던 일을, Pandas는 어떻게 한 번에 처리할까?"

🎯 학습 목표

  • read_csv로 CSV 파일을 DataFrame으로 읽을 수 있다.
  • 원하는 열만 선택해서 볼 수 있다.
  • 조건 검색(불리언 인덱싱)으로 원하는 행만 골라낼 수 있다.
  • 정렬로 값이 높은/낮은 순서를 확인할 수 있다.

선수 지식: 3차시 — 반복문·함수

⏮️ 지난 시간 복습

3차시 연결 3차시에서는 for와 if로 리스트를 하나씩 순회하며 judge_pass 함수로 직접 판정했다. 오늘 배울 Pandas는 "표 전체"를 다루는 도구로, 3차시에 여러 줄로 짰던 반복 작업을 대부분 한 줄로 처리해준다. 딕셔너리의 리스트가 사실 "표(DataFrame)"와 매우 비슷한 모양이라는 것을 오늘 확인한다.

📚 열 선택 — 원하는 열만 보기

Python
print(df["온도_섭씨"])                 # 열 하나 (Series)
print(df[["온도_섭씨", "압력_Pa"]])      # 열 여러 개 (대괄호 두 번!)
가장 흔한 함정 열을 여러 개 선택할 때는 df["온도_섭씨", "압력_Pa"]처럼 대괄호를 한 번만 쓰면 오류가 난다. df[["온도_섭씨", "압력_Pa"]]처럼 안쪽에 리스트를 한 번 더 감싸야 한다(2차시에서 배운 리스트 [ ]를 대괄호 안에 넣는 것).

📚 조건 검색 — 원하는 행만 골라내기

  • Pandas — 조건식 하나로 표 전체에서 한 번에 골라냄 = 조건 검색(불리언 인덱싱)

📚 loc / iloc — 이름과 위치로 정확히 접근하기

  • 지금까지 — 열 이름으로 열 전체 선택(df["열이름"]), 조건으로 행 전체 필터(df[조건])
  • 필요할 때가 많음 — "몇 번째 행의, 이 열들만"처럼 행과 열을 동시에 정확히 짚기
  • 이때 쓰는 것 = loc, iloc — 데이터 분석에서 자주 쓰는 접근법, 충분히 연습 필요
loc vs iloc — 가장 중요한 차이
  • loc — 이름(라벨)로 찾는다. 행 인덱스 값과 열 이름을 그대로 쓴다.
  • iloc — 위치(정수)로 찾는다. 앞에서부터 몇 번째 행/열인지 0부터 센다 (2차시에서 배운 리스트의 인덱스 번호와 같은 방식).

loc — 이름(라벨)로 찾기

Python
# 행 하나 + 열 하나
print(df.loc[0, "온도_섭씨"])

# 조건으로 행을 고르면서, 보고 싶은 열도 함께 지정
eq02_view = df.loc[df["설비번호"] == "EQ-02", ["로트번호", "온도_섭씨", "합격여부"]]
print(eq02_view.head())
실행 결과

      로트번호  온도_섭씨  합격여부
0  LOT-0141   297.6     1
2  LOT-0156   296.9    -1
3  LOT-0224   297.2     1
...
동작 원리
  • df.loc[행조건, 열이름목록] — 대괄호 안이 "행, 열" 두 부분으로 나뉜다. 앞은 4차시에서 배운 조건 검색과 똑같고, 뒤는 보고 싶은 열 이름 리스트다.
  • 열 부분을 생략하면(df.loc[조건]) 조건에 맞는 모든 열이 나온다 — 지금까지 써온 df[조건]과 사실상 같은 결과다.

iloc — 위치(정수)로 찾기

Python
# 첫 번째 행 (위치 0)
print(df.iloc[0])

# 앞에서 3개 행, 앞에서 2개 열
print(df.iloc[0:3, 0:2])

# 맨 마지막 행
print(df.iloc[-1])
주의 — loc과 iloc의 슬라이스 범위가 다르다 df.loc[0:2]는 인덱스 0, 1, 2까지 포함해 3개 행을 돌려주지만, df.iloc[0:3]은 파이썬 리스트 슬라이싱과 똑같이 끝 번호를 포함하지 않아 위치 0, 1, 2인 3개 행을 돌려준다. "숫자만 보면 헷갈리지만 결과 개수는 같다"는 점, "loc은 끝 포함, iloc은 끝 미포함"이라는 규칙을 꼭 기억하자.
구분lociloc
기준이름(라벨) — 인덱스 값, 열 이름위치(정수) — 0부터 센 순서
행 하나 예시df.loc[0]df.iloc[0]
조건으로 행 고르기df.loc[df["합격여부"]==-1]불가능(조건은 loc 전용)
슬라이스 끝 번호포함미포함
오류 — iloc에 열 이름을 넣으면? df.iloc[0, "온도_섭씨"]처럼 iloc에 열 이름을 넣으면 ValueError가 난다. iloc은 오직 정수 위치만 받는다 — 열 이름이 몇 번째 열인지 알고 싶다면 df.columns.get_loc("온도_섭씨")로 먼저 확인하거나, 이름으로 접근할 때는 loc을 쓰면 된다.
언제 무엇을 쓸까?
  • 조건으로 행을 거르면서 특정 열도 같이 보고 싶다 → loc
  • "처음 5행", "마지막 3행"처럼 순서(위치)로 잘라내고 싶다 → iloc
  • 반복문에서 i번째 행에 차례로 접근하고 싶다 → iloc

📚 종합 — 3차시 함수와 Pandas 비교하기

  • Pandas 조건 검색 조합 → 훨씬 짧아짐

eq02_fail = eq02[eq02["합격여부"] == -1]
fail_rate = len(eq02_fail) / len(eq02) * 100

print(f"EQ-02 불합격 건수: {len(eq02_fail)}건")

🗂️ 핵심 용어 카드

DataFrame

DataFrame
한 줄 설명
Pandas가 CSV를 읽어 만든 행·열 구조의 표.
쉬운 비유
엑셀 시트, 또는 딕셔너리가 여러 개 담긴 리스트.
데이터에서의 예
df = pd.read_csv(...)
자주 하는 오해
DataFrame이 리스트·딕셔너리와 완전히 다른 개념이라고 생각하기 쉽다. 사실 개념적으로 매우 비슷하다.

열 선택

Column Selection
한 줄 설명
원하는 열(들)만 골라 보는 방법.
쉬운 비유
엑셀에서 특정 세로줄(열)만 눈으로 훑어보는 것.
데이터에서의 예
df[["온도_섭씨", "압력_Pa"]]
자주 하는 오해
여러 열 선택 시 대괄호를 한 번만 쓰는 실수가 흔하다.

조건 검색

Boolean Indexing
한 줄 설명
조건에 맞는 행만 골라내는 방법.
쉬운 비유
3차시의 if를 표 전체에 한 번에 적용하는 것.
데이터에서의 예
df[df["설비번호"] == "EQ-02"]
자주 하는 오해
결과가 원본을 바꾼다고 착각하기 쉽다. 실제로는 새 표가 만들어진다.

정렬

Sort
한 줄 설명
특정 열을 기준으로 행의 순서를 바꾸는 것.
쉬운 비유
키 순서대로 줄을 서는 것.
데이터에서의 예
df.sort_values("온도_섭씨", ascending=False)
자주 하는 오해
기본 정렬이 내림차순이라고 착각하기 쉽다. 기본값은 오름차순이다.

loc

Label-based Indexing
한 줄 설명
행 인덱스 값·열 이름 같은 "이름(라벨)"으로 데이터를 골라내는 방법.
쉬운 비유
출석부에서 "이름"으로 학생을 찾는 것.
데이터에서의 예
df.loc[df["설비번호"]=="EQ-02", ["온도_섭씨"]]
자주 하는 오해
df.loc[0:2]처럼 슬라이스를 쓸 때 끝 번호 2가 결과에서 빠진다고 착각하기 쉽다. loc은 끝 번호를 포함한다.

iloc

Position-based Indexing
한 줄 설명
0부터 세는 "위치(정수)"로 데이터를 골라내는 방법.
쉬운 비유
번호표 순서대로 "몇 번째" 학생인지로 찾는 것.
데이터에서의 예
df.iloc[0:3, 0:2]
자주 하는 오해
iloc에 열 이름을 넣을 수 있다고 착각하기 쉽다. iloc은 오직 정수 위치만 받는다.

⚠️ 주의할 점 & 자주 발생하는 오류

오류 1 KeyError: '온도' — 열 이름을 정확히 쓰지 않은 경우다(실제 열 이름은 온도_섭씨). df.columns로 정확한 이름을 먼저 확인하자.
오류 2 조건식에서 df[df["설비번호"] = "EQ-02"]처럼 =을 쓰면 SyntaxError가 난다. 비교는 항상 ==다(3차시 복습).
주의 — 대괄호 개수 열 하나는 df["열이름"](대괄호 1개), 열 여러 개는 df[["열1", "열2"]](대괄호 2개, 안쪽이 리스트)다.
오류 3 ValueError — df.iloc[0, "온도_섭씨"]처럼 iloc에 열 이름을 넣은 경우다. iloc은 정수 위치만 받으므로, 열 이름으로 접근하려면 loc을 써야 한다.
주의 — loc은 끝 포함, iloc은 끝 미포함 df.loc[0:2]는 3개 행(0,1,2)을, df.iloc[0:2]는 2개 행(0,1)만 돌려준다. 슬라이스 결과 개수가 예상과 다르면 이 규칙을 먼저 떠올리자.

🚀 도전 실습

도전 문제 1 df[df["설비번호"] != "EQ-02"]로 EQ-02가 아닌 나머지 설비의 기록만 골라내고, 그 안에서 불합격 비율을 계산해서 EQ-02(20.0%)와 비교해보자.
도전 문제 2 df.sort_values("온도_섭씨")(오름차순)로 온도가 가장 낮았던 하위 5건을 확인해보자. 그 5건 중 불합격은 몇 건인가?
도전 문제 3 — loc df.loc[(df["설비번호"]=="EQ-02") & (df["합격여부"]==-1), ["로트번호", "온도_섭씨"]]로 EQ-02에서 불합격한 로트의 로트번호와 온도만 뽑아보자.
도전 문제 4 — iloc df.iloc[-5:]로 데이터의 마지막 5행을 확인하고, df.sort_values("측정시간").iloc[-5:]와 비교해 두 결과가 왜 다른지(원본 순서 vs 정렬된 순서) 설명해보자.

Q1. (객관식) 온도_섭씨와 압력_Pa 두 열을 함께 선택하는 올바른 코드는?

  • B. df[["온도_섭씨", "압력_Pa"]]
  • C. df.온도_섭씨.압력_Pa
  • D. df("온도_섭씨", "압력_Pa")
정답: B. 여러 열을 선택할 때는 대괄호 안에 리스트(대괄호)를 한 번 더 감싸야 한다.
Q2. (참/거짓) df.sort_values("온도_섭씨")는 기본적으로 온도가 높은 순서(내림차순)로 정렬한다.
정답: 거짓. 기본값은 오름차순이다. 내림차순은 ascending=False를 명시해야 한다.
Q3. (빈칸) 조건에 맞는 행만 골라낼 때, 먼저 True/False 목록을 만드는 부분은 df["합격여부"] ______ -1이다.
정답: ==. 비교 연산자를 써서 각 행이 조건을 만족하는지 True/False로 판단한 뒤, 그 목록으로 원본을 걸러낸다.
Q4. (서술) 3차시의 for+if 방식과 오늘 배운 Pandas 조건 검색의 차이를 한 문장으로 설명해보자.
예시 답안: "3차시에는 반복문으로 값을 하나씩 확인하며 조건을 검사했지만, Pandas는 조건식 한 줄로 표 전체에서 한 번에 원하는 행을 골라낼 수 있다."
Q5. (객관식) df.iloc[0:3]이 돌려주는 행의 개수는?
  • A. 2개(위치 0, 1)
  • B. 3개(위치 0, 1, 2)
  • C. 4개(위치 0, 1, 2, 3)
정답: B. iloc의 슬라이스는 파이썬 리스트처럼 끝 번호(3)를 포함하지 않으므로 위치 0, 1, 2 세 개 행이 나온다.
Q6. (빈칸) 조건으로 행을 고르면서 특정 열도 함께 지정하고 싶을 때 쓰는 것은 df.______[조건, 열이름목록]이다.
정답: loc. iloc은 조건식이 아니라 정수 위치만 받으므로 이 용도로는 쓸 수 없다.

Python — AI가 만들어줄 수 있는 코드 예시
import pandas as pd

data = {
    "설비번호": ["EQ-01", "EQ-01", "EQ-02", "EQ-02", "EQ-02"],
    "합격여부": [1, -1, 1, 1, -1],
}
df = pd.DataFrame(data)

summary = pd.crosstab(df["설비번호"], df["합격여부"])
print(summary)

📝 과제(다음 차시까지)

  • 아래 과제를 에디터 파일 하나에 순서대로 작성, 각 결과를 확인할 수 있게 만들어 제출
과제 1 — 설비별 요약 EQ-01, EQ-03, EQ-04에 대해서도 각각 조건 검색으로 행 개수와 불합격 건수를 확인하고, 어느 설비가 가장 불안정해 보이는지 문장으로 정리한다.
과제 2 — 압력 조건 검색 압력_Pa가 1020 이상인 행만 골라내 몇 건인지 확인하고, 그중 불합격 비율도 계산해본다.
과제 3 — loc/iloc 종합 df.loc[df["압력_Pa"] > 1015, ["설비번호", "압력_Pa", "합격여부"]]로 압력이 높은 행의 세 열만 뽑아보고, df.iloc[:5, :3]으로 앞에서 5행·3열만 잘라내 두 결과가 각각 무엇을 기준으로 골라졌는지 한 문장씩 설명한다.
과제 4(도전) — 두 조건 동시 검색 df[(df["설비번호"] == "EQ-02") & (df["합격여부"] == -1)]처럼 & 기호로 조건 두 개를 동시에 적용하는 코드를 검색해서 실행해보고, 결과가 무엇을 의미하는지 설명해본다(5차시 결측값 필터링에서 다시 쓰인다).
체크포인트 — & 를 쓸 때는 조건마다 괄호가 필요하다 df[df["설비번호"] == "EQ-02" & df["합격여부"] == -1]처럼 괄호 없이 쓰면 연산 순서가 꼬여 오류가 나거나 잘못된 결과가 나온다. 위 예시처럼 (df["설비번호"] == "EQ-02") & (df["합격여부"] == -1)처럼 각 조건을 반드시 괄호로 감싸야 한다. 그리고 and가 아니라 &를 써야 한다는 점도 함께 기억하자(파이썬의 and는 표 전체에는 쓸 수 없다).
