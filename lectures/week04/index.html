Pandas 가장 기본적인 부분

오늘의 질문: "3차시에 반복문으로 한 줄씩 처리했던 일을, Pandas는 어떻게 한 번에 처리할까?"

오늘의 데이터
week04_process_filtering.csv (가상)
크기
100행 × 8열
설비
EQ-01 ~ EQ-04
전체 불합격
13건 (13.0%)
EQ-02 불합격
5건 / 25건

오늘의 학습 목표

  • CSV 파일을 read_csv로 읽어 표(DataFrame)로 만들고, head·shape·columns로 생김새를 확인할 수 있다.
  • 필요한 열만 꺼내 볼 수 있다. 열 하나는 df["열"], 여러 개는 df[["열1", "열2"]].
  • 조건 검색으로 특정 설비·불합격 기록만 골라내고, 건수와 비율로 설비끼리 비교할 수 있다.
  • sort_values로 값이 큰 순서·작은 순서로 줄 세울 수 있다.

선수 지식: 1차시 — 표의 행과 열, 2차시 — 딕셔너리의 리스트, 3차시 — for+if. loc은 맛보기만 한다.

왜 이걸 배워야 할까?

  • 오늘 표는 100줄, 실제 공장은 하루 수십만 줄이다. 눈으로 세지 않고 Pandas(파이썬의 표 전용 공구)로 열고, 고르고, 줄 세운다.
  • 표를 나눠 보면 보인다. 전체 불합격은 13.0%지만 설비별로는 EQ-04 22.7%, EQ-02 20.0%, EQ-03 4.5%다. 반 전체 평균은 괜찮은데 한 반만 점수가 낮은 것과 같다.

STEP 01

CSV와 DataFrame — 1차시의 그 표를 파이썬으로 읽기

read_csv()로 CSV(쉼표로 칸을 나눈 표 파일)를 읽으면 DataFrame이라는 표가 된다. 행 하나는 2차시의 딕셔너리 하나, 열 이름은 그 키와 같다.

오늘 수업 방식
  • 개념은 카페 주문 기록(cafe)으로 배운다. 반도체 공정 기록(df)은 뒤의 "반도체 데이터로 확인하기"와 실습지에서 같은 모양의 코드로 다룬다.
  • 두 데이터 모두 교육용 가상 데이터다. 아래 표처럼 열 이름만 바뀐다.
카페 표(쉬운 예제) 열뜻반도체 표에서 같은 자리
주문번호주문마다 붙는 번호(C-001~C-012)로트번호
매장·메뉴주문이 들어온 매장(강남점·홍대점), 메뉴 이름-
종류커피·차·디저트. 묶어서 따로 떼어 보는 기준설비번호
가격_원·수량_개한 개 가격(원), 산 개수온도_섭씨 같은 숫자 열
평가손님 평가. 1 = 좋아요, -1 = 별로예요합격여부(1 = 합격, -1 = 불합격)

STEP 02

조건 검색 — 원하는 행만 골라내기

조건에 맞는 행만 남기는 것이다(불리언 인덱싱). 엑셀 필터에서 원하는 값에만 체크하는 것과 같다.

쉬운 예제 — 커피 주문만, 5000원보다 비싼 주문만

Python — 1단계: 체크 표시 보기
check = cafe["종류"] == "커피"
print(check.head())
실행 결과 
0     True
1     True
2    False
3    False
4     True
Name: 종류, dtype: bool

오른쪽 cafe["종류"] == "커피"를 먼저 계산하고(행마다 True/False), 그 결과를 =로 check에 저장한다.

Python — 2단계: True인 행만 남기기
coffee = cafe[cafe["종류"] == "커피"]
print(coffee.shape)
실행 결과 
(5, 7)

바깥 cafe[ ] 안의 식은 위 check와 같다. cafe[check]라고 써도 결과가 같고, check 자리에 식을 그대로 넣은 것이 cafe[cafe["종류"] == "커피"]다.

① ==(같은가?)로 모든 행에 True/False를 붙이고, ② 바깥 cafe[ ]가 True인 행만 새 표로 남긴다. 원래 cafe(12행)는 바뀌지 않는다.

Python — 5000원보다 비싼 주문
pricey = cafe[cafe["가격_원"] > 5000]
print(len(pricey))
실행 결과 
5

>는 "보다 크다", 행 개수는 len()으로 센다. 3차시에 빈 리스트·for·if·append() 네 줄로 하던 일이 한 줄이 됐다.

쉬운 예제 — 골라낸 표에서 한 번 더 고르기

Python — 별로예요만, 비싼 주문 중 별로예요만
bad = cafe[cafe["평가"] == -1]
print(bad.shape)
pricey_bad = pricey[pricey["평가"] == -1]
print(len(pricey_bad))
실행 결과

  • 평가는 1 = 좋아요, -1 = 별로예요다. 비싼 주문 5건 안에서 별로예요를 한 번 더 고르니 3건이다.
  • 두 조건을 한 줄에 거는 방법은 8차시에 배운다. 오늘은 두 번 나눠 고른다.
