Pandas 가장 기본적인 부분

오늘의 질문: "3차시에 반복문으로 한 줄씩 처리했던 일을, Pandas는 어떻게 한 번에 처리할까?"

오늘의 미션 — 입사 넷째 날, 기록 100건짜리 CSV 파일을 받았다. EQ-02에서 불합격이 몇 건인지 찾아 보고하자. (신입 데이터 담당자의 10일 이야기와 공장·데이터는 모두 교육용 가상이다.)

학습 목표

  • CSV 파일을 read_csv로 읽고, head·shape·columns로 표의 생김새를 확인할 수 있다.
  • 필요한 열만 고르고, 조건 검색으로 원하는 행만 골라 개수를 셀 수 있다.
  • sort_values로 값이 큰 순서대로 줄 세울 수 있다.
  • Orange3 Select Columns·Select Rows로 같은 결과를 만들어 파이썬과 건수를 비교하고, 반도체 공정 중 되풀이되는 단계를 찾을 수 있다.

선수 지식: 3차시 — for+if로 세기, Orange Select Rows / 2차시 — len, 리스트 / 1차시 — 공정 지도

왜 이걸 배워야 할까?

3차시에는 for와 if 네 줄로 기록을 하나씩 꺼내 셌다. 1~3차시 Orange에서는 File로 표를 열고 Select Rows로 행을 골랐다. 오늘은 그 일을 Pandas(파이썬의 표 전용 도구)로 한다. 표 전체에 조건을 한 번에 걸어 한 줄로 고른다.

공장 기록은 금방 수백, 수천 줄이 된다. 같은 공정을 층마다 되풀이하는 것도 큰 이유다(PART 2에서 공정 흐름표로 확인한다). 줄이 많아질수록 눈으로 세기 어렵다.

비유 — 피자 가게 주문 장부 장부가 수천 장이면 "2번 오븐에서 덜 익은 판"을 손으로 넘겨 찾기 어렵다. 장부를 표로 열고(read_csv), 필요한 칸만 보고(열 선택), 조건에 맞는 줄만 남기면(조건 검색) 한 번에 찾는다.

CSV 파일 읽기 — read_csv

CSV는 칸을 쉼표(,)로 나눠 적은 표 파일이다. pd.read_csv()로 읽으면 행과 열이 있는 표가 된다. 이 표를 DataFrame이라고 부른다.

  • import pandas as pd — Pandas를 불러와 짧은 이름 pd로 쓴다.
  • "week04_easy_cafe_orders.csv" — 읽을 파일의 이름. 노트북과 같은 곳에 있는 파일이라 이름만 쓰면 된다. 강의 코드 그대로 쓴다.
  • encoding="utf-8-sig" — 한글이 깨지지 않게 읽는 방법. 오늘 파일은 모두 이렇게 읽는다.
  • cafe.head() — 앞 5행만 보여 준다. 셀 마지막 줄에 쓰면 표 모양으로 나온다.
Python — 카페 주문 기록 읽기 (노트북 1단계)

cafe = pd.read_csv("week04_easy_cafe_orders.csv", encoding="utf-8-sig")

숫자 조건과 한 번 더 고르기

숫자 열에는 >, <, >= 같은 비교 기호를 쓴다(3차시와 같다). 골라낸 표에서 다시 조건을 걸면 두 조건을 모두 만족하는 행이 남는다. len()(2차시)으로 행 수를 센다.

Python — 5000원 넘는 주문, 그중 "별로예요" (노트북 4~5단계)
pricey = cafe[cafe["가격_KRW"] > 5000]
print(len(pricey))

pricey_bad = pricey[pricey["평가"] == -1]
print(len(pricey_bad))
실행 결과 
5
3

노트북에서는 첫 줄의 비교 기호 >가 빈칸 ____이다 — 직접 채운다.

5000원 넘는 주문 5건 중 3건이 "별로예요"(-1)다. 두 번째 줄은 cafe가 아니라 고른 표 pricey에서 다시 고른다. Orange Select Rows에 조건을 두 줄 건 것과 같은 일이다.

주의할 점 & 자주 발생하는 오류

오류 1 — 파일 이름 오타 파일 이름을 한 글자라도 틀리면(아래는 process를 proces로 쓴 경우) FileNotFoundError: [Errno 2] No such file or directory: 'week04_proces_filtering.csv'가 난다. 메시지 끝의 파일 이름을 강의 코드와 한 글자씩 비교한다.
오류 2 — 열 이름 오타 df["온도_c"]처럼 대문자 C를 소문자로 쓰면 KeyError: '온도_c'가 난다. 열 이름은 글자 하나, 대소문자까지 같아야 한다. print(df.columns)로 확인해 그대로 옮긴다.
오류 3 — 여러 열을 대괄호 한 겹으로 df["설비번호", "온도_C", "합격여부"]는 KeyError: ('설비번호', '온도_C', '합격여부')가 난다. 여러 열은 df[["설비번호", "온도_C", "합격여부"]]처럼 두 겹으로 감싼다.
오류 없이 틀리는 경우 골라낸 표에서 한 번 더 고를 때 eq02[...] 대신 df[...]를 쓰면 오류 없이 전체 불합격 수가 나온다. eq01·eq02·df처럼 이름이 비슷하니, 두 번째 줄의 표 이름이 첫 줄에서 만든 이름과 같은지 본다. 합격여부는 숫자라 == -1처럼 따옴표 없이 쓴다. == "-1"로 쓰면 오류 없이 0건이 나온다(설비번호 "EQ-02"는 글자라 따옴표를 붙인다). 노트북의 ____를 채우지 않고 실행하면 NameError: name '____' is not defined가 난다 — 빈칸을 아직 안 채웠다는 뜻이다.

for name in ["산화", "포토", "식각", "증착", "세정"]:
    part = df[df["공정명"] == name]
    part_fail = part[part["합격여부"] == -1]
    print(f"{name}: 기록 {len(part)}건, 불합격 {len(part_fail)}건")
실행 결과 
산화: 기록 23건, 불합격 1건
포토: 기록 20건, 불합격 3건
식각: 기록 15건, 불합격 2건
증착: 기록 24건, 불합격 4건
세정: 기록 18건, 불합격 3건

불합격 1 + 3 + 2 + 4 + 3 = 13건으로 전체와 같다. 기록 수도 더하면 100건이다.

AI 코드를 다룰 때 직접 실행해 숫자를 확인하고, 합계처럼 이미 아는 값과 맞춰 본다. 회사의 실제 데이터는 AI에 붙여 넣지 않는다.

핵심 질문 → 데이터 연결

  • 질문: 3차시에 반복문으로 한 줄씩 처리했던 일을, Pandas는 어떻게 한 번에 처리할까?
