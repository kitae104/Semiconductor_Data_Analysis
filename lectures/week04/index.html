Pandas 가장 기본적인 부분

오늘의 질문: "3차시에 반복문으로 한 줄씩 처리했던 일을, Pandas는 어떻게 한 번에 처리할까?"

week04_process_filtering.csv (가상)
크기
100행 × 8열
설비
EQ-01 ~ EQ-04
전체 불합격
13건 (13.0%)
EQ-02 불합격
5건 / 25건

오늘의 학습 목표

  • CSV 파일을 read_csv로 읽어 표(DataFrame)로 만들고, head·shape·columns로 생김새를 확인할 수 있다.
  • 필요한 열만 꺼내 볼 수 있다. 열 하나는 df["열"], 여러 개는 df[["열1", "열2"]].
  • 조건 검색으로 특정 설비·불합격 기록만 골라내고, 건수와 비율로 설비끼리 비교할 수 있다.
  • sort_values로 값이 큰 순서·작은 순서로 줄 세울 수 있다.

선수 지식: 1차시 — 표의 행과 열, 2차시 — 딕셔너리의 리스트, 3차시 — for+if. loc은 오늘 "맛보기"만 한다(값을 고칠 때도 쓸 수 있다 — 5차시에서 잠깐 다시 본다).

왜 이걸 배워야 할까?

  • 1차시에는 40줄짜리 표를 강사가 눈으로 세어 "불합격 8건"이라고 알려줬다. 오늘 표는 100줄이고, 실제 공장은 하루에도 수십만 줄이 쌓인다. 눈으로 세는 방법은 곧 한계가 온다.
  • Pandas(판다스)는 파이썬 안에서 표를 다루는 전용 도구다. 1차시에 말한 "공구함 속 표 전용 공구"가 바로 이것이다. 엑셀처럼 표를 다루지만, 한 번 써 둔 코드는 100줄이든 10만 줄이든 그대로 다시 쓸 수 있다.
  • 무엇보다 표를 나눠서 볼 수 있다. 전체를 한 덩어리로 볼 때는 안 보이던 것이, 특정 설비만 따로 떼어 보면 보인다.
예를 들면 — 오늘 데이터에서 실제로 나온 숫자
  • 100건 전체로 보면 불합격은 13건(13.0%)이다. 이 숫자 하나로는 "그럭저럭 괜찮네"로 끝나기 쉽다.
  • 설비별로 따로 떼어 보면 이야기가 달라진다. EQ-04는 22건 중 5건(22.7%), EQ-02는 25건 중 5건(20.0%)이 불합격인데, EQ-03은 22건 중 1건(4.5%)뿐이다. 같은 공장 안에서 약 다섯 배 차이가 난다(기록이 적어 우연일 수도 있다 — 뒤에서 다시 본다).
  • 학교 전체 평균은 괜찮은데 반별로 나눠 보니 한 반만 점수가 낮은 것과 같다. 오늘 배우는 조건 검색이 이렇게 "따로 떼어 보는" 도구다.

STEP 01

CSV와 DataFrame — 1차시의 그 표를 파이썬으로 읽기

  • CSV는 표의 칸을 쉼표(,)로 구분해 저장한 파일이다(1차시). 엑셀로도 열린다.
  • Pandas의 read_csv()로 CSV를 읽으면 DataFrame(데이터프레임)이라는 표가 된다. 1차시에 눈으로 본 그 표를 파이썬이 읽어 들고 있는 것이다.
  • DataFrame은 보통 df라는 짧은 이름의 변수에 담는다(1차시의 변수와 같다).
Python — 데이터 읽기
import pandas as pd

df = pd.read_csv("../../data/weekly/week04/week04_process_filtering.csv", encoding="utf-8-sig")
df.head()
  • 경로의 ../는 "한 단계 위 폴더"라는 뜻이다. 노트북이 있는 notebooks/student/에서 두 단계 위로 올라가 data 폴더를 찾아간다.
  • import pandas as pd — Pandas 공구를 꺼내 pd라는 짧은 이름으로 부르겠다는 뜻. 매 노트북 맨 위에 한 번 쓴다.
  • 괄호 안 첫 번째는 파일 위치(경로), encoding="utf-8-sig"는 한글을 읽는 방식이다. 이 과정의 CSV는 모두 이렇게 저장돼 있으니 그대로 따라 쓴다.
  • df.head()는 표의 맨 앞 5행만 보여준다. 표를 처음 열면 습관처럼 먼저 실행한다.

DataFrame은 "딕셔너리의 리스트"와 같은 모양

행 하나는 2차시에 만든 딕셔너리 하나, 열 이름은 딕셔너리의 키, 표 전체는 딕셔너리들을 담은 리스트다. 차이는 Pandas가 이것을 표 모양으로 보여주고, 표 전체에 한 번에 명령을 내릴 수 있게 해 준다는 점이다.

표의 크기와 열 이름 확인하기

Python — 기본 정보 확인
print(df.shape)
print(df.columns)
실행 결과

  • df.shape — (행 개수, 열 개수). 기록 100건, 항목 8개라는 뜻이다.

  • 둘 다 뒤에 괄호 ()를 붙이지 않는다. head()는 "해 줘"라는 명령이라 괄호가 있고, shape·columns는 표가 원래 가진 정보라 괄호가 없다.
  • Pandas 버전에 따라 마지막 dtype='str'이 dtype='object'로 보일 수 있다. 둘 다 정상이다.

STEP 02

조건 검색 — 원하는 행만 골라내기

열 선택이 "세로줄 고르기"라면, 조건 검색은 "가로줄(행) 고르기"다. "설비번호가 EQ-02인 기록만", "불합격인 기록만"처럼 조건에 맞는 행만 남긴다. 정식 이름은 불리언 인덱싱(Boolean Indexing)이다. 불리언은 1차시에 배운 True/False다.

비유 — 엑셀 필터 엑셀에서 설비번호 열의 필터 단추를 눌러 "EQ-02"에만 체크하면 EQ-02 행만 남는다. 조건 검색이 바로 그 일이다. 차이는 두 가지다. 코드로 남아 있어 언제든 다시 실행할 수 있고, 데이터가 10만 줄이어도 같은 한 줄이면 된다.

1단계 — 행마다 체크 표시(True/False) 붙이기

Python — 조건식의 결과 보기
check = df["설비번호"] == "EQ-02"
print(check.head())
실행 결과 
0     True
1    False
2     True
3     True
4    False
Name: 설비번호, dtype: bool
  • ==는 "같은가?"를 묻는 비교다(3차시). 표 전체 100행에 한꺼번에 물어보고, 행마다 True(맞다) 또는 False(아니다)를 붙인다.
  • 위 head() 결과의 0·2·3번 행이 EQ-02라서 True, 1·4번 행은 EQ-04·EQ-01이라 False다.

2단계 — True인 행만 남기기

Python — 특정 설비만 찾기
eq02 = df[df["설비번호"] == "EQ-02"]
print(eq02.shape)
실행 결과 
(25, 8)

안쪽 df["설비번호"] == "EQ-02"가 체크 표시 목록을 만들고, 바깥 df[ ]가 True인 행만 남긴다. 위에서 만든 check를 넣어 df[check]라고 써도 결과는 같다. 100행이 EQ-02 기록 25행으로 줄었다.

조건 검색은 두 단계다. ① 모든 행에 True/False 체크 표시를 붙이고, ② 체크(True)된 행만 줄 세워 새 표로 만든다. 그림은 앞 5행만 보여준 것이고, 실제로는 100행 전체에 같은 일이 한 번에 일어난다.

주의 — 원본은 그대로다 df[조건]의 결과는 새 표다. eq02 = ...처럼 변수에 저장해야 다시 쓸 수 있고, 원래 df(100행)는 바뀌지 않는다.

3차시 for+if와 비교하기

3차시 방식 — 한 줄씩 직접 확인오늘 방식 — 표 전체에 한 번에
hot_equipment = []
for eq in equipment_list:
    if eq["온도_섭씨"] > 305:
        hot_equipment.append(eq["설비번호"])
 
hot = df[df["온도_섭씨"] > 305]
Python — 온도가 305도를 넘는 기록
hot = df[df["온도_섭씨"] > 305]
print(len(hot))
실행 결과 
13

Pandas가 속으로는 3차시처럼 100행을 하나씩 확인하지만, 우리는 그 반복을 쓰지 않아도 된다. "100개의 if문을 한 줄로" 실행하는 셈이다. 표의 행 개수는 2차시에 배운 len()으로 센다.

불합격 기록만 골라내기

오늘 데이터의 합격여부 열은 1 = 합격, -1 = 불합격이다(0이 아니다).

Python — 불합격만 찾기
fail = df[df["합격여부"] == -1]
print(fail.shape)
실행 결과 
(13, 8)

고온 기록과 불합격 기록은 같은 기록일까

공교롭게도 고온(305도 초과) 기록도 13건, 불합격 기록도 13건이다. 같은 13건일까? 고온 기록 hot 안에서 불합격만 다시 골라 보자. 조건 검색은 이미 골라낸 표에 한 번 더 할 수 있다.

Python — 골라낸 표에서 한 번 더 고르기
hot_fail = hot[hot["합격여부"] == -1]
print(len(hot_fail))
실행 결과 
3
숫자가 같다고 같은 기록은 아니다 고온 13건 중 불합격은 3건뿐이다. 거꾸로 말하면 불합격 13건 중 10건은 온도가 305도 이하였다. "온도가 높으면 불합격"이라는 짐작은 이 데이터에서는 잘 맞지 않는다. 1차시에 "온도 하나만으로는 불합격 대부분이 설명되지 않는다"고 한 것과 같은 이야기다. 열 하나의 숫자만 보지 말고, 골라낸 기록을 다른 열과 함께 확인하는 습관이 필요한 이유다.

정렬 — 값의 크기 순서로 줄 세우기

키 순서대로 줄을 서듯, 한 열의 값 크기 순서로 행을 다시 늘어놓는 것이 정렬이다. "가장 뜨거웠던 기록은?"처럼 극단의 값을 찾을 때 쓴다.

Python — 온도가 높은 순서로 상위 5건
df.sort_values("온도_섭씨", ascending=False).head(5)

  • !=는 "같지 않다"를 묻는 비교다. df[df["설비번호"] != "EQ-02"]는 EQ-02를 뺀 나머지 기록을 고른다.
  • 그 안에서 불합격률을 구해 EQ-02(20.0%)와 비교해 보자. 종합 실습 코드와 같은 모양이다.
  • 노트북 8단계 끝의 "도전 문제 1" 셀에서 푼다.
도전 문제 2 — 온도가 가장 낮은 5건
  • df.sort_values("온도_섭씨").head(5)로 온도가 가장 낮은 5건을 고른다(ascending을 빼면 작은 값부터).
  • 그 5건은 어느 설비의 기록인가? 불합격은 몇 건인가? 설비번호·온도·합격여부 세 열을 함께 꺼내 확인하자.
  • 노트북 8단계 끝의 "도전 문제 2" 셀에서 푼다.

결과 정리 & 퀴즈

더 많은 문제는 실습지에 있다.

Q1. (객관식) CSV 파일을 읽어 DataFrame으로 만드는 명령은?
  • A. pd.open_csv()
  • B. pd.read_csv()
  • C. pd.load_csv()
  • D. print(csv)
정답: B. pd.read_csv("경로", encoding="utf-8-sig")로 읽는다.
Q2. (객관식) 설비번호와 온도_섭씨 두 열을 함께 꺼내는 올바른 코드는?
  • A. df["설비번호", "온도_섭씨"]
  • B. df[["설비번호", "온도_섭씨"]]
  • C. df("설비번호", "온도_섭씨")
정답: B. 여러 열은 열 이름 리스트를 넣어 대괄호가 두 겹이 된다. A는 KeyError가 난다.
Q3. (결과 예측) 오늘 데이터의 0~4번 행 설비번호는 EQ-02, EQ-04, EQ-02, EQ-02, EQ-01이다. df["설비번호"] == "EQ-02"의 앞 5개 결과는?
정답: True, False, True, True, False. 조건에 맞는 행에 True, 아닌 행에 False 체크 표시가 붙는다.
Q4. (참/거짓) df.sort_values("온도_섭씨")는 온도가 높은 기록부터 보여준다.
정답: 거짓. 기본은 작은 값부터(오름차순)다. 큰 값부터 보려면 ascending=False를 쓴다.
Q5. (참/거짓) EQ-02와 EQ-04는 불합격이 똑같이 5건이므로 불합격률도 같다.
정답: 거짓. 전체 기록 수가 다르다. EQ-02는 25건 중 5건(20.0%), EQ-04는 22건 중 5건(22.7%)이다.
Q6. (서술) 전체 불합격률(13.0%)만 볼 때와 설비별로 따로 떼어 볼 때, 무엇이 달라졌는지 한두 문장으로 설명해 보자.
예시 답안: "전체로는 100건 중 13건(13.0%)이 불합격이라 평범해 보였지만, 설비별로 떼어 보니 EQ-04(22.7%)와 EQ-02(20.0%)가 EQ-03(4.5%)·EQ-01(6.5%)보다 훨씬 높았다. 다만 기록이 적어 원인이라고 단정할 수는 없고, 원인 후보로 더 살펴볼 만하다."

AI로 한 걸음 더 — 질문하고 코드 받아보기

질문해보기 — 하나 이상 골라서 (노트북 9단계)
  • "pandas의 df[조건]이 엑셀의 필터와 어떻게 비슷하고 어떻게 다른지 초보자에게 설명해주세요."
  • "pandas에서 여러 열을 고를 때 왜 대괄호를 두 겹 [[ ]] 써야 하나요?"
  • "pandas의 DataFrame과 Series는 어떻게 다른가요? 엑셀에 비유해 주세요."
AI에게 물어보기 — 복사해서 AI 챗봇에 붙여넣기
df라는 이름의 pandas DataFrame이 이미 있어. 설비번호 열과 합격여부 열(1=합격, -1=불합격)로 설비별 합격/불합격 건수를 한 번에 표로 보여주는 코드를 만들어줘. df를 새로 만들지 말고 그대로 써줘.

이렇게 확인해보자: 결과표의 숫자가 위 "설비별로 따로 떼어 보면" 표(EQ-02 불합격 5건, 합격 20건 등)와 같은지 맞춰 보자.

Python — AI가 만들어줄 수 있는 코드 예시 (노트북 10단계)
summary = pd.crosstab(df["설비번호"], df["합격여부"])
print(summary)
실행 결과

설비번호
EQ-01   2  29
EQ-02   5  20

AI 코드를 다룰 때 꼭 지킬 점
  • pd.crosstab()은 오늘 배우지 않은 함수다. 구경만 하자. 7차시에 설비별로 묶어 세는 방법을 배운다. 지금은 "-1 열이 불합격 건수, 1 열이 합격 건수"라고 읽을 수 있으면 충분하다.
  • AI 코드에 df = pd.DataFrame(...) 줄이 있으면 1단계에서 읽은 100행 데이터가 예시 데이터로 덮어써진다. 그러면 연습문제에서 KeyError: '공정명'이 난다. 그 줄을 지우고 실행하거나, 이미 덮어썼다면 1단계 셀을 다시 실행한다.
  • AI가 만든 코드는 직접 실행해서 결과를 확인한다. AI의 답도 틀릴 수 있다.

연습문제 — 세정 공정만 골라 살펴보기

이번에는 설비가 아니라 공정으로 따로 떼어 보자. 공정명이 세정인 기록만 골라 건수와 불합격률을 구한다.

직접 해보기 (노트북 11단계)
  • cleaning에 세정 기록만 골라 담고 shape를 확인한다.
  • cleaning 안에서 불합격만 골라 cleaning_fail에 담고, 불합격률을 :.1f로 출력한다. 종합 실습 코드와 같은 모양이다.
cleaning = df[df["공정명"] == "세정"]
print(cleaning.shape)

cleaning_fail = cleaning[cleaning["합격여부"] == -1]
cleaning_rate = len(cleaning_fail) / len(cleaning) * 100
print(f"세정 {len(cleaning)}건 중 불합격 {len(cleaning_fail)}건 ({cleaning_rate:.1f}%)")
실행 결과: (18, 8), 세정 18건 중 불합격 3건 (16.7%)

AI로 재미있는 미니 프로그램 만들기 — 나만의 설비 검색기

오늘의 미니 프로젝트 (노트북 12단계) 설비번호를 입력하면 그 설비의 성적표를 보여주는 검색기를 AI에게 만들어 달라고 해 보자. 오늘 배운 조건 검색에 1차시의 input()과 3차시의 if/else를 합친 프로그램이다.
프롬프트 예시 — 그대로 물어보기 "df라는 pandas DataFrame에 설비번호 열과 합격여부 열(1=합격, -1=불합격)이 있어. input()으로 설비번호(예: EQ-02)를 입력받아 그 설비의 기록 건수, 불합격 건수, 불합격률을 한 줄로 출력하고, 없는 설비번호면 안내 문구를 출력하는 코드를 만들어줘. df는 새로 만들지 말고 그대로 써줘."
Python — AI가 만들어줄 수 있는 코드 예시
target = "EQ-02"  # 실제로는 input("검색할 설비번호를 입력하세요: ")

matched = df[df["설비번호"] == target]
if len(matched) > 0:
    matched_fail = matched[matched["합격여부"] == -1]
    rate = len(matched_fail) / len(matched) * 100
    print(f"[{target}] 기록 {len(matched)}건, 불합격 {len(matched_fail)}건 ({rate:.1f}%)")
else:
    print(f"{target} 설비 기록을 찾을 수 없습니다.")
실행 결과(입력값: EQ-02) 
[EQ-02] 기록 25건, 불합격 5건 (20.0%)
더 놀아보기
  • 첫 줄을 target = input("검색할 설비번호를 입력하세요: ")로 바꾸고 EQ-01부터 EQ-04까지 차례로 입력해 보자. 위 설비별 표와 같은 숫자가 나오는가?
  • EQ-99처럼 없는 번호나 eq-02처럼 소문자를 넣어 보자. 조건 검색 결과가 0행이라 else 쪽 문장이 나온다.
