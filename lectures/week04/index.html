Pandas 가장 기본적인 부분

💬 오늘의 질문: "3차시에 반복문으로 한 줄씩 처리했던 일을, Pandas는 어떻게 한 번에 처리할까?"

🎯 학습 목표

  • read_csv로 CSV 파일을 DataFrame으로 읽을 수 있다.
  • 원하는 열만 선택해서 볼 수 있다.
  • 조건 검색(불리언 인덱싱)으로 원하는 행만 골라낼 수 있다.
  • 정렬로 값이 높은/낮은 순서를 확인할 수 있다.

선수 지식: 3차시 — 반복문·함수

⏮️ 지난 시간 복습

3차시 연결 3차시에서는 for와 if로 리스트를 하나씩 순회하며 judge_pass 함수로 직접 판정했다. 오늘 배울 Pandas는 "표 전체"를 다루는 도구로, 3차시에 여러 줄로 짰던 반복 작업을 대부분 한 줄로 처리해준다. 딕셔너리의 리스트가 사실 "표(DataFrame)"와 매우 비슷한 모양이라는 것을 오늘 확인한다.

📚 CSV와 DataFrame

CSV(Comma-Separated Values)는 쉼표로 값을 구분한 텍스트 표 파일이다. Pandas의 read_csv()로 읽으면 DataFrame이라는 행·열 구조의 표로 바뀐다.

Python
import pandas as pd

df = pd.read_csv("week04_process_filtering.csv")
df.head()

📚 열 선택 — 원하는 열만 보기

Python
print(df["온도_섭씨"])                 # 열 하나 (Series)
print(df[["온도_섭씨", "압력_Pa"]])      # 열 여러 개 (대괄호 두 번!)
가장 흔한 함정 열을 여러 개 선택할 때는 df["온도_섭씨", "압력_Pa"]처럼 대괄호를 한 번만 쓰면 오류가 난다. df[["온도_섭씨", "압력_Pa"]]처럼 안쪽에 리스트를 한 번 더 감싸야 한다(2차시에서 배운 리스트 [ ]를 대괄호 안에 넣는 것).

📚 조건 검색 — 원하는 행만 골라내기

3차시에서는 for와 if로 조건에 맞는 항목을 하나씩 확인했다. Pandas는 조건식 하나로 표 전체에서 한 번에 골라낸다 — 이를 조건 검색(불리언 인덱싱)이라고 부른다.

Python — 특정 설비만 찾기
eq02 = df[df["설비번호"] == "EQ-02"]
print(eq02.shape)
실행 결과 
(25, 8)
동작 원리 — 2단계로 이해하기
  • df["설비번호"] == "EQ-02": 모든 행에 대해 참/거짓(True/False) 목록을 만든다.
  • df[ 그 True/False 목록 ]: True인 행만 남기고 나머지는 걸러낸다.
Python — 불합격 데이터만 찾기
fail = df[df["합격여부"] == -1]
print(fail.shape)
실행 결과 
(13, 8)
주의 — 원본은 그대로다 df[df["설비번호"] == "EQ-02"]의 결과는 새로운 표다. eq02 = ...처럼 변수에 저장해야 이후에 계속 쓸 수 있고, 원본 df는 전혀 바뀌지 않는다.

📚 종합 — 3차시 함수와 Pandas 비교하기

3차시에서 만든 judge_pass 함수와 for 반복문으로 EQ-02의 불합격 건수를 세려면 여러 줄이 필요했다. Pandas 조건 검색을 조합하면 훨씬 짧아진다.

Python
eq02_fail = eq02[eq02["합격여부"] == -1]
fail_rate = len(eq02_fail) / len(eq02) * 100

print(f"EQ-02 불합격 건수: {len(eq02_fail)}건")
print(f"EQ-02 불합격률: {fail_rate:.1f}%")
실행 결과 
EQ-02 불합격 건수: 5건
EQ-02 불합격률: 20.0%
비교해보기 3차시라면 for eq in equipment_list: if judge_pass(...) == "불합격": count += 1처럼 반복문+조건문+함수를 조합해야 했다. Pandas는 df[조건] 한 줄로 "300개의 if문"을 한 번에 실행하는 셈이다 — 이것이 표 데이터를 다룰 때 Pandas를 쓰는 이유다.

🗂️ 핵심 용어 카드

DataFrame

DataFrame
한 줄 설명
Pandas가 CSV를 읽어 만든 행·열 구조의 표.
쉬운 비유
엑셀 시트, 또는 딕셔너리가 여러 개 담긴 리스트.
데이터에서의 예
df = pd.read_csv(...)
자주 하는 오해
DataFrame이 리스트·딕셔너리와 완전히 다른 개념이라고 생각하기 쉽다. 사실 개념적으로 매우 비슷하다.

열 선택

Column Selection
한 줄 설명
원하는 열(들)만 골라 보는 방법.
쉬운 비유
엑셀에서 특정 세로줄(열)만 눈으로 훑어보는 것.
데이터에서의 예
df[["온도_섭씨", "압력_Pa"]]
자주 하는 오해
여러 열 선택 시 대괄호를 한 번만 쓰는 실수가 흔하다.

조건 검색

Boolean Indexing
한 줄 설명
조건에 맞는 행만 골라내는 방법.
쉬운 비유
3차시의 if를 표 전체에 한 번에 적용하는 것.
데이터에서의 예
df[df["설비번호"] == "EQ-02"]
자주 하는 오해
결과가 원본을 바꾼다고 착각하기 쉽다. 실제로는 새 표가 만들어진다.

정렬

Sort
한 줄 설명
특정 열을 기준으로 행의 순서를 바꾸는 것.
쉬운 비유
키 순서대로 줄을 서는 것.
데이터에서의 예
df.sort_values("온도_섭씨", ascending=False)
자주 하는 오해
기본 정렬이 내림차순이라고 착각하기 쉽다. 기본값은 오름차순이다.

⚠️ 주의할 점 & 자주 발생하는 오류

오류 1 KeyError: '온도' — 열 이름을 정확히 쓰지 않은 경우다(실제 열 이름은 온도_섭씨). df.columns로 정확한 이름을 먼저 확인하자.
오류 2 조건식에서 df[df["설비번호"] = "EQ-02"]처럼 =을 쓰면 SyntaxError가 난다. 비교는 항상 ==다(3차시 복습).
주의 — 대괄호 개수 열 하나는 df["열이름"](대괄호 1개), 열 여러 개는 df[["열1", "열2"]](대괄호 2개, 안쪽이 리스트)다.

🚀 도전 실습

도전 문제 1 df[df["설비번호"] != "EQ-02"]로 EQ-02가 아닌 나머지 설비의 기록만 골라내고, 그 안에서 불합격 비율을 계산해서 EQ-02(20.0%)와 비교해보자.
도전 문제 2 df.sort_values("온도_섭씨")(오름차순)로 온도가 가장 낮았던 하위 5건을 확인해보자. 그 5건 중 불합격은 몇 건인가?

✅ 결과 정리 & 퀴즈

퀴즈는 실습지와 아래 정리 문제로 확인한다.

Q1. (객관식) 온도_섭씨와 압력_Pa 두 열을 함께 선택하는 올바른 코드는?
  • A. df["온도_섭씨", "압력_Pa"]
  • B. df[["온도_섭씨", "압력_Pa"]]
  • C. df.온도_섭씨.압력_Pa
  • D. df("온도_섭씨", "압력_Pa")
정답: B. 여러 열을 선택할 때는 대괄호 안에 리스트(대괄호)를 한 번 더 감싸야 한다.
Q2. (참/거짓) df.sort_values("온도_섭씨")는 기본적으로 온도가 높은 순서(내림차순)로 정렬한다.
정답: 거짓. 기본값은 오름차순이다. 내림차순은 ascending=False를 명시해야 한다.
Q3. (빈칸) 조건에 맞는 행만 골라낼 때, 먼저 True/False 목록을 만드는 부분은 df["합격여부"] ______ -1이다.
정답: ==. 비교 연산자를 써서 각 행이 조건을 만족하는지 True/False로 판단한 뒤, 그 목록으로 원본을 걸러낸다.
Q4. (서술) 3차시의 for+if 방식과 오늘 배운 Pandas 조건 검색의 차이를 한 문장으로 설명해보자.
예시 답안: "3차시에는 반복문으로 값을 하나씩 확인하며 조건을 검사했지만, Pandas는 조건식 한 줄로 표 전체에서 한 번에 원하는 행을 골라낼 수 있다."

📝 과제(다음 차시까지)

아래 과제를 Colab 노트북 한 개에 순서대로 작성하고, 각 결과를 확인할 수 있게 만들어 제출한다.

과제 1 — 설비별 요약 EQ-01, EQ-03, EQ-04에 대해서도 각각 조건 검색으로 행 개수와 불합격 건수를 확인하고, 어느 설비가 가장 불안정해 보이는지 문장으로 정리한다.
과제 2 — 압력 조건 검색 압력_Pa가 1020 이상인 행만 골라내 몇 건인지 확인하고, 그중 불합격 비율도 계산해본다.
과제 3(도전) — 두 조건 동시 검색 df[(df["설비번호"] == "EQ-02") & (df["합격여부"] == -1)]처럼 & 기호로 조건 두 개를 동시에 적용하는 코드를 검색해서 실행해보고, 결과가 무엇을 의미하는지 설명해본다(5차시 결측값 필터링에서 다시 쓰인다).
체크포인트 — & 를 쓸 때는 조건마다 괄호가 필요하다 df[df["설비번호"] == "EQ-02" & df["합격여부"] == -1]처럼 괄호 없이 쓰면 연산 순서가 꼬여 오류가 나거나 잘못된 결과가 나온다. 위 예시처럼 (df["설비번호"] == "EQ-02") & (df["합격여부"] == -1)처럼 각 조건을 반드시 괄호로 감싸야 한다. 그리고 and가 아니라 &를 써야 한다는 점도 함께 기억하자(파이썬의 and는 표 전체에는 쓸 수 없다).
