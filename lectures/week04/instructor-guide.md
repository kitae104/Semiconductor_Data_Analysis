## 왜 이걸 배워야 할까? (학생에게 전달할 메시지)

오늘 표는 100줄, 실제 공장은 하루 수십만 줄이다. Pandas("표 전용 공구")로 열고 고르고 줄 세운다.
전체 불합격은 13.0%지만 설비별로는 EQ-04 22.7%, EQ-02 20.0%, EQ-03 4.5%다. "따로 떼어 보는" 도구가 조건 검색이다(기록이 적어 우연일 수 있다는 말도 함께).

## 수업 흐름

**쉬운 예제로 개념 → 반도체 데이터로 핵심 확인 → 실습지·노트북으로 반도체 실습.**

1. 복습(1차시 표, 2차시 딕셔너리의 리스트, 3차시 `for`+`if`) → 오늘의 질문
2. 카페 열 ↔ 반도체 열 짝 표를 보여주고, 개념은 카페 예제로만 진행한다(노트북 1~8단계와 같은 코드)
   - CSV와 DataFrame → 열 선택(한 겹 `KeyError` 시연) → 조건 검색(체크 표시 그림, 두 번 걸러내기) → 정렬 → loc(`iloc`은 실행만) → 디저트 50.0%
3. 휴식
4. "반도체 데이터로 확인하기" 시연: 열 이름 표 → EQ-02 5건·20.0% → 불합격 5건 여러 열 → EQ-04 22.7%와 설비별 표, "원인 후보"
5. 학생 실습: 실습지 문제 1~11 = 노트북 9~12단계(반도체 데이터, `____` 채우기)
6. AI 활용(노트북 13·14단계) → 퀴즈·과제·예고

## 강사 설명 포인트
- 개념은 카페 예제로만 설명한다. "반도체 데이터로 확인하기"에서 "카페 코드와 어느 글자만 바뀌었나?"를 묻는다(`cafe`→`df`, `"종류"`→`"설비번호"`, `"평가"`→`"합격여부"`).
- `[[ ]]`는 틀린 코드를 먼저 실행해 `KeyError: ('설비번호', '온도_섭씨', '합격여부')`를 보여준 뒤 고친다.
- 조건 검색은 두 단계(체크 표시 → True만 남기기)로 보여준다. 원본은 바뀌지 않는다.
- 실습 중에는 실습지 힌트("강의의 어느 카페 예제와 같은 모양")를 가리키며 돕는다.
- `== -1`을 쓸 때마다 "카페는 -1 = 별로예요, 반도체는 -1 = 불합격"을 말한다.
- 두 조건은 `&` 없이 두 번 걸러낸다. `&`는 8차시.
- loc은 모양(쉼표 앞 행, 뒤 열)만, iloc은 실행만 한다(뒤 차시에서 쓰지 않는다).
- 종합에서 "EQ-04가 원인이다"가 아니라 "EQ-02·EQ-04를 원인 후보로 더 살펴볼 만하다"까지만 말한다.
- 학생이 "EQ-01이 왜 모든 공정을 하나요?"라고 물으면: 가상 데이터라 설비와 공정이 무작위로 짝지어졌다(실제 공장은 정해져 있다).
- **강사만 알 것**: EQ-02에 불합격이 몰리도록 설계했지만 비율은 EQ-04가 더 높게 나왔다(데이터 설명서). "진짜 문제 설비냐"고 물으면 가상 데이터이고 기록이 적어 우연도 섞일 수 있다고 답한다.

## 예상 오개념
- 카페 표와 반도체 표를 같은 이름에 담는다 → `cafe`와 `df`로 나눈다.
- 여러 열을 대괄호 한 겹으로 고른다 → 두 겹 `[[ ]]`.
- 조건식에 `=` 하나를 쓴다 → 비교는 `==`.
- 조건 검색이 원본을 바꾼다고 생각한다 → 결과는 새 표, 변수에 저장한다.
- `sort_values()` 기본이 큰 값부터라고 생각한다 → 기본은 오름차순.
- 불합격 건수가 같으면 비율도 같다고 생각한다 → EQ-02 20.0% vs EQ-04 22.7%.
- 비율이 높은 설비 = 원인이라고 결론 낸다 → 원인 후보일 뿐이다.
- 불합격을 0으로 생각한다 → -1이다.

## 실습 중 오류 대응
- `AttributeError: module 'pandas' has no attribute '____'`: 문제 1 빈칸(`read_csv`)을 채우지 않았다.
- `NameError: name 'df' is not defined`: 9단계 문제 1 셀을 실행하지 않았거나 실패했다. 맨 처음 난 오류부터 본다.
- `NameError: name 'cafe' is not defined` / `name 'pd' is not defined`: 1단계 셀(`import pandas as pd`)을 실행하지 않았다(커널을 다시 시작했다면 1단계부터).
- `NameError: name 'hot' is not defined`: 문제 5 셀을 건너뛰고 문제 6을 실행했다.
- `SyntaxError: invalid syntax`: 비교 기호·대괄호 자리의 `____`를 채우지 않았다. 문제 3②·5처럼 `____` 바로 뒤에 값이 오면 `SyntaxError: invalid syntax. Perhaps you forgot a comma?`로 나온다 — 쉼표를 넣으라는 뜻이 아니라 빈칸을 채우라는 뜻이라고 알려 준다.
- `AttributeError: 'DataFrame' object has no attribute '____'`: `print(df.____)`, `df.____[0, "온도_섭씨"]` 빈칸을 채우지 않았다.
- `NameError: name '____' is not defined`: `hot_fail = ____[...]`, `df[____]` 빈칸을 채우지 않았다.
- `FileNotFoundError: [Errno 2] No such file or directory: 'week04_process_filtering.csv'`: 경로를 줄여 썼다. 강의 경로를 그대로 복사한다.
- `KeyError: '온도'`: 열 이름 오타(`온도_섭씨`).
- `KeyError: '가격_원'`: 카페 열 이름을 `df`에 썼다. 표 이름과 열 이름을 짝 맞춘다.
- `KeyError: ('설비번호', '온도_섭씨', '합격여부')`: 대괄호 한 겹.
- `SyntaxError: cannot assign to subscript here. Maybe you meant '==' instead of '='?`: 조건식에 `=` 하나.
- `TypeError: 'tuple' object is not callable`: `df.shape()`.
- `NameError: name 'false' is not defined`: `False`는 대문자로 시작한다.
- 오류 없이 `(0, 8)`: `"eq-02"`처럼 철자가 데이터와 다르다.
- 14단계 AI 코드 실행 후 숫자가 강의와 다름: `df = pd.DataFrame(...)` 줄이 데이터를 덮어썼다. 지우고 문제 1 셀을 다시 실행한다.
