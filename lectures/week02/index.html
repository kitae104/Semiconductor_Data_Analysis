2차시

리스트와 딕셔너리

오늘의 질문: "여러 개의 측정값을 한 번에 담고, 각 값에 이름표까지 붙이려면 어떻게 해야 할까?"

오늘의 미션 — 팀장이 EQ-03 설비 온도 7개를 메모로 줬다. 최고·최저·평균을 정리해 보고하자. 가장 높은 온도와 가장 낮은 온도는 몇 도이고, 평균은 몇 도일까?

「신입 데이터 담당자의 10일」 둘째 날. 이야기 속 공장과 기록은 모두 교육용 가상 데이터다.

오늘 마지막에 Orange로 보게 될 표. 같은 설비의 기록끼리 모여 있다. EQ-03의 최고·최저·평균은 PART 1 노트북 7단계에서 직접 구한다.

오늘의 학습 목표

  • 여러 값을 리스트에 담고, 인덱스(칸 번호)로 값을 꺼낼 수 있다.
  • len()으로 개수를 세고 append()로 값을 더할 수 있다.
  • max()·min()·sum()으로 최고·최저·평균을 구할 수 있다.
  • 딕셔너리로 값에 이름표를 붙이고 키로 꺼낼 수 있다. Orange Column Statistics로 한 열의 평균·최고·최저를 읽을 수 있다.

왜 이걸 배워야 할까?

  • 설비는 온도를 한 번만 재지 않는다. 같은 설비가 같은 작업을 해도 잴 때마다 값이 조금씩 다르다. 1차시처럼 상자 하나에 값 하나를 담으면 상자가 끝없이 늘어난다.
  • 리스트는 여러 값을 한 줄로 담고, 딕셔너리는 값마다 이름표를 붙인다. 이 둘이 4차시에 배우는 "표"의 재료다.

리스트 — 번호 붙은 칸에 여러 값 담기

  • 리스트: 대괄호 [ ] 안에 값을 쉼표로 늘어놓은 묶음. 칸마다 번호가 붙은 약통과 같다.
  • 인덱스: 칸 번호. 리스트[번호]로 값 하나를 꺼낸다. 번호는 0부터 센다. -1은 마지막 칸이다.
Python — 쉬운 예제: 일주일 기온 (노트북 1단계)
week_temps = [21.5, 23.0, 30.5, 24.0, 22.5, 25.0, 23.5]   # 월~일 낮 기온
print(week_temps)

print(week_temps[0])    # 첫 번째 값(월요일)
print(week_temps[2])    # 세 번째 값(수요일)
print(week_temps[-1])   # 마지막 값(일요일)
실행 결과 
[21.5, 23.0, 30.5, 24.0, 22.5, 25.0, 23.5]
21.5
30.5
23.5

노트북에서는 위 코드가 셀 두 개로 나뉘어 있다(리스트 만들기 / 꺼내기). # 뒤의 글은 주석이라 실행되지 않는다.

첫 칸(월요일)의 번호는 1이 아니라 0이다. 칸이 7개면 번호는 0~6번이다. 칸 위의 음수는 뒤에서부터 센 번호로, 마지막 칸이 [-1]이다.

구경만 — 슬라이싱 week_temps[0:5]처럼 쓰면 0번 칸부터 4번 칸까지(5번 칸은 빠진다) 여러 칸을 한 번에 꺼낸다. 결과는 [21.5, 23.0, 30.5, 24.0, 22.5](평일 기온)다. 오늘 실습에는 쓰지 않는다.

개수 세고 값 더하기 — len(), append()

print(), type()처럼 이름 뒤에 괄호를 붙여 일을 시키는 것을 함수라고 한다. 괄호 안에 일감(값이나 리스트)을 넣는다. 노트북의 "함수 이름을 채우세요"는 괄호 앞 이름을 쓰라는 뜻이다.

  • len(리스트): 리스트에 값이 몇 개 있는지 센다. len은 length(길이)의 줄임말이다.
  • 리스트.append(값): 리스트 맨 뒤에 값을 하나 더한다. 장바구니에 물건 하나를 더 담는 것과 같다.
Python — 쉬운 예제: 장바구니 (노트북 2단계)
cart = ["우유", "빵", "계란"]
print(len(cart))

cart.append("사과")
print(cart)
print(len(cart))
실행 결과 
3
['우유', '빵', '계란', '사과']
4

글자 값도 리스트에 담을 수 있다. append()는 리스트 이름 뒤에 점(.)을 찍고 쓴다.

주의 — append 셀을 다시 실행하면 노트북에서 cart.append("사과") 셀을 한 번 더 실행하면 사과가 또 들어가 5개가 된다(오류는 나지 않는다). 처음 상태로 돌리려면 위 셀 cart = [...]부터 다시 실행한다.

최고·최저·평균 구하기 — max(), min(), sum()

  • max() = 가장 큰 값, min() = 가장 작은 값, sum() = 모두 더한 값.
  • 평균 = 합계 ÷ 개수 = sum(리스트) / len(리스트).
Python — 쉬운 예제: 일주일 기온 요약 (노트북 3단계)
print(max(week_temps))
print(min(week_temps))
print(sum(week_temps))

average = round(sum(week_temps) / len(week_temps), 1)
print(f"이번 주 평균 기온은 {average}도입니다.")
실행 결과 
30.5
21.5
170.0
이번 주 평균 기온은 24.3도입니다.
  • round(값, 1)은 소수 첫째 자리까지 반올림한다. 170.0 ÷ 7 = 24.28…이 24.3이 된다.
  • 평균 24.3도만 보면 수요일의 30.5도가 안 보인다. 그래서 최고·최저를 함께 본다.

딕셔너리 — 이름표로 찾는 사물함

  • 리스트 ["지민", 15, 3]은 "2번 칸이 반이었지?"를 외워야 한다. 딕셔너리는 칸 번호 대신 이름표(키)로 값을 찾는다. 이름표 붙은 사물함과 같다.
  • 중괄호 { } 안에 "이름표": 값을 쌍으로 적는다. 꺼낼 때는 딕셔너리["이름표"]처럼 대괄호에 키를 쓴다.
Python — 쉬운 예제: 학생 한 명의 정보 (노트북 4단계)
student = {
    "이름": "지민",
    "나이": 15,
    "반": 3,
}
print(student)

print(student["이름"])
print(student["반"])
# print(student["혈액형"])   # 없는 이름표 → KeyError
실행 결과 
{'이름': '지민', '나이': 15, '반': 3}
지민
3

PART 2 Orange3 — 한 열을 숫자로 요약하기

파이썬에서는 max()·min()·sum()을 하나씩 썼다. Orange의 Column Statistics는 표의 모든 숫자 열에 대해 평균·최고·최저를 한 화면에 보여 준다.

위젯 이름표

위젯(화면 이름)어느 묶음에 있나한국어 뜻오늘 하는 일
Column StatisticsData열 통계오늘 새 위젯. 열마다 Mean(평균)·Min.(최저)·Max.(최고)·Missing(빈칸 수)을 한 줄로 본다
Column Statistics 읽는 법
  • 한 행 = 열 하나. 오늘 읽는 칸은 Mean(평균), Min.(최저), Max.(최고)다.
  • Mode는 "가장 흔한 값"이다. 오늘 표는 같은 숫자가 한 번씩만 나와서 Mode 칸에 가장 작은 값이 보인다. 최고·최저는 Mode가 아니라 Max.·Min. 칸에서 읽는다.
  • 그 밖에 Distribution(열마다 작은 막대 그림), Median(크기 순으로 줄 세웠을 때 가운데 값), Dispersion(퍼짐 정도) 칸도 보이지만 오늘은 읽지 않는다.
  • 노선·시간대·설비번호 같은 글자 열도 한 행씩 나온다. 글자는 평균을 낼 수 없어서 Mean 칸이 비어 있다. 화면이 잘못된 것이 아니다.
Data Table 정렬 열 이름(열 머리)을 한 번 누르면 작은 값부터, 두 번 누르면 큰 값부터 정렬된다. Data Table 뒤에는 다른 위젯을 잇지 않는다. 위젯은 모두 File에서 갈래로 잇는다.

워밍업 — 지하철 역별 승하차

가상 도시의 지하철 두 노선, 역 8개에서 하루 세 시간대(출근·낮·퇴근)에 타고 내린 사람 수를 센 기록이다(24행, 교육용 가상 데이터). 열은 역이름, 노선, 시간대, 승차인원_count, 하차인원_count다. _count = 센 사람 수(명).

주의할 점 & 자주 발생하는 오류

오류 1 — 없는 칸 번호를 꺼낼 때 칸이 7개인 week_temps에서 week_temps[7]을 쓰면 IndexError: list index out of range가 난다. 번호는 0~6번까지다. 마지막 값은 [-1]로 꺼낸다.
오류 2 — 없는 이름표를 꺼낼 때 student["혈액형"]처럼 없는 키를 쓰면 KeyError: '혈액형'이 난다. 오타나 띄어쓰기 하나만 달라도 같은 오류다. print(student)로 키를 먼저 확인한다.
오류 3 — 대괄호와 중괄호를 바꿔 쓸 때 딕셔너리를 student = ["이름": "지민"]처럼 대괄호로 만들면 SyntaxError: invalid syntax가 난다. 리스트는 [ ], 딕셔너리는 { }로 만든다. 꺼낼 때는 둘 다 [ ]를 쓴다.
주의 — 오류 없이 틀린 숫자가 나올 때 이름이 비슷한 리스트를 바꿔 쓰면 오류 없이 다른 설비의 숫자가 나온다. eq02_temps(확인 1)와 eq03_temps(실습)는 서로 다른 상자다. 결과를 보기 전에 변수 이름부터 확인한다.

결과 정리 & 퀴즈

오늘의 반도체 이해 포인트
  • 같은 설비·같은 작업이라도 측정값은 매번 조금씩 다르다. 그래서 값 하나가 아니라 최고·최저·평균으로 요약해 본다.
  • 공장에는 설비(기계)가 여러 대 있다(오늘 표에는 EQ-01~EQ-04). 그래서 기록마다 설비번호를 붙여 어느 기계의 기록인지 구분한다.
  • 파이썬: 여러 값을 리스트에 담아 len()·max()·min()·sum()으로 요약하고, 딕셔너리로 이름표를 붙였다. EQ-02 온도 4개는 최고 305.6 · 최저 298.8 · 평균 301.7이었다.
  • Orange: Column Statistics로 열 전체의 Mean·Min.·Max.를 한 번에 읽었다. 지하철 승차인원은 Max(9872)가 Mean(2876.58)보다 훨씬 커서, 평균만으로는 붐비는 한 곳이 안 보였다.
  • 미션(EQ-03)의 답은 실습지에서 직접 구한다.

나머지 문항은 실습지와 수업 뒤 퀴즈로 복습한다.

Q1. (결과 예측) week_temps = [21.5, 23.0, 30.5, 24.0, 22.5, 25.0, 23.5]일 때 print(week_temps[1])의 출력은?
정답: 23.0. 인덱스는 0부터 세므로 [1]은 두 번째 값(화요일)이다.
Q2. (객관식) 딕셔너리 student에 없는 키로 student["혈액형"]을 실행하면?
  • A. IndexError
  • B. KeyError
  • C. 빈칸이 출력된다
  • D. SyntaxError
정답: B. 없는 이름표를 꺼내면 KeyError: '혈액형'이 난다. IndexError는 리스트에서 없는 칸 번호를 쓸 때 난다.

파이썬 리스트 eq03_temps = [303.8, 303.4, 292.2, 308.5, 307.5, 298.5, 304.0]에서 295 이상 305 이하 범위를 벗어난 값만 골라 개수와 함께 출력하는 짧은 코드를 만들어 줘.

아래는 받은 코드의 예시다. for와 if는 3차시에 배운다. 지금은 실행해서 결과만 확인한다. 295~305는 이 과정에서 쓰는 연습용 기준이다.

Python — AI가 만든 코드 예시
eq03_temps = [303.8, 303.4, 292.2, 308.5, 307.5, 298.5, 304.0]

out_of_range = []
for t in eq03_temps:
    if t < 295 or t > 305:
        out_of_range.append(t)

print(f"범위 밖 온도: {out_of_range}")
print(f"범위 밖 개수: {len(out_of_range)}개")

노트북 7단계를 마친 뒤 실행하고, 결과는 아래 버튼으로 확인한다(EQ-03의 최저·최고가 들어 있다).

실행 결과 
범위 밖 온도: [292.2, 308.5, 307.5]
범위 밖 개수: 3개
AI 코드를 다룰 때 AI가 준 코드와 숫자는 직접 실행해서 확인한다. 오늘 배운 append()와 len()이 코드 안에 들어 있다. 빈 리스트 []를 만들고 조건에 맞는 값만 하나씩 더했다.
