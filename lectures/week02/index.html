파이썬과 데이터 분석의 기본

💬 오늘의 질문: "숫자 여러 개를 어떻게 하나의 요약값으로 만들 수 있을까?"

🎯 학습 목표

  • 변수(variable)와 리스트(list)가 무엇인지 설명하고 직접 만들 수 있다.
  • 함수(function)가 무엇이고 왜 사용하는지 이해한다.
  • 여러 개의 온도 값으로 평균·최댓값·최솟값을 직접 계산할 수 있다.
  • 정상범위(295~305℃)를 벗어난 값이 있는지 조건문으로 확인할 수 있다.
  • 합격/불합격 데이터를 바탕으로 수율(%)을 직접 계산할 수 있다.

⏮️ 지난 시간 복습

1주차 복습 지난주에는 반도체·웨이퍼·칩의 차이, FAB과 공정·설비·센서의 의미를 배우고, Colab에서 pandas로 CSV를 열어 head(), shape, columns, value_counts()로 데이터를 처음 조회해 보았다. 또한 이 과정에서는 합격여부 열의 값이 1이면 합격, -1이면 불합격이라는 규칙도 확인했다.

오늘은 그 value_counts() 같은 Pandas 함수 "안에서" 실제로 어떤 계산이 일어나는지 파이썬 기본 문법(변수·리스트·함수)으로 직접 손으로 계산해본다. 이렇게 계산 원리를 이해해두면 이후 주차에서 Pandas 함수가 왜 그런 결과를 주는지 더 잘 이해할 수 있다.

📊 데이터 분석 개념 이해하기

변수(Variable) — 값을 담는 이름표

변수는 숫자나 문자 같은 값을 저장해두고 나중에 다시 쓸 수 있게 이름을 붙인 상자다. 예를 들어 temp1 = 302.7이라고 쓰면, temp1이라는 이름의 상자에 302.7이라는 값을 저장한 것이다.

숫자와 문자열 — 값의 종류(자료형)

파이썬은 값의 종류(자료형)를 구분한다. 302.7처럼 소수점이 있는 숫자는 실수(float), 25처럼 소수점이 없는 숫자는 정수(int), "증착"처럼 따옴표로 감싼 글자는 문자열(str)이라고 부른다. 자료형에 따라 할 수 있는 계산이 다르다(숫자끼리는 더할 수 있지만, 숫자와 문자열은 그냥 더할 수 없다).

개념 type(temp1)을 실행하면 변수에 담긴 값의 자료형을 확인할 수 있다.

리스트(List) — 여러 값을 한 번에 담는 상자

변수 하나에는 값을 하나만 담을 수 있지만, 리스트를 쓰면 여러 개의 값을 순서대로 한 번에 담을 수 있다. temps = [302.7, 300.1, 292.0]처럼 대괄호 [] 안에 값을 쉼표로 나열하면 리스트가 된다.

함수(Function) — 반복 작업에 이름을 붙인 것

함수는 자주 하는 계산을 미리 만들어두고 이름으로 불러 쓰는 도구다. sum(temps)는 "리스트 안 숫자를 모두 더하라"는 계산을, len(temps)는 "리스트 안에 값이 몇 개 있는지 세라"는 계산을 대신 해준다. 매번 더하기 계산을 직접 풀어 쓰지 않아도 되므로 편리하다.

평균과 최댓값·최솟값 — 여러 숫자를 하나의 요약값으로

측정값이 여러 개일 때, 그 값들을 대표하는 요약값을 구하면 전체 상황을 한눈에 파악할 수 있다.

  • 평균(average) = 모든 값의 합 ÷ 개수 → 파이썬에서는 sum(리스트) / len(리스트)
  • 최댓값(max) = 값 중 가장 큰 것 → max(리스트)
  • 최솟값(min) = 값 중 가장 작은 것 → min(리스트)

왜 계산이 필요한가 — 공정 데이터와 연결

공정 온도를 25번 측정했다면, 25개의 숫자를 하나하나 눈으로 보는 것보다 "평균 몇 도였는지", "가장 높았던 온도는 몇 도였는지"를 계산해서 보는 것이 훨씬 빠르게 상태를 판단할 수 있게 해준다. 오늘 배우는 평균·최댓값·최솟값·수율 계산은 앞으로 10주 내내 반복해서 쓰이는 가장 기본적인 도구다.

👩‍🏫 강사 코드 시연

Python — Colab / Jupyter
# 1. 온도 변수 하나 만들기 (첫 번째 측정값)
temp1 = 302.7
print(temp1, type(temp1))

# 2. 여러 온도를 리스트에 저장하기 (앞의 6개 측정값)
temps = [302.7, 300.1, 292.0, 299.0, 291.9, 303.5]
print(temps)
print("측정 개수:", len(temps))

# 3. 평균/최댓값/최솟값 계산하기 (순수 파이썬)
average = sum(temps) / len(temps)
maximum = max(temps)
minimum = min(temps)
print("평균:", round(average, 1), "최댓값:", maximum, "최솟값:", minimum)

# 4. 정상범위(295~305) 조건 확인하기
if maximum > 305 or minimum < 295:
    print("정상범위를 벗어난 값이 있습니다.")
else:
    print("모든 값이 정상범위 안에 있습니다.")

# 5. 전체 25건 데이터를 Pandas로 불러와 리스트로 바꾸기
import pandas as pd
df = pd.read_csv("week02_basic_process_values.csv")
all_temps = df["온도_섭씨"].tolist()
print("전체 평균:", round(sum(all_temps) / len(all_temps), 1))
print("전체 최댓값:", max(all_temps), " 전체 최솟값:", min(all_temps))

# 6. 수율(합격 비율) 계산하기
pass_count = len(df[df["합격여부"] == 1])
total_count = len(df)
yield_pct = pass_count / total_count * 100
print(f"수율: {pass_count}/{total_count} = {round(yield_pct, 1)}%")
코드 한 줄씩 설명
  • temp1 = 302.7: temp1이라는 이름의 변수에 302.7이라는 실수(float) 값을 저장한다.
  • type(temp1): 변수에 담긴 값의 자료형을 확인한다.
  • temps = [ ... ]: 대괄호로 여러 온도 값을 리스트에 담는다.
  • len(temps): 리스트 안에 값이 몇 개 들어있는지 센다.
  • sum(temps) / len(temps): 합을 개수로 나누어 평균을 계산한다.
  • max(temps), min(temps): 리스트에서 가장 큰 값과 가장 작은 값을 찾는다.
  • if maximum > 305 or minimum < 295:: 조건문으로 정상범위(295~305)를 벗어난 값이 있는지 확인한다.
  • df["온도_섭씨"].tolist(): Pandas의 열(Series)을 파이썬 리스트로 바꾼다. 그러면 지금까지 배운 sum(), max(), min()을 그대로 쓸 수 있다.
  • df[df["합격여부"] == 1]: 합격(1)인 행만 골라낸다. len(...)으로 그 행의 개수를 센다.
  • pass_count / total_count * 100: 합격 건수를 전체 건수로 나누고 100을 곱해 수율(%)을 계산한다.

🙋 실생활 비유로 정리하기

평균·최댓값·최솟값 계산은 일기예보를 떠올리면 쉽다. 일주일 동안 매일 낮 기온을 적어두면 "이번 주 평균 기온", "가장 더웠던 날", "가장 추웠던 날"을 계산할 수 있다. 공정 데이터도 마찬가지다. 하루 동안 여러 번 측정한 온도를 리스트에 모아두면, 그 리스트로 평균 온도와 가장 뜨거웠던·차가웠던 순간을 계산할 수 있다. 그리고 시험에 합격한 학생 수를 전체 학생 수로 나누면 "합격률"이 되듯, 합격한 웨이퍼 수를 전체 웨이퍼 수로 나누면 "수율"이 된다.

🟣 단계별 따라 하기 실습

1
온도 변수 만들기 — temp1 = 302.7처럼 변수 하나를 만들고 print(temp1)로 확인한다.
2
리스트 만들기 — 데이터 미리보기 표에서 온도 값 6개를 골라 리스트 temps를 직접 만들어본다.
3
평균/최댓값/최솟값 계산 — sum(temps) / len(temps), max(temps), min(temps)를 각각 실행한다.
4
정상범위 확인 — if 문으로 295~305를 벗어난 값이 있는지 확인한다.
5
전체 데이터 불러오기 — pd.read_csv("week02_basic_process_values.csv")로 25건 전체를 불러오고, df["온도_섭씨"].tolist()로 리스트를 만든다.
6
전체 평균/최댓값/최솟값 — 3단계와 같은 함수로 전체 25건의 평균·최댓값·최솟값을 계산하고 6개짜리 리스트 결과와 비교한다.
7
수율 계산 — df[df["합격여부"] == 1]의 행 개수를 전체 행 개수로 나누고 100을 곱해 수율(%)을 구한다.

⚠️ 주의할 점 & 자주 발생하는 오류

오류 1 NameError: name 'temps' is not defined — 리스트를 만드는 코드를 실행하지 않고 temps를 먼저 사용하면 발생한다. 셀을 위에서부터 순서대로 실행했는지 확인한다.
오류 2 TypeError: unsupported operand type(s) — 숫자와 문자열을 더하려고 할 때 발생한다. "온도는 " + 302.7처럼 쓰면 오류가 난다. str(302.7)로 문자열로 바꾸거나 f"온도는 {302.7}"처럼 f-문자열을 쓴다.
오류 3 ZeroDivisionError — 평균을 구할 때 리스트가 비어 있으면(len()이 0이면) 나누기를 할 수 없어 오류가 난다. 리스트에 값이 잘 들어갔는지 먼저 print()로 확인하는 습관을 들인다.
주의 max와 max()는 다르다. 괄호 ()가 있어야 함수가 "실행"된다. 괄호를 빼먹으면 계산 결과가 아니라 함수 자체가 출력되어 원하는 값을 얻을 수 없다.

🚀 도전 실습

도전 문제 df["압력_Pa"].tolist()로 압력 리스트를 만들고, 같은 방법으로 평균·최댓값·최솟값을 계산해보자. 그리고 df[df["합격여부"] == 1]["온도_섭씨"]와 df[df["합격여부"] == -1]["온도_섭씨"]의 평균을 각각 구해서, 합격 그룹과 불합격 그룹의 평균 온도가 다른지 비교해보자.

Q1. (객관식) 리스트 temps = [302.7, 300.1, 292.0]의 평균을 구하는 올바른 코드는?
  • A. max(temps) / 3
  • B. sum(temps) / len(temps)
  • C. temps / 3
  • D. len(temps) / sum(temps)
정답: B. 평균은 "값의 합 ÷ 개수"이므로 sum(temps) / len(temps)가 맞다.
Q2. (참/거짓) 이번 주 데이터에서 온도 최댓값이 정상범위를 벗어났다고 해서, 그 로트가 항상 불합격 처리된 것은 아니다.
정답: 참. 최댓값 320.0℃가 나온 LOT-0047은 오히려 합격 처리되었다. 반면 실제 불합격 2건은 더 완만한 값에서 발생했다.
Q3. (서술) 오늘 계산한 전체 평균 온도(301.9℃), 최댓값(320.0℃), 수율(92.0%)을 바탕으로 이 데이터를 처음 보는 사람에게 한 문장으로 설명해보자.
예시 답안: "이번 배치 25건의 평균 온도는 301.9℃로 정상범위 안이었지만, 최댓값은 320.0℃까지 올라간 경우도 있었다. 전체 수율은 92.0%(23/25건 합격)였다."
