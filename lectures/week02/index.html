리스트와 딕셔너리

💬 오늘의 질문: "여러 개의 측정값을 한 번에 담고, 각 값에 이름표까지 붙이려면 어떻게 해야 할까?"

🎯 학습 목표

  • 리스트에 여러 값을 담고 인덱싱·슬라이싱으로 특정 값을 꺼낼 수 있다.
  • 리스트에 값을 추가(append)하고 길이(len)를 확인할 수 있다.
  • 리스트 전체의 최댓값·최솟값·합계·평균을 내장 함수로 계산할 수 있다.
  • 딕셔너리로 값에 이름표를 붙여 하나의 레코드를 표현할 수 있다.
  • 리스트 안에 딕셔너리를 담아 여러 설비 정보를 한 번에 표현하고 꺼내 쓸 수 있다.

선수 지식: 1차시 — 변수·자료형·출력

🤔 왜 이걸 배워야 할까?

  • 실제 공정에는 값이 하나만 있는 게 아니라, 여러 설비·여러 시점의 측정값이 함께 존재한다. 리스트는 이런 "여러 개의 값"을, 딕셔너리는 "이름표가 붙은 값들의 묶음"을 다루는 방법이며, 4차시부터 배우는 표(DataFrame)도 결국 이 둘을 확장한 것이다.
쉬운 예시 한 설비의 온도를 하루에 5번 측정했다면 값 5개를 변수 5개로 따로 만드는 건 번거롭다. 리스트에 [298, 301, 299, 305, 300]처럼 담아두면 최고·최저·평균 온도를 한 번에 계산할 수 있고, 딕셔너리로 {"설비번호": "EQ-03", "온도_섭씨": 301}처럼 이름표를 붙이면 이 값이 어느 설비의 기록인지도 함께 관리할 수 있다.

⏮️ 지난 시간 복습

1차시 연결 1차시에서는 값 하나를 변수 하나에 담았다 — pass_count = 34처럼 "이름표 하나에 값 하나"였다. 오늘은 이것을 두 방향으로 확장한다. 여러 값을 순서대로 한 번에 담고 싶다면 리스트, 값 하나하나에 각각 이름표를 붙이고 싶다면 딕셔너리를 쓴다.

📚 리스트 — 여러 값을 순서대로 담기

리스트란 무엇인가

  • 여러 개의 값을 순서대로 담고 싶을 때 → 리스트(List)
    • 대괄호 [ ]로 값을 감싸고, 값 사이는 콤마(,)로 구분
먼저 아주 간단한 예로 감을 잡자 반도체 데이터로 바로 들어가기 전에, 과일 이름 세 개를 담은 가장 단순한 리스트로 연습해보자.
Python — 아주 간단한 리스트
fruits = ["사과", "바나나", "포도"]
print(fruits)
print(fruits[0])    # 첫 번째 값
print(fruits[-1])   # 마지막 값
실행 결과 
['사과', '바나나', '포도']
사과
포도
  • 리스트는 문자열뿐 아니라 숫자도 같은 방식으로 담을 수 있음 → 이제 반도체 데이터의 온도 값으로 확장
Python — 리스트 만들기
temperatures = [295.4, 298.1, 312.6, 301.0, 296.8]
print(temperatures)
실행 결과 
[295.4, 298.1, 312.6, 301.0, 296.8]

인덱스(순서 번호)는 0부터 시작한다. 보라색으로 강조된 인덱스 2가 가장 큰 값(312.6) — 뒤에서 배울 max()가 찾아줄 값이다.

인덱싱 — 순서로 값 꺼내기

  • 대괄호 안에 인덱스를 넣으면 → 그 위치의 값을 꺼낼 수 있음
Python
print(temperatures[0])    # 첫 번째 값
print(temperatures[2])    # 세 번째 값
print(temperatures[-1])   # 마지막 값(음수 인덱스는 뒤에서부터)
실행 결과 
295.4
312.6
296.8
가장 흔한 함정 리스트의 첫 번째 값은 인덱스 0이다(1이 아니다!). temperatures[1]은 "두 번째" 값(298.1)이라는 점을 꼭 기억하자.
🤖 AI에게 물어보기 — 복사해서 AI 챗봇에 붙여넣기
파이썬 리스트 인덱스가 왜 1이 아니라 0부터 시작하는지, 엘리베이터 층수나 줄 서기 같은 일상 비유로 3줄 이내로 재미있게 설명해줘.

👀 이렇게 확인해보자: AI의 비유대로 따라가면 temperatures[1]이 두 번째 값(298.1)이 되는지 확인하자.

슬라이싱 — 여러 값을 한 번에 잘라내기

  • 콜론(:)을 쓰면 리스트의 일부(구간)를 한 번에 꺼낼 수 있음
  • list[시작:끝] = 시작 인덱스부터 끝 인덱스 바로 앞까지
    • 끝 인덱스 자신은 포함되지 않음
Python
print(temperatures[1:3])   # 인덱스 1~2 (3은 포함 안 됨)
print(temperatures[:2])    # 처음부터 인덱스 1까지
print(temperatures[2:])    # 인덱스 2부터 끝까지
실행 결과 
[298.1, 312.6]
[295.4, 298.1]
[312.6, 301.0, 296.8]
🙋 직접 해보기 temperatures[-2:]를 실행해보고, 음수 인덱스와 슬라이싱을 함께 쓰면 어떤 값이 나오는지 확인해보자.
🤖 AI에게 물어보기 — 복사해서 AI 챗봇에 붙여넣기
리스트 [10, 20, 30, 40, 50]으로 파이썬 슬라이싱 OX 퀴즈 3문제를 내줘. 정답은 숨겨두고, 내가 답하면 그때 정답과 이유를 알려줘.

👀 이렇게 확인해보자: 해설에 "끝 번호는 포함하지 않는다"는 규칙이 들어 있는지, 노트북에서 직접 실행한 결과와 같은지 확인하자.

리스트 다루기 — 길이와 추가

  • len() — 리스트에 담긴 값의 개수를 셈
  • append() — 리스트 끝에 새 값을 추가
Python
print(len(temperatures))     # 리스트 길이(값 개수)

temperatures.append(303.2)   # 끝에 새 값 추가
print(temperatures)
print(len(temperatures))
실행 결과 
5
[295.4, 298.1, 312.6, 301.0, 296.8, 303.2]
6
체크포인트 — append()는 아무것도 돌려주지 않는다 append()는 리스트 자체를 바로 바꿔줄 뿐, 결과값(리턴값)은 없다(정확히는 None). temperatures = temperatures.append(303.2)처럼 다시 대입하면 temperatures가 None이 되어버려 이후 코드가 모두 오류가 난다. 그냥 temperatures.append(303.2)만 한 줄로 쓰면 된다.

리스트에서 최댓값·최솟값·평균 구하기

  • 파이썬 내장 함수로 리스트 전체 계산 가능
    • max() — 최댓값
    • min() — 최솟값
    • sum() — 합계
  • 평균 = "합계 ÷ 개수" → sum()과 len()을 조합
Python
print(max(temperatures))     # 최댓값
print(min(temperatures))     # 최솟값
print(sum(temperatures))     # 합계

average = sum(temperatures) / len(temperatures)
print(f"평균 온도는 {round(average, 1)}도입니다.")   # round()로 소수점 정리 + 1차시 f-string 복습
실행 결과 
312.6
295.4
1807.1
평균 온도는 301.2도입니다.
🙋 직접 해보기 temp_range = max(temperatures) - min(temperatures)로 온도 범위(최고-최저 차이)를 계산하고, f"온도 범위는 {temp_range:.1f}도입니다." 같은 문장을 출력해보자.

📚 딕셔너리 — 값에 이름표 붙이기

딕셔너리란 무엇인가

  • 리스트 = 순서로 값을 구분 → "이 값이 무엇을 의미하는지" 이름은 없음
  • 설비 1대가 가진 여러 정보(번호, 공정, 온도)처럼 값마다 이름표를 붙이고 싶을 때 → 딕셔너리(Dictionary)
    • 중괄호 { } 안에 키(key): 값(value) 쌍을 콤마로 나열
먼저 아주 간단한 예로 감을 잡자 반도체 데이터로 들어가기 전에, 사람 한 명의 정보를 담은 가장 단순한 딕셔너리로 연습해보자.
Python — 아주 간단한 딕셔너리
person = {"이름": "지민", "나이": 15}
print(person)
print(person["이름"])
실행 결과 
{'이름': '지민', '나이': 15}
지민
  • 같은 방식으로 설비 1대의 정보를 딕셔너리로 표현
Python — 딕셔너리 만들기
equipment = {
    "설비번호": "EQ-01",
    "공정명": "식각",
    "온도_섭씨": 301.2,
}
print(equipment)
실행 결과 
{'설비번호': 'EQ-01', '공정명': '식각', '온도_섭씨': 301.2}

딕셔너리는 "신분증 카드"와 비슷하다 — 각 항목에 이름표(키)가 붙어 있어, 순서를 몰라도 이름으로 바로 값을 찾을 수 있다.

키로 값 접근하기

  • 딕셔너리는 인덱스(순서 번호) 대신 키(이름표)로 값을 꺼냄
Python
print(equipment["설비번호"])
print(equipment["온도_섭씨"])
실행 결과 
EQ-01
301.2
오류 주의 딕셔너리에 없는 키를 쓰면 KeyError가 발생한다. 예를 들어 equipment["압력_Pa"]는 이 딕셔너리에 "압력_Pa"라는 키가 없으므로 오류가 난다. 오타가 없는지, 키를 먼저 만들었는지 확인해야 한다.

값 수정하기 / 새 키 추가하기

  • 이미 있는 키에 새 값을 대입 → 값이 바뀜
  • 없던 키에 값을 대입 → 새 항목이 추가됨
Python
equipment["온도_섭씨"] = 305.5     # 기존 값 수정
equipment["압력_Pa"] = 1012.3      # 새 키 추가

print(equipment)
실행 결과 
{'설비번호': 'EQ-01', '공정명': '식각', '온도_섭씨': 305.5, '압력_Pa': 1012.3}
🙋 직접 해보기 나만의 equipment 딕셔너리를 만들고, f-string으로 f"설비 {equipment['설비번호']}은(는) {equipment['공정명']} 공정이며 온도는 {equipment['온도_섭씨']}도입니다." 같은 문장을 출력해보자.
🤖 AI에게 물어보기 — 복사해서 AI 챗봇에 붙여넣기
너는 반도체 공장의 설비 관리 담당자야. 설비 1대의 정보를 파이썬 딕셔너리로 적는다면 어떤 키 5개를 넣을지 이유와 함께 알려주고, 값은 가짜 예시로 채워줘.

👀 이렇게 확인해보자: 결과가 {"키": 값} 모양인지, 글자 값에는 따옴표가 있고 숫자 값에는 없는지 확인하고, 노트북에 붙여넣어 print()로 출력해보자.

📚 리스트 안에 딕셔너리 담기 — 여러 설비를 한 번에 표현하기

  • 설비 하나는 딕셔너리로 표현 완료 — 설비가 여러 대라면?
  • 답 = 리스트 안에 딕셔너리를 여러 개 넣기 = "딕셔너리의 리스트"
    • 앞으로 표(DataFrame) 데이터를 이해하는 데 중요한 기초(4차시 Pandas 예고)
먼저 아주 간단한 예로 감을 잡자 학생 두 명의 정보를 담은 가장 단순한 "딕셔너리의 리스트"로 먼저 연습해보자.
Python — 아주 간단한 딕셔너리의 리스트
students = [
    {"이름": "지민", "점수": 90},
    {"이름": "하은", "점수": 85},
]

print(students[0])              # 첫 번째 학생(딕셔너리 하나)
print(students[0]["점수"])      # 첫 번째 학생의 점수
print(students[1]["이름"])      # 두 번째 학생의 이름
실행 결과 
{'이름': '지민', '점수': 90}
90
하은
  • 같은 방식으로 설비 여러 대를 "딕셔너리의 리스트"로 표현
Python — 딕셔너리의 리스트
equipment_list = [
    {"설비번호": "EQ-01", "공정명": "식각", "온도_섭씨": 301.2},
    {"설비번호": "EQ-02", "공정명": "증착", "온도_섭씨": 308.7},
    {"설비번호": "EQ-03", "공정명": "포토", "온도_섭씨": 297.5},
]

print(len(equipment_list))              # 설비 개수
print(equipment_list[0])                # 첫 번째 설비(딕셔너리 하나)
print(equipment_list[0]["온도_섭씨"])    # 첫 번째 설비의 온도
print(equipment_list[1]["설비번호"])     # 두 번째 설비의 번호
실행 결과 
3
{'설비번호': 'EQ-01', '공정명': '식각', '온도_섭씨': 301.2}
301.2
EQ-02

리스트가 카드 3장을 순서대로 들고 있고, 카드 각각(딕셔너리)이 자기만의 이름표-값 쌍을 가지고 있다. equipment_list[1]["온도_섭씨"]처럼 "몇 번째 카드"와 "무슨 이름표"를 순서대로 지정하면 원하는 값을 정확히 꺼낼 수 있다.

🙋 직접 해보기 equipment_list[2]["공정명"]을 출력해 세 번째 설비의 공정명을 확인해보자.

종합 실습 — 나만의 설비 목록 만들기

Python — 종합 실습
my_equipment = [
    {"설비번호": "EQ-04", "공정명": "세정", "온도_섭씨": 299.0},
    {"설비번호": "EQ-05", "공정명": "산화", "온도_섭씨": 302.4},
]

print(f"{my_equipment[0]['설비번호']} 설비는 {my_equipment[0]['공정명']} 공정, "
      f"온도는 {my_equipment[0]['온도_섭씨']}도입니다.")
print(f"{my_equipment[1]['설비번호']} 설비는 {my_equipment[1]['공정명']} 공정, "
      f"온도는 {my_equipment[1]['온도_섭씨']}도입니다.")
실행 결과 
EQ-04 설비는 세정 공정, 온도는 299.0도입니다.
EQ-05 설비는 산화 공정, 온도는 302.4도입니다.
따옴표 규칙 f-string 바깥은 큰따옴표("...")를 썼으므로, 딕셔너리 키 안쪽은 작은따옴표 ('설비번호')를 써야 한다. 같은 종류의 따옴표를 겹쳐 쓰면 문자열이 예상보다 일찍 끝나버려 SyntaxError가 날 수 있다(파이썬 3.12 이전 버전). 버전과 상관없이 안전하게 쓰려면 안쪽은 작은따옴표를 쓰자.

🗂️ 핵심 용어 카드

리스트

List
한 줄 설명
여러 값을 순서대로 담는 자료구조. 대괄호 [ ]로 만든다.
쉬운 비유
번호가 매겨진 칸이 줄지어 있는 서랍장.
데이터에서의 예
temperatures = [295.4, 298.1, 312.6]
자주 하는 오해
인덱스가 1부터 시작한다고 착각하기 쉽다. 실제로는 0부터 시작한다.

인덱스

Index
한 줄 설명
리스트에서 값의 위치를 나타내는 순서 번호(0부터 시작).
쉬운 비유
서랍장의 몇 번째 칸인지를 나타내는 번호표.
데이터에서의 예
temperatures[0] → 첫 번째 값.
자주 하는 오해
음수 인덱스(-1)는 "오류"가 아니라 "뒤에서부터 세기"라는 정상 기능이다.

슬라이싱

Slicing
한 줄 설명
리스트의 일부 구간을 한 번에 잘라내는 방법.
쉬운 비유
김밥을 통째로 자르지 않고 원하는 구간만 잘라내는 것.
데이터에서의 예
temperatures[1:3] → 인덱스 1, 2만.
자주 하는 오해
[1:3]에 인덱스 3의 값까지 포함된다고 착각하기 쉽다(포함 안 됨).

딕셔너리

Dictionary
한 줄 설명
키-값 쌍으로 값에 이름표를 붙여 저장하는 자료구조. 중괄호 { }로 만든다.
쉬운 비유
이름표가 붙은 신분증 카드.
데이터에서의 예
{"설비번호": "EQ-01", "온도_섭씨": 301.2}
자주 하는 오해
딕셔너리도 리스트처럼 [0]으로 접근할 수 있다고 착각하기 쉽다(키로만 접근 가능).

키-값 쌍

Key-Value Pair
한 줄 설명
딕셔너리를 이루는 "이름표(키)"와 "내용(값)"의 짝.
쉬운 비유
택배 상자에 붙은 "받는 사람" 이름표와 그 안의 물건.
데이터에서의 예
"공정명": "식각"에서 키는 공정명, 값은 식각.
자주 하는 오해
글자(문자열)인 키와 값에는 따옴표가 필요하지만, 301.2 같은 숫자 값에는 따옴표를 붙이지 않는다는 점을 헷갈리기 쉽다.

⚠️ 주의할 점 & 자주 발생하는 오류

오류 1 IndexError: list index out of range — 리스트에 없는 인덱스에 접근한 경우다 (예: 값이 5개뿐인 리스트에서 temperatures[10]). len()으로 리스트 길이를 먼저 확인하는 습관을 들이자.
오류 2 KeyError: '압력_Pa' — 딕셔너리에 없는 키에 접근한 경우다. 오타가 없는지, print(equipment)로 전체 키를 먼저 확인해보자.
주의 — 대괄호 vs 중괄호 리스트는 [ ], 딕셔너리는 { }를 쓴다. 자주 헷갈리는 실수이니 "순서만 있으면 대괄호, 이름표가 있으면 중괄호"로 기억해두자.

✅ 결과 정리 & 퀴즈

퀴즈는 실습지와 아래 정리 문제로 확인한다.

Q1. (객관식) numbers = [10, 20, 30, 40]일 때 numbers[1]의 값은?
  • A. 10
  • B. 20
  • C. 30
  • D. 오류가 난다
정답: B. 인덱스는 0부터 시작하므로 numbers[0]이 10, numbers[1]이 20이다.
Q2. (참/거짓) numbers[1:3]은 인덱스 1, 2, 3의 값을 모두 포함한다.
정답: 거짓. 슬라이싱의 끝 인덱스는 포함되지 않는다. numbers[1:3]은 인덱스 1, 2만 포함한다.
Q3. (빈칸) equipment = {"설비번호": "EQ-01"}일 때, 설비번호 값을 출력하려면? print(equipment[______])
정답: "설비번호" → print(equipment["설비번호"]). 딕셔너리는 키(문자열)로 값을 꺼낸다.
Q4. (객관식) 리스트와 딕셔너리의 차이를 가장 잘 설명한 것은?
  • A. 리스트는 순서로, 딕셔너리는 이름표(키)로 값을 구분한다
  • B. 리스트는 숫자만, 딕셔너리는 문자만 담을 수 있다
  • C. 딕셔너리는 값을 하나만 담을 수 있다
  • D. 리스트와 딕셔너리는 완전히 같은 기능을 한다
정답: A. 리스트는 순서(인덱스)로, 딕셔너리는 이름표(키)로 값을 구분해 관리한다.
Q5. (서술) equipment_list[1]["공정명"]이 무엇을 의미하는지 말로 설명해보자.
예시 답안: "equipment_list 리스트의 두 번째(인덱스 1) 딕셔너리에서, '공정명'이라는 키에 해당하는 값을 꺼낸다."

💡 AI에게 프롬프트로 코드 생성 요청하기

  • 오늘 만든 equipment_list처럼 "딕셔너리의 리스트"를 다루는 코드를 AI에게 요청해보자. 아직 배우지 않은 문법(예: max()의 key 옵션)이 나올 수도 있다.
🙋 코드 생성 프롬프트 따라 해보기
  • "설비 정보 딕셔너리가 여러 개 담긴 리스트에서, 온도가 가장 높은 설비 하나만 찾아주는 코드를 만들어줘."
  • "리스트에서 295~305 범위를 벗어나는 온도 값만 골라 새 리스트로 만들어주는 코드를 만들어줘."
Python — AI가 만들어줄 수 있는 코드 예시
equipment_list = [
    {"설비번호": "EQ-01", "온도_섭씨": 301.2},
    {"설비번호": "EQ-02", "온도_섭씨": 308.7},
    {"설비번호": "EQ-03", "온도_섭씨": 297.5},
]

hottest = max(equipment_list, key=lambda eq: eq["온도_섭씨"])
print(f"가장 온도가 높은 설비는 {hottest['설비번호']}이고, 온도는 {hottest['온도_섭씨']}도입니다.")
실행 결과 
가장 온도가 높은 설비는 EQ-02이고, 온도는 308.7도입니다.
AI 코드를 다룰 때 꼭 지킬 점
  • 위 예시의 max(..., key=lambda ...)는 오늘 배우지 않은 문법이다 — "이 코드가 어떤 뜻이야?"라고 AI에게 되물어보며 하나씩 이해하고 넘어가자.
  • AI가 만든 코드도 직접 실행해서 내가 기대한 결과가 맞는지 확인해야 한다.
  • 변수 이름이나 딕셔너리 키 이름이 오늘 쓴 것과 다르게 나올 수 있다 — 내 코드에 맞게 바꿔서 사용하자.

🟣 연습문제 — 압력 리스트와 새 설비 딕셔너리

새로운 값으로 리스트·딕셔너리를 한 번 더 연습해보자. 오늘 측정한 압력 값이다.

🙋 직접 해보기 pressures = [1010.2, 1005.4, 1022.9, 998.7, 1011.0] 리스트를 만들고 최댓값·최솟값·평균을 계산해보자. 그다음 설비번호 "EQ-04", 공정명 "세정", 온도_섭씨 299.9인 딕셔너리 eq04를 만들고, 방금 구한 평균 압력을 압력_Pa 키로 추가해보자. 
pressures = [1010.2, 1005.4, 1022.9, 998.7, 1011.0]
average_p = sum(pressures) / len(pressures)

eq04 = {"설비번호": "EQ-04", "공정명": "세정", "온도_섭씨": 299.9}
eq04["압력_Pa"] = average_p
print(eq04)
실행 결과: {'설비번호': 'EQ-04', '공정명': '세정', '온도_섭씨': 299.9, '압력_Pa': 1009.64}

🎉 AI로 재미있는 미니 프로그램 만들기 — 오늘의 럭키 설비 뽑기

오늘의 미니 프로젝트 오늘 배운 리스트·딕셔너리로, 실행하면 재미를 느낄 수 있는 나만의 프로그램을 AI에게 만들어달라고 요청해보자.
🙋 프롬프트 예시 — 그대로 물어보기 "설비 정보 딕셔너리가 여러 개 담긴 리스트(equipment_list)에서, random.choice()로 하나를 무작위로 뽑아서 '오늘의 럭키 설비'라는 제목과 함께 설비번호·공정명·온도를 예쁘게 출력하는 파이썬 코드를 만들어줘."
Python — AI가 만들어줄 수 있는 코드 예시
import random

equipment_list = [
    {"설비번호": "EQ-01", "공정명": "식각", "온도_섭씨": 301.2},
    {"설비번호": "EQ-02", "공정명": "증착", "온도_섭씨": 308.7},
    {"설비번호": "EQ-03", "공정명": "포토", "온도_섭씨": 297.5},
    {"설비번호": "EQ-04", "공정명": "세정", "온도_섭씨": 299.9},
]

lucky = random.choice(equipment_list)
print("🎉 오늘의 럭키 설비 🎉")
print(f"설비번호: {lucky['설비번호']}")
print(f"공정명: {lucky['공정명']}")
print(f"온도: {lucky['온도_섭씨']}도")
실행 결과 예시 
🎉 오늘의 럭키 설비 🎉
설비번호: EQ-04
공정명: 세정
온도: 299.9도
더 놀아보기
  • "설비를 2개 더 추가해줘"처럼 요청해서 뽑기 대상을 풍성하게 만들어보자.
  • random 모듈 자체는 오늘 처음 보는 표현이다 — 리스트·딕셔너리는 오늘 배운 내용이니, random.choice()가 리스트 안에서 하나를 무작위로 골라준다는 정도만 이해하고 넘어가도 충분하다.
