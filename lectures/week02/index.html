파이썬 기초 Ⅰ — 변수, 자료형, 리스트, 딕셔너리

💬 오늘의 질문: "측정값 하나하나를 어떻게 이름 붙여 기억하고, 여러 개를 한 번에 담을 수 있을까?"

작성 상태 이 페이지는 v2 커리큘럼 구성이 확정된 직후 작성된 개요(skeleton)입니다. 제목·학습 목표·다룰 내용·데이터까지는 확정되었지만, 상세 설명·예제 코드·단계별 실습·퀴즈는 아직 채워지지 않았습니다. 구성이 최종 확정되면 이어서 상세 내용을 작성합니다. 배경은 docs/restructure-plan.md 참고.

🎯 학습 목표

  • 변수에 값을 저장하고 숫자형/문자열형/불리언을 구분할 수 있다.
  • 리스트에 여러 값을 담고 인덱싱으로 특정 값을 꺼낼 수 있다.
  • 딕셔너리로 하나의 레코드(설비 정보 등)에 이름표를 붙여 표현할 수 있다.
  • 리스트와 딕셔너리를 언제 각각 쓰는지 구분할 수 있다.

선수 지식: 1주차 — Colab 사용법

📚 다룰 이론 주제(초안)

  • 변수와 대입
  • 숫자형 · 문자열형 · 불리언
  • 리스트 — 순서 있는 여러 값, 인덱싱
  • 딕셔너리 — 키-값 쌍
  • 리스트 vs 딕셔너리, 언제 무엇을 쓰는가

🧪 다룰 실습 흐름(초안)

  1. 온도 값 하나를 변수에 저장해보기
  2. 하루치 온도 여러 개를 리스트에 저장하기
  3. 리스트 길이(len)와 특정 위치 값 꺼내기(인덱싱)
  4. 설비 1대의 정보(설비번호·공정명·온도)를 딕셔너리로 표현하기
  5. 여러 설비를 '딕셔너리의 리스트'로 표현해보기
