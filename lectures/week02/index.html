리스트와 딕셔너리

오늘의 질문: "여러 개의 측정값을 한 번에 담고, 각 값에 이름표까지 붙이려면 어떻게 해야 할까?"

오늘의 예제 데이터
한 설비의 하루 온도 6건(가상 값)
평균
301.2°C
최고 (2번 칸)
312.6°C
최저 (0번 칸)
295.4°C
학습용 정상 범위
295~305°C
LEARNING OUTCOMES

오늘의 학습 목표

OUTCOME 01

여러 값을 한 줄로 담기

List
OUTCOME 02

값에 이름표 붙이기

Dictionary
OUTCOME 03

표의 한 행 = 딕셔너리 하나

List of Dict
  • 리스트에 여러 값을 담고, 칸 번호(인덱스)로 하나 또는 여러 개를 꺼낸다.
  • max()·min()·sum()·len()으로 최고·최저·평균을 구하고, 평균에 숨는 "튀는 값"을 말한다.
  • 딕셔너리로 기록에 이름표(키)를 붙이고, 키로 값을 꺼내고 바꾼다.
  • "딕셔너리의 리스트"가 표 모양이라는 것을 알고, 원하는 칸을 꺼낸다.

왜 이걸 배워야 할까?

  • 온도 센서는 하루에도 여러 번 잰다. 변수 하나에 값 하나로는 부족하다 → 리스트.
  • "301.2"만 있으면 어느 설비의 무슨 값인지 모른다 → 이름표를 붙이는 딕셔너리.
  • 평균 301.2도는 학습용 정상 범위(295~305도) 안이지만, 값을 늘어놓으면 한 번은 312.6도까지 올랐다. 여러 값을 함께 담아야 보인다.

지난 시간 복습

  • 변수 = 상자 하나에 값 하나(pass_count = 32), f-string으로 문장 출력({값:.1f}).
  • 표의 한 행 = 기록 1건, 한 열 = 기록 항목. 합격여부는 1 = 합격, -1 = 불합격.
  • 숫자 하나보다 여러 값을 함께 볼 때 질문이 생긴다. 오늘은 그 "여러 값"을 코드에 담는다.
STEP 01

리스트 — 번호 붙은 칸에 여러 값 담기

오늘 수업 방식

개념은 쉬운 예제(지어낸 생활 값)로 익히고, 뒤의 "반도체 데이터로 확인하기"에서 핵심만 공장 데이터로 확인한다. 실습지와 노트북 뒷부분은 반도체 데이터(교육용 가상 데이터)로 푼다.

리스트와 인덱스 — 칸 번호로 값 하나 꺼내기

  • 리스트: 대괄호 [ ] 안에 값을 콤마로 나열한 묶음. 번호 붙은 약통과 같다.
  • 인덱스: 리스트[번호]의 번호. 0부터 센다("맨 앞에서 몇 칸 떨어졌나"). -1은 마지막 칸.

쉬운 예제 — 일주일 기온

Python — 일주일 기온 리스트
week_temps = [21.5, 23.0, 30.5, 24.0, 22.5, 25.0, 23.5]   # 월~일 낮 기온
print(week_temps)

print(week_temps[0])    # 첫 번째 값(월요일)
print(week_temps[2])    # 세 번째 값(수요일)
print(week_temps[-1])   # 마지막 값(일요일)
실행 결과 
[21.5, 23.0, 30.5, 24.0, 22.5, 25.0, 23.5]
21.5
30.5
23.5

첫 칸(월요일)의 번호는 1이 아니라 0이다.

가장 흔한 실수 week_temps[1]은 두 번째 값(화요일 23.0)이다. 칸이 7개면 번호는 0~6번이라 week_temps[7]은 IndexError가 난다.
Python — 직접 확인하기
print(week_temps[1])    # 두 번째 값(첫 번째가 아니다!)
# print(week_temps[7])  # 칸은 0~6번뿐 → IndexError
실행 결과 
23.0
AI에게 물어보기 — 복사해서 AI 챗봇에 붙여넣기
파이썬 리스트 번호가 왜 1이 아니라 0부터 시작하는지, 자의 눈금 같은 일상 비유로 3줄 이내로 설명해줘.

슬라이싱 — 여러 칸을 한 번에 꺼내기

  • 리스트[시작:끝]: 시작 칸은 들어가고 끝 칸은 빠진다. 개수는 끝 - 시작.
  • 시작을 비우면 처음부터, 끝을 비우면 마지막까지. 결과도 리스트다.

쉬운 예제 — 평일과 주말 기온

Python — 평일과 주말 잘라내기
print(week_temps[1:3])   # 1번 칸부터 3번 칸 앞까지(화·수)
print(week_temps[:5])    # 처음부터 5번 칸 앞까지(평일)
print(week_temps[5:])    # 5번 칸부터 끝까지(주말)
실행 결과 
[23.0, 30.5]
[21.5, 23.0, 30.5, 24.0, 22.5]
[25.0, 23.5]

개수 세기와 값 추가하기 — len(), append()

  • len(리스트)는 칸 수를 세고, 리스트.append(값)은 맨 끝에 값을 붙인다.
  • cart.append의 점(.)은 "cart의"라는 뜻이다. 그 리스트에 딸린 기능을 부른다.

쉬운 예제 — 장바구니

Python — 장바구니 세기와 추가
cart = ["우유", "빵", "계란"]
print(len(cart))

cart.append("사과")
print(cart)
print(len(cart))
실행 결과 
3
['우유', '빵', '계란', '사과']
4

빈 리스트 []에서 시작해 채울 수도 있다(3차시에서 자주 쓴다).

Python — 빈 장바구니에서 시작하기
new_cart = []
new_cart.append("바나나")
new_cart.append("두부")
print(new_cart)
실행 결과 
['바나나', '두부']
주의 append 셀은 한 번만 실행한다(두 번 실행하면 값이 두 번 붙는다). cart = cart.append("사과")처럼 다시 저장하면 None(아무것도 없다는 뜻의 값)이 된다.

최고·최저·평균 구하기 — max(), min(), sum()

  • max() 최고, min() 최저, sum() 합계. 평균 = sum(리스트) / len(리스트).

쉬운 예제 — 이번 주 기온 요약

Python — 이번 주 최고·최저·평균 기온
print(max(week_temps))
print(min(week_temps))
print(sum(week_temps))

average = sum(week_temps) / len(week_temps)
print(f"이번 주 평균 기온은 {average:.1f}도입니다.")
실행 결과 
30.5
21.5
170.0
이번 주 평균 기온은 24.3도입니다.

평균 24.3도는 선선한 한 주 같지만, 수요일 하루는 30.5도였다. 평균은 튀는 하루를 섞어 숨긴다.

STEP 02

딕셔너리 — 이름표로 찾는 사물함

  • 리스트 ["지민", 15, 3]은 "2번 칸이 반이었지?"를 외워야 한다. 딕셔너리는 칸 번호 대신 이름표(키)로 값을 찾는다.
  • 이름표 붙은 사물함, 단어로 뜻을 찾는 국어사전과 같다. 이름표 = 키(key), 내용 = 값(value).
리스트딕셔너리
괄호대괄호 [ ]중괄호 { }
값을 찾는 법칸 번호(0, 1, 2 …)이름표(키)
어울리는 값같은 종류 여러 개(일주일 기온, 하루 온도)뜻이 다른 값 묶음(학생 한 명, 설비 한 대)

딕셔너리 만들고 키로 꺼내기

  • {키: 값, …}로 만들고 딕셔너리[키]로 꺼낸다. 글자는 따옴표로 감싸고 숫자는 그대로 쓴다.

쉬운 예제 — 학생 한 명의 정보

Python — 학생 정보를 딕셔너리로
student = {
    "이름": "지민",
    "나이": 15,
    "반": 3,
}
print(student)

print(student["이름"])
print(student["반"])
# print(student["혈액형"])   # 없는 이름표 → KeyError
실행 결과 
{'이름': '지민', '나이': 15, '반': 3}
지민
3
없는 이름표 → KeyError 마지막 줄의 #을 지우면 KeyError: '혈액형'이 난다. 오타도 같은 오류다. print(student)로 키를 먼저 확인하자.

값 바꾸기와 키 추가하기

  • 딕셔너리[키] = 값: 있던 키면 값이 바뀌고, 없던 키면 새로 생긴다.

쉬운 예제 — 학생 정보 고치기

Python — 값 바꾸기, 키 추가하기, 문장 만들기
student["나이"] = 16           # 있던 키 → 값 바꾸기
student["동아리"] = "과학반"   # 없던 키 → 새로 추가
print(student)

print(f"{student['이름']} 학생은 {student['나이']}살, 동아리는 {student['동아리']}입니다.")
실행 결과 
{'이름': '지민', '나이': 16, '반': 3, '동아리': '과학반'}
지민 학생은 16살, 동아리는 과학반입니다.
따옴표 규칙 f-string 바깥이 큰따옴표면 안쪽 키는 작은따옴표('이름')로 쓴다. 겹치면 SyntaxError: f-string: unmatched '['가 난다(파이썬 3.11 이하. 3.12부터는 오류가 안 나지만, 어느 버전에서나 되도록 작은따옴표로 쓴다).
STEP 03

딕셔너리의 리스트 — 표의 한 행 = 딕셔너리 하나

  • 딕셔너리 여러 개를 리스트에 담으면 표가 된다. 행 = 딕셔너리 하나, 열 이름 = 키, 표 전체 = 리스트.
  • 칸 하나는 [행 번호] 먼저, ["열 이름"] 다음(극장 좌석 "몇 번째 줄, 무슨 자리"). 순서를 바꾸면 TypeError.

딕셔너리의 리스트 만들고 칸 꺼내기

STEP 04

반도체 데이터로 확인하기

핵심 용어 카드

리스트

List
한 줄 설명
여러 값을 순서대로 담는 묶음. [ ]로 만든다.
예
[21.5, 23.0, 30.5, 24.0, 22.5, 25.0, 23.5]

인덱스

Index
한 줄 설명
칸의 위치 번호. 0부터 센다([1]은 두 번째, [-1]은 마지막).
예
week_temps[2] → 30.5(수요일)

슬라이싱

Slicing
한 줄 설명
[시작:끝]으로 여러 칸을 잘라낸다. 끝 칸은 빠진다.
예
week_temps[1:3] → [23.0, 30.5]

딕셔너리

Dictionary
한 줄 설명
값마다 이름표(키)를 붙인 묶음. { }로 만들고 키로만 꺼낸다([0]은 KeyError: 0).
예
{"이름": "지민", "나이": 15}

키와 값

Key & Value
한 줄 설명
딕셔너리를 이루는 짝. 키는 이름표(따옴표까지 쓴다), 값은 내용.
예
"이름": "지민"

딕셔너리의 리스트

List of Dictionaries
한 줄 설명
딕셔너리를 리스트에 담은 표 모양. [행 번호] 먼저, [키] 다음.
예
friends[1]["이름"] → 서준

결과 정리 & 퀴즈

더 많은 문제는 실습지에 있다.

Q1. (객관식) week_temps = [21.5, 23.0, 30.5, 24.0, 22.5, 25.0, 23.5]일 때 week_temps[1]의 값은?
  • A. 21.5
  • B. 23.0
  • C. 30.5
  • D. 오류가 난다
정답: B. 번호는 0부터 센다.
Q2. (참/거짓) week_temps[1:3]에는 1번, 2번, 3번 칸의 값이 모두 들어 있다.
정답: 거짓. 끝 칸(3번)은 빠져 [23.0, 30.5]이다.
Q3. (빈칸) student = {"이름": "지민", "나이": 15}에서 지민을 꺼내려면? print(student[______])
정답: "이름". 키는 따옴표까지 쓴다.
Q4. (객관식) 리스트와 딕셔너리의 차이로 가장 알맞은 것은?
  • A. 리스트는 칸 번호로, 딕셔너리는 이름표(키)로 값을 찾는다
  • B. 리스트는 숫자만, 딕셔너리는 글자만 담을 수 있다
  • C. 딕셔너리는 값을 하나만 담을 수 있다
  • D. 둘은 완전히 같다
정답: A. 번호 붙은 약통과 이름표 붙은 사물함.
Q5. (결과 예측) 쉬운 예제의 friends에서 friends[1]["이름"]의 값은?
정답: 서준. 1번 행(두 번째 친구)의 이름 칸이다.
Q6. (서술) 하루 온도 6건의 평균이 301.2도였다. 이 숫자만 보고 "오늘 온도는 정상"이라고 보고하면 무엇을 놓칠까?
예시 답안: "평균은 정상 범위 안이지만 최고값 312.6도는 범위를 벗어났다. 평균만 보면 이 튀는 값을 놓친다."

AI로 한 걸음 더 — 질문하고 코드 받아보기

AI의 답도 틀릴 수 있으니 강의와 비교하고 코드는 직접 실행한다. 실제 회사 데이터·개인정보는 붙여넣지 않는다.

질문해보기 — 하나 이상 골라서 (노트북 11단계)
  • "파이썬 리스트와 딕셔너리를 약통과 사물함에 비유해서 차이를 설명해줘."
  • "딕셔너리 여러 개를 리스트에 담은 것이 엑셀 표와 어떻게 닮았는지 예를 들어 설명해줘."
  • "파이썬 리스트 번호가 왜 1이 아니라 0부터 시작하는지, 자의 눈금 같은 일상 비유로 3줄 이내로 설명해줘."
코드 받아보기 (노트북 12단계) "온도 리스트 [295.4, 298.1, 312.6, 301.0, 296.8]의 최고값, 최저값, 평균을 계산해서 하나의 딕셔너리로 정리해 출력하는 파이썬 코드를 만들어줘. 리스트 이름은 temps로 해줘."
Python — AI가 만들어줄 수 있는 코드 예시
temps = [295.4, 298.1, 312.6, 301.0, 296.8]
report = {
    "최고": max(temps),
    "최저": min(temps),
    "평균": round(sum(temps) / len(temps), 1),
}
print(report)
실행 결과 
{'최고': 312.6, '최저': 295.4, '평균': 300.8}
확인할 점
  • round(값, 1)은 소수 첫째 자리 반올림이다. 처음 보는 함수는 AI에게 되물어 보자.
  • 평균이 301.2가 아니라 300.8인 이유: 이 요청의 리스트는 303.2를 붙이기 전 5개다.
  • AI 코드가 temperatures를 다시 만들면 내 리스트가 바뀐다. 그래서 이름을 temps로 요청했다.
