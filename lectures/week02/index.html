2차시 · 2시간 수업 · 개요(skeleton)

리스트와 딕셔너리

💬 오늘의 질문: "여러 개의 측정값을 한 번에 담고, 각 값에 이름표까지 붙이려면 어떻게 해야 할까?"

작성 상태 이 페이지는 v2 커리큘럼 구성이 확정된 직후 작성된 개요(skeleton)입니다. 제목·학습 목표·다룰 내용·데이터까지는 확정되었지만, 상세 설명·예제 코드·단계별 실습·퀴즈는 아직 채워지지 않았습니다. 구성이 최종 확정되면 이어서 상세 내용을 작성합니다. 배경은 docs/restructure-plan.md 참고.

🎯 학습 목표

  • 리스트에 여러 값을 담고 인덱싱·슬라이싱으로 특정 값을 꺼낼 수 있다.
  • 리스트에 값을 추가(append)하고 길이(len)를 확인할 수 있다.
  • 딕셔너리로 값에 이름표를 붙여 하나의 레코드를 표현할 수 있다.
  • 리스트 안에 딕셔너리를 담아 여러 설비 정보를 한 번에 표현할 수 있다.

선수 지식: 1차시 — 변수·자료형·출력

📚 다룰 이론 주제(초안)

  • 리스트 생성, 인덱싱, 슬라이싱
  • 리스트에 값 추가하기(append), 길이(len)
  • 딕셔너리 생성, 키로 값 접근, 값 수정
  • 리스트 안에 딕셔너리 담기 — 여러 설비를 한 번에 표현

🐍 다룰 실습 흐름(초안)

  1. 온도 여러 개를 리스트에 담기
  2. 리스트에서 최댓값·최솟값·평균 직접 계산하기
  3. 설비 1대의 정보(설비번호·공정명·온도)를 딕셔너리로 표현하기
  4. 여러 설비를 '딕셔너리의 리스트'로 표현하기
  5. 리스트 안 딕셔너리에서 특정 설비의 값 꺼내기
