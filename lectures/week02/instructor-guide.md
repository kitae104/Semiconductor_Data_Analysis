# 2차시 강의 운영안 — 리스트와 딕셔너리

## 수업 흐름

1. 지난 시간 복습: 1차시에서 만든 변수(`pass_count = 34`)를 다시 띄우고, "값 하나"의 한계를 체감시키기
2. 오늘의 질문 제시 — "여러 개의 측정값을 한 번에 담고, 각 값에 이름표까지 붙이려면 어떻게 해야 할까?"
3. 리스트 개념 설명(생성, 인덱싱, 슬라이싱, len/append) + 용어 카드
4. 강사 코드 시연: 리스트 만들기 → 인덱싱/슬라이싱 → max/min/sum/평균
5. 딕셔너리 개념 설명(생성, 키로 값 접근, 값 수정/새 키 추가)
6. 강사 코드 시연: 딕셔너리 만들기 → 값 접근 → 리스트 안에 딕셔너리 담기
7. 휴식
8. 학생 실습: 리스트 만들기 → 인덱싱/슬라이싱 → 통계 계산 → 딕셔너리 → 딕셔너리의 리스트 → 종합 실습
9. 도전 실습: 딕셔너리의 리스트에서 최댓값을 가진 항목 찾기
10. 정리 퀴즈 + 과제 안내 + 다음 차시 예고

## 준비물
- 발표자용 에디터 실습 환경, 프로젝터
- `data/weekly/week02/week02_python_basics_1.csv` (참고 자료용 — 오늘은 이 CSV를 Pandas로 읽지
  않고, 값을 리스트/딕셔너리 리터럴로 직접 옮겨 적어 사용한다)

## 강사 설명 포인트
- 리스트를 소개하기 전에 "변수 하나에는 값을 하나만 담을 수 있다"는 1차시의 한계를 반드시
  먼저 체감시킨다. 리스트가 "왜 필요한지" 동기부여가 없으면 개념이 겉돈다.
- 리스트 인덱스가 0부터 시작한다는 점은 이번 차시에서 가장 많이 틀리는 지점이다. 상자 그림을
  칠판에 그려 "첫 번째 상자의 번호표가 0"이라는 것을 눈으로 반복해서 보여준다.
- 딕셔너리를 소개할 때는 리스트와 곧바로 비교한다 — "리스트는 순서로, 딕셔너리는 이름표로
  값을 구분한다"는 문장을 칠판에 나란히 적어두고 수업 내내 참조한다.
- "리스트 안에 딕셔너리를 담는다"는 개념은 이번 차시의 핵심 도약이다. 3장의 카드가 든 상자
  그림(강의 자료의 SVG 참고)으로 설명하면 4차시 Pandas의 표(행=딕셔너리 하나, 표 전체=리스트)
  개념과 자연스럽게 연결된다.

## 질문 예시
- "어제 배운 변수 하나로 온도 측정값 5개를 모두 저장하려면 어떻게 해야 할까요?"
- "리스트의 첫 번째 값을 꺼내려면 인덱스 몇 번을 써야 할까요? (0이라는 답이 나올 때까지 유도)"
- "설비번호, 공정명, 온도를 리스트 하나에 순서대로 담아두면 나중에 헷갈리지 않을까요? (딕셔너리로 자연스럽게 연결)"

## 예상 오개념
- 리스트 인덱스가 1부터 시작한다고 착각 → 실제로 `list[1]`을 실행해 "두 번째" 값이 나오는 것을
  직접 보여준다.
- 슬라이싱 `[1:3]`에 인덱스 3의 값까지 포함된다고 착각 → "끝 인덱스는 포함되지 않는다"를
  실제 실행 결과로 반복 확인시킨다.
- 딕셔너리도 리스트처럼 `[0]`으로 접근하려 시도 → `TypeError`(또는 `KeyError`)가 나는 것을
  직접 보여주고, "딕셔너리는 키로만 접근한다"고 짚어준다.
- 리스트는 `[ ]`, 딕셔너리는 `{ }`를 혼동 → "순서만 있으면 대괄호, 이름표가 있으면 중괄호"로
  암기 문구를 함께 반복한다.
- f-string 안에서 딕셔너리 키에 큰따옴표를 중복 사용해 `SyntaxError` 발생 → f-string 바깥이
  큰따옴표면 안쪽 딕셔너리 키는 작은따옴표를 써야 한다는 규칙을 강조한다.

## 실습 중 오류 대응
- `IndexError: list index out of range`: `len()`으로 리스트 길이를 먼저 확인하게 한다.
- `KeyError`: `print(딕셔너리이름)`으로 전체 키를 먼저 출력해 정확한 키 이름을 확인하게 한다.
- `SyntaxError`(따옴표 중복): f-string 바깥/안쪽 따옴표 종류가 다른지 확인하게 한다.
- 대괄호 `[]`와 중괄호 `{}`를 혼동해 오류가 나는 경우: 리스트인지 딕셔너리인지 다시 묻고
  올바른 기호로 고치게 한다.

## 빠른 학습자용 추가 과제
- 강의 자료의 "도전 문제 1"(딕셔너리의 리스트에서 온도만 모은 새 리스트 만들어 `max()` 적용)을
  먼저 시도해보게 한다.
- 딕셔너리에 `keys()`, `values()`를 검색해서 스스로 사용해보게 한다(3차시 반복문 예고 겸용).

## 느린 학습자용 최소 과제
- 리스트 인덱싱(`temperatures[0]`, `temperatures[-1]`)까지만 성공해도 충분하다. 슬라이싱과
  딕셔너리는 강사·동료와 함께 짝 활동으로 진행한다.
- 딕셔너리는 미리 만들어진 `equipment` 예시에서 값을 꺼내보는 것(`equipment["설비번호"]`)만
  성공해도 이번 차시 최소 목표는 달성한 것으로 인정한다.
