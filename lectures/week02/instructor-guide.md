# 2차시 강의 운영안 — 리스트와 딕셔너리

## 왜 이걸 배워야 할까? (학생에게 전달할 메시지)

공장의 온도 센서는 하루에도 여러 번 온도를 잰다. 1차시의 변수는 상자 하나에 값 하나라서, 값이 여러 개면
변수를 여러 개 만들어야 한다. 오늘은 여러 값을 한 줄로 담는 **리스트**와, 값마다 이름표를 붙이는 **딕셔너리**를 배운다.

**예를 들면**: 어떤 설비의 하루 온도 6건의 평균은 301.2도로 학습용 정상 범위(295~305도) 안이다. 그런데 값을 하나씩
늘어놓으면 한 번은 312.6도까지 올라갔다. 여러 값을 한 번에 담아 두어야 평균·최고·최저를 함께 보고 이런 "튀는 값"을
놓치지 않는다. 1차시의 "여러 열 함께 보기"와 같은 생각을, 오늘은 "한 열 안의 여러 값"에 적용한다.

## 수업 흐름

1. 지난 시간 복습: 변수 = 상자 하나에 값 하나(`pass_count = 32`), f-string, 표의 행과 열, 합격여부 1/-1,
   "불합격 8건을 공정명과 함께 보니 세정에 몰려 있었다". 오늘은 "상자 여러 개를 한 줄로", "값마다 이름표".
2. 리스트(STEP 01): 오늘 값이 공장에서 무엇인지(한 설비의 온도 센서가 하루 동안 잰 온도) → 번호 붙은 약통 비유 →
   과일 리스트 → 온도 리스트 → 인덱스(0부터인 이유: "맨 앞에서 몇 칸 떨어졌나", 자의 눈금) → 슬라이싱(칼금 그림,
   끝 번호 칸은 빠짐, 개수 = 끝 - 시작) → `len`/`append`/빈 리스트 → `max`/`min`/`sum`/평균
3. "왜 여러 값을 함께 봐야 할까": 첫 값·평균·최저·최고를 정상 범위와 나란히 놓은 표, 하루 체온 비유
4. 휴식
5. 딕셔너리(STEP 02): 리스트로 설비 기록을 담을 때의 불편함 → 이름표 붙은 사물함·국어사전 비유 → 리스트와 비교표 →
   `person` → `equipment` → 키로 꺼내기·KeyError → 값 바꾸기·키 추가(합격여부 1 = 합격) → 따옴표 규칙
6. 딕셔너리의 리스트(STEP 03): 표 그림(리스트 칸 번호 열 포함) → "표의 한 행 = 딕셔너리 하나, 열 이름 = 키,
   표 전체 = 리스트" → `[행 번호]["열 이름"]` → 종합 실습(오늘 데이터 앞 3행 `records`, `row = records[1]`)
7. 학생 실습(STEP 04): 학생용 노트북 1~9단계. 먼저 끝난 학생은 9단계 끝 도전 문제 1·2(강의 STEP 05)
8. AI 활용(노트북 10·11단계) → 연습문제(12단계, EQ-02 온도 요약) → 럭키 설비 미니 프로그램(13단계)
9. 정리 퀴즈 + 과제 안내 + 3차시 예고

## 강사 설명 포인트
- **"왜 리스트가 필요한지"를 먼저.** `temp1`~`temp5` 변수 다섯 개를 칠판에 적어 보이고 "100개면?"이라고 묻는다.
- **인덱스 0은 그림으로 반복한다.** 약통 칸 그림 아래 번호를 0부터 적고, "번호 = 맨 앞 칸에서 몇 칸 떨어졌나"를 말로 반복한다.
  `temperatures[1]`을 실행해 298.1(두 번째 값)이 나오는 것을 직접 보여준다.
- **슬라이싱은 "칼금 두 개" 그림으로.** 칸 사이 경계에 번호를 적고 1번과 3번 경계에서 자른다. "끝 번호 칸은 빠진다"와
  "개수 = 끝 - 시작" 두 문장만 기억하게 한다.
- **"튀는 값" 표에서 멈춘다.** 첫 값·평균·최저·최고를 정상 범위와 나란히 놓은 표를 보여주고 "평균만 보고 보고서를 쓰면
  무엇을 놓칠까요?"라고 묻는다. 1차시의 "여러 열 함께 보기"와 같은 생각이라고 연결한다.
- **튀는 값 = 불량이 아니다.** 종합 실습의 LOT-0097(308.7도, 합격 1)을 예로 "온도 하나로 불량이라고 단정할 수 없다"를
  짚는다. 1차시 "원인 후보" 이야기와 같은 결이다. 오늘은 단정하지 않는 습관만 강조하고, 계산은 7~8차시에서 한다.
- **딕셔너리는 리스트와 나란히 비교한다.** 리스트·딕셔너리 비교표를 칠판에 적어두고 수업 내내 가리킨다.
  "만들 때만 괄호가 다르고, 꺼낼 때는 둘 다 대괄호"를 강조한다.
- **딕셔너리의 리스트는 표 그림이 핵심이다.** 강의의 표(리스트 칸 번호 열 포함)를 띄우고 "가로 한 줄 = 딕셔너리 하나,
  맨 윗줄 = 키, 표 전체 = 리스트"를 손으로 짚는다. 이 그림이 3차시 `for` 반복과 4차시 Pandas 표로 그대로 이어진다.
- `합격여부`는 1 = 합격, -1 = 불합격. 7단계(`equipment["합격여부"] = 1`)와 9단계(`records`)에서 다시 말한다.

## 예상 오개념
- 인덱스가 1부터 시작한다고 착각 → `temperatures[1]` 실행 결과(298.1)로 직접 확인. 마지막 칸 번호는 "칸 수 - 1".
- 음수 인덱스를 오류로 생각 → `-1`은 "뒤에서 첫 번째"라는 정상 기능이다.
- 슬라이싱 `[1:3]`에 3번 칸까지 들어간다고 착각 → 칼금 그림과 실행 결과 `[298.1, 312.6]`.
- 평균이 범위 안이면 모든 값이 범위 안이라고 생각 → 평균 301.2 / 최고 312.6 표.
- 범위를 벗어난 값 = 불량이라고 생각 → LOT-0097(308.7도, 합격 1).
- 딕셔너리도 `[0]`으로 꺼낼 수 있다고 생각 → `KeyError: 0`을 보여주고 "딕셔너리는 키로만".
- 딕셔너리의 리스트에서 꺼내는 순서를 거꾸로 씀 → "행 번호 먼저, 열 이름 다음"(극장 좌석 "몇 번째 줄, 무슨 자리").
- `temperatures = temperatures.append(303.2)`처럼 다시 저장 → `append()`는 돌려주는 값이 없어 `None`이 된다.

## 실습 중 오류 대응
아래는 모두 노트북 코드로 직접 실행해 확인한 메시지다(Python 3.11).
- `NameError: name '____' is not defined`: 빈칸을 채우지 않고 실행했다. 빈칸을 채우게 한다.
  `temperatures.____(303.2)`처럼 점 뒤의 빈칸은 `AttributeError: 'list' object has no attribute '____'`로 나온다.
- `NameError: name 'temperatures' is not defined`: 1단계 셀을 실행하지 않았다. 맨 위 셀부터 차례대로 실행하게 한다.
- `IndexError: list index out of range`: `temperatures[5]`처럼 없는 칸 번호를 썼다. `len()`으로 칸 수를 확인하게 한다.
- `KeyError: '압력_Pa'` / `KeyError: 0`: 없는 키를 썼거나 딕셔너리에 번호를 넣었다. `print(equipment)`로 키를 확인하게 한다.
  띄어쓰기·밑줄 오타(`온도 섭씨`)도 같은 오류다.
- `SyntaxError: f-string: unmatched '['`: f-string 안에서 큰따옴표를 겹쳐 썼다(`f"{equipment["공정명"]}"`).
  안쪽 키를 작은따옴표로 바꾸게 한다.
- `TypeError: list indices must be integers or slices, not str`: `equipment_list["온도_섭씨"][1]`처럼 순서를 바꿨다.
  `equipment_list[1]["온도_섭씨"]`로 고치게 한다.
- `TypeError: 'NoneType' object is not iterable`: `temperatures = temperatures.append(303.2)`로 다시 저장한 뒤 `max()`를 썼다.
  1단계부터 다시 실행하고 `append` 줄은 저장 없이 한 줄로 쓰게 한다.
- 4단계 마지막 줄이 7 이상, 도전 2의 `len(records)`가 5 이상: `append` 셀을 여러 번 실행했다. 각각 1단계, 9단계 첫 셀부터 다시 실행.
- `SyntaxError: ':' expected after dictionary key`: 딕셔너리에서 키 뒤의 콜론을 빠뜨렸다(`{"a": 1, "b" 2}`).
