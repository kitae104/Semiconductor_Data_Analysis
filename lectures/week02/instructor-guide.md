# 2차시 강의 운영안 — 리스트와 딕셔너리

## 왜 이걸 배워야 할까? (학생에게 전달할 메시지)

센서는 하루에도 여러 번 잰다. 여러 값을 한 줄로 담는 **리스트**, 값마다 이름표를 붙이는 **딕셔너리**를 배운다.
하루 온도 6건의 평균 301.2도는 정상 범위(295~305도) 안이지만 한 번은 312.6도까지 올랐다. 여러 값을 함께 봐야 보인다.

수업 방식: 개념은 **쉬운 예제**(지어낸 생활 값)로만 설명 → 강의 STEP 04 **반도체 데이터로 확인하기**에서 핵심 2개만 시연 →
실습지·노트북 8~10단계에서 **반도체 데이터로 문제 1~9**를 푼다.

## 수업 흐름

1. 복습: 변수·f-string, 표의 행과 열, 합격여부 1 = 합격 / -1 = 불합격
2. STEP 01 리스트(쉬운 예제만): 일주일 기온 인덱스·`[1]` 함정·IndexError / 평일·주말 슬라이싱 / 장바구니 `len`·`append`·빈 리스트 /
   이번 주 기온 요약(평균 24.3, 수요일 30.5)
3. 휴식
4. STEP 02 딕셔너리: 학생 정보 만들기·꺼내기·KeyError / 값 바꾸기·키 추가·따옴표 규칙
5. STEP 03 딕셔너리의 리스트: 친구 3명 표, `friends[1]["이름"]`, 친구 소개 문장
6. STEP 04 반도체 데이터로 확인하기(강사 시연): 확인 1 하루 온도 6건 최고·최저·평균(튀는 값 표) / 확인 2 CSV 3행 `records`, 두 열 함께 읽기(답은 접혀 있음 — 먼저 묻고 연다)
7. STEP 05 학생 실습: 노트북 1~7단계(쉬운 예제 실행) → 8~10단계(실습지 문제 1~9, 반도체 데이터). 실습지 문제 10(오류 찾기)은 손으로.
8. AI 활용(노트북 11·12단계) → 퀴즈·과제·3차시 예고

## 강사 설명 포인트
- 개념 설명은 쉬운 예제로만 한다. 실습지 문제마다 "쉬운 예제의 어느 줄과 같은 모양일까요?"를 묻고, 바뀌는 이름(`week_temps` → `temperatures` 등)만 칠판에 적는다.
- 인덱스 0: 칸 그림의 "월 = 0번"을 가리키며 "맨 앞에서 몇 칸 떨어졌나"를 반복한다.
- 슬라이싱: "끝 칸은 빠진다", "개수 = 끝 - 시작" 두 문장만.
- 튀는 값: 쉬운 예제(평균 24.3 / 수요일 30.5)로 먼저 느끼게 하고, 확인 1 표에서 멈춘다. 튀는 값 = 불량이 아니라는 것은 확인 2(308.7도, 합격 1)로 짚는다.
- 딕셔너리의 리스트: 표를 손으로 짚으며 "행 = 딕셔너리, 열 이름 = 키, 표 = 리스트". 3차시 `for`, 4차시 Pandas로 이어진다.
- 합격여부 1 = 합격, -1 = 불합격을 확인 2와 실습지 문제 7·9에서 다시 말한다.

## 예상 오개념
- 인덱스가 1부터 → `week_temps[1]`이 화요일(23.0)인 것으로 확인.
- `-1`을 오류로 생각 → 마지막 칸이라는 정상 기능.
- `[1:3]`에 3번 칸까지 들어간다고 생각 → 칼금 그림, `[23.0, 30.5]`.
- 평균이 범위 안이면 모두 범위 안 → 평균 301.2 / 최고 312.6.
- 범위 밖 = 불량 → LOT-0097(308.7도, 합격 1).
- 딕셔너리도 `[0]`으로 꺼낸다 → `KeyError: 0`.
- 쉬운 예제 이름을 문제에 그대로 씀(`week_temps`) → 오류 없이 20 근처 값이 나온다. 결과 크기로 알아챈다.

## 실습 중 오류 대응
아래는 모두 노트북 코드로 직접 실행해 확인한 메시지다(Python 3.11).
- `NameError: name '____' is not defined`: 빈칸을 안 채웠다. 점 뒤 빈칸은 `AttributeError: 'list' object has no attribute '____'`.
- `NameError: name 'temperatures' is not defined`: 위 셀을 건너뛰었다. 맨 위부터 실행.
- `IndexError: list index out of range`: 없는 칸 번호(`week_temps[7]`, `temperatures[5]`). `len()`으로 확인.
- `KeyError: '혈액형'` / `KeyError: '압력_Pa'` / `KeyError: 0`: 없는 키·오타·번호 사용. `print(student)`로 키 확인.
- `SyntaxError: f-string: unmatched '['`: f-string 안 큰따옴표 겹침. 안쪽 키를 작은따옴표로. 파이썬 3.12 이상에서는 오류가 나지 않는다(강의와 다르다는 질문이 나오면 버전 차이라고 답한다).
- `TypeError: list indices must be integers or slices, not str`: `friends["이름"][1]`, `equipment_list["온도_섭씨"][1]`처럼 순서를 바꿨다. `[행 번호]` 먼저.
- `TypeError: 'NoneType' object is not iterable`: `temperatures = temperatures.append(303.2)` 뒤 `max()`. 8단계 첫 셀부터 다시 실행.
- 문제 3 마지막 줄이 7 이상: append 셀을 여러 번 실행했다. 8단계 첫 셀부터 다시 실행.
- `SyntaxError: ':' expected after dictionary key`: 키 뒤 콜론 누락(`{"a": 1, "b" 2}`).
