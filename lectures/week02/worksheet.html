리스트와 딕셔너리 — 실습지

왜 이걸 배워야 할까?

  • 공장의 센서는 하루에도 여러 번 값을 잰다. 여러 값을 한 번에 담아야 평균·최고·최저를 함께 보고 "튀는 값"을 찾을 수 있다(리스트).
  • 숫자만 있으면 어느 설비의 무슨 값인지 모른다. 값마다 이름표를 붙여 둔다(딕셔너리).
  • 딕셔너리를 리스트에 여러 개 담으면 표가 된다. 4차시에 배우는 표 데이터의 기초다.

모든 숫자는 교육용 가상 데이터다. 정상 온도 범위 295~305도는 이 과정에서 정한 학습용 기준이다.

1. 용어 연결 문제

왼쪽 용어와 오른쪽 설명을 알맞게 연결해보자.

용어설명 후보
① 리스트A. 값마다 이름표(키)를 붙여 담는 묶음. 중괄호 { }
B. 리스트에서 칸의 위치 번호(0부터 센다)
C. 여러 값을 순서대로 한 줄에 담는 묶음. 대괄호 [ ]
D. 딕셔너리에서 값을 찾는 이름표
② 딕셔너리
③ 인덱스
④ 키
① C ② A ③ B ④ D. 리스트 = 번호 붙은 약통, 딕셔너리 = 이름표 붙은 사물함.

2. 인덱스 빈칸 문제

강의의 온도 리스트로 빈칸을 채워보자. (노트북 2단계와 같은 문제)

Python
temperatures = [295.4, 298.1, 312.6, 301.0, 296.8]

print(temperatures[____])    # 첫 번째 값 295.4
print(temperatures[____])    # 세 번째 값 312.6
print(temperatures[____])    # 마지막 값 296.8 (뒤에서부터 세기)
순서대로 0, 2, -1. 번호는 "맨 앞 칸에서 몇 칸 떨어졌나"라서 첫 칸이 0번이다. 칸이 5개면 번호는 0~4번이고, temperatures[5]는 IndexError가 난다.

같은 temperatures(값 5개)로 실행하면 무엇이 나올지 먼저 적어보자.

[298.1, 312.6], [295.4, 298.1], [301.0, 296.8]. 끝 번호 칸은 빠지고, 꺼내지는 개수는 끝 - 시작이다([1:3]은 2개).

4. 최고·최저·평균 계산 문제

오늘 데이터 파일에서 EQ-03 설비의 기록 7건의 온도를 옮겨 왔다.

eq03_temps = [303.8, 303.4, 292.2, 308.5, 307.5, 298.5, 304.0]
  1. 최고값, 최저값을 구하는 코드를 쓰고 값을 적어보자.
  2. 평균을 구하는 코드를 쓰고, 소수 첫째 자리까지 적어보자.
  3. 최고값과 최저값은 각각 몇 번 칸에 있는가?

노트북 5단계 코드에서 리스트 이름만 바꿔 실행해 확인해도 된다.

1) max(eq03_temps) → 308.5, min(eq03_temps) → 292.2
2) sum(eq03_temps) / len(eq03_temps) → 2117.9 ÷ 7 = 302.557… → 302.6도
3) 최고 308.5는 3번 칸(네 번째 값), 최저 292.2는 2번 칸(세 번째 값)

5. 결과 해석 문제 — 평균에 숨는 값

4번 문제의 결과를 학습용 정상 범위(295~305도)와 비교해보자.

  1. 평균 302.6도는 정상 범위 안인가?
  2. 7개 값 중 정상 범위를 벗어난 값은 몇 개이고, 무엇인가?
  3. 평균만 보고 "EQ-03 온도 정상"이라고 보고하면 무엇을 놓치는가?
1) 안이다. 2) 3개 — 292.2(범위보다 낮음), 308.5, 307.5(범위보다 높음). 3) 평균은 높은 값과 낮은 값이 섞여 가운데로 모이기 때문에, 위아래로 범위를 벗어난 값 3개가 드러나지 않는다. 평균·최고·최저를 함께 봐야 한다.

6. 딕셔너리 결과 예측 문제

아래 코드를 실행하면 무엇이 출력될지 예측해보자.

Python
equipment = {"설비번호": "EQ-01", "공정명": "식각", "온도_섭씨": 301.2}
equipment["온도_섭씨"] = 305.5
equipment["합격여부"] = 1
print(equipment["온도_섭씨"])
print(equipment)
305.5 그리고 {'설비번호': 'EQ-01', '공정명': '식각', '온도_섭씨': 305.5, '합격여부': 1}. 있던 키(온도_섭씨)는 값이 바뀌고, 없던 키(합격여부)는 새로 생긴다. 합격여부 1 = 합격, -1 = 불합격.

8. 오류 찾기 문제

아래 세 줄은 각각 오류가 난다. 무슨 오류인지, 어떻게 고치면 되는지 적어보자.

Python — 오류 있는 코드
temperatures = [295.4, 298.1, 312.6, 301.0, 296.8]
equipment = {"설비번호": "EQ-01", "온도_섭씨": 301.2}

print(temperatures[5])          # (가)
print(equipment["압력_Pa"])     # (나)
print(equipment[0])             # (다)
(가) IndexError: list index out of range — 칸은 0~4번뿐이다. 마지막 값은 temperatures[4] 또는 temperatures[-1].
(나) KeyError: '압력_Pa' — 없는 이름표다. print(equipment)로 있는 키를 확인한다.
(다) KeyError: 0 — 딕셔너리는 칸 번호가 아니라 키로 꺼낸다. equipment["설비번호"]처럼 쓴다.

9. 분석 문장 쓰기

노트북 9단계에서 꺼낸 행은 다음과 같았다.

LOT-0097 로트: EQ-04 설비, 포토 작업
온도 308.7도, 합격여부 1
문장 작성 온도와 합격여부를 함께 보고 빈칸을 채워보자. "LOT-0097의 온도는 ____도로 학습용 정상 범위를 (벗어났다 / 벗어나지 않았다). 그런데 합격여부는 ____(____)이다. 그래서 온도 하나만 보고 ____라고 단정할 수 없다."
"LOT-0097의 온도는 308.7도로 학습용 정상 범위를 벗어났다. 그런데 합격여부는 1(합격)이다. 그래서 온도 하나만 보고 불량이라고 단정할 수 없다."

10. 도전 — 온도만 모으기, 행 추가하기

도전 노트북 9단계의 records(앞 3행)로 두 가지를 해보자. (노트북 9단계 끝 "도전 문제 1·2")
  1. 세 행의 온도_섭씨만 꺼내 record_temps 리스트를 만들고 max()로 최고 온도를 구한다.
  2. 4번째 행(LOT-0160, 포토, EQ-04, 295.7, 1)을 딕셔너리로 만들어 records.append(...)로 붙이고 len(records)를 확인한다.
체크포인트 1) record_temps는 [302.5, 308.7, 303.8], 최고는 308.7(1번 행, LOT-0097). 2) len(records)가 4면 성공이다. 5 이상이 나오면 append 셀을 여러 번 실행한 것이니 9단계 첫 셀부터 다시 실행한다.
