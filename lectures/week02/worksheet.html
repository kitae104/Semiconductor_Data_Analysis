오늘의 미션: 팀장이 설비 EQ-03의 온도 7개를 메모로 줬다(설비 온도 기록표 week02_python_basics_1.csv에서 옮긴 값, 교육용 가상 데이터). 최고·최저·평균을 정리해 보고하자.

문제 1. EQ-03 온도 리스트의 첫 값·마지막 값·개수 (노트북 7단계 문제 1)

EQ-03 온도 리스트에서 첫 값과 마지막 값을 꺼내고, 값이 몇 개인지 세자. 첫 줄 결과가 303.8이 아니면 칸 번호를 다시 본다.

힌트: 강의 "리스트" 절의 week_temps[0], week_temps[-1]과 "개수 세고 값 더하기" 절의 len(cart)와 같은 모양이다. ____는 빈칸 표시일 뿐이라, 밑줄 개수와 상관없이 필요한 만큼 쓴다.

Python — 첫 값·마지막 값
eq03_temps = [303.8, 303.4, 292.2, 308.5, 307.5, 298.5, 304.0]
# TODO: 첫 값과 마지막 값의 칸 번호를 채우세요.
print(eq03_temps[____])
print(eq03_temps[____])
Python — 개수
# TODO: 리스트의 개수를 세는 함수 이름을 채우세요.
print(____(eq03_temps))
빈칸은 순서대로 0, -1(또는 6), 그리고 len. 출력은 303.8, 304.0, 7이다.
첫 칸은 1번이 아니라 0번이다. 칸이 7개라 [7]을 쓰면 IndexError가 난다. 대괄호 대신 소괄호(eq03_temps(0))를 쓰면 TypeError: 'list' object is not callable이 난다.

문제 2. EQ-03 최고·최저·평균 온도 (노트북 7단계 문제 2)

EQ-03 온도의 최고와 최저를 구하고, 평균을 보고 문장으로 출력하자.

힌트: 강의 "최고·최저·평균 구하기" 절의 max(week_temps)와 average = round(sum(week_temps) / len(week_temps), 1)과 같은 모양이다.

주의 강의 확인 1의 eq02_temps가 아니라 eq03_temps를 넣는다. 다른 리스트를 쓰면 오류 없이 다른 설비의 숫자가 나온다.
Python — 최고·최저
# TODO: 가장 큰 값과 가장 작은 값을 구하는 함수 이름을 채우세요.
print(____(eq03_temps))
print(____(eq03_temps))
Python — 평균 문장
# TODO: 합계를 구하는 함수 이름을 채우세요.
eq03_avg = round(____(eq03_temps) / len(eq03_temps), 1)
print(f"EQ-03 평균 온도는 {eq03_avg}도입니다.")
빈칸은 순서대로 max, min, 그리고 sum. 출력은 308.5, 292.2, EQ-03 평균 온도는 302.6도입니다.
합계 2117.9 ÷ 개수 7 = 302.557…을 소수 첫째 자리로 반올림해 302.6이다. EQ-03의 기록 7건은 온도가 292.2도에서 308.5도까지 기록마다 다르다.

문제 3. EQ-04 온도 8개로 report 딕셔너리 직접 만들기 (노트북 7단계 문제 3)

팀장이 설비 EQ-04도 같은 모양으로 정리해 달라고 했다. 이번에는 빈칸이 없다. 최고·최저·평균을 구해 report 딕셔너리로 묶고, 평균만 꺼내 출력하는 코드를 직접 쓰자.

힌트: 문제 2의 평균 계산(round(sum(…) / len(…), 1))과 강의 "딕셔너리" 절의 student = {"이름": "지민", …} 모양을 그대로 쓰고, 이름만 eq04로 바꾼다. 이름표는 "설비번호"·"최고"·"최저"·"평균" 네 개다.

주의 — 따옴표 이름표(키)는 따옴표로 감싸고, 변수 이름(eq04_avg)은 따옴표 없이 쓴다. "평균": "eq04_avg"처럼 따옴표를 붙이면 오류 없이 숫자 대신 글자 'eq04_avg'가 들어간다.
Python — report 만들기
eq04_temps = [308.7, 295.7, 316.6, 294.2, 317.9, 298.1, 312.4, 303.0]
# TODO: 문제 2처럼 평균(eq04_avg)을 구하고, "설비번호"·"최고"·"최저"·"평균" 이름표로 report 딕셔너리를 만들어 출력하세요.
Python — 평균 꺼내기
# TODO: report에서 평균을 꺼내 출력하세요.
Python — 풀이 예시
eq04_temps = [308.7, 295.7, 316.6, 294.2, 317.9, 298.1, 312.4, 303.0]
eq04_avg = round(sum(eq04_temps) / len(eq04_temps), 1)
report = {
    "설비번호": "EQ-04",
    "최고": max(eq04_temps),
    "최저": min(eq04_temps),
    "평균": eq04_avg,
}
print(report)

print(report["평균"])
출력: {'설비번호': 'EQ-04', '최고': 317.9, '최저': 294.2, '평균': 305.8}, 305.8
변수 이름이 달라도 출력이 같으면 맞다. 키에 따옴표를 빼고 report[평균]으로 쓰면 NameError: name '평균' is not defined가 난다. 첫째 셀이 실패한 채 둘째 셀을 실행하면 NameError: name 'report' is not defined가 난다.

문제 4. Orange로 단 하나뿐인 불합격 기록 찾기

Orange 3.35에서 week02_2_temps_start.ows를 연다(강의 PART 2에서 이어 붙인 화면이 있으면 그대로 써도 된다). 오늘 표 20건 가운데 불합격(합격여부 = -1)은 한 건뿐이다.

  1. File 위젯에 Data Table(표 보기)을 잇고 더블클릭한다.
  2. 합격여부 열 머리를 두 번 눌러 -1 행을 맨 위로 올린다(한 번 누르면 -1 행이 맨 아래로 간다).
  3. 그 행의 설비번호와 온도_C를 읽는다.
적어 보기 불합격 기록: 설비 ______ · 온도 ______도.
표 전체 평균(강의 PART 2의 Mean) 303.8도보다 ______도 (높다 / 낮다). 문제 3의 같은 설비 평균 ______도보다 (높다 / 낮다).
이 불합격 기록보다 온도가 더 높은데 합격(1)인 기록이 있을까? (있다 / 없다)
체크포인트 불합격 기록은 EQ-04 · 312.4도(LOT-0184, 식각)다. 표 전체 평균 303.8도보다 8.6도 높고, 문제 3의 EQ-04 평균 305.8도보다도 높다.
그런데 같은 EQ-04의 317.9도·316.6도 기록은 합격이다(있다). 온도가 높다고 모두 불합격은 아니다 — 불합격 한 건만으로 "온도가 높아서 불합격"이라고 말할 수 없다. 온도와 판정의 관계는 3차시에 규칙으로 다시 본다.
막혔으면 같은 폴더의 week02_2_temps_done.ows를 연다.

문제 5. 해석 문장 쓰기

EQ-03 결과를 팀장에게 보고하는 문장을 완성하고, 이어지는 질문에 한 문장으로 답하자. 표 전체 평균은 강의 PART 2의 Feature Statistics Mean(303.8도)이다.

문장 작성 ① "EQ-03 온도 ____건은 최저 ______도에서 최고 ______도이고, 평균 ______도는 표 전체 평균 303.8도보다 (높다 / 낮다)."
② 이 숫자만으로 EQ-03이 문제 있는 설비라고 말할 수 있을까? 그렇게 생각한 이유와 함께 한 문장으로: ____________________________

힌트: EQ-03 기록의 합격여부와 기록 수를 떠올려 보자. 1차시 "숫자 하나로는 모르는 것"과 같은 질문이다.

① "EQ-03 온도 7건은 최저 292.2도에서 최고 308.5도이고, 평균 302.6도는 표 전체 평균 303.8도보다 낮다."
② "말할 수 없다. 기록이 7건뿐이고, EQ-03의 7건은 모두 합격이며, 온도가 평균보다 높거나 낮다는 것만으로는 좋고 나쁨을 판단할 기준이 없기 때문이다."
평균과 함께 최저·최고를 보고하면 "기록마다 온도가 16도 넘게 다르다"는 것까지 전할 수 있다. 문제 설비인지는 검사 결과와 더 많은 기록으로 따로 확인한다.
