3. 계산 문제

어느 공정의 압력 측정값 리스트가 아래와 같다.

pressures = [1000.0, 1010.0, 1020.0, 990.0]

이 리스트의 평균, 최댓값, 최솟값을 각각 계산해보자.

합계 = 1000.0+1010.0+1020.0+990.0 = 4020.0, 개수 = 4
평균 = 4020.0 ÷ 4 = 1005.0
최댓값 = 1020.0, 최솟값 = 990.0

4. 결과 해석 문제

2주차 데이터(25건)를 계산한 결과가 아래와 같았다.

전체 평균: 301.9
전체 최댓값: 320.0  전체 최솟값: 289.3
수율: 23/25 = 92.0%

이 결과를 보고 "정상범위(295~305℃)를 벗어난 값이 있는가?"와 "수율이 몇 %인가?"를 한 문장씩 적어보자.

최댓값 320.0℃와 최솟값 289.3℃ 모두 정상범위(295~305℃)를 벗어났다. 수율은 92.0%로, 25건 중 23건이 합격했다.
