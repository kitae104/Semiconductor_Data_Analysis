문제 1. 인덱스로 꺼내기 (노트북 8단계)

한 설비가 하루에 다섯 번 잰 온도에서 세 번째 값과 마지막 값을 꺼내자.
힌트: 쉬운 예제 week_temps[2], week_temps[-1]과 같은 모양.

Python
temperatures = [295.4, 298.1, 312.6, 301.0, 296.8]
print(temperatures[0])    # 첫 번째 값
print(temperatures[____])    # 세 번째 값
print(temperatures[____])   # 마지막 값
2, -1 → 295.4, 312.6, 296.8. 세 번째 측정 312.6이 정상 범위를 넘었다.

문제 2. 슬라이싱 (노트북 8단계)

1번·2번 칸(298.1, 312.6)을 한 번에 꺼내고, 나머지 두 줄의 결과를 예측하자.
힌트: 쉬운 예제 week_temps[1:3]과 같은 모양. 끝 칸은 빠진다.

Python
print(temperatures[____:____])   # 1번 칸부터 3번 칸 앞까지
print(temperatures[:2])    # 처음부터 2번 칸 앞까지
print(temperatures[2:])    # 2번 칸부터 끝까지
1:3 → [298.1, 312.6], [295.4, 298.1], [312.6, 301.0, 296.8]

문제 3. 개수 세기와 추가 (노트북 8단계)

칸 수를 세고, 오후에 잰 303.2를 끝에 붙이자(셀은 한 번만 실행).
힌트: 쉬운 예제 len(cart), cart.append("사과")와 같은 모양.

Python
print(____(temperatures))

temperatures.____(303.2)
print(temperatures)
print(len(temperatures))
len, append → 5, [295.4, 298.1, 312.6, 301.0, 296.8, 303.2], 6. 7이 나오면 append 셀을 두 번 실행한 것이다.

문제 4. 최고·최저·평균 (노트북 8단계)

값 6개(문제 3에서 303.2를 붙인 리스트)의 최고·최저·합계·평균을 구하고, "오늘 온도는 정상"이라고 말해도 되는지 한 문장으로 적자.
힌트: 쉬운 예제 "이번 주 기온 요약"에서 week_temps를 temperatures로 바꾼다.

Python
temperatures = [295.4, 298.1, 312.6, 301.0, 296.8, 303.2]   # 하루 6번 잰 온도
print(len(temperatures))

print(____(temperatures))
print(____(temperatures))
print(sum(temperatures))

average = ____(temperatures) / ____(temperatures)
print(f"평균 온도는 {average:.1f}도입니다.")
max, min, sum, len → 6, 312.6, 295.4, 1807.1, 평균 온도는 301.2도입니다.
평균은 정상 범위 안이지만 최고 312.6도(2번 칸)는 7.6도 넘었다. 평균만 보고 정상이라고 하면 이 값을 놓친다.

문제 5. EQ-03 설비 온도 7건 요약 (노트북 8단계)

오늘 데이터 파일의 EQ-03 기록 7건이다. 최고·최저·평균을 구하고, 정상 범위 밖 값이 몇 개인지 세어 보자.
힌트: 문제 4 코드에서 리스트 이름만 eq03_temps로 바꾼다.

Python
eq03_temps = [303.8, 303.4, 292.2, 308.5, 307.5, 298.5, 304.0]
print(____(eq03_temps))
print(____(eq03_temps))

average = ____(eq03_temps) / ____(eq03_temps)
print(f"EQ-03 평균 온도는 {average:.1f}도입니다.")
max, min, sum, len → 308.5(3번 칸), 292.2(2번 칸), EQ-03 평균 온도는 302.6도입니다.
범위 밖 값은 3개(292.2, 308.5, 307.5)다. 위아래로 벗어난 값이 평균 302.6도에 섞여 드러나지 않는다.

문제 6. 딕셔너리 만들고 꺼내기 (노트북 9단계)

설비 기록(EQ-01, 식각, 301.2도)을 equipment로 만들고 설비번호와 온도를 꺼내자.
힌트: 쉬운 예제 student = {...}, student["이름"]과 같은 모양.

Python
equipment = {
    "설비번호": "EQ-01",
    "공정명": ____,
    "온도_섭씨": ____,
}
print(equipment)

print(equipment[____])

"식각", 301.2, "설비번호", "온도_섭씨" → {'설비번호': 'EQ-01', '공정명': '식각', '온도_섭씨': 301.2}, EQ-01, 301.2

문제 7. 값 바꾸기와 키 추가 (노트북 9단계)

온도를 305.5로 바꾸고 합격여부에 1(합격)을 추가한 뒤 문장으로 출력하자. 합격여부는 1 = 합격, -1 = 불합격.
힌트: 쉬운 예제 student["나이"] = 16, student["동아리"] = "과학반"과 같은 모양. 마지막 줄 빈칸은 f-string 안이라 작은따옴표('공정명')로 쓴다(강의 "따옴표 규칙").

Python
equipment["온도_섭씨"] = ____   # 있던 키 → 값 바꾸기
equipment[____] = 1        # 없던 키 → 새로 추가(1 = 합격)
print(equipment)

print(f"{equipment['설비번호']} 설비는 {equipment[____]} 공정, 온도는 {equipment[____]}도입니다.")
305.5, "합격여부", '공정명', '온도_섭씨'(f-string 안은 작은따옴표) → {'설비번호': 'EQ-01', '공정명': '식각', '온도_섭씨': 305.5, '합격여부': 1}, EQ-01 설비는 식각 공정, 온도는 305.5도입니다.

문제 8. 설비 3대의 표 (노트북 10단계)

설비 3대(설명용 값)의 행 수, 0번 행의 온도, 1번 행의 설비번호를 꺼내자.
힌트: 쉬운 예제 len(friends), friends[0]["나이"], friends[1]["이름"]과 같은 모양.

Python
equipment_list = [
    {"설비번호": "EQ-01", "공정명": "식각", "온도_섭씨": 301.2},
    {"설비번호": "EQ-02", "공정명": "증착", "온도_섭씨": 308.7},
    {"설비번호": "EQ-03", "공정명": "포토", "온도_섭씨": 297.5},
]
print(____(equipment_list))
print(equipment_list[0])

print(equipment_list[____]["온도_섭씨"])   # 0번 행의 온도_섭씨 칸
print(equipment_list[1][____])    # 1번 행의 설비번호 칸
len, 0, "설비번호" → 3, {'설비번호': 'EQ-01', '공정명': '식각', '온도_섭씨': 301.2}, 301.2, EQ-02

문제 9. 오늘 데이터 한 행 읽기 (노트북 10단계)

CSV 앞 3행을 옮긴 records(노트북에 완성 코드)에서 두 번째 행을 row로 꺼내 문장으로 읽고, 아래 문장을 완성하자.
힌트: 쉬운 예제 friend = friends[1], friend['이름']과 같은 모양.

Python
row = records[____]
print(f"{row['로트번호']} 로트: {row['설비번호']} 설비, {row[____]} 작업")
print(f"온도 {row['온도_섭씨']}도, 합격여부 {row['합격여부']}")
문장 작성 "LOT-0097의 온도는 ____도로 학습용 정상 범위를 (벗어났다 / 벗어나지 않았다). 그런데 합격여부는 ____(____)이다. 그래서 온도 하나만 보고 ____라고 단정할 수 없다."
1, '공정명' → LOT-0097 로트: EQ-04 설비, 포토 작업 / 온도 308.7도, 합격여부 1
"LOT-0097의 온도는 308.7도로 학습용 정상 범위를 벗어났다. 그런데 합격여부는 1(합격)이다. 그래서 온도 하나만 보고 불량이라고 단정할 수 없다."

문제 10. 오류 찾기 (실습지 전용)

세 줄은 각각 오류가 난다. 무슨 오류인지, 어떻게 고치는지 적자.

Python — 오류 있는 코드
temperatures = [295.4, 298.1, 312.6, 301.0, 296.8]
equipment = {"설비번호": "EQ-01", "온도_섭씨": 301.2}

print(temperatures[5])          # (가)
print(equipment["압력_Pa"])     # (나)
print(equipment[0])             # (다)
(가) IndexError: list index out of range — 칸은 0~4번. temperatures[-1]로 고친다.
(나) KeyError: '압력_Pa' — 없는 키. print(equipment)로 확인한다.
(다) KeyError: 0 — 딕셔너리는 키로 꺼낸다(equipment["설비번호"]).
