리스트와 딕셔너리 — 실습지

🤔 왜 이걸 배워야 할까?

  • 실제 공정에는 값이 하나만 있는 게 아니라, 여러 설비·여러 시점의 측정값이 함께 존재한다. 리스트는 이런 "여러 개의 값"을, 딕셔너리는 "이름표가 붙은 값들의 묶음"을 다루는 방법이며, 4차시부터 배우는 표(DataFrame)도 결국 이 둘을 확장한 것이다.
쉬운 예시 한 설비의 온도를 하루에 5번 측정했다면 값 5개를 변수 5개로 따로 만드는 건 번거롭다. 리스트에 [298, 301, 299, 305, 300]처럼 담아두면 최고·최저·평균 온도를 한 번에 계산할 수 있고, 딕셔너리로 {"설비번호": "EQ-03", "온도_섭씨": 301}처럼 이름표를 붙이면 이 값이 어느 설비의 기록인지도 함께 관리할 수 있다.

D. 딕셔너리를 이루는 "이름표"와 "내용"의 짝

③ 인덱스
④ 키-값 쌍
① C ② A ③ B ④ D

2. 코드 빈칸 문제

Python
temps = [302.7, 300.1, 292.0, 299.0, 291.9, 303.5]

print(temps[____])          # 첫 번째 값(302.7)을 출력하려면?
print(temps[____])          # 마지막 값(303.5)을 리스트 길이를 몰라도 뒤에서부터 세어 출력하려면?
print(temps[1:____])        # 두 번째~세 번째 값([300.1, 292.0])만 출력하려면?

average = ____(temps) / ____(temps)   # 평균 계산
순서대로 0, -1, 3, sum, len. temps[1:3]은 인덱스 1, 2만 포함한다(3은 포함 안 됨).

3. 계산 문제

어느 공정의 압력 측정값 리스트가 아래와 같다.

pressures = [1000.0, 1010.0, 1020.0, 990.0]

이 리스트의 평균, 최댓값, 최솟값을 각각 계산해보자.

합계 = 1000.0+1010.0+1020.0+990.0 = 4020.0, 개수 = 4
평균 = 4020.0 ÷ 4 = 1005.0
최댓값 = 1020.0, 최솟값 = 990.0

4. 결과 예측 문제

아래 코드를 실행하면 무엇이 출력될지 먼저 예측해보고 정답을 확인하자.

Python
lot = {"로트번호": "LOT-0398", "설비번호": "EQ-03", "합격여부": 1}
print(f"{lot['로트번호']} 로트는 {lot['설비번호']}에서 처리되었다.")
정답: LOT-0398 로트는 EQ-03에서 처리되었다. — 딕셔너리의 키로 값을 꺼내 f-string 문장 속에 그대로 끼워 넣는다.

5. 오류 찾기 문제

아래 코드는 실행하면 오류가 난다. 어디가 문제인지 찾아 고쳐보자.

Python — 오류 있는 코드
equipment_list = [
    {"설비번호": "EQ-01", "온도_섭씨": 301.2},
    {"설비번호": "EQ-02", "온도_섭씨": 308.7},
]
print(equipment_list[2]["설비번호"])
문제: equipment_list에는 인덱스 0, 1의 딕셔너리 2개만 있는데 [2]에 접근해 IndexError가 발생한다. 수정: equipment_list[1]["설비번호"]처럼 실제로 존재하는 인덱스를 사용해야 한다.

7. 심화 실습

심화 압력 6개가 담긴 리스트 pressures = [998.0, 1005.2, 1010.8, 995.4, 1020.1, 1002.3]에서 슬라이싱으로 "가운데 4개 값"(인덱스 1~4)만 골라 평균을 구해보자. 그리고 아래처럼 딕셔너리 안에 리스트를 값으로 담은 중첩 구조를 만들어, lot["온도기록"]에서 max()로 최고 온도를 구해보자. 
lot = {"로트번호": "LOT-0205", "온도기록": [299.5, 306.2, 301.0]}
체크포인트 슬라이싱은 "시작 인덱스는 포함, 끝 인덱스는 미포함"이다. 가운데 4개(인덱스 1~4)를 가져오려면 pressures[1:5]처럼 끝 인덱스를 필요한 마지막 인덱스보다 1 크게 써야 한다. pressures[1:4]라고 쓰면 3개만 나오니 개수를 세어 꼭 확인하자.
