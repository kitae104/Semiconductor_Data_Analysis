⏮️ 지난 시간 복습

6주차 복습 지난주에는 groupby()로 설비별 평균 온도·압력·합격률을 비교했다. "EQ-04는 불량률이 높은 편"이라는 결과를 봤는데, 이번 주에는 그 관찰을 수율(收率)이라는 정식 지표로 다시 계산하고, 한 걸음 더 나아가 "그 설비 전체가 나쁜 것인지, 특정 로트 몇 개만 나쁜 것인지"까지 확인해본다.

📚 오늘의 개념 이해하기 — 양품·불량·수율·불량률

양품과 불량

검사를 마친 웨이퍼(또는 다이)는 양품(良品)과 불량(不良)으로 나뉜다. 한 웨이퍼 안에는 여러 개의 다이가 있고, 검사 결과 정상으로 판정된 개수가 양품수량, 비정상으로 판정된 개수가 불량수량이다.

수율(Yield)이란

수율은 검사한 것 중 양품이 차지하는 비율이다. 계산식은 다음과 같다.

공식 수율(%) = 양품수량 ÷ 검사수량 × 100

예를 들어 24개를 검사해서 22개가 양품이면 수율은 22 ÷ 24 × 100 ≈ 91.7%다.

불량률이란

불량률은 수율의 반대 개념으로, 불량이 차지하는 비율이다.

공식 불량률(%) = 불량수량 ÷ 검사수량 × 100 = 100 − 수율(%)

수율은 어느 단위로도 계산할 수 있다

수율은 "전체", "공정별", "설비별", "로트별"처럼 어떤 범위로 묶어서 보느냐에 따라 다른 숫자가 나온다. 오늘은 이 네 가지 단위를 모두 계산해보고, 그중에서도 "로트별 수율"을 이용해 문제가 되는 로트를 찾아낼 것이다.

📚 오늘의 개념 이해하기 — 파레토 분석 기초

불량 유형

불량이 발생하면 원인을 분류한 불량 유형(예: 파티클, 두께 불량, 패턴 불량 등)을 함께 기록해둔다. 어떤 불량 유형이 가장 자주 발생하는지 알면, 무엇을 먼저 개선해야 효과가 큰지 판단할 수 있다.

파레토 분석이란

파레토(Pareto) 분석은 "전체 문제의 대부분은 소수의 원인에서 발생한다"는 경험 법칙(파레토 법칙, 흔히 80/20 법칙)을 데이터로 확인하는 방법이다. 불량 유형을 발생 빈도가 많은 순서로 막대그래프로 그리고, 누적 비율을 함께 표시하면 "상위 몇 개 유형이 전체 불량의 몇 %를 차지하는지" 한눈에 볼 수 있다.

기초 개념 오늘은 파레토 차트를 "그리고 읽는" 수준까지만 다룬다. 각 원인의 실제 개선 우선순위를 정하는 것은 현업에서 추가 정보(비용, 난이도 등)를 함께 고려해야 하는 더 복잡한 문제다.

⚠️ 함정 주의 — 웨이퍼 단위 수율 vs 로트 단위 수율

이 데이터의 수율_pct 열은 웨이퍼 한 장 단위로 이미 계산되어 있다. 그런데 "이 로트의 수율은 얼마인가?"를 구할 때, 초보자가 가장 많이 하는 실수는 웨이퍼별 수율_pct 값을 그냥 mean()으로 평균 내는 것이다. 이렇게 하면 웨이퍼마다 검사수량이 다르다는 사실이 무시된다.

틀리기 쉬운 방법 df.groupby("로트번호")["수율_pct"].mean() → 웨이퍼 8장이면 8개의 %를 단순히 더해서 8로 나눈 값. 검사수량이 20개인 웨이퍼와 25개인 웨이퍼를 "똑같은 비중"으로 취급한다.

👩‍🏫 강사 코드 시연 — 전체 / 공정별 / 설비별 수율

Python — Colab / Jupyter
import pandas as pd

df = pd.read_csv("week07_yield_defect_analysis.csv")

# 1. 전체 수율 = 전체 양품수량 합 ÷ 전체 검사수량 합 × 100
overall_yield = df["양품수량"].sum() / df["검사수량"].sum() * 100
print(f"전체 수율: {overall_yield:.1f}%")

# 2. 공정별 수율 (공정명으로 묶은 뒤, 합산 후 나누기)
process_yield = df.groupby("공정명").apply(
    lambda g: g["양품수량"].sum() / g["검사수량"].sum() * 100
)
print(process_yield.round(1))

# 3. 설비별 수율
equipment_yield = df.groupby("설비번호").apply(
    lambda g: g["양품수량"].sum() / g["검사수량"].sum() * 100
)
print(equipment_yield.round(1))
코드 한 줄씩 설명
  • df["양품수량"].sum(): 양품수량 열 전체의 합계.
  • df.groupby("공정명"): 공정명이 같은 행끼리 묶는다(6주차 복습).
  • .apply(lambda g: ...): 묶인 그룹(g)마다 "합산 후 나누기" 계산을 반복 적용한다.
  • 주의: groupby("공정명")["수율_pct"].mean()이 아니라, 위처럼 양품수량·검사수량을 각각 합산한 뒤 나누는 방식을 써야 정확하다.

👩‍🏫 강사 코드 시연 — 로트별 수율과 저수율 로트 찾기

Python
# 로트번호로 묶어서 검사수량·양품수량·불량수량을 먼저 합산합니다.
lot_summary = df.groupby("로트번호").agg(
    검사수량=("검사수량", "sum"),
    양품수량=("양품수량", "sum"),
    불량수량=("불량수량", "sum"),
    설비번호=("설비번호", "first"),   # 로트당 설비는 하나뿐이므로 첫 값만 가져옴
)

# 합산된 값으로 로트 수율을 계산합니다.
lot_summary["수율_pct"] = (lot_summary["양품수량"] / lot_summary["검사수량"] * 100).round(1)

# 수율이 낮은 순서로 정렬해 하위 5개 로트를 확인합니다.
lot_summary.sort_values("수율_pct").head(5)
코드 한 줄씩 설명
  • .agg(검사수량=("검사수량","sum"), ...): 여러 열을 한 번에 원하는 이름으로 합산한다.
  • ("설비번호","first"): 그룹의 첫 번째 값만 가져온다. 로트당 설비가 하나뿐이라 안전하게 쓸 수 있다.
  • .sort_values("수율_pct"): 기본은 오름차순(작은 값부터)이라 수율이 낮은 로트가 위로 온다.
  • .head(5): 정렬된 결과에서 상위 5개 행만 본다.

👩‍🏫 강사 코드 시연 — 불량 유형 빈도와 파레토 차트

Python
import matplotlib.pyplot as plt

# 불량유형별 발생 빈도 (개수 많은 순으로 자동 정렬됨)
defect_counts = df["불량유형"].value_counts()
print(defect_counts)

# 누적 비율 계산 (파레토 차트의 핵심)
cum_pct = defect_counts.cumsum() / defect_counts.sum() * 100
print(cum_pct.round(1))

# 막대그래프 + 누적선 그래프로 파레토 차트 그리기
fig, ax1 = plt.subplots(figsize=(9, 5))
ax1.bar(defect_counts.index, defect_counts.values, color="#ea580c")
ax1.set_ylabel("발생 빈도(건)")

ax2 = ax1.twinx()
ax2.plot(defect_counts.index, cum_pct.values, color="#2563eb", marker="o")
ax2.set_ylabel("누적 비율(%)")
plt.title("불량 유형별 파레토 차트")
plt.show()
코드 한 줄씩 설명
  • df["불량유형"].value_counts(): 불량유형별 등장 횟수를 세고, 개수 많은 순으로 자동 정렬한다(빈 값은 제외).
  • .cumsum(): 위에서부터 누적으로 더한다. 총합으로 나누면 "누적 비율(%)"이 된다.
  • ax1.bar(...): 발생 빈도를 막대그래프로 그린다.
  • ax1.twinx(): 같은 x축을 공유하는 오른쪽 y축을 하나 더 만든다(누적 비율용).
  • ax2.plot(...): 누적 비율을 선 그래프로 겹쳐 그린다. 이 둘을 합친 것이 파레토 차트다.

📊 결과 표 — 저수율 로트와 설비 요약

수율 하위 5개 로트가 모두 EQ-04라는 것을 확인했으니, EQ-04 안에서도 어떤 로트가 문제인지 더 자세히 살펴보자.

중요한 발견 EQ-04에서 만든 로트가 전부 나쁜 것은 아니다! EQ-04의 18개 로트 중 13개는 오히려 89.7~97.1%로 평균보다도 우수하다. 문제는 EQ-04 로트 18개 중 5개에서만 집중적으로 발생했다. 이 5개 로트가 EQ-04 전체 평균(86.8%)을 끌어내린 것이다.

🧭 결과 해석 — 저수율 로트의 공통점

오늘의 질문 "수율이 낮은 로트에는 공통점이 있을까?"에 대한 답을 데이터로 정리해보면 다음과 같다.

데이터로 확인한 사실
  1. 전체 수율은 91.4%이고, 정상 로트의 수율은 대체로 88~99% 범위에 있다.
  2. 수율 하위 5개 로트(LOT-0053, LOT-0050, LOT-0006, LOT-0037, LOT-0029)는 전부 EQ-04에서 생산되었고, 수율은 66.3~68.5%로 뚜렷하게 낮다.
  3. 그러나 EQ-04에서 만든 나머지 13개 로트는 오히려 수율이 높다. 즉 "EQ-04 설비 자체"보다 "EQ-04에서 만든 특정 로트들"이 공통점이라고 더 정확히 말할 수 있다.
한 걸음 더(8주차 예고) "EQ-04라서 나쁘다"고 성급히 결론 내리면 안 된다. 지금은 "저수율 로트와 EQ-04 사이에 관계가 있어 보인다"는 관찰까지만 할 수 있다. 왜 하필 그 5개 로트만 낮은지(온도, 진공도 등 다른 원인이 있는지)는 8주차 "공정 이상과 원인 후보 찾기"에서 더 파헤쳐 본다.

🙋 실생활 비유로 정리하기

수율 계산은 "반 평균 점수"를 내는 것과 비슷하다. 학생 30명의 점수를 단순히 더해 30으로 나누면 반 평균이 되듯, 로트의 웨이퍼들을 "검사수량 합"과 "양품수량 합"으로 먼저 더한 뒤 나누어야 정확한 로트 수율이 나온다. 그리고 "우리 반 평균이 낮다"고 학생 전원을 탓할 수 없듯, "EQ-04 평균이 낮다"고 EQ-04에서 만든 모든 로트를 의심할 수는 없다 — 실제로는 일부 로트(학생)만 유독 낮았기 때문이다.

🟣 단계별 따라 하기 실습

1
데이터 읽기 — week07_yield_defect_analysis.csv를 업로드하고 pd.read_csv()로 읽는다. df.head(), df.shape로 데이터를 먼저 확인한다.
2
전체 수율 계산 — df["양품수량"].sum() / df["검사수량"].sum() * 100을 계산한다.
3
공정별·설비별 수율 — groupby() 뒤 "합산 후 나누기"로 계산한다.
4
로트별 수율과 저수율 로트 찾기 — groupby("로트번호").agg(...)로 로트별 합계를 만들고, sort_values("수율_pct")로 낮은 순 정렬한다.
5
불량 유형 빈도와 파레토 차트 — value_counts()로 세고, 막대그래프 + 누적선 그래프로 그린다.
6
결과 문장 작성 — 저수율 로트가 어느 설비에 몰려 있는지 한 문장으로 정리한다.

⚠️ 주의할 점 & 자주 발생하는 오류

오류 1 groupby("로트번호")["수율_pct"].mean()을 로트 수율이라고 잘못 사용하는 경우. 반드시 양품수량과 검사수량을 각각 합산한 뒤 나누어야 한다.
오류 2 value_counts()는 결측값(빈 불량유형)을 기본적으로 세지 않는다. "전체 421행"과 "불량유형이 있는 376행"을 혼동하지 않도록 주의한다.
주의 "EQ-04 평균 수율이 낮다"는 결과만 보고 "EQ-04에서 만든 모든 로트가 문제"라고 성급히 결론 내리지 않도록 한다. 반드시 로트별로 다시 확인하는 습관을 들이자.

🚀 도전 실습

도전 문제 1 수율이 가장 높은 5개 로트도 sort_values("수율_pct", ascending=False).head(5)로 찾아보자. 어느 설비에서 나왔는지 확인하고, 저수율 로트와 비교해보자. (힌트: 놀랍게도 같은 설비일 수 있다!)
도전 문제 2(심화) 저수율 5개 로트(LOT-0053 등)만 따로 골라 불량유형의 value_counts()를 내보자. 전체 데이터의 파레토 순위와 같은지, 다른지 비교해보자.
