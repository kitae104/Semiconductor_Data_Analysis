설비·공정 비교와 수율·불량 분석

💬 오늘의 질문: "설비마다 차이가 있어 보이는데, 숫자로 계산해도 정말 그럴까?"

🎯 학습 목표

  • Orange3로 먼저 설비별 분포 차이가 있어 보이는지 훑어볼 수 있다.
  • groupby로 설비별/공정별 평균값과 합격률을 비교할 수 있다.
  • 로트 단위 수율을 계산할 수 있다(단순 평균과의 차이 포함).
  • 불량 유형을 집계하고 파레토 관점에서 가장 큰 원인을 찾을 수 있다.

선수 지식: 6차시 — 그래프로 관찰한 차이

⏮️ 지난 시간 복습

6차시 연결 6차시에서는 박스플롯으로 "EQ-02의 온도가 유독 넓게 퍼져 있다"는 것을 그림으로 확인했다. 그림은 인상을 주지만 정확한 숫자를 알려주지는 않는다. 오늘은 groupby로 그 인상을 정확한 숫자로 바꾸고, 수율·불량 분석까지 연결한다.

🟠 ① Orange3로 먼저 훑어보기

위젯 Box Plot · Bar Chart

groupby 코드를 쓰기 전에 Orange3 Box Plot/Bar Chart 위젯으로 설비별 온도·합격 여부 분포를 먼저 살펴보고, 차이가 있어 보이는 설비를 미리 짐작해본다.

💡 실제 Orange3 화면 캡처(설비번호별 Box Plot, 합격여부 Bar Chart)를 강사가 추가하면 더 좋다.

이제 Orange3로 미리 살펴본 인상을, 아래에서 groupby로 정확한 숫자로 확인해본다.

🐍 ② 파이썬으로 확인하기 — groupby로 설비별 비교하기

groupby()는 특정 열의 값(예: 설비번호)이 같은 행끼리 묶어주는 기능이다. 그 자체로는 결과를 보여주지 않으며, 반드시 .mean(), .std() 같은 집계 함수를 뒤에 붙여야 숫자가 나온다.

Python — 설비별 평균 온도
import pandas as pd

df = pd.read_csv("week07_equipment_yield.csv")
print(df.groupby("설비번호")["온도_섭씨"].mean())
실행 결과 
설비번호
EQ-01    300.21
EQ-02    300.07
EQ-03    299.35
EQ-04    301.65
Name: 온도_섭씨, dtype: float64
평균만 봐서는 안 되는 이유 네 설비의 평균 온도는 모두 299~302℃로 비슷해 보인다. 하지만 평균이 비슷하다고 "똑같이 안정적"이라는 뜻은 아니다 — 6차시에서 본 것처럼 EQ-02는 표준편차(퍼짐)가 더 크다. 평균과 표준편차는 함께 봐야 한다.

설비별 합격률 비교

Python
pass_rate = df.groupby("설비번호")["합격여부"].apply(lambda s: (s == 1).mean() * 100)
print(pass_rate)

📚 로트 단위 수율 계산하기

합격률(웨이퍼 단위 단순 비율)과 수율(로트 단위로 양품수량÷검사수량)은 계산 방식이 다르다. 이번 데이터는 로트 하나당 웨이퍼 4장으로 구성되어 있으므로, 로트별로 묶어 수율을 계산해보자.

Python — 로트별 수율 계산
lot_summary = df.groupby("로트번호").agg(
    설비번호=("설비번호", "first"),
    검사수량=("합격여부", "count"),
    양품수량=("합격여부", lambda s: (s == 1).sum()),
)
lot_summary["수율_pct"] = (lot_summary["양품수량"] / lot_summary["검사수량"] * 100).round(1)

print(lot_summary.head())
로트번호설비번호검사수량양품수량수율_pct
LOT-0001EQ-0144100.0
LOT-0005EQ-0444100.0
LOT-0006EQ-044375.0
LOT-0008EQ-04400.0
주의 — 단순 평균과 다르다 "전체 합격률"은 300건 전체를 한 번에 나눈 값이지만, "로트별 수율"은 로트 하나하나를 따로 계산한다. 로트 하나가 통째로 저조하면(예: LOT-0008은 4건 중 0건 합격, 수율 0%) 전체 합격률만 봐서는 놓칠 수 있다.
체크포인트 — 로트별 수율을 그냥 평균 내면 안 될 수 있다 lot_summary["수율_pct"].mean()처럼 로트별 수율(%)을 단순히 평균 내면, 로트마다 웨이퍼 수가 다를 경우 실제 전체 수율과 다른 값이 나올 수 있다(웨이퍼가 적은 로트와 많은 로트를 "똑같이 1표씩" 취급하기 때문). 이번 데이터는 로트마다 웨이퍼가 4장으로 같아 크게 문제되지 않지만, 로트 크기가 다르다면 양품수량 합계 ÷ 검사수량 합계로 다시 계산해야 정확하다(실습지 3번 문제에서 직접 비교해본다).

저수율 로트 찾기

Python
low_yield_lots = lot_summary[lot_summary["수율_pct"] < 80]
print(len(low_yield_lots), "개 로트가 수율 80% 미만")
print(low_yield_lots["설비번호"].value_counts())

결과 해석 저수율 로트 21개 중 11개(절반 이상)가 EQ-04에서 나왔다 — 합격률이 가장 낮았던 설비와 저수율 로트가 가장 많이 나온 설비가 일치한다. 두 가지 다른 방법(합격률, 로트별 수율)이 같은 결론을 가리킨다는 것은 그 결론이 우연이 아닐 가능성을 높여준다.

📚 불량 유형 집계와 파레토 분석

파레토 분석은 "소수의 원인이 대부분의 결과를 만든다"는 관점으로 문제를 우선순위화하는 방법이다. 불량 유형을 집계해 어떤 유형이 가장 많은지 확인해보자.

Python
defect_counts = df[df["합격여부"] == -1]["불량유형"].value_counts()
print(defect_counts)
실행 결과

정렬 불량         4
식각 부족         4
전기적 특성 불량     1
Name: count, dtype: int64

"두께 불량"이 전체 불량(36건)의 약 31%를 차지하는 가장 큰 원인이다. 상위 2개 유형(두께 불량, 패턴 불량)만 해결해도 전체 불량의 절반 가까이를 줄일 수 있다.

🗂️ 핵심 용어 카드

groupby

Group By
한 줄 설명
특정 열의 값이 같은 행끼리 묶는 기능. 집계 함수와 함께 써야 결과가 나온다.
쉬운 비유
학생들을 반별로 줄 세운 뒤, 반마다 평균 점수를 내는 것.
데이터에서의 예
df.groupby("설비번호")["온도_섭씨"].mean()
자주 하는 오해
groupby()만 쓰면 결과가 바로 보인다고 착각하기 쉽다. 집계 함수를 붙여야 한다.

합격률 vs 수율

Pass Rate vs Yield
한 줄 설명
합격률은 전체를 한 번에 나눈 비율, 수율은 로트처럼 묶음 단위로 계산한 비율.
쉬운 비유
학년 전체 평균 vs 반별 평균처럼, 어떤 단위로 나누느냐에 따라 다른 그림이 보인다.
데이터에서의 예
전체 합격률과 로트별 수율이 다른 결론을 보여줄 수 있다.
자주 하는 오해
둘이 항상 같은 결과를 준다고 착각하기 쉽다.

파레토 분석

Pareto Analysis
한 줄 설명
소수의 원인이 대부분의 결과를 만든다는 관점으로 우선순위를 정하는 분석법.
쉬운 비유
옷장 정리할 때 자주 입는 옷 20%가 착용 횟수의 80%를 차지하는 것.
데이터에서의 예
"두께 불량" 하나가 전체 불량의 약 31%를 차지.
자주 하는 오해
모든 불량 유형을 동시에 해결하려 하기 쉽다. 가장 큰 것부터 우선순위를 정하는 것이 효율적이다.

⚠️ 주의할 점 & 자주 발생하는 오류

오류 1 TypeError: agg function failed — 문자열 열(로트번호 등)에 .mean()을 적용하려 한 경우다. 숫자 열에만 평균/표준편차를 적용해야 한다.
오류 2 groupby("설비번호", "온도_섭씨")처럼 콤마로 열을 나열하는 실수가 흔하다. 올바른 형태는 groupby("설비번호")["온도_섭씨"]다.
주의 KeyError가 나면 df.columns로 정확한 열 이름을 먼저 확인하자.

🚀 도전 실습

도전 문제 df.groupby(["설비번호", "작업조"])["합격여부"].apply(lambda s: (s==1).mean()*100)처럼 설비와 작업조 두 기준을 동시에 그룹화해보자. 특정 설비+작업조 조합이 유독 낮은 합격률을 보이는지 확인해본다.

Q1. (객관식) df.groupby("설비번호")["온도_섭씨"]만 실행하고 아무 메서드도 붙이지 않으면 어떻게 되는가?
  • A. 설비별 평균이 자동으로 출력된다
  • B. 오류가 난다
  • C. groupby 객체만 만들어질 뿐, 집계 함수를 붙여야 결과가 보인다
  • D. 전체 평균이 출력된다
정답: C. .mean(), .std() 같은 집계 함수를 뒤에 붙여야 실제 숫자 결과를 볼 수 있다.
Q2. (참/거짓) 두 설비의 평균 온도가 같으면, 두 설비는 똑같이 안정적으로 운영되고 있다고 말할 수 있다.
정답: 거짓. 평균이 같아도 표준편차(퍼짐)가 다르면 안정성이 다르다. 평균과 표준편차를 함께 봐야 한다.
Q3. (빈칸) 값이 몇 번 나왔는지 세는 파이썬/Pandas 메서드는 ______()이다 (불량유형 집계에 사용).
정답: value_counts
Q4. (서술) 파레토 분석이 왜 유용한지, 오늘 데이터(두께 불량이 전체 불량의 약 31%)를 예로 들어 한 문장으로 설명해보자.
예시 답안: "파레토 분석은 가장 큰 원인부터 우선순위를 정할 수 있게 해주는데, 오늘 데이터에서는 '두께 불량' 하나만 해결해도 전체 불량의 약 31%를 줄일 수 있어 어디부터 개선해야 할지 명확해진다."
