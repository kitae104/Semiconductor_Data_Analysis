수율과 정답률 — 무엇 중에 무엇의 비율일까

수율은 만든 것 중 합격한 것의 비율이다. 피자 조각 100개를 만들어 92개를 팔 수 있으면 수율 92%, 나머지 8%가 불량률이다. 쪽지시험이라면 "푼 문항 중 맞힌 문항의 비율", 곧 정답률이 같은 계산이다. 비율을 말할 때는 늘 "무엇 중에"(분모)를 먼저 정한다.

import pandas as pd

quiz = pd.read_csv("../../data/weekly/week07/week07_easy_quiz_results.csv", encoding="utf-8-sig")
print(quiz.shape)

quiz.head()

오답유형 칸의 NaN은 빈칸이다(5차시). 맞힌 문항이라 오답 유형이 없다.

비교해서 새 열 만들기

quiz["정답여부"] == 1은 행마다 "1과 같은가?"를 물어 True/False를 만든다(3차시 비교). 그 결과를 새 열 정답에 저장한다. True는 1, False는 0으로 계산되므로 sum()은 맞힌 문항 수, mean() * 100은 정답률(%)이 된다.

Python — 정답 열 만들고 정답률 구하기 (노트북 1단계)
quiz["정답"] = quiz["정답여부"] == 1
print(quiz["정답"].sum())
print(quiz["정답"].mean() * 100)
실행 결과 
18
75.0

24문항 중 18문항을 맞혀 정답률 75.0%다. 정답여부(1/-1)를 그대로 평균 내면 1과 -1이 서로 지워져 0.5가 나온다 — 정답률이 아니다. 그래서 True/False 열을 먼저 만든다.

검색어 반도체 수율 뜻

ChatGPT에 물어보기 — 복사해서 붙여 넣기
반도체를 처음 배우는 사람에게 반도체 공장에서 말하는 '수율(yield)'이 무엇인지 피자 가게에서 구운 피자 조각에 비유해서 3문장으로 설명해줘. 수율이 왜 공장에서 중요한 숫자인지도 알려줘.
좋은 답이라면 "웨이퍼 위에 만든 다이(칩이 될 작은 네모) 중 검사를 통과한 것의 비율"이라는 뜻과, "수율이 낮으면 같은 재료와 공정으로 팔 수 있는 칩이 줄어 비용이 커진다"는 내용이 들어 있다. 수율을 다이 단위로 셀지 웨이퍼 단위로 셀지는 회사·상황마다 다르다. 오늘 공장 기록은 웨이퍼 1장 = 검사 1건으로 단순화했다.

groupby — 반별로 묶어서 비교하기

groupby("반")은 같은 반끼리 행을 묶고, 뒤의 ["정답"].mean()은 묶음마다 정답 열의 평균을 낸다. 피자 가게에서 판을 오븐별로 모아 오븐마다 탄 비율을 따로 세는 것과 같다.

반푼 문항맞힌 문항정답률
A반877 ÷ 8 × 100 = 87.5
B반855 ÷ 8 × 100 = 62.5
C반866 ÷ 8 × 100 = 75.0

groupby가 반마다 하는 계산(쪽지시험 기록의 실제 값). 아래 코드 한 줄이 이 표를 만든다.

Python — 반별 정답률 구하고 줄 세우기 (노트북 2단계)
class_rate = quiz.groupby("반")["정답"].mean() * 100
print(class_rate.round(1))

print(class_rate.sort_values())

  • 맨 위 반은 묶은 열 이름, 맨 아래 Name: 정답은 평균 낸 열 이름이다. dtype: float64는 "소수가 있는 숫자"라는 뜻이라 보지 않아도 된다.
  • .round(1)은 소수 첫째 자리까지 반올림한다. sort_values()(4차시)는 작은 값부터 줄 세운다 — 가장 낮은 반이 맨 위에 온다.
  • 전체 75.0%였지만 B반은 62.5%다. 다만 한 반에 두 명뿐이라, 학생 한 명에 따라 반 정답률이 크게 흔들린다. 건수가 적은 묶음의 비율은 조심해서 읽는다.

오답 유형 줄 세우기 — 무엇부터 고칠까

반도체 데이터로 확인하기

공장 기록 week07_equipment_yield.csv(300행 11열, 교육용 가상 데이터)는 로트 75개 × 웨이퍼 4장 = 웨이퍼 300장의 기록이다(실제 로트는 보통 25장 안팎, 이 기록은 연습용으로 4장). 한 행 = 웨이퍼 1장이다. 위 코드에서 표 이름이 quiz → df로, 열 이름만 바뀐다.

공정 지도 위치: ② 산화 ~ ⑤ 증착/이온주입 + 세정 설비의 기록과, ⑦ EDS(전기 검사)까지 마친 뒤의 최종 합격 여부다(1차시 공정 지도 그림은 PART 2에서 다시 본다).

열공장에서의 뜻
로트번호, 웨이퍼번호웨이퍼 묶음 번호와 묶음 안에서 몇 번째 웨이퍼인지(1~4)
설비번호, 공정명어느 기계(EQ-01~EQ-04)에서 어떤 작업(산화·포토·식각·증착·세정)을 했나. 설비 4대가 여러 공정 기록을 함께 남겼다(교육용 가상 기록)
작업조그 시간에 일한 교대 근무팀(A·B·C조)
온도_C, 압력_Pa, 진공도_mTorr, 처리시간_sec설비 안 온도(섭씨 도), 압력(파스칼), 진공도(공기를 얼마나 뺐나, 낮을수록 진공에 가깝다), 작업에 걸린 초. 압력 값의 절대 크기는 해석하지 않는다(교육용 가상 값, 데이터 설명서 참고)
불량유형불합격일 때 기록된 불량의 종류(두께 불량·파티클 등). 공정 중간의 두께 측정·표면 검사와 마지막 전기 검사(⑦ EDS)에서 찾은 것을 한 열에 모아 둔 교육용 설정이다. 합격이면 빈칸. 같은 행의 공정명 작업에서 생겼다는 뜻은 아니다
합격여부그 웨이퍼의 최종 판정(공정 중간 검사와 전기 검사 결과를 모은 교육용 설정), 행마다. 1 = 합격, -1 = 불합격

실제 공장은 웨이퍼 위 다이 단위로 수율을 세는 경우가 많다. 이 기록은 웨이퍼 1장 = 검사 1건으로 단순화해, 웨이퍼를 센 비율(설비별·로트별 모두)을 합격률이라 부르고 수율 대신 쓴다. 다이를 센 비율(PART 2 워밍업)만 수율이라 부른다.

이 기록의 단순화 실제 웨이퍼는 여러 공정을 모두(여러 번) 거친다. 이 기록은 로트마다 설비 하나·공정 하나만 적어 둔 교육용 단순화다. 그래서 공정 차이와 설비 차이(그리고 로트 차이)를 숫자로 떼어 볼 수 없다 — 무엇을 찾든 "원인 후보"까지만 말한다.

확인 1 — 작업조별 불합격률은 다를까

주의할 점 & 자주 발생하는 오류

오류 1 — groupby 뒤 대괄호 빠뜨림 df.groupby("설비번호").mean()처럼 평균 낼 열을 고르지 않으면 TypeError: dtype 'str' does not support operation 'mean'가 난다. 글자 열(로트번호·공정명 등)까지 평균을 내려 한 것이다. groupby("설비번호")["합격"].mean()처럼 묶은 뒤 열 하나를 대괄호로 고른다.
오류 2 — == 대신 = (오류 없이 틀림) df["합격"] = df["합격여부"] = 1처럼 비교 기호 ==를 =로 쓰면 오류가 나지 않는다. "합격여부 열에 1을 넣고, 합격 열에도 1을 넣어라"라는 뜻이 되어 합격여부 열이 모두 1로 덮어써진다. 전체 합격률이 100.0으로 나오면 이것을 의심한다. ==로 고친 뒤 노트북 4단계(read_csv)부터 다시 실행해야 원래 기록이 돌아온다.
오류 3 — 1/-1을 그대로 평균 냄 (오류 없이 틀림) df["합격여부"].mean()은 오류 없이 0.76을 낸다. 1과 -1이 서로 지워진 값이라 합격률이 아니다. == 1로 True/False 열을 만든 뒤 그 열의 평균을 낸다.
빈칸을 그대로 두고 실행하면 노트북의 ____를 채우지 않으면 NameError: name '____' is not defined(숫자·열 이름 자리)나 AttributeError: 'Series' object has no attribute '____'(함수 이름 자리, Series = 표의 열 하나)가 난다. 빈칸을 아직 안 채웠다는 뜻이다. 열 이름은 따옴표로 감싼다 — groupby(설비번호)는 NameError: name '설비번호' is not defined가 난다. 앞 셀이 실패한 채 다음 셀을 실행하면 NameError: name 'eq_rate' is not defined나 NameError: name 'defect_counts' is not defined가 난다. 그 변수를 만드는 앞 셀부터 고친다.

결과 정리 & 퀴즈

  • 비율 = True/False 열의 평균 × 100. == 1로 열을 먼저 만들고 평균을 낸다(쪽지시험 정답률 75.0%).
  • groupby로 묶으면 전체 숫자에 숨은 차이가 보인다: 반별 정답률 87.5 · 62.5 · 75.0, 작업조별 불합격률 9.8 · 15.5 · 9.7.
  • 불량·오답 유형은 value_counts()로 많은 순으로 세우고 막대로 그린다. 많은 것부터 살펴본다.
  • Orange 워밍업: Pivot Table로 식각-3의 수율 83.1%(나머지 95.2 · 94.8%)를 찾고, 웨이퍼 맵으로 불합격 다이 214개 중 194개가 가장자리 고리에 몰린 것을 봤다.
  • 눈에 띄는 설비·작업조는 "원인 후보"다. 이유로 확정하려면 다른 조건을 함께 확인해야 한다.
오늘의 반도체 이해 포인트
  • 수율은 만든 다이(칩이 될 작은 네모) 중 합격한 비율이다. 설비별로 묶어 비교하면 수율이 낮은 곳이 보인다(식각-3 83.1%). 그곳이 먼저 살펴볼 원인 후보다.
  • 불량 위치 패턴(가장자리·가운데·긁힌 자국 모양)은 원인 후보를 좁히는 단서다. 단서일 뿐 원인 확정이 아니다.

AI로 한 걸음 더 — 질문하고 코드 받아보기

ChatGPT에 아래처럼 물어 받은 코드의 예시다. for와 if는 3차시에 배운 반복문·조건문이다. 노트북 6단계에서 실행해 실습지 문제 2의 결과와 같은 설비가 표시되는지 확인한다.

ChatGPT에 물어보기 — 복사해서 붙여 넣기
pandas Series eq_rate(설비별 합격률 %)가 있어. 합격률이 90% 미만인 설비는 "원인 후보 — 더 살펴보기", 아니면 "연습용 기준 이상"이라고 한 줄씩 출력하는 짧은 코드를 만들어 줘. 90%는 연습용 기준이야.
Python — AI가 만들어 준 코드 예시 (노트북 6단계)
for eq, rate in eq_rate.items():
    if rate < 90:
        print(f"{eq} 합격률 {round(rate, 1)}% → 원인 후보 — 더 살펴보기")
    else:
        print(f"{eq} 합격률 {round(rate, 1)}% → 연습용 기준 이상")

eq_rate는 실습지 문제 2에서 만드는 변수라, 문제 2를 먼저 풀어야 실행된다(안 풀었으면 NameError: name 'eq_rate' is not defined). .items()는 설비 이름과 값을 한 쌍씩 꺼내는 함수다(처음 보는 함수라 구경만 한다).

EQ-02 합격률 86.5% → 원인 후보 — 더 살펴보기
EQ-03 합격률 91.1% → 연습용 기준 이상

AI 코드를 다룰 때 직접 실행해 숫자를 확인하고, 변수 이름이 내 노트북과 같은지 맞춘다. 90% 같은 기준은 연습용이다. EQ-02(52장)·EQ-03(56장)은 EQ-01(104장)의 절반쯤이라, 쪽지시험의 작은 반처럼 몇 장에 따라 합격률이 흔들리기 쉽다. 회사의 실제 데이터는 AI에 붙여 넣지 않는다.

8차시에는 "어느 설비"에서 한 걸음 더 들어가 "어떤 값이 불합격과 함께 움직이나"를 본다. 산점도와 상관계수로 관계를 재고, Orange에서는 Correlations로 모든 열 쌍을 한 번에 줄 세운다.
