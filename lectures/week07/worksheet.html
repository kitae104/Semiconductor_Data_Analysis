설비·공정 비교와 수율·불량 분석 — 실습지

모든 문제는 공장 기록 week07_equipment_yield.csv(웨이퍼 300장, 300행 11열, 교육용 가상 데이터)로 푼다. 공정 지도 위치: ②~⑤ + 세정 설비 기록과 ⑦ 뒤 최종 합격 여부. 설비 4대가 여러 공정 기록을 함께 남겼다(교육용 가상 기록). 문제 1~3은 학생용 노트북 5단계와 같다 — 노트북 4단계 셀을 먼저 실행해 df를 만들어 둔다. 합격여부는 1 = 합격, -1 = 불합격이다. 이 기록은 웨이퍼를 세므로 비율을 합격률(수율 대신 쓰는 값)이라 부른다. 문제 1~3을 풀면 오늘의 미션(합격률이 가장 낮은 설비, 가장 많은 불량 유형)의 답이 나온다.

문제 1 — 합격 열 만들고 전체 합격률 구하기 (노트북 5단계 문제 1)

합격여부가 1인 행은 True, 아니면 False인 합격 열을 만들고, 전체 합격률(%)을 구하자. 힌트: 강의 "비교해서 새 열 만들기"의 quiz["정답"] = quiz["정답여부"] == 1과 같은 모양이다.

Python — 노트북 5단계 문제 1
# TODO: 합격을 뜻하는 숫자와, 평균을 내는 함수 이름을 채우세요.
df["합격"] = df["합격여부"] == ____
print(df["합격"].____() * 100)
주의 ==(같은가?)를 =로 쓰면 오류 없이 합격여부 열이 모두 1로 덮어써진다. 결과가 100.0이면 ==로 고친 뒤 노트북 4단계부터 다시 실행한다. 결과가 12.0이면 4단계를 따라 -1(불합격)을 쓴 것이다 — 합격은 1.

전체 웨이퍼 중 몇 %가 합격했나?

1, mean 
88.0
웨이퍼 300장 중 88.0%가 합격했다. df["합격여부"].mean()처럼 1/-1을 그대로 평균 내면 0.76이 나온다 — 합격률이 아니다.

문제 2 — 설비별 합격률 비교하기 (노트북 5단계 문제 2)

설비별로 묶어 합격률을 구하고, 작은 값부터 줄 세우자. 힌트: 강의 "groupby — 반별로 묶어서 비교하기"의 quiz.groupby("반")["정답"].mean() * 100과 같은 모양이다. 묶는 열은 설비번호, 평균 낼 열은 문제 1의 합격이다.

print(eq_rate.round(1))

# TODO: 작은 값부터 줄 세우는 함수 이름을 채우세요.
print(eq_rate.round(1).____())
주의 열 이름은 따옴표로 감싼다. 평균 낼 열은 문제 1에서 새로 만든 합격이다 — 합격여부를 넣으면 오류 없이 엉뚱한 값(EQ-04가 50.0)이 나온다. 문제 1을 건너뛰면 KeyError: 'Column not found: 합격', 첫 셀이 실패한 채 둘째 셀을 실행하면 NameError: name 'eq_rate' is not defined가 난다.

문제 3 — 불량 유형 줄 세우고 막대 그리기 (노트북 5단계 문제 3)

불합격(-1) 웨이퍼만 골라 불량유형을 많은 순으로 세자. 힌트: 강의 "오답 유형 줄 세우기"의 wrong_counts와 같은 모양이다.

Python — 노트북 5단계 문제 3
# TODO: 불합격을 뜻하는 숫자와, 셀 열 이름을 채우세요.
defect_counts = df[df["합격여부"] == ____][____].value_counts()
print(defect_counts)
주의 1을 쓰면 오류 없이 빈 결과 Series([], Name: count, dtype: int64)가 나온다 — 불합격은 -1. (value_counts()는 빈칸을 세지 않아 조건 없이도 같은 표가 나오지만, "불합격 웨이퍼 중에서"라는 뜻을 코드에 드러내려고 고른다.)

이어서 직접 쓰기(전이 문제, 빈칸 없음) — 바로 아래 빈 셀에, 강의 "오답 유형 줄 세우기"의 막대 코드(4줄 틀)를 보고 defect_counts로 막대그래프를 직접 쓴다. x축 이름은 "불량유형", y축 이름은 "불량 건수"로 한다. 불량 유형 이름이 길어 서로 겹치면 plt.bar(…) 다음 줄에 plt.xticks(rotation=45)(이름을 45도 기울이기)를 넣는다. 첫 셀이 실패한 채 실행하면 NameError: name 'defect_counts' is not defined가 난다.

가장 많은 불량 유형은 두께 불량(11건)이다. 모두 더하면 36건 = 불합격 웨이퍼 수와 같다. 직접 쓴 막대 코드의 예: 
plt.bar(defect_counts.index, defect_counts)
plt.xticks(rotation=45)   # 이름이 길어 겹치지 않게 45도 기울이기
plt.xlabel("불량유형")
plt.ylabel("불량 건수")
plt.show()
불량 유형은 검사에서 발견된 불량의 종류다. 같은 행의 공정명 작업에서 생겼다는 뜻은 아니다.
체크포인트 막대가 7개이고 왼쪽부터 두께 불량이 가장 높아야 한다. 막대가 나오지 않으면 노트북 3단계 첫 그래프 셀(import matplotlib.pyplot as plt)을 실행했는지 확인한다. 한글이 네모로 깨지면 그 셀의 plt.rcParams[…] 두 줄을 실행하지 않은 것이다.

문제 4 — Orange Pivot Table로 설비별 불합격 수 세기

Orange3에서 week07_2_yield_start.ows를 연다. 강의 PART 2 워밍업에서 한 Pivot Table을 이번에는 공장 기록에 쓴다.

  1. File을 더블클릭해 300행이 들어왔는지 확인한다.
  2. Transform 묶음의 Pivot Table을 File에 잇고 더블클릭한다. 처음에는 Rows가 합격여부, Columns가 None이라 엉뚱한 표가 뜬다. Rows = 설비번호, Columns = 합격여부로 바꾸고, Aggregations에서 Count에 체크돼 있는지 확인한다.
  3. 설비마다 -1(불합격) 칸과 Total 칸의 숫자를 읽는다.
  4. 이어서 Rows만 불량유형으로 바꾸고, 두께 불량 줄의 숫자를 읽어 문제 3과 비교한다.

① 불합격 칸이 가장 큰 설비는? ② 그 설비의 합격 칸 ÷ Total 칸 × 100을 계산해 문제 2의 합격률과 비교하자. 같은가, 다른가? ③ Rows를 불량유형으로 바꿨을 때 두께 불량은 몇 건인가? 문제 3과 같은가?

EQ-01 102 / 2 / 104 · EQ-02 45 / 7 / 52 · EQ-03 51 / 5 / 56 · EQ-04 66 / 22 / 88(합격 / 불합격 / Total, 웨이퍼 장수). 화면에는 102.0처럼 소수점이 붙어 보인다. ① 불합격 칸이 가장 큰 설비는 EQ-04(22). ② 66 ÷ 88 × 100 = 75.0% — 문제 2의 groupby 결과와 같다. 같은 표에서 세었기 때문이다. ③ 두께 불량 11 — 문제 3의 value_counts()와 같다. 화면의 두께 불량 줄은 0.0 / 11.0 / 11.0(1 / -1 / Total)이다. 줄은 가나다순(식각 부족 4 · 오염 5 · 전기적 특성 불량 1 · 정렬 불량 4 · 파티클 5 · 패턴 불량 6)이고, 합격 웨이퍼는 불량유형이 빈칸이라 표에서 빠져 Total 줄이 0.0 / 36.0 / 36.0이다(300이 아니다).
체크포인트 Total 줄이 264 / 36 / 300이면 맞게 센 것이다(합격 264 ÷ 300 = 88.0% = 문제 1). Total이 300이 아니면 File에 다른 파일이 들어 있다 — _start.ows를 다시 연다. 줄·칸이 바뀌어 보이면 Rows와 Columns를 서로 바꿔 고른 것이다(숫자는 같다). 막히면 같은 폴더의 week07_2_yield_done.ows를 연다.

문제 5 — 해석 문장 쓰기

오늘의 질문 "설비마다 차이가 있어 보이는데, 숫자로 계산해도 정말 그럴까?"에 문제 2의 숫자로 답하자.

문장 틀 "전체 합격률은 ______%인데, ______는 합격률 ______%로 가장 낮아 원인 후보다. 원인이라 말하려면 ______을(를) 더 확인해야 한다."
앞의 세 빈칸은 문제 1·2의 출력으로 채운다. 마지막 빈칸에는 데이터로 더 확인할 것 한 가지를 쓴다.

판단해 보기 — 이 숫자만으로 "EQ-04 때문에 불량이 났다"고 말할 수 있을까? 예/아니오와 이유를 한 줄로 쓰자.

"전체 합격률은 88.0%인데, EQ-04는 합격률 75.0%로 가장 낮아 원인 후보다. 원인이라 말하려면 EQ-04가 맡은 공정·로트, 다른 시기의 기록, 설비 점검 기록을 더 확인해야 한다."
판단: 아니오. 합격률 비교는 "어디를 먼저 살펴볼지"까지만 알려 준다. EQ-04에 어려운 공정이나 문제가 있는 로트가 몰렸을 수도 있다. 이 기록에서는 로트 하나의 웨이퍼 4장이 모두 같은 설비·같은 공정을 거쳐서, 설비 차이와 로트·공정 차이를 숫자로 떼어 볼 수 없다. (참고: 온도 상자가 가장 긴 설비는 EQ-02였다 — 합격률이 가장 낮은 설비와 다르다. 원인 후보를 한 가지로 좁히기 전에 여러 열을 함께 본다.)
