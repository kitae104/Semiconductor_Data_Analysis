# 7차시 강의 운영안 — 설비·공정 비교와 수율·불량 분석

## 왜 이걸 배워야 할까? (학생에게 전달할 메시지)

"어느 설비를 먼저 점검하지?"에 답하려면 설비별로 **묶어서** 비교해야 한다. 오늘 데이터는 전체 합격률 88.0%지만
설비별로 EQ-01 98.1%, EQ-03 91.1%, EQ-02 86.5%, **EQ-04 75.0%**다.

## 수업 흐름

1. 복습(1차시 용의자 ≠ 범인) → 오늘의 질문 → 데이터 열 표 → 쪽지시험 데이터와 짝 표(반↔설비번호, 이름↔로트번호, 정답여부↔합격여부)
2. 개념: 수율·불량률 → 왜 묶나 → 왜 여러 열을 보나 → 조심할 점 3가지 → groupby 그림 → 파레토
3. 휴식 → Orange3 시연: File → Box Plot · Distributions(합격여부를 categorical로)
4. **쉬운 예제로 파이썬 개념**(강의 파이썬 ①~④ = 노트북 1~4단계): 정답 열 → 반별 groupby → 학생별 묶기 → 오답 유형 파레토
5. **반도체 데이터로 핵심 확인**(강사 시연): 설비별 합격률 → 최저 수율 로트 LOT-0008 → EQ-04 로트 → "EQ-04가 원인일까?" 토론
6. **실습지 문제 1~9 = 노트북 5~7단계**(반도체 데이터, 학생 실습)
7. AI 활용(노트북 8·9단계) → 정리 퀴즈 + 과제 + 8차시 예고

## 오늘 데이터 핵심 수치(실제 실행 결과, 강의 중 반드시 확인)

### 쉬운 예제 — 반별 쪽지시험(`quiz`, 24행 6열, 가상 데이터, 정답여부 1 = 정답 / -1 = 오답)

### 반도체 — `week07_equipment_yield.csv`(300행 11열, 가상 데이터, 합격여부 1 = 합격 / -1 = 불합격)

- AI 예시 코드(9단계): EQ-02·EQ-04에 `점검 필요`

## 강사 설명 포인트
- 코드보다 숫자 대비를 먼저. 개념 절의 숫자는 뒤 코드에서 다시 나온다고 미리 말한다.
- 짝 표(`quiz`↔`df`, 반↔설비번호, 이름↔로트번호, 정답↔합격, 오답유형↔불량유형)를 칠판에 적는다. 실습지에서 막히면 "노트북 1~4단계의 같은 모양 셀을 복사해 이름만 바꾸라"고 안내한다.
- 칠판에 "1 = 합격, -1 = 불합격". `합격여부`를 바로 평균 내면 EQ-04가 0.5로 나온다는 것을 보여 준다.
- `66 ÷ 88 = 0.75`를 같이 계산해 `mean()`이 "합격 장수 ÷ 처리 장수"임을 확인시킨다.
- "B반 → 학생별"과 "EQ-04 → 로트별"은 같은 발견이다. 쉬운 예제에서 먼저 보여 준 뒤 "반도체 데이터로 확인하기" 확인 3으로 간다.
- "EQ-04가 원인일까요?"를 반드시 묻는다. 22개 중 11개 100%, LOT-0008의 증착·B조로 "원인 후보"까지임을 정리한다.
- 강사만 알 것: 생성기가 EQ-04에 불합격 확률을 높게 줬다. 수업에서 "EQ-04가 실제 문제 설비"라고 말하지 않는다.
- 파레토 상위 3가지는 약 61.1%로 80/20만큼 쏠리지 않는다. 억지로 맞추지 않는다.

## 예상 오개념
- "전체 88.0%면 모든 설비가 88% 근처다" → 75.0~98.1%로 벌어진다.
- "합격 장수가 많으면 좋은 설비다" → 처리 장수가 달라 비율로 비교한다.
- "100%면 완벽하다" → 몇 개 중의 100%인지 본다(서준은 4문항 중 4).
- "평균 온도가 비슷하면 차이가 없다" → 합격률은 크게 달랐다.
- "EQ-04 로트는 다 나쁘다" → 22개 중 11개는 100%.
- "가장 많은 불량 유형 = 원인" → 파레토는 우선순위만 알려 준다.
- "쉬운 예제와 반도체 코드는 다른 문법이다" → 이름만 바뀐다.

## 실습 중 오류 대응
직접 실행해 확인한 오류다(pandas 3.0.2).
- `ValueError: level name 온도_섭씨 is not the name of the index`: `df.groupby("설비번호", "온도_섭씨")` → `df.groupby("설비번호")["온도_섭씨"].mean()`
- `KeyError: 'Column not found: 온도'`: 열 이름 오타 → `print(df.columns)`. 쉬운 예제 열 이름(`정답`, `반`)을 `df`에 쓴 경우도 KeyError.
- `TypeError: dtype 'str' does not support operation 'mean'`: `df.groupby("설비번호").mean()` → 숫자 열을 고른다.
- `SyntaxError: leading zeros in decimal integer literals are not permitted`: `"EQ-04"`·`"LOT-0008"` 따옴표 누락(문제 6·7).
- `FileNotFoundError`: `../../` 누락 또는 `notebooks/student/` 밖에서 연 경우.
- 숫자가 이상함: `<pandas.api.typing.SeriesGroupBy object at 0x...>` → 계산 미부착. EQ-04가 0.5 → `합격` 열을 쓰게 한다.
- `NameError: name 'pass_rate' is not defined`(9단계): 5단계 문제 3 셀 미실행. `NameError: name 'plt' is not defined`(문제 8): 4단계 그래프 셀 미실행.
- 빈칸 미입력(직접 실행해 확인): 값 자리 `NameError: name '____' is not defined`(1·3단계, 문제 1·2·3·4·5·6·7·8),
  함수 자리 `AttributeError: 'SeriesGroupBy' object has no attribute '____'`(2단계, 문제 2), `AttributeError: 'Series' object has no attribute '____'`(4단계, 문제 8),
  `AttributeError: module 'pandas' has no attribute '____'`(문제 1 첫 셀), 비교 기호 `SyntaxError: invalid syntax. Perhaps you forgot a comma?`(문제 5).
  문제 1이 실패하면 아래는 `NameError: name 'df' is not defined` — 맨 위부터 채운다.
- 한글이 네모로 깨짐: 4단계 그래프 셀의 `"Malgun Gothic"` 줄 삭제 또는 Mac(`"AppleGothic"`).

## 빠른 학습자용 추가 과제
- 수율 80% 미만 로트만 골라 불량 유형 세기(조건 검색 + `value_counts()`) → 전체 파레토와 비교.
- 과제 1 미리 하기: 증착 76.9%로 가장 낮다. "설비와 공정 중 무엇이 더 관련 있어 보이나?"(8차시에 다룸)
- `quiz.groupby("문제번호")["정답"].mean() * 100`(1·3번 83.3%, 2·4번 66.7%). 단, 웨이퍼번호별 묶기는 뜻이 다르다 —
  1번 문제는 모두 같은 문제지만 1번 웨이퍼는 로트마다 다른 웨이퍼(상자 안 순번)다.
