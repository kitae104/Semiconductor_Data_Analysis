# 5차시 강의 운영안 — 데이터 훑어보기와 정리(EDA)

## 왜 이걸 배워야 할까? (학생에게 전달할 메시지)

공장 데이터에는 빈칸·중복·튀는 값이 끼어들고, 정리하지 않으면 코드는 돌아가도 숫자가 틀린다.
정리 전 평균 압력 994.4는 학습용 정상 범위(995~1025) 밖처럼 보이지만, 음수 기록 2건을 정리하면 1013.6이다(반 학생 기록에서도 키 1720cm 하나로 평균 키가 276.6cm).

## 수업 흐름

**쉬운 예제(반 학생 기록, `students`)로 개념 → 반도체 데이터로 핵심 확인(강사 시연) → 실습지·노트북 반도체 실습(문제 1~10, `df`)** 순서다.

1. 복습(4차시 `read_csv`·조건 검색·열 선택) → 오늘의 질문 → 정리 전후 표(113→102행, 온도 304.9→300.6, 압력 994.4→1013.6)
2. 개념: 반 학생 기록 15줄에서 눈으로 오류 찾기 → 반도체 열 → 네 가지 문제 표
3. Orange3 시연(반도체 CSV): 빈칸 `?`, Missing, 온도 Max 557.727, 압력 Min -42.9105
4. 휴식
5. 쉬운 예제로 개념(노트북 1~6단계): `describe()`·정리 전 값 → `isna`·`dropna`·`fillna(중앙값)` → 중복 → 이상값 찾기·들여다보기·지우기 → 전후 비교
6. "반도체 데이터로 확인하기" 시연(정답 노트북 7~9단계 셀): 확인 1 빈칸 10칸 = Orange3 / 확인 2 이상값 모두 합격·EQ-03 쏠림 / 확인 3 전후 평균
7. 학생 실습: 실습지 문제 1~10을 보며 학생용 노트북 7~9단계 `____` 채우기 → 해석 한 문장
8. AI로 한 걸음 더(노트북 10·11단계) → 퀴즈 + 과제 + 6차시 예고

## 오늘 데이터 핵심 수치(실제 실행 결과, 강의 중 반드시 확인)

### 쉬운 예제 — `week05_easy_class_records.csv`(생활 예제용 가상 데이터, 15행 5열)
- 결측 3칸(반 조예준, 키 최수아, 몸무게 장서준), 중복 1행(14행 박지호 = 2행), 이상값 1개(4행 정도윤 키 1720.0, 몸무게 66.0).
- `describe()`: 키 count 14 / mean 276.57 / 50% 166.75 / max 1720.0. 정리 전: `15명, 평균 키 276.6, 평균 몸무게 56.4`.
- 행 수: 15 → `dropna(subset=["반"])` 14 → 중앙값 채우기(키 165.2, 몸무게 53.6) → 중복 제거 13 → 키 250 초과 제거 **12**.
- 전후: `학생 수: 15 → 12`, `평균 키: 276.6 → 164.8`, `평균 몸무게: 56.4 → 54.6`.

### 반도체 — `week05_dirty_process_data.csv`(교육용 가상 데이터, 113행 9열)
- 값과 정상 범위(온도 295~305, 압력 995~1025, 가스유량 47~53)는 학습용. `압력_Pa`는 단위·자릿수가 실제와 맞지 않아 절대값을 해석하지 않는다.
- `합격여부` 1 = 합격, -1 = 불합격, 빈칸 2건.
- 결측 **10칸**(온도 3, 압력 2, 가스유량 3, 합격여부 2). 빈칸 있는 행 9행(전부 지우면 104행), 그중 7행은 측정값 한 칸만 빔.
- 문제 1 `describe()`: 온도 mean 304.94 / 50% 300.45 / max 557.73, 압력 mean 994.36 / min -42.91, 가스유량 min -5.0 / max 250.0(Orange3와 같음).
- 행 수: 113 → 문제 4 111 → 문제 5 111(빈칸 0) → 문제 6 108(중복 110·111·112행 = 90·104·2행) → 문제 9 **102**.
- 이상값 6건(전부 합격 1): 고온 17번 EQ-03 식각 540.32, 67번 EQ-03 증착 557.73 / 음수 압력 37번 EQ-04 식각 -42.91, 79번 EQ-02 산화 -26.98 /
  가스유량 65번 EQ-03 -5.0, 86번 EQ-03 250.0. **6건 중 4건 EQ-03.**
- 문제 10: `행 개수: 113 → 102`, `평균 온도: 304.9 → 300.6`, `평균 압력: 994.4 → 1013.6`. 정리 후 count 102, 온도 max 310.9, 압력 min 996.3, 가스유량 43.62~54.7.
- AI 예시 코드: 온도·가스유량 빈칸 3개(2.7%), 압력·합격여부 2개(1.8%).
- 공정명 오타 3건·측정시간 형식 2건은 데이터에 남아 있으나 오늘은 "입력 오류"라는 이름만 소개한다.

## 강사 설명 포인트
- 개념은 쉬운 예제로만 설명하고, 반도체는 "확인하기" 세 가지만 시연한다. 실습지 힌트가 "어느 쉬운 예제와 같은 모양"인지 알려 준다(`students` → `df`, 열 이름만 바꿈).
- "짐작으로 채울 수 없는 값(반, 검사 결과)은 행을 지우고, 측정값 한 칸은 중앙값으로 채운다." 쉬운 예제의 반 = 반도체의 합격여부. 채울 값은 중앙값(용돈 1·1·2·2·100만 원 → 평균 21.2, 중앙값 2).
- `dropna()`·`drop_duplicates()`는 원래 표를 바꾸지 않는다 — 앞에 `df =`를 붙인다.
- 이상값은 "확인할 대상"(건강검진 비유). 키 1720cm·몸무게 66kg → 입력 실수 의심을 먼저 보이고, 같은 생각법으로 확인 2(실습지 문제 8)를 연다.
- **강사만 알 것**: 이상값 위치는 무작위로 정했다. "EQ-03에 4건"은 우연이므로 "확인할 단서"까지만 말한다.
- "정상 범위 밖"(310.9도, 남김)과 "있을 수 없는 값"(지움)을 구분한다. 이상값 기준은 교육용이다. 음수 압력은 이 과정의 기준(진공 = 0)에서만 있을 수 없는 값이고, 게이지 압력이면 음수가 가능하다.
- `loc`로 값만 고치기는 표에서 구경만 한다.

## 예상 오개념
- 빈칸 = 0 → 키를 안 잰 학생은 0cm가 아니다.
- `dropna()`만 실행하면 표가 바뀐다 → `df = df.dropna(...)`. 다음 셀 `shape`로 확인.
- 이상값도 `isna()`로 잡힌다 → 값이 있으므로 조건 검색.
- 이상값은 무조건 지운다 / 정상 범위 밖은 모두 이상값이다 → 오늘 지우는 것은 "있을 수 없는 값"뿐.
- 중복 3건을 지우면 6행이 사라진다 → 복사본 3행만(111 → 108). 쉬운 예제는 14 → 13.
- 쉬운 예제 코드를 그대로 붙이면 된다 → `students`와 열 이름을 바꿔야 한다.
- 이상값이 몰린 설비가 원인이다 → "확인할 단서"까지만. 설비 비교는 7~8차시.
- 문제 8 출력의 `합격여부` `1.0`을 1과 다른 값으로 읽는다 → 빈칸(NaN)이 섞인 열이라 소수로 저장돼 보일 뿐, 1(합격)과 같다.

## 실습 중 오류 대응
- `KeyError: '온도'`: 열 이름을 줄여 썼다. `print(df.columns)`로 확인.
- `KeyError: ['반']`: 쉬운 예제의 `subset=["반"]`을 그대로 두었다. `"합격여부"`로.
- `NameError: name 'students' is not defined`: 쉬운 예제 첫 셀을 건너뛰었다. 위에서부터 다시 실행.
- `AttributeError: 'function' object has no attribute 'sum'`: `df.duplicated.sum()`처럼 괄호 누락.
- `TypeError: Invalid comparison between dtype=float64 and str`: `> "400"`처럼 숫자를 따옴표로 감쌌다.
- 빈칸 `____`을 채우지 않고 실행(실제 메시지):
  - `pd.____(...)`: `AttributeError: module 'pandas' has no attribute '____'`
  - `df.____()`: `AttributeError: 'DataFrame' object has no attribute '____'`
  - `df["____"]`: `KeyError: '____'` / `subset=["____"]`: `KeyError: ['____']` / 문제 8 열 목록: `KeyError: "['____'] not in index"`
  - 비교 기호(문제 7·9): `SyntaxError: invalid syntax. Perhaps you forgot a comma?`
  - 숫자(문제 9): `NameError: name '____' is not defined`
- 오류 없이 `shape`가 그대로: `df =`(`students =`) 누락.
- 전후 비교가 같게 나옴(`102 → 102`, 노트북 9단계): 정리 전 값 셀을 나중에 다시 실행했다. "커널 → 다시 시작 후 모두 실행".
- Orange3 입력 숫자가 113이 아님: Data Table에서 행 선택됨 → Clear Selection. Feature Statistics = Column Statistics(버전 차이).
