⏮️ 지난 시간 복습

4차시 연결 4차시에서는 Pandas로 원하는 행·열을 골라내는 법을 배웠다. 그런데 현실의 데이터에는 빈 칸 (결측값), 같은 내용이 두 번 저장된 행(중복값), 말이 안 되는 값(이상값)이 섞여 있는 경우가 많다. 이런 문제를 그대로 두고 분석하면 평균 같은 요약값이 왜곡된다. 오늘은 Orange3로 먼저 문제를 눈으로 확인한 뒤, Pandas로 직접 찾아 정제하는 법을 배운다.

🟠 ① Orange3로 먼저 훑어보기

위젯 File → Data Table → Feature Statistics

파이썬 코드를 쓰기 전에 Orange3로 같은 CSV를 먼저 열어본다. File 위젯으로 week05_dirty_process_data.csv를 불러오고, Data Table 위젯을 연결하면 빈 칸(결측 셀)이 표에 그대로 보인다. Feature Statistics 위젯을 연결하면 각 열의 최댓값·최솟값이 한눈에 표로 나오는데, 온도_섭씨 열에 500이 넘는 값이 있다면 눈으로 바로 "뭔가 이상하다"는 것을 알아챌 수 있다.

  • Orange3 설치·위젯 사용법이 처음이라면 부록: Orange3 시작하기 참고

💡 실제 Orange3 화면 캡처(위 워크플로를 연결한 캔버스 화면, 결측 셀이 강조된 Data Table 화면)를 강사가 추가하면 더 좋다.

  • Orange3로 미리 살펴본 문제 → 아래에서 파이썬 코드로 하나씩 직접 찾아 정제

🐍 ② 파이썬으로 확인하기 — 숫자 요약부터, 그다음 결측값

먼저 아주 작은 표로 오늘 배울 것 미리 보기

  • 오늘 배울 "결측값·이상값 찾기"를 반도체 데이터로 연습하기 전, 학생 5명 점수로 먼저 감 잡기

Python — 아주 작은 표로 미리 보기
toy = pd.DataFrame({

print(toy)

가장 먼저 하는 습관 — describe()로 숫자 요약 훑어보기

  • 결측값을 하나씩 세기 전, describe()로 숫자 열 전체를 한 번에 요약 — 데이터 분석에서 가장 먼저 하는 습관 중 하나
    • 최솟값·최댓값만 봐도 "말이 안 되는 값" 여부를 바로 감 잡을 수 있음
Python — 숫자 요약
import pandas as pd

df = pd.read_csv("week05_dirty_process_data.csv")
print(df.describe())
실행 결과

count   110.00     111.00      110.00      113.00

결과 읽는 법
  • count — 결측이 아닌(값이 있는) 개수. 전체 113행보다 적은 열 (온도_섭씨 110, 압력_Pa 111, 가스유량_slm 110)에는 결측값이 있다는 뜻이다.
  • mean과 50%(중앙값) — 온도_섭씨의 평균(304.94)이 중앙값 (300.45)보다 눈에 띄게 크다. 평균이 중앙값보다 많이 높다면 극단적으로 큰 값이 섞여 있을 가능성이 높다는 신호다.
  • min/max — 온도_섭씨의 max가 557.73으로 정상 범위 (295~305℃)를 크게 벗어나고, 압력_Pa의 min은 음수(-42.91)다. Orange3 Feature Statistics에서 본 이상값을 숫자로도 확인한 것이다.
주의 — describe()는 숫자형 열만 보여준다 로트번호·설비번호·공정명처럼 문자열(범주형) 열은 describe() 결과에 나오지 않는다. 범주형 열은 value_counts()나 unique()로 따로 확인해야 한다.

결측값 정확히 세기 — isna()

  • describe()의 count → "결측이 있는 열이 있다"까지만 확인 가능
  • isna()로 열별 결측 개수를 정확히 세기
Python — 결측값 확인
print(df.isna().sum())
실행 결과 
측정시간        0
로트번호        0
설비번호        0
공정명         0
온도_섭씨       3
압력_Pa       2
가스유량_slm    3
처리시간_sec    0
합격여부        2
dtype: int64
코드 설명
  • isna(): 각 칸이 결측값(NaN)인지 True/False로 판단한다.
  • .sum(): True를 1로 세어 열별 결측 개수를 더한다.

결측값 처리 — 제거 vs 대체

  • 합격여부 같은 범주형(1 또는 -1) 값 — 평균·중앙값으로 채울 수 없음 → 제거
  • 온도_섭씨 같은 숫자형 값 — 중앙값으로 대체가 안전 (극단값 영향을 덜 받음)
Python
# 합격여부가 결측인 행은 제거(범주형은 대체 불가)
df = df.dropna(subset=["합격여부"])

# 숫자형 열은 중앙값으로 대체
for col in ["온도_섭씨", "압력_Pa", "가스유량_slm"]:
    median_value = df[col].median()
    df[col] = df[col].fillna(median_value)

print(df.isna().sum().sum())   # 남은 결측값 총합
실행 결과 
0
주의 — dropna/fillna는 원본을 바꾸지 않는다 df.dropna(...)와 df[col].fillna(...)는 모두 새 결과를 돌려줄 뿐 원본을 바꾸지 않는다. df = df.dropna(...)처럼 다시 저장해야 실제로 반영된다.

print(df.duplicated().sum())   # 중복 행 개수

df = df.drop_duplicates()
print(df.shape)
실행 결과

주의 — 3건이 사라지면 행이 몇 개 줄어들까? 완전 중복 행이 3건이면, 각 중복 쌍에서 "여분" 1개만 제거되므로 정확히 3행만 줄어든다 (6행이 줄어드는 것이 아니다).

🐍 이상값 찾기 — 4차시 조건 검색 재활용

  • 이상값 = "값이 없는 것"이 아니라 "값은 있지만 말이 안 되는 것" → isna()로 잡히지 않음
  • 4차시에서 배운 조건 검색으로 직접 찾아야 함
Python
hot_outlier = df[df["온도_섭씨"] > 400]
neg_pressure = df[df["압력_Pa"] < 0]
bad_gas = df[(df["가스유량_slm"] < 0) | (df["가스유량_slm"] >= 200)]

print("고온 이상값:", len(hot_outlier), "건")
print("음수 압력:", len(neg_pressure), "건")
print("비정상 가스유량:", len(bad_gas), "건")
실행 결과 
고온 이상값: 2 건
음수 압력: 2 건
비정상 가스유량: 2 건
🙋 직접 해보기 df["공정명"].unique()를 실행해 공정명 열에 어떤 값들이 있는지 확인해보자. 중착, 포토공정처럼 오타가 섞여 있는 것이 보이는가?
Python — 이상값 제거
df = df[df["온도_섭씨"] <= 400]
df = df[df["압력_Pa"] >= 0]
df = df[(df["가스유량_slm"] >= 0) & (df["가스유량_slm"] < 200)]

print(df.shape)
실행 결과 
(102, 9)

참고 — loc로 행을 지우지 않고 "값만" 정정하기

  • 방금은 이상값이 있는 행 전체를 삭제
    • 다른 열은 정상인데 한 열만 튀는 경우 → 행 전체를 버리기 아까움
  • 4차시에서 배운 loc — 조건에 맞는 행의 특정 열 값만 골라 바꿀 수 있음
Python — loc로 값 정정
# 온도가 400도를 넘는 행만, 온도_섭씨 값만 중앙값으로 바꾼다(행은 남긴다)
df.loc[df["온도_섭씨"] > 400, "온도_섭씨"] = df["온도_섭씨"].median()
동작 원리
  • df.loc[조건, "열이름"]은 조건에 맞는 행의 그 열만 콕 집어 가리킨다.
  • 지금까지는 조건 검색으로 데이터를 "읽기"만 했다면, df.loc[조건, 열] = 값은 골라낸 칸에만 새 값을 "쓰는(수정하는)" 것이다 — 다른 칸과 다른 열은 전혀 바뀌지 않는다.
언제 삭제하고, 언제 loc로 정정할까? 여러 값이 동시에 비정상인 행은 행 삭제가 안전하고, 한 열만 튀고 나머지는 정상인 행은 loc로 값만 정정하는 편이 데이터 손실을 줄인다. 정해진 정답은 없으니 상황에 맞게 판단하되, 실습에서는 계속 "행 삭제" 방식을 이어서 쓴다.
체크포인트 — 필터링 후 인덱스에 구멍이 생긴다 dropna()·drop_duplicates()·조건 검색으로 행을 걸러내면, 남은 행의 인덱스 번호(맨 왼쪽 숫자)는 0, 1, 2, ...처럼 다시 매겨지지 않고 원래 번호 그대로 남아 중간중간 번호가 빠지게 된다. 리스트처럼 "몇 번째 행"으로 순서대로 접근하고 싶다면 df = df.reset_index(drop=True)를 추가로 실행해 인덱스를 새로 매겨야 한다.

🗂️ 핵심 용어 카드

결측값

Missing Value
한 줄 설명
칸에 값이 전혀 입력되지 않은 것(NaN).
쉬운 비유
설문지에서 응답하지 않고 비워둔 칸.
데이터에서의 예
df["온도_섭씨"].isna()
자주 하는 오해
결측값(NaN)과 값 0을 혼동하기 쉽다. 0은 "측정된 값이 0"이고 NaN은 "측정 자체가 안 됨"이다.

중복값

Duplicate
한 줄 설명
완전히 똑같은 행이 두 번 이상 저장된 것.
쉬운 비유
같은 사진을 실수로 두 번 저장한 것.
데이터에서의 예
df.duplicated().sum()
자주 하는 오해
중복 3건을 제거하면 6행이 사라진다고 착각하기 쉽다. 실제로는 여분만 제거되어 3행만 줄어든다.

이상값

Outlier
한 줄 설명
정상 범위를 크게 벗어난, 있을 수 없는 값.
쉬운 비유
사람 키가 300cm로 기록된 것처럼 말이 안 되는 값.
데이터에서의 예
온도_섭씨 540℃(정상 범위 295~305℃)
자주 하는 오해
이상값도 결측값처럼 isna()로 잡힌다고 착각하기 쉽다. 값이 "존재"하므로 조건 검색으로 찾아야 한다.

제거 vs 대체

Drop vs Fill
한 줄 설명
결측값을 없애는 두 가지 방법 — 행을 지우거나(제거), 값을 채우거나(대체).
쉬운 비유
빈칸이 많은 시험지는 버리고(제거), 빈칸이 적으면 평균 점수로 채워 넣는(대체) 것.
데이터에서의 예
dropna() vs fillna(중앙값)
자주 하는 오해
항상 평균으로 채우면 된다고 생각하기 쉽지만, 극단값이 있으면 중앙값이 더 안전하다.

주의 — fillna 대상 지정 df.fillna(값)을 열 지정 없이 통째로 쓰면 모든 열이 같은 값으로 채워질 수 있다. 반드시 df["열이름"] = df["열이름"].fillna(값)처럼 열을 지정해야 한다.
