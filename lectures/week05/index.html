결측값과 이상한 데이터 정리하기

💬 오늘의 질문: "빈 칸이 있거나 말이 안 되는 값이 있으면 분석 결과가 어떻게 달라질까? 코드 없이도 이런 문제를 확인할 수 있을까?"

작성 상태 이 페이지는 v2 커리큘럼 구성이 확정된 직후 작성된 개요(skeleton)입니다. 제목·학습 목표·다룰 내용·데이터까지는 확정되었지만, 상세 설명·예제 코드·단계별 실습·퀴즈는 아직 채워지지 않았습니다. 구성이 최종 확정되면 이어서 상세 내용을 작성합니다. 배경은 docs/restructure-plan.md 참고.

🎯 학습 목표

  • 결측값·중복값·이상값을 찾을 수 있다.
  • 결측값을 제거하거나 대체할 수 있다.
  • 정제 전후 데이터를 비교해 차이를 설명할 수 있다.
  • Orange3로 같은 CSV를 코드 없이 열어 결측/이상값을 재확인할 수 있다.

선수 지식: 4주차 — 조건 검색

📚 다룰 이론 주제(초안)

  • 결측값, 중복값, 입력 오류, 이상값
  • 평균/중앙값 대체 vs 제거
  • Orange3 소개 — File → Data Table → Feature Statistics

🧪 다룰 실습 흐름(초안)

  1. isna().sum()으로 결측값 개수 확인하기
  2. dropna(), fillna()로 결측값 처리하기
  3. duplicated()로 중복 행 찾기
  4. 음수 압력·비정상 온도 같은 이상값 찾기
  5. 정제 전후 행 개수·평균값 비교하기

🟠 Orange3 실습(추가 예정)

위젯 File → Data Table → Feature Statistics

같은 CSV를 Orange3로 불러와 Data Table에서 결측 셀을, Feature Statistics에서 최댓값/최솟값(이상값)을 확인한다. Pandas로 계산한 값과 같은지 맞춰본다.
