선수 지식: 4차시 — 조건 검색

⏮️ 지난 시간 복습

4차시 연결 4차시에서는 Pandas로 원하는 행·열을 골라내는 법을 배웠다. 그런데 현실의 데이터에는 빈 칸 (결측값), 같은 내용이 두 번 저장된 행(중복값), 말이 안 되는 값(이상값)이 섞여 있는 경우가 많다. 이런 문제를 그대로 두고 분석하면 평균 같은 요약값이 왜곡된다. 오늘은 Orange3로 먼저 문제를 눈으로 확인한 뒤, Pandas로 직접 찾아 정제하는 법을 배운다.

🟠 ① Orange3로 먼저 훑어보기

위젯 File → Data Table → Feature Statistics

파이썬 코드를 쓰기 전에 Orange3로 같은 CSV를 먼저 열어본다. File 위젯으로 week05_dirty_process_data.csv를 불러오고, Data Table 위젯을 연결하면 빈 칸(결측 셀)이 표에 그대로 보인다. Feature Statistics 위젯을 연결하면 각 열의 최댓값·최솟값이 한눈에 표로 나오는데, 온도_섭씨 열에 500이 넘는 값이 있다면 눈으로 바로 "뭔가 이상하다"는 것을 알아챌 수 있다.

🖼️ 이미지 자리 — 실제 Orange3 화면 캡처(File → Data Table → Feature Statistics를 연결한 워크플로 화면, 결측 셀이 강조된 Data Table 화면)를 강사가 추가하면 좋다.

이제 Orange3로 미리 살펴본 문제를, 아래에서 파이썬 코드로 하나씩 직접 찾아 정제해본다.

🐍 ② 파이썬으로 확인하기 — 결측값 찾고 처리하기

Python — 데이터 읽기와 결측값 확인
import pandas as pd

df = pd.read_csv("week05_dirty_process_data.csv")
print(df.shape)
print(df.isna().sum())
실행 결과

코드 설명
  • isna(): 각 칸이 결측값(NaN)인지 True/False로 판단한다.
  • .sum(): True를 1로 세어 열별 결측 개수를 더한다.

결측값 처리 — 제거 vs 대체

합격여부처럼 범주형(1 또는 -1) 값은 평균이나 중앙값으로 채울 수 없으므로 제거한다. 온도_섭씨처럼 숫자형 값은 중앙값으로 대체하는 것이 안전하다(극단값의 영향을 덜 받기 때문).

Python
# 합격여부가 결측인 행은 제거(범주형은 대체 불가)
df = df.dropna(subset=["합격여부"])

# 숫자형 열은 중앙값으로 대체
for col in ["온도_섭씨", "압력_Pa", "가스유량_slm"]:
    median_value = df[col].median()
    df[col] = df[col].fillna(median_value)

print(df.isna().sum().sum())   # 남은 결측값 총합
실행 결과 
0
주의 — dropna/fillna는 원본을 바꾸지 않는다 df.dropna(...)와 df[col].fillna(...)는 모두 새 결과를 돌려줄 뿐 원본을 바꾸지 않는다. df = df.dropna(...)처럼 다시 저장해야 실제로 반영된다.

🐍 중복값 찾고 제거하기

Python
print(df.duplicated().sum())   # 중복 행 개수

df = df.drop_duplicates()
print(df.shape)
실행 결과 
3
(108, 9)
주의 — 3건이 사라지면 행이 몇 개 줄어들까? 완전 중복 행이 3건이면, 각 중복 쌍에서 "여분" 1개만 제거되므로 정확히 3행만 줄어든다 (6행이 줄어드는 것이 아니다).

🐍 이상값 찾기 — 4차시 조건 검색 재활용

이상값은 "값이 없는 것"이 아니라 "값은 있지만 말이 안 되는 것"이므로 isna()로는 잡히지 않는다. 4차시에서 배운 조건 검색으로 직접 찾아야 한다.

Python
hot_outlier = df[df["온도_섭씨"] > 400]
neg_pressure = df[df["압력_Pa"] < 0]
bad_gas = df[(df["가스유량_slm"] < 0) | (df["가스유량_slm"] >= 200)]

print("고온 이상값:", len(hot_outlier), "건")
print("음수 압력:", len(neg_pressure), "건")
print("비정상 가스유량:", len(bad_gas), "건")
실행 결과 
고온 이상값: 2 건
음수 압력: 2 건
비정상 가스유량: 2 건
🙋 직접 해보기 df["공정명"].unique()를 실행해 공정명 열에 어떤 값들이 있는지 확인해보자. 중착, 포토공정처럼 오타가 섞여 있는 것이 보이는가?
Python — 이상값 제거
df = df[df["온도_섭씨"] <= 400]
df = df[df["압력_Pa"] >= 0]
df = df[(df["가스유량_slm"] >= 0) & (df["가스유량_slm"] < 200)]

print(df.shape)
실행 결과 
(102, 9)

🗂️ 핵심 용어 카드

결측값

Missing Value
한 줄 설명
칸에 값이 전혀 입력되지 않은 것(NaN).
쉬운 비유
설문지에서 응답하지 않고 비워둔 칸.
데이터에서의 예
df["온도_섭씨"].isna()
자주 하는 오해
결측값(NaN)과 값 0을 혼동하기 쉽다. 0은 "측정된 값이 0"이고 NaN은 "측정 자체가 안 됨"이다.

중복값

Duplicate
한 줄 설명
완전히 똑같은 행이 두 번 이상 저장된 것.
쉬운 비유
같은 사진을 실수로 두 번 저장한 것.
데이터에서의 예
df.duplicated().sum()
자주 하는 오해
중복 3건을 제거하면 6행이 사라진다고 착각하기 쉽다. 실제로는 여분만 제거되어 3행만 줄어든다.

이상값

Outlier
한 줄 설명
정상 범위를 크게 벗어난, 있을 수 없는 값.
쉬운 비유
사람 키가 300cm로 기록된 것처럼 말이 안 되는 값.
데이터에서의 예
온도_섭씨 540℃(정상 범위 295~305℃)
자주 하는 오해
이상값도 결측값처럼 isna()로 잡힌다고 착각하기 쉽다. 값이 "존재"하므로 조건 검색으로 찾아야 한다.

제거 vs 대체

Drop vs Fill
한 줄 설명
결측값을 없애는 두 가지 방법 — 행을 지우거나(제거), 값을 채우거나(대체).
쉬운 비유
빈칸이 많은 시험지는 버리고(제거), 빈칸이 적으면 평균 점수로 채워 넣는(대체) 것.
데이터에서의 예
dropna() vs fillna(중앙값)
자주 하는 오해
항상 평균으로 채우면 된다고 생각하기 쉽지만, 극단값이 있으면 중앙값이 더 안전하다.

오류 1 KeyError — 열 이름에 오타나 공백이 있는 경우다. df.columns로 정확한 열 이름을 먼저 확인하자(특히 가스유량_slm, 처리시간_sec).
주의 — fillna 대상 지정 df.fillna(값)을 열 지정 없이 통째로 쓰면 모든 열이 같은 값으로 채워질 수 있다. 반드시 df["열이름"] = df["열이름"].fillna(값)처럼 열을 지정해야 한다.

Q1. (객관식) 결측값(NaN)에 대한 설명으로 가장 알맞은 것은?
  • A. 값이 0으로 기록된 것
  • B. 칸에 값이 전혀 입력되지 않은 것
  • C. 정상 범위를 크게 벗어난 값
  • D. 완전히 똑같은 행이 두 번 저장된 것
정답: B. 결측값은 칸이 비어 있는 것이다. C는 이상값, D는 중복값에 대한 설명이다.
Q2. (참/거짓) df.dropna()를 실행하면 원본 df 자체가 바로 바뀐다.
정답: 거짓. 결과를 새로 돌려줄 뿐 원본은 바뀌지 않는다. df = df.dropna()처럼 다시 저장해야 한다.
Q3. (참/거짓) 이상값이 섞여 있을 가능성이 있는 열은 평균보다 중앙값으로 대체하는 것이 더 안전하다.
정답: 참. 평균은 극단값 하나에도 크게 흔들리지만, 중앙값은 크기순 정가운데 값이라 극단값의 영향을 거의 받지 않는다.
Q4. (빈칸) 중복 행을 제거하는 Pandas 메서드는 df.______()이다.
정답: drop_duplicates
Q5. (서술) Orange3에서 눈으로 확인한 문제와 Pandas 코드로 찾은 문제가 같았는지, 각각 어떤 장단점이 있었는지 한 문장으로 비교해보자.
