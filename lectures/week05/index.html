데이터 훑어보기와 정리(EDA)

오늘의 질문: "코드를 한 줄도 쓰기 전에, 이 데이터에 어떤 문제가 있어 보이는지 먼저 확인할 수 있을까?"

학습 목표

  • 공장 데이터에 빈칸·중복·튀는 값이 왜 생기는지, 그대로 두면 평균이 어떻게 틀어지는지 설명할 수 있다.
  • Orange3로 CSV를 열어 빈칸과 튀는 값이 있는 열을 먼저 눈으로 찾을 수 있다.
  • Pandas로 결측값·중복값·이상값을 찾고, 지울지 채울지 골라 정리할 수 있다.
  • 정리 전후의 행 개수와 평균을 비교해 한 문장으로 해석할 수 있다.

선수 지식: 4차시 — read_csv, 열 선택, 조건 검색 / 3차시 — for 반복문 / 1차시 — f-string

왜 이걸 배워야 할까?

공장 데이터에는 빈칸·중복·튀는 값이 끼어든다. 정리하지 않으면 코드는 돌아가도 숫자가 틀린다(오늘 실습에서 직접 계산하는 결과).

비유 — 가계부 같은 영수증을 두 번 적은 가계부로는 지출을 믿을 수 없다. 분석 전에 데이터를 훑어보고 정리하는 일을 EDA(탐색적 데이터 분석)라고 한다.

오늘 반도체 데이터의 열

week05_dirty_process_data.csv(113행 9열, 교육용 가상 데이터). 한 행 = 공정 작업 1건.

열공장에서의 뜻
측정시간, 로트번호, 설비번호, 공정명언제, 어느 웨이퍼 묶음을, 어느 기계(EQ-01~EQ-04)에서, 어떤 작업(포토·식각·증착·세정·산화)으로
온도_섭씨, 압력_Pa, 가스유량_slm센서가 잰 설비 안의 온도·압력, 흘려 넣은 가스의 양(slm: 1분 동안 흐른 가스 리터)
처리시간_sec작업에 걸린 시간(초)
합격여부검사 결과. 1 = 합격, -1 = 불합격
단위 읽는 법 이번 차시에 새로 나오는 단위들이다. 열 이름의 밑줄 뒤가 단위인 규칙은 1차시와 같다.
표기읽는 법뜻
cm (키_cm)센티미터길이. 100cm = 1m
kg (몸무게_kg)킬로그램무게. 1kg = 1000g
sec (처리시간_sec)초 (영어로 second의 줄임)시간. 60초 = 1분

값과 정상 범위(온도 295~305, 압력 995~1025, 가스유량 47~53)는 학습용이라 실제 공정 조건으로 해석하지 않는다.

이상값값은 있는데 말이 안 되게 튄다키 1720cm센서 고장, 입력 실수, 또는 진짜 설비 문제6건
입력 오류같은 뜻인데 글자·형식이 다르다없음오타, 설비마다 다른 날짜 형식공정명 3건, 측정시간 2건(오늘은 이름만)
  • 두 데이터의 오류는 연습용으로 일부러 넣었다. 표의 이유는 현장에서 흔한 예다.

  • 순서: 훑어보기 → 결측값 → 중복값 → 이상값 → 정리 전후 비교.

코드 없이 반도체 CSV를 열어본다. 왼쪽 Data 묶음에서 위젯 세 개를 캔버스로 끌어다 놓고 선으로 잇는다 (처음이면 부록: Orange3 시작하기).

  1. File — 더블클릭 → 폴더 아이콘 → week05_dirty_process_data.csv 선택.
  2. Data Table — File과 잇고 더블클릭. 빈칸은 ?로 보인다.
  3. Column Statistics(버전에 따라 Feature Statistics) — Data Table과 잇고 Min., Max., Missing 칸을 본다.

isna()는 칸마다 "비어 있나?"를 True/False로 바꾸고, .sum()이 True를 세어 열별 빈칸 개수가 나온다.

지울까, 채울까 — dropna()와 fillna()

방법이럴 때반 학생 기록
dropna() — 행 지우기짐작해서 채우면 안 되는 값(반·검사 결과)조예준의 반
fillna(값) — 채우기측정값 한 칸만 비고 나머지는 멀쩡최수아의 키, 장서준의 몸무게
비유 — 용돈 용돈 1·1·2·2·100만 원의 평균은 21.2만 원, 중앙값(크기순 한가운데 값)은 2만 원이다. 튀는 값에 덜 흔들리는 중앙값으로 채운다.

쉬운 예제 — 반이 빈 행은 지우고, 키·몸무게 빈칸은 채우기

Python — 쉬운 예제: 지우기와 채우기
students = students.dropna(subset=["반"])
print(students.shape)

for col in ["키_cm", "몸무게_kg"]:
    median_value = students[col].median()
    students[col] = students[col].fillna(median_value)

print(students.isna().sum())

키_cm      0

  • subset=["반"]은 "이 열이 빈 행만 지워라". 앞의 students =로 다시 저장해야 반영된다.
  • for로 두 열을 돌며 중앙값(키 165.2, 몸무게 53.6)으로 빈칸을 채웠다.
  • col에는 반복할 때마다 "키_cm", "몸무게_kg"가 차례로 들어간다. = 왼쪽에 students[col]을 쓰면 그 열을 빈칸을 채운 값으로 바꿔 저장한다.
AI에게 물어보기 — 복사해서 AI 챗봇에 붙여넣기
데이터 분석을 처음 배우는 사람이야. 빈칸(결측값)을 지우는 것과 채우는 것은 각각 언제 쓰는지, 반 학생들 시험 점수표를 예로 들어 초보자 눈높이로 설명해줘.

중복값 찾고 지우기

duplicated()는 앞의 행과 모든 칸이 같은 행을 True로 표시하고, drop_duplicates()는 그 여분을 지운다.

쉬운 예제 — 두 번 적힌 학생

Python — 쉬운 예제: 세고, 들여다보고, 지우기
print(students.duplicated().sum())

dup = students[students.duplicated()]
print(dup[["이름", "반", "키_cm", "몸무게_kg"]])

students = students.drop_duplicates()
print(students.shape)

students[students.duplicated()]는 4차시 df[조건]과 같은 모양이다(duplicated()가 True인 행만 고른다). 원본(2행)은 남고 여분(14행)만 지워져 1행만 줄었다.

이상값 찾기 — 지우기 전에 들여다보기

이상값은 값이 있어서 isna()로 안 잡힌다. 조건 검색으로 찾고, 지우기 전에 다른 열과 함께 본다.

비유 — 건강검진 혈압 300이 나오면 의사는 지우지 않고 다시 재고 다른 결과와 함께 본다. 기계 고장일 수도, 진짜 위험 신호일 수도 있다.

print(tall[["이름", "반", "키_cm", "몸무게_kg"]])

이상값 지우기 — 무엇을 지우고 무엇을 남길까

선택언제방법
행을 지운다기록 오류가 분명할 때조건 검색으로 정상 행만 남긴다(오늘 실습)
값만 고친다한 칸만 튀고 올바른 값이 확실할 때(1720 → 172.0)df.loc[조건, "열이름"] = 새 값 (오늘은 구경만)
남겨두고 표시한다진짜 문제의 신호일 수 있을 때따로 모아 담당자에게 확인 요청

질문해보기 — 하나 이상 골라서 (노트북 10단계)
  • "데이터에 빈칸이 있을 때 지우는 것과 채우는 것은 각각 언제 쓰나요? 공장 데이터 예시로 설명해주세요."
  • "평균과 중앙값의 차이를 용돈 이야기로 설명해주세요."
  • "이상값을 무조건 지우면 안 되는 이유를 예시와 함께 알려주세요."
코드 받아보기 (노트북 11단계) "week05_dirty_process_data.csv를 읽어서, 열마다 빈칸이 몇 개이고 전체의 몇 %인지 한 줄씩 출력하는 파이썬 코드를 만들어줘. for 반복문과 f-string을 써줘."
Python — AI가 만들어줄 수 있는 코드 예시
import pandas as pd

data = pd.read_csv("../../data/weekly/week05/week05_dirty_process_data.csv", encoding="utf-8-sig")

for col in data.columns:
    count = data[col].isna().sum()
    rate = count / len(data) * 100
    print(f"{col}: 빈칸 {count}개 ({rate:.1f}%)")
