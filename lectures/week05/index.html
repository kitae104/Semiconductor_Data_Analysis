데이터 훑어보기와 정리(EDA)

오늘의 질문: "코드를 한 줄도 쓰기 전에, 이 데이터에 어떤 문제가 있어 보이는지 먼저 확인할 수 있을까?"

학습 목표

  • 공장 데이터에 빈칸·중복·튀는 값이 왜 생기는지, 그대로 두면 평균이 어떻게 틀어지는지 설명할 수 있다.
  • Orange3로 CSV를 열어 빈칸과 튀는 값이 있는 열을 먼저 눈으로 찾을 수 있다.
  • Pandas로 결측값·중복값·이상값을 찾고, 지울지 채울지 골라 정리할 수 있다.
  • 정리 전후의 행 개수와 평균을 비교해 한 문장으로 해석할 수 있다.

선수 지식: 4차시 — read_csv, 열 선택, 조건 검색 / 3차시 — for 반복문 / 1차시 — f-string

왜 이걸 배워야 할까?

  • 공장 데이터는 사람이 한 줄씩 적는 것이 아니라 센서·설비·네트워크가 자동으로 쌓는다. 그 과정에서 빈칸, 같은 기록의 중복, 말이 안 되게 튀는 값이 끼어든다.
  • 지저분한 채로 계산하면 결과가 틀린다. 코드가 오류 없이 돌아가도 숫자가 틀린다는 점이 더 무섭다.
  • 오늘 데이터를 정리하기 전과 후를 비교하면 이렇다(실습에서 직접 계산하는 실제 결과다).
항목정리 전정리 후무엇이 달라졌나
행 개수113행102행중복 3행, 결과가 빈 2행, 튀는 값이 있는 6행을 덜어냈다

비유 — 가계부 같은 영수증을 두 번 적거나, 5,000원을 50,000원으로 잘못 적은 가계부로는 "이번 달에 얼마 썼는지" 믿을 수 없다. 그래서 분석의 첫 단계는 데이터를 훑어보고 정리하는 것이다. 이 단계를 EDA(탐색적 데이터 분석)라고 부른다.

문제는 크게 네 종류다. 이름보다 왜 생기는지를 먼저 보자.

문제한 줄 뜻공장에서 생기는 이유(예)생활 속 비유오늘 데이터

오늘 데이터의 문제는 일부러 넣은 것 오늘 데이터의 빈칸·중복·튀는 값은 연습을 위해 일부러 넣었다. 그래서 하나하나가 정확히 왜 생겼는지는 알 수 없다. 위 표의 이유는 실제 공장에서 흔히 생기는 경우를 예로 든 것이다.

빈칸은 0이 아니다

  • Pandas는 빈칸을 NaN(Not a Number, "값 없음")으로 표시한다.
  • 시험을 안 본 학생(빈칸)과 0점을 받은 학생은 다르다. 빈칸을 0으로 바꾸면 평균이 엉뚱하게 내려간다.

정리 전 값 기억해 두기

정리가 끝난 뒤 비교하려면 지금 값을 변수에 저장해 둬야 한다(1차시 변수·f-string). .mean()은 평균을 구한다. 빈칸은 빼고 계산한다.

Python — 정리 전 값 저장
before_rows = len(df)
before_temp = df["온도_섭씨"].mean()
before_pressure = df["압력_Pa"].mean()

print(f"정리 전: {before_rows}행, 평균 온도 {before_temp:.1f}, 평균 압력 {before_pressure:.1f}")
실행 결과

주의 — 이 셀은 한 번만 정리가 끝난 뒤 이 셀을 다시 실행하면 정리된 값이 "정리 전"으로 저장된다. 그러면 마지막 비교에서 전후가 똑같이 나온다.

지울까, 채울까 — dropna()와 fillna()

방법하는 일이럴 때 쓴다오늘 데이터
dropna() — 지우기빈칸이 있는 행을 통째로 뺀다빈칸을 짐작해서 채우면 안 되는 값일 때(검사 결과처럼)합격여부가 빈 2행
fillna(값) — 채우기빈칸에 정한 값을 넣는다측정값 한 칸만 비었고 그 행의 나머지는 멀쩡할 때온도·압력·가스유량의 빈칸 8칸
한 줄 기준 "결과는 지우고, 측정값은 채운다." 합격여부를 지어내 채우면 없던 검사 결과를 만드는 셈이다. 반대로 온도 한 칸이 비었다고 행을 통째로 버리면 멀쩡한 압력·가스유량·검사 결과까지 버리게 된다. 오늘 데이터에서 빈칸이 있는 행을 전부 지우면 9행이 사라지는데, 그중 7행은 측정값 한 칸만 빈 기록이다.
Python — 결과가 빈 행 지우기
df = df.dropna(subset=["합격여부"])
print(df.shape)
실행 결과 
(111, 9)
  • subset=["합격여부"] — "이 열이 빈 행만 지워라"라는 뜻이다. 빼면 아무 열이나 빈 행을 모두 지운다.
  • 앞의 df =가 중요하다. dropna()는 지운 결과를 새로 돌려줄 뿐 원래 df를 바꾸지 않는다. 다시 저장해야 반영된다.

채울 값은 평균이 아니라 중앙값으로 한다. 중앙값은 값을 크기순으로 줄 세웠을 때 한가운데 값이다.

비유 — 용돈 다섯 명의 한 달 용돈이 1만, 1만, 2만, 2만, 100만 원이면 평균은 21.2만 원, 중앙값은 2만 원이다. 평균은 100만 원 한 명에게 끌려가지만 중앙값은 거의 흔들리지 않는다. 오늘 온도에도 557도 같은 값이 섞여 있으니 빈칸은 중앙값으로 채우는 편이 안전하다.
Python — 측정값 빈칸을 중앙값으로 채우기
for col in ["온도_섭씨", "압력_Pa", "가스유량_slm"]:
    median_value = df[col].median()
    df[col] = df[col].fillna(median_value)

print(df.isna().sum())

코드 설명
  • 3차시 for 반복문이다. 세 열 이름을 하나씩 col에 넣으며 같은 일을 반복한다.
  • df[col].median() — 그 열의 중앙값을 구한다.
  • df[col] = df[col].fillna(median_value) — 빈칸을 중앙값으로 채운 결과를 같은 열에 다시 저장한다.
  • 다시 isna().sum()을 해 보니 모두 0이다. 빈칸이 남지 않았다.

dropna vs fillna
한 줄 설명

  • 해결: print(df.columns)로 정확한 열 이름을 확인한다. 밑줄(_)과 단위까지 똑같이 쓴다.
오류 2 — 괄호를 빼먹었을 때
  • AttributeError: 'function' object has no attribute 'sum'
  • 원인: df.duplicated.sum()처럼 duplicated 뒤의 ()를 빼먹었다.
  • 해결: df.duplicated().sum()처럼 함수 이름 뒤에 괄호를 붙인다. isna()도 같다.
오류 3 — 숫자를 따옴표로 감쌌을 때
  • TypeError: Invalid comparison between dtype=float64 and str
  • 원인: df["온도_섭씨"] > "400"처럼 숫자 400을 글자로 적었다.
  • 해결: 숫자와 비교할 때는 따옴표 없이 400으로 쓴다.
주의 — 오류는 안 나는데 결과가 그대로일 때 df.dropna(subset=["합격여부"])처럼 앞에 df =를 빼면 오류 없이 결과만 보여주고 df는 그대로다. 다음 셀의 shape가 줄지 않았다면 이것부터 확인한다.
주의 — 맨 왼쪽 번호에 빈 곳이 생긴다 행을 지우면 맨 왼쪽 행 번호(인덱스)는 다시 매겨지지 않는다. 102행인데 번호가 112까지 가는 것은 오류가 아니다.

도전 실습

노트북 6단계 아래의 도전 문제 셀에서 푼다. 본 실습을 다 끝낸 사람만 도전한다.

도전 문제 1 — 공정명 오타 통일
  • df["공정명"].value_counts()로 공정명별 개수를 보면 중착, 포토공정이 보이고, 식각이 두 줄로 나온다. 하나는 뒤에 눈에 안 보이는 공백이 붙은 식각 이다.
  • ① str.strip() — 글자 앞뒤 공백을 지운다: df["공정명"] = df["공정명"].str.strip()
  • ② replace() — 2차시 딕셔너리 {옛 값: 새 값}대로 바꾼다: df["공정명"] = df["공정명"].replace({"중착": "증착", "포토공정": "포토"})
  • 다시 value_counts()를 보면 공정명이 5개만 남는다.
도전 문제 2 — 형식이 다른 측정시간 찾기
  • 정상 측정시간은 2024-03-05 10:00처럼 16글자다. 형식이 다른 기록이 2건 섞여 있다.
  • ① 글자 수로 찾기: odd_time = df[df["측정시간"].str.len() != 16] → 결과가 1건뿐이다.
  • ② 왜 1건뿐일까? 나머지 03-05-2024 10:00은 정상값과 똑같이 16글자라 길이로는 안 걸린다. 5번째 글자가 -인지로 찾으면 2건이 모두 나온다: odd_time = df[df["측정시간"].str[4] != "-"] (파이썬은 위치를 0부터 세므로 5번째 글자는 str[4]다)
여기서 얻어갈 것 한 가지 방법으로 찾았다고 다 찾은 것은 아니다. "이 방법이 놓치는 경우는 없을까?"를 한 번 더 묻자.

결과 정리 & 퀴즈

더 많은 문제는 실습지에 있다.

Q1. (객관식) 결측값(NaN)에 대한 설명으로 가장 알맞은 것은?
  • A. 값이 0으로 기록된 것
  • B. 값이 있어야 할 칸이 비어 있는 것
  • C. 다른 값들과 동떨어지게 튀는 값
  • D. 똑같은 행이 두 번 저장된 것
정답: B. A의 0은 "잰 값이 0"이라 결측값과 다르다. C는 이상값, D는 중복값이다.
Q2. (객관식) 합격여부 칸이 빈 행은 어떻게 처리하는 것이 알맞은가?
  • A. 합격여부의 평균으로 채운다
  • B. 1(합격)로 채운다
  • C. 그 행을 지운다(dropna)
  • D. 0으로 채운다
정답: C. 검사 결과는 짐작해서 채우면 없던 결과를 지어내는 셈이다. "결과는 지우고, 측정값은 채운다."
Q3. (참/거짓) 이상값도 결측값처럼 isna()로 찾을 수 있다.
정답: 거짓. 이상값은 값이 "있기" 때문에 isna()에 잡히지 않는다. 조건 검색(df[df["온도_섭씨"] > 400])으로 찾는다.
Q4. (빈칸) 중복 행을 지우는 Pandas 함수는 df.______()이다.
정답: drop_duplicates
Q5. (객관식) 고온 이상값 2건(540.3도, 557.7도)이 모두 합격이었고 같은 설비(EQ-03) 기록이었다. 가장 알맞은 태도는?
  • A. 이상값이니 바로 지우고 잊는다
  • B. 합격했으니 문제없는 값으로 보고 그대로 평균을 낸다
  • C. 기록 오류인지 진짜 설비 문제인지 확인할 단서로 보고, EQ-03 센서 점검을 제안한다
  • D. EQ-03이 불량의 원인이라고 결론 내린다
정답: C. 이상값은 지울 대상이기 전에 확인할 대상이다. 6건뿐이라 우연일 수 있으므로 D처럼 단정할 수는 없다.
Q6. (서술) 오늘 데이터를 정리하기 전과 후를 비교해 한 문장으로 설명해보자.
예시 답안: "원본 113행에서 중복·결과 누락·이상값을 정리해 102행이 남았고, 평균 온도는 304.9에서 300.6으로, 평균 압력은 994.4에서 1013.6으로 바뀌었다. 몇 건의 튀는 값이 평균을 크게 움직이고 있었다."

AI로 한 걸음 더 — 질문하고 코드 받아보기

이번 차시도 AI와 함께 데이터 정리에는 정답이 하나로 정해져 있지 않은 경우가 많다. AI에게 질문하며 오늘 배운 방법 외의 선택지도 알아보자.
질문해보기 — 하나 이상 골라서 (노트북 7단계)
  • "데이터에 빈칸이 있을 때 지우는 것과 채우는 것은 각각 언제 쓰나요? 공장 데이터 예시로 설명해주세요."
  • "평균과 중앙값의 차이를 용돈 이야기로 설명해주세요."
  • "이상값을 무조건 지우면 안 되는 이유를 예시와 함께 알려주세요."
  • "이상값을 찾는 통계적 방법(IQR 등)에는 어떤 것이 있나요?" (오늘 배우지 않은 내용이라 구경만 한다)
코드 받아보기 (노트북 8단계) "week05_dirty_process_data.csv를 읽어서, 열마다 빈칸이 몇 개이고 전체의 몇 %인지 한 줄씩 출력하는 파이썬 코드를 만들어줘. for 반복문과 f-string을 써줘."
Python — AI가 만들어줄 수 있는 코드 예시
import pandas as pd

data = pd.read_csv("../../data/weekly/week05/week05_dirty_process_data.csv", encoding="utf-8-sig")

for col in data.columns:
    count = data[col].isna().sum()
    rate = count / len(data) * 100
    print(f"{col}: 빈칸 {count}개 ({rate:.1f}%)")

연습문제 — 나만의 정제 리포트 만들기

원본 파일을 raw_df라는 새 이름으로 다시 읽어, 정리 전 상태를 리포트로 출력해보자. (df는 이미 정리가 끝났으므로 원본을 보려면 파일을 새로 읽어야 한다.)

직접 해보기 (노트북 9단계)
  • raw_df["온도_섭씨"].isna().sum()으로 온도 빈칸 개수를, raw_df.duplicated().sum()으로 중복 행 개수를 센다.
  • 원본 행 수 len(raw_df)와 정리 후 행 수 len(df)를 f-string으로 함께 출력한다.
raw_df = pd.read_csv("../../data/weekly/week05/week05_dirty_process_data.csv", encoding="utf-8-sig")
temp_missing = raw_df["온도_섭씨"].isna().sum()
dup_count = raw_df.duplicated().sum()

print(f"정제 리포트: 원본 {len(raw_df)}행 → 정리 후 {len(df)}행")
print(f"온도 빈칸 {temp_missing}건, 중복 행 {dup_count}건을 확인했습니다.")

AI로 재미있는 미니 프로그램 만들기 — 이상값 탐정 게임

오늘의 미니 프로젝트 (노트북 10단계) 오늘 배운 "있을 수 없는 값"과 "정상 범위 밖이라 확인할 값"의 차이를 게임으로 만들어보자. 3차시에 배운 for, if/elif/else로 만들 수 있다.
프롬프트 예시 — 그대로 물어보기 "온도 리스트를 받아서 400보다 크면 '있을 수 없는 값', 295~305 밖이면 '용의자', 나머지는 '정상 범위'라고 하나씩 판정하는 이상값 탐정 게임 코드를 파이썬으로 만들어줘. for와 if/elif/else를 써줘."
Python — AI가 만들어줄 수 있는 코드 예시
temps = [301.2, 298.5, 310.9, 540.3, 299.9, 291.3, 302.4]

print("이상값 탐정 게임 시작!")
for t in temps:
    if t > 400:
        print(f"{t}도 → 있을 수 없는 값! 기록 오류부터 의심")
    elif t > 305:
        print(f"{t}도 → 용의자! 정상 범위보다 높아 확인 필요")
    elif t < 295:
        print(f"{t}도 → 용의자! 정상 범위보다 낮아 확인 필요")
    else:
        print(f"{t}도 → 정상 범위")
