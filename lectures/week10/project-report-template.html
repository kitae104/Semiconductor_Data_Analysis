2. 분석 배경

작성 안내 [여기에 분석 배경을 2~3문장으로 작성하세요. 왜 이 주제를 선택했는지, 어떤 문제의식에서 출발했는지를 적습니다. 예: "6주차에서 설비별로 불량률 차이가 있다고 배웠는데, 더 큰 규모의 데이터에서도 같은 패턴이 나타나는지 확인하고 싶었다."]

3. 분석 질문

작성 안내 [여기에 데이터로 답하고자 하는 구체적인 질문을 한 문장으로 작성하세요. "~와 ~는 관계가 있을까?", "어느 ~가 가장 ~한가?" 형태를 권장합니다. 예: "설비별로 불량률에 차이가 있을까?"]

4. 사용 데이터

작성 안내 [사용한 데이터 파일명과 크기(행/열)를 적으세요. 예: "week10_mini_project_dataset.csv (600행 16열)"]

5. 데이터 설명

작성 안내 [분석에 사용한 주요 열(컬럼)이 무엇을 의미하는지 2~4개 정도 짧게 설명하세요. 예: "설비번호는 공정을 수행한 설비 ID(EQ-01~EQ-04)이고, 검사결과는 0=정상/1=이상을 의미한다."]

6. 데이터 정리 과정

작성 안내 [결측값·이상값을 어떻게 확인하고 처리했는지 적으세요. 처리한 것이 없다면 "결측값과 이상값을 확인했으나 특별한 처리가 필요하지 않았다"처럼 확인 사실 자체를 적어도 됩니다. 예: "isna().sum()으로 확인한 결과 불량유형 열에만 결측값(541건)이 있었으며, 이는 정상 판정이라 불량 유형을 기록하지 않은 경우였다."]
