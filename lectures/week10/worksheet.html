모델 평가와 새 데이터 예측 — 실습지

왜 이걸 배워야 할까?

  • 9차시에 만든 모델은 "공부를 마친 학생"이다. 오늘은 모의고사(test) 점수를 제대로 읽고, 정답지가 없는 실제 시험(새 로트)을 보게 한다.
  • 정확도 하나만 보면 쓸모없는 모델을 믿게 될 수 있다. 그리고 예측이 맞아도 원인을 안 것은 아니다.
부호와 확률 열 정답 열 합격여부는 1~8차시와 같은 표기다(1 = 합격, -1 = 불합격). 확률 표의 열 순서는 model.classes_([-1 1])를 따르므로 0번 열이 불합격(-1)일 확률이다.

2. 정확도의 함정 — 계산 문제

  1. 로트 100개 중 합격이 95개, 불합격이 5개다. "전부 합격"이라고 찍으면 정확도는 몇 %인가? 이때 불합격은 몇 개 잡는가?
  2. 오늘 test 데이터는 합격(1) 116건, 불합격(-1) 31건이다. "전부 합격"이라고 찍으면 정확도는 몇 %인가? (소수 첫째 자리까지)
  3. 오늘 모델의 정확도는 80.3%였다. 이 모델은 찍기(기준선)보다 얼마나 나은가? 맞힌 개수로 비교해 보자.
1) 95%, 불합격은 0개를 잡는다. 점수는 높지만 찾아야 할 것을 하나도 못 찾았다.
2) 116 ÷ 147 × 100 = 78.9% (노트북 2단계 기준선 셀의 결과와 같다)
3) 조금(1.4%p) 낫다. 맞힌 개수로는 모델 118건, 찍기 116건으로 2건 차이다. 80%라는 숫자만 보면 잘하는 것 같지만 찍기도 79%다.

노트북 3~5단계의 빈칸과 같다.

Python
X_new = new_lots[__________]

new_lots["예측_합격여부"] = model.__________(X_new)

proba = model.__________(X_new)
new_lots["불합격_확률"] = proba[:, __].round(3)
순서대로 feature_cols, predict, predict_proba, 0. classes_가 [-1 1]이라 0번 열이 불합격(-1)일 확률이다. feature_cols는 1단계에서 만든 단서 열 6개의 목록이라, 학습 때와 같은 열을 같은 순서로 고를 수 있다.

5. 왜 열 구성이 같아야 할까?

친구가 model.predict(new_lots)처럼 새 로트 표를 통째로 넣었더니 오류가 났다.

  1. 어떤 오류가 나는가? 오류 메시지 아래에 어떤 열 이름이 나오는가?
  2. 이 오류가 나는 이유를 "모의고사·실제 시험" 비유로 한 문장으로 설명해보자.
1) ValueError: The feature names should match those that were passed during fit. — 아래에 학습 때 못 본 열 공정명, 설비번호가 나온다.
2) 예시: "모델은 온도·압력·가스유량·두께·진공도·습도 6개 단서로 답하는 연습만 했으므로, 실제 시험에서도 같은 단서를 같은 순서로 줘야 문제를 풀 수 있다."

6. 결과 해석 문제

새 로트 9건을 예측한 결과, 2번만 불합격(-1)으로 예측되었고 나머지 8건은 합격(1)으로 예측되었다. 불합격 확률은 2번 61.4%, 0번·6번 37.5%, 나머지 7.6%였다.

  1. 예측 결과(1/-1)만 보고서에 적으면 놓치게 되는 정보는 무엇인가?
  2. 합격(1)으로 예측된 로트 중 불합격 확률이 가장 높은 로트는 몇 번과 몇 번인가? 두 로트의 공통점은 무엇인가? (노트북 5단계 표를 보고 답한다)
  3. "그러니 진공도가 낮은 것이 불합격의 원인이다"라고 단정해도 될까?
1) 같은 합격 예상이라도 확신의 정도가 다르다는 정보(37.5% vs 7.6%). 어떤 로트를 먼저 다시 확인할지 정할 수 없게 된다.
2) 0번과 6번(둘 다 37.5%). 진공도가 4.02, 4.35로 9건 중 가장 낮다. 온도는 294.5도와 305.2도로 서로 다르다.
3) 안 된다. 모델은 "진공도가 낮은 묶음에 과거 불합격이 많았다"를 이용했을 뿐이다. 근거도 정답 없는 새 로트가 아니라 연습문제(train) 데이터에서 찾는다(온도가 비슷한 로트 중 진공도 약 4.42 이하 묶음 24건 중 9건 불합격 vs 옆 묶음 382건 중 29건). 그래서 진공도는 불합격의 원인 후보로 더 살펴볼 만하다고까지만 쓴다.

10. 연습문제 — 위험 로트 개수 세기

불합격 확률이 0.5보다 큰 로트를 "위험 로트"로 정하고, 몇 개인지 세어보자(4차시 조건 검색). 노트북 9단계와 같다.

Python
risky_lots = new_lots[new_lots["불합격_확률"] ____ 0.5]
print(f"위험 로트(불합격 확률 50% 초과) 개수: {len(risky_lots)}개")
빈칸은 >. 결과는 1개(2번, 61.4%)다. predict()가 -1로 예측한 로트와 같다. predict()는 불합격 확률이 50%를 넘으면 -1을 고르기 때문이다. 기준을 0.3으로 낮추면 (new_lots[new_lots["불합격_확률"] >= 0.3]) 3개(0번·2번·6번)가 잡힌다.

11. 심화 실습 — 더 깊은 나무

심화 강의 「도전 실습」처럼 max_depth=8인 model2를 만들어, 두 모델의 연습문제(train) 데이터 정확도와 test 정확도를 비교해보자. 그리고 결과를 "연습문제 답을 외운 학생"에 빗대어 한 문장으로 적어보자. (노트북 5단계 끝 "도전 문제")
체크포인트 깊이 4는 연습문제 84.7% / test 80.3%, 깊이 8은 연습문제 94.2% / test 78.9%(찍기와 같음)다. 깊이 8은 새 로트 0번을 불합격(-1), 2번을 합격(1)으로 예측해 깊이 4와 답이 엇갈린다. 공부한 문제는 더 잘 맞히지만 처음 보는 문제는 더 틀린다. 복잡한 모델이 항상 더 좋은 것은 아니다.
