반도체 공정 데이터 분석 미니 프로젝트 — 프로젝트 기획서

이 실습지는 오늘 프로젝트를 시작하기 전, 생각을 정리하는 "기획서"다. 빈칸을 채운 뒤 Notebook 실습으로 넘어가자.

1. 주제 선택 체크리스트

아래 8가지 주제 중 하나에 표시(✔)하자.

선택주제주로 쓰는 열
☐① 설비별 불량률 비교설비번호, 검사결과
☐② 저수율 로트 찾기로트번호, 검사결과
☐③ 온도 이상 구간 탐지측정시간, 온도_섭씨
☐④ 진공도-불량 관계진공도_mTorr, 검사결과
☐⑤ 냉각수온도-공정온도 관계냉각수온도_섭씨, 온도_섭씨
☐⑥ 막두께 불량 원인 후보두께_nm, 불량유형
☐⑦ 주요 센서 불량 예측수치형 센서 열 전체, 검사결과
☐⑧ 설비 시간대별 변화측정시간, 설비번호

2. 분석 질문 적어보기

선택한 주제를 "~와 ~는 관계가 있을까?" 또는 "어느 ~가 가장 ~한가?" 형태의 구체적인 질문으로 바꿔보자.

질문 작성 "나의 분석 질문: ________________________________________________?"
좋은 질문의 예 "설비별 불량률에 차이가 있을까?", "진공도가 정상 범위를 벗어나면 불량률이 올라갈까?"처럼 데이터의 열 이름을 넣어 구체적으로 쓰면 좋다. "데이터를 분석해보자"는 질문이 아니다.

4. 10단계 진행 체크리스트

진행하면서 완료한 단계에 표시하자.

단계내용완료
1질문 정하기☐
2관련 데이터 열 파악하기☐
3데이터 불러오고 구조 확인하기☐
4결측값·이상값 점검하고 정리하기☐
5그래프로 먼저 살펴보기☐
6설비·공정·작업조별로 비교하기☐
7수율·불량률 계산하기☐
8이상 구간·원인 후보 찾기☐
9(선택) 예측 모델로 확인해보기☐
10결과 정리 + 개선안 작성 → 발표자료 만들기☐
10단계의 핵심은 순서다: 질문 → 데이터 확인 → 정제 → 시각화 → 비교 → 수율 → 원인탐색 → (예측) → 정리/발표. 순서를 건너뛰고 바로 "원인 후보"부터 찾으면 엉뚱한 결론에 빠지기 쉽다.

6. 결과 해석 문장 초안 작성

아래 문장 틀을 참고해 결과가 나오는 대로 채워보자. (Notebook 실습 후 다시 돌아와 완성해도 된다.)

문장 틀 1 — 관찰 "____________별로 비교한 결과, ____________의 ____________이(가) ___%로 가장 (높았다/낮았다)."
문장 틀 2 — 경향 "데이터에서 이러한 경향이 관찰되었다: ________________________________."
문장 틀 3 — 원인 후보(신중하게) "____________이(가) 불량과 관련 있을 가능성이 있다. 다만 상관관계만으로 원인이라고 단정할 수 없으며, 정확한 원인 확인을 위해 추가 데이터가 필요하다."
