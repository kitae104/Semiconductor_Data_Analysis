# 10주차 강의 운영안 — 반도체 공정 데이터 분석 미니 프로젝트

## 이 주차의 성격

10주차는 **새 이론을 가르치는 시간이 아니라, 1~9주차 내용을 종합해 학생이 직접 분석 보고서를
완성하는 실습·코칭 중심 세션**이다. 강사는 앞부분 30~35분만 강의하고, 나머지 대부분은
개별(또는 조별) 프로젝트 진행을 순회하며 코칭하는 데 쓴다.

## 2시간 세부 시간표

| 시간 | 내용 |
| --- | --- |
| 0~10분 | 오리엔테이션: 오늘은 "만드는 날"임을 안내, 산출물(Notebook·보고서·발표 요약) 소개 |
| 10~20분 | 1~9주차 복습 — 조회→정제→시각화→비교→수율→이상탐지→예측 흐름을 빠르게 되짚기 |
| 20~30분 | 8가지 프로젝트 주제 소개 + 데이터(`week10_mini_project_dataset.csv`) 미리보기 |
| 30~40분 | 미니 예시 시연: 설비별 불량률 비교(주제 ①)를 10단계 중 1~7단계까지 라이브 코딩으로 짧게 시연 |
| 40~45분 | 학생 각자 주제 선택 + 분석 질문 작성(실습지 1~2번) — 강사가 질문 문장을 개별 점검 |
| 45~50분 | 휴식 |
| 50~100분 | **개별/조별 프로젝트 진행 시간(핵심)** — 학생용 Notebook을 열고 10단계를 직접 수행,
  강사는 순회하며 질문 대응 및 막힌 지점 코칭 |
| 100~110분 | 조별 중간 공유 — 각자 1~2분씩 "지금까지 찾은 것" 한 문장 공유 |
| 110~118분 | 최종 보고서 양식(`project-report-template.html`) 채우기 마무리 안내 + 발표 준비 체크리스트 확인 |
| 118~120분 | 과정 마무리 인사 및 소감 나누기 |

## 준비물

- 발표자용 Colab 계정, 프로젝터
- `data/weekly/week10/week10_mini_project_dataset.csv` (학생 각자 다운로드 준비)
- 1~9주차 강의 자료 링크(복습 시 즉시 열어 보여줄 수 있도록 즐겨찾기 해두기)
- 시간이 부족한 조를 위한 "완료된 예시 보고서" 1부(참고용, 그대로 베끼지 않도록 안내)

## 강사 설명 포인트

- 오늘은 "정답을 알려주는 시간"이 아니라 "학생이 스스로 판단하도록 돕는 시간"임을 초반에 분명히 한다.
- 미니 예시(설비별 불량률 비교)는 짧게만 보여준다 — 학생이 그대로 베끼지 않고 자기 주제에
  적용하도록 "예시는 여기까지, 나머지는 각자 다르게 진행"이라고 명확히 안내한다.
- 8주차부터 강조해온 "상관관계 ≠ 원인" 문구를 오늘 다시 한번 칠판에 적어두고,
  보고서의 "원인 후보"와 "분석의 한계" 항목을 채울 때 반드시 참고하게 한다.
- 로트별 분석(주제 ②)을 선택한 학생에게는 표본 수가 적은 로트(웨이퍼 1~2장)의 수율을
  과도하게 해석하지 않도록 미리 안내한다.

## 질문 예시

- "여러분이 고른 질문에 '예/아니오'로 답할 수 있나요, 아니면 숫자로 답해야 하나요?"
- "그 결과가 우연이 아니라고 어떻게 확신할 수 있을까요? (표본 수, 반복 확인)"
- "만약 이 결과를 실제 설비 담당자에게 보고한다면, 어떤 다음 행동을 제안하시겠어요?"

## 예상 오개념

- "상관관계가 보이면 원인을 찾은 것이다" → 8주차 원칙을 재상기: 원인 후보일 뿐이다.
- "그래프가 많을수록 좋은 보고서다" → 질문과 무관한 그래프를 억지로 채우기보다,
  핵심 그래프 1~2개에 집중하는 것이 더 좋은 보고서임을 강조.
- "결측값은 무조건 나쁜 것" → `불량유형` 열의 결측값은 "정상이라 기록할 내용이 없음"을
  의미할 수 있다는 4주차·10주차 데이터의 특징을 다시 짚어준다.
- "9단계(예측 모델)까지 꼭 해야 한다" → 9단계는 선택 사항이며, 주제 ⑦을 고르지 않았다면
  생략해도 됨을 명확히 한다.

## 실습 중 오류 대응

- `FileNotFoundError`: 파일 업로드 여부, 경로(`../../data/weekly/week10/...`) 확인.
- `KeyError`: `df.columns`로 정확한 열 이름을 먼저 출력해보게 한다.
- `groupby` 결과가 예상과 다를 때: `df.groupby(...)['열'].mean()`처럼 집계할 열을
  명확히 지정했는지 확인한다.
- 그래프에 한글이 깨질 때: `matplotlib.rcParams['font.family']`에 한글 폰트를 지정하도록 안내한다
  (Colab 환경별 안내는 강사가 사전에 확인).

## 느린 학습자용 최소 과제

- 미니 예시(설비별 불량률 비교)를 그대로 따라 실행하고, 결과 숫자만 자신의 언어로 한 문장 요약.
- 보고서 12개 항목 중 최소 8개(프로젝트 제목~분석 결과)만 완성해도 충분히 인정한다.
- 그래프는 강사가 제공한 예시 코드를 그대로 실행해 1개만 만들어도 좋다.
