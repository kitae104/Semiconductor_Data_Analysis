# 10차시 강의 운영안 — 모델 평가와 새 데이터 예측

## 왜 이걸 배워야 할까? (학생에게 전달할 메시지)

9차시 모델의 모의고사 점수를 제대로 읽고, 정답 없는 새 데이터를 예측한다. 쉬운 예제 모델은 찍기(70.8%)보다 5일 더 맞혀 91.7%,
반도체 모델은 찍기(78.9%)보다 2건 더 맞혀 80.3%다. 둘을 나란히 보여 주면 "정확도만으로는 판단할 수 없다"가 바로 보인다.

## 수업 흐름

개념은 **쉬운 예제(야외 체육 수업)** 로만 설명하고, STEP 05 **반도체 데이터로 확인하기**에서 핵심만 시연한다. 학생 실습(실습지·노트북 5~6단계)은 모두 반도체 문제다.

1. 복습(Feature/Label, train/test) + 판서: 부호(`합격여부`·`진행여부` 1/-1), `classes_` `[-1 1]`, "`easy_`를 떼면 반도체 코드"
2. STEP 01~02 쉬운 예제: 모델 다시 만들기 → 화재경보기 비유 → 정확도·기준선 → 혼동행렬·세 가지 질문 (노트북 1~2단계)
3. STEP 03~04 쉬운 예제: 예보된 7일 `predict()` → 열 구성 주의 → 취소 확률·묶음 표 (노트북 3~4단계)
4. 휴식
5. STEP 05 반도체 데이터로 확인하기(시연): 준비(모델) → 확인 1 찍기보다 2건 더 → 확인 2 불합격 31건 중 9건 → 확인 3 새 로트 예측·불합격 확률·원인 후보
6. 학생 실습: 실습지 문제 1~5 = 노트북 5~6단계
7. STEP 06 Orange3 예측 위젯 시연, STEP 07 과정 되짚기(우산 비유) + 노트북 7단계 회고, 실습지 문제 6~10
8. AI 활용(노트북 8·9단계) → 퀴즈·과제 안내·마무리 인사

## 오늘 데이터 핵심 수치(실제 실행 결과, 강의 중 반드시 확인)
- 가상 데이터다. `압력_Pa`는 단위·자릿수가 맞지 않는 가상 값이라 크기를 해석하지 않는다.

**쉬운 예제** (`random_state=42`, `max_depth=4`, `test_size=0.2`, `stratify`)
- 116일(dropna 후), `(116, 4)`, train 92일 / test 24일(진행 17, 취소 7).
- 정확도 **91.7%**(22일), 기준선 **70.8%** → 5일 더. `easy_y_test == -1`이면 29.2%.
- 혼동행렬 `[[16 1] [1 6]]`: 놓친 취소 1일(2024-04-11, 바람 9.2m/s), 헛경보 1일(2024-04-14, 비 12.1mm인데 진행).
- 예보 7일: 7/31·8/1·8/2만 -1. 취소 확률 0.016, 1.000, 1.000, 1.000, **0.375**(8/3), 0.016, 0.016.
- 트리 묶음(train 92일): 비 4.75 초과 17/17, 기온 31.75 초과 5/5, 바람 9.9 초과 1/1(근거 1일), 약한 비 3/8 → 0.375, 맑음 1/61 → 0.016. 8/4(바람 8.5)는 9.9보다 약해 0.016.

**반도체**
- 750행 → 735행(합격 582, 불합격 153), `(735, 6)`, train 588 / test 147(합격 116, 불합격 31).
- 기준선 **78.9%**, 모델 **80.3%**(118건 vs 116건). `y_test == -1`이면 21.1%.
- 혼동행렬 `[[109 7] [22 9]]`: 불합격 31건 중 9건만 잡고 22건 놓침, 멀쩡한 로트 7건을 불합격이라 함.
- 새 로트 `predict()` `[1 1 -1 1 1 1 1 1 1]` — 2번만 -1. 불합격 확률(0번 열): 2번 **0.614**, 0번·6번 0.375(진공도 4.02, 4.35로 최저), 나머지 0.076.
  쉬운 예제 8/3과 같은 0.375는 우연(8일 중 3일, 24건 중 9건)이다.
- 묶음(`export_text`, `model.apply(X_train)`으로 확인): 2번 "온도 293.95 이하·압력 1009.0 초과·가스유량 53.94 이하" 44건 중 27건 /
  0번·6번 "온도 293.95~306.05·진공도 4.425 이하" 24건 중 9건 / 나머지 "진공도 4.425~5.495" 382건 중 29건.
- 원인 후보 근거(train 비율): 온도 293.95 이하 65건 중 34건(약 52%) vs 293.95~306.05 459건 중 56건(약 12%).
  **새 로트의 확률로 후보를 정하면 순환 논리다.**
- 강사만: 2번 압력 1009.2는 기준 1009.0을 겨우 넘는다(이하였다면 train 10개 모두 합격인 갈래). 작은 차이로 묶음이 바뀌는 트리의 성질 예.
- AI 예시 코드: 높음 1건(61.4%), 보통 2건(37.5%), 낮음 6건(7.6%).

## 강사 설명 포인트
- 개념은 쉬운 예제로만 설명한다. 반도체는 STEP 05에서 강사가 시연하고, 학생은 실습지에서 "`easy_`를 떼고 바꿔 적용"한다.
- 두 모델 비교가 핵심: 5일 더·취소 7일 중 6일 vs 2건 더·불합격 31건 중 9건. "쓸모없다"가 아니라 "80%만으로는 판단할 수 없다".
- 확률 열 순서: `classes_` `[-1 1]` → 0번 열이 -1. `proba[:, 1]`은 오류 없이 합격 확률이 붙는다는 것을 보여준다.
- 열 구성: 정답 노트북의 주석 줄(3단계 `# easy_model.predict(new_days)`, 6단계 `# model.predict(new_lots)`)을 풀어 `ValueError`를 시연하고 다시 주석 처리한다.
- 묶음 확률은 쉬운 예제(8/3 = 8일 중 3일)로 감을 잡은 뒤 반도체 0번·6번으로 넘어간다. 8/2의 1.000은 근거 1일뿐이다.
- "진공도가 낮아서 불합격"이 나오면 "원인 후보"로 고쳐 말한다. 쉬운 예제도 중요도만으로는 원인을 확정하지 않는다.
  비가 수업 취소의 원인이라고 말할 수 있는 것은 학교의 "비 오면 취소" 규칙을 따로 알기 때문이다. 반도체에서는 그 확인이 현장 실험이다.
- 강사만: 생성기는 온도·압력·진공도(4.5 미만/5.5 초과)·두께 이탈 시 불합격이 늘게 만들었고, 가스유량·습도는 대조군이다.
  그런데 2번의 묶음은 가스유량 조건(53.94)으로 정해졌다 — "모델이 참고한 열 ≠ 원인"의 예로 회고 때 공개해도 좋다.
- Orange3 그림 10-2는 캡처 전이라 점선 상자로 보인다. 학생 화면에는 9행이 나와야 한다.

## 예상 오개념
- "정확도가 높으면 좋은 모델" → 기준선·혼동행렬을 함께 본다.
- "쉬운 예제와 반도체는 다른 코드" → 같은 모양. `easy_`를 떼지 않으면 오류 없이 쉬운 예제 숫자가 다시 나온다.
- "왼쪽 열은 합격(진행) 확률" → `classes_` 순서상 -1의 확률. 0.924가 나왔다면 `proba[:, 1]`을 쓴 것이다.
- "새 데이터에도 정답이 있다" → `new_lots["합격여부"]`는 `KeyError`.
- "열이 더 많거나 순서가 달라도 된다" → `ValueError`. `feature_cols`를 그대로 쓴다.
- "확률 1.000이면 확실하다" → 8/2는 근거 1일뿐이다.
- "두 도구 결과가 다르면 한쪽이 틀렸다" / "모델이 참고한 열 = 원인" → 조건이 다를 뿐이고, 원인 후보일 뿐이다.

## 실습 중 오류 대응
- `AttributeError: 'DecisionTreeClassifier' object has no attribute '____'`: 메서드 빈칸(`fit`, `predict`, `predict_proba`)을 비움.
- `NotFittedError: This DecisionTreeClassifier instance is not fitted yet.`: 5단계 문제 1의 `fit` 빈칸을 비움.
- `KeyError: '____'`: 문제 1의 `df["____"]`를 비움. `NameError: name '____' is not defined`: 값·변수 빈칸(`1`, `pred`, `feature_cols`, 쉬운 예제 2단계의 `1`)을 비움.
- `NameError: name 'model' is not defined`(또는 `'easy_model'`): 위 셀을 건너뜀. 맨 위부터 다시 실행.
- `ValueError: The feature names should match those that were passed during fit.`: `new_lots`·`new_days`를 통째로 넣었거나 열을 바꿈.
- `KeyError: '합격여부'`: 새 로트에서 정답 열을 찾음. `KeyError: '불합격_확률'`: 6단계 문제 5를 건너뛰고 9단계로 감.
- 숫자가 쉬운 예제와 똑같음: `easy_`를 떼지 않았다.
