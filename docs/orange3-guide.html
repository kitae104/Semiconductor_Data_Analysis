Orange3 시작하기

💬 이 부록으로 확인할 질문: "코드를 한 줄도 쓰기 전에, 마우스만으로 데이터를 살펴보려면 Orange3를 어떻게 쓰면 될까?"

🎯 이 부록으로 할 수 있는 것

  • Orange3가 무엇이고 이 과정에서 왜 쓰는지 한 문장으로 설명할 수 있다.
  • 내 컴퓨터(Windows/Mac)에 맞는 설치 파일을 골라 Orange3를 설치하고 실행할 수 있다.
  • 위젯을 캔버스에 놓고 서로 연결해 워크플로를 만들 수 있다.
  • File 위젯으로 실습용 CSV를 불러올 수 있다.
  • 5~10차시에서 실제로 쓰는 위젯(Data Table, Feature Statistics, Scatter Plot, Box Plot, Distributions, Bar Chart, Correlations, Tree, Test and Score, Predictions)이 각각 무엇을 보여주는지 설명할 수 있다.
  • 자주 발생하는 문제(연결 실패, 한글 깨짐 등)를 스스로 해결할 수 있다.

언제 보면 좋은가: 5차시를 시작하기 전에 한 번 전체를 훑어보고, 이후 6~10차시에서 새 위젯이 나올 때마다 해당 위젯 설명만 다시 찾아보면 된다.

📚 Orange3란 무엇인가

한 줄 정의 Orange3는 코드를 한 줄도 쓰지 않고, 위젯(widget)이라는 상자를 마우스로 끌어다 놓고 선으로 연결하는 것만으로 데이터를 열고·그래프를 그리고·모델을 만들 수 있는 무료 데스크톱 프로그램이다.

이 과정에서는 Orange3로 먼저 결과를 눈으로 훑어본 뒤, 같은 내용을 파이썬 코드로 직접 계산·확인하는 순서로 5~10차시를 진행한다. Orange3가 새로운 개념을 가르치는 것이 아니라, "이번 시간에 코드로 확인할 내용의 예고편"을 미리 보여주는 역할을 한다고 생각하면 된다.

쉬운 비유 — 레고 블록으로 만드는 분석 공장 위젯 하나하나는 "파일 열기", "표로 보기", "그래프 그리기", "모델 만들기"처럼 한 가지 일만 하는 레고 블록이다. 블록을 순서대로 놓고 선으로 이으면 데이터가 컨베이어 벨트를 타듯 앞 블록에서 뒤 블록으로 흘러가며 처리된다. 이렇게 이어 붙인 전체 모양을 워크플로(workflow)라고 부른다.

엑셀·Orange3·파이썬은 모두 데이터를 다루는 도구지만, 잘하는 일이 조금씩 다르다.

도구사용 방법잘하는 일이 과정에서의 역할
엑셀셀에 직접 입력·수식작은 표 정리, 간단한 합계익숙한 비교 대상(1·4차시에서 비교)
Orange3위젯을 마우스로 연결코드 없이 빠르게 그래프·모델 확인먼저 눈으로 훑어보기
파이썬코드 작성정확한 계산, 반복 작업 자동화숫자로 직접 확인하기
체크포인트 — Orange3는 파이썬 패키지가 아니다 requirements.txt의 패키지들은 pip install -r requirements.txt로 한 번에 설치되지만, Orange3는 별도의 데스크톱 프로그램이라 항상 따로 설치해야 한다. Orange3 없이도 이 과정의 파이썬 실습(Jupyter Notebook)은 전부 문제없이 진행할 수 있다 — Orange3는 "먼저 눈으로 확인하는" 보조 도구다.

🧩 설치하기

설치 방법은 두 가지다. 파이썬을 처음 배우는 중이라면 방법 A(설치 파일)를 쓰면 된다. 방법 A는 게임이나 메신저를 설치하듯 다음 버튼만 누르면 끝나고, 필요한 파이썬도 설치 파일 안에 함께 들어 있어 따로 준비할 것이 없다.

설치 전에 확인할 것

  • 운영체제: 64비트 Windows 또는 macOS(Apple Silicon·Intel 모두 지원)
  • 관리자 권한: Windows 설치 파일은 관리자 권한 없이도 설치할 수 있다(회사·학교 PC도 대부분 가능).
  • 인터넷: 설치 파일을 내려받을 때만 필요하다. 설치 후 실습은 인터넷 없이도 된다.

방법 A — 설치 파일로 설치하기 (초보자 추천)

1
공식 다운로드 페이지 접속 — 웹 브라우저에서 orangedatamining.com/download 에 접속한다. 내 운영체제(Windows / macOS) 탭이 자동으로 선택되어 있는지 확인한다.
2
내 컴퓨터에 맞는 파일 내려받기
  • Windows: Orange3-(버전)-x86_64.exe 형태의 설치 파일(Standalone installer)
  • Mac(M1·M2 등 Apple Silicon): 파일 이름에 arm64가 들어간 .dmg
  • Mac(Intel): 파일 이름에 x86_64가 들어간 .dmg
내 Mac이 어느 쪽인지 모르겠다면 화면 왼쪽 위 사과 모양 메뉴 → 이 Mac에 관하여에서 "칩" 항목에 Apple M1/M2/M3…이 보이면 Apple Silicon, "프로세서"에 Intel이 보이면 Intel이다.
참고 — 버전 번호는 계속 바뀐다 2026년 9월 기준 최신 버전은 3.40.0이다. 파일 이름의 숫자가 이 문서와 달라도 괜찮다. 다운로드 페이지에 보이는 가장 위(최신) 파일을 받으면 된다.
3
설치 파일 실행 — 내려받은 파일(보통 "다운로드" 폴더에 있다)을 더블클릭한다. Windows에서는 설치 마법사가 뜨면 Next(다음)를 계속 눌러 기본 설정 그대로 설치하고, 마지막에 Finish(마침)를 누른다. Mac에서는 열린 창에서 Orange 아이콘을 Applications(응용 프로그램) 폴더로 끌어다 놓으면 설치가 끝난다.
체크포인트 — 보안 경고 창이 뜨는 경우 Windows에서 "Windows의 PC 보호" 파란 창이 뜨면 추가 정보 → 실행을 누른다. Mac에서 "확인되지 않은 개발자" 경고가 뜨면 응용 프로그램 폴더의 Orange 아이콘을 마우스 오른쪽 클릭 → 열기로 실행한다. 단, 이 방법은 반드시 위의 공식 사이트에서 받은 파일에만 사용한다.
4
처음 실행하기 — Windows는 시작 메뉴에서 Orange를 검색해 실행하고, Mac은 응용 프로그램 폴더에서 Orange를 실행한다. 처음 실행하면 시작 안내 창 (Welcome)이 뜨는데, New(새 워크플로)를 누르면 빈 캔버스가 열린다.
체크포인트 — 처음 실행은 오래 걸릴 수 있다 Orange3를 처음 실행하면 위젯 목록을 준비하느라 몇십 초~1분 정도 창이 하얗게 떠 있거나 아무 반응이 없을 수 있다. 오류가 아니니 기다리면 된다. 아이콘을 여러 번 누르면 창이 여러 개 열리니 한 번만 누르고 기다리자. 두 번째 실행부터는 훨씬 빨라진다.
설치가 막힐 때 — 포터블(압축) 버전 Windows에서 설치가 계속 막히면 다운로드 페이지의 Portable 버전(.zip)을 받아 압축을 풀고, 폴더 안의 바로가기를 실행해도 된다. 설치 과정 없이 바로 쓸 수 있다.

방법 B — 명령어로 설치하기 (파이썬에 익숙한 경우만)

이미 Anaconda나 파이썬 가상환경을 다룰 줄 안다면 명령어로 설치할 수도 있다. 이 과정의 실습용 가상환경과 섞이지 않도록 Orange3 전용 환경을 따로 만드는 것을 권장한다.

Anaconda Prompt (conda 사용 시)
conda create python=3.11 --yes --name orange3
conda activate orange3
conda config --add channels conda-forge
conda config --set channel_priority strict
conda install orange3

# 실행(캔버스 창이 뜬다)
python -m Orange.canvas
터미널 (pip 사용 시)
# Orange3 화면을 그리는 PyQt6를 먼저 설치한다
pip install PyQt6 PyQt6-WebEngine
pip install orange3

# 실행(캔버스 창이 뜬다)
python -m Orange.canvas
체크포인트 — 명령어 방식이 어렵다면 명령어 설치 중 빨간 오류 메시지가 나오면 고치려고 애쓰기보다 방법 A(설치 파일)로 바꾸는 것이 가장 빠르다. 두 방법으로 설치한 Orange3는 기능이 같다.

🟣 실습: 첫 워크플로 만들어보기

어떤 차시든 Orange3 실습은 항상 File 위젯으로 CSV를 불러오는 것에서 시작한다. 5차시 데이터로 직접 연습해보자.

1
File 위젯 놓기 — 왼쪽 위젯 목록의 Data 카테고리에서 File 아이콘을 캔버스로 끌어다 놓는다.
2
CSV 불러오기 — File 위젯을 더블클릭해 창을 열고, 폴더 아이콘을 눌러 data/weekly/week05/week05_dirty_process_data.csv를 선택한다.
알아두기 — File 창 아래의 열 목록(Type·Role) File 창 아래 표에는 열마다 Type(숫자 numeric / 범주 categorical / 글자 text 등)과 Role(feature: 재료로 쓰는 열, target: 맞힐 정답 열, meta: 참고용 열)이 표시된다. Orange3가 자동으로 정해 주므로 5~8차시에는 그대로 두면 된다. 9차시에는 맞힐 열 (검사결과)의 Role을 target, Type을 categorical로 바꿔야 한다. 칸을 더블클릭하면 바꿀 수 있고, 바꾼 뒤에는 오른쪽 아래 Apply를 누른다.
3
Data Table 위젯 추가 — Data 카테고리에서 Data Table 위젯을 캔버스로 끌어다 놓는다.
4
두 위젯 연결하기 — File 위젯의 오른쪽 가장자리에서 마우스 버튼을 누른 채로 Data Table 위젯의 왼쪽 가장자리까지 끌고 가서 놓는다. 화살표가 있는 선이 생기면 연결 성공이다.
5
결과 확인 — Data Table 위젯을 더블클릭하면 CSV 내용이 표로 나타난다. 빈 칸(결측값)이 그대로 보이는지 확인해보자.
자주 하는 실수 — 위젯이 연결되지 않는다 가장자리가 아니라 위젯 가운데를 클릭하면 위젯이 움직이기만 하고 연결선이 생기지 않는다. 반드시 위젯 테두리(오른쪽 끝)에 마우스를 올려 커서 모양이 바뀌는 지점에서 드래그를 시작해야 한다.
자주 하는 실수 — 한글이 깨져 보인다 이 과정의 모든 CSV는 utf-8-sig 인코딩으로 저장되어 있어 대부분 자동으로 잘 열린다. 그래도 글자가 깨져 보이면 File 위젯 창의 Encoding 옵션을 "UTF-8"로 직접 지정해본다.

🗂️ 위젯 사전 — 이 과정에서 쓰는 위젯 11가지

아래 위젯은 실제로 사용하는 차시 순서대로 정리했다. 해당 차시에 도착하면 이 표를 다시 펼쳐 찾아봐도 좋다.

📁 File — 5·8·9차시

CSV 파일을 Orange3 안으로 불러오는 시작점 위젯. 모든 워크플로는 File 위젯에서 시작한다. 더블클릭 → 폴더 아이콘으로 CSV 선택 → 첫 줄이 자동으로 열 이름으로 인식된다.

📋 Data Table — 5차시

불러온 데이터를 표 형태 그대로 보여준다. 빈 칸(결측값)이 그대로 빈칸으로 보이므로, 어느 열에 결측이 많은지 눈으로 훑어보기 좋다. 열 머리글을 클릭하면 정렬도 된다.

📊 Feature Statistics — 5차시

각 열의 평균·최솟값·최댓값·표준편차 등을 표와 막대그래프로 한눈에 보여준다. Max/Min 값이 상식적인 범위를 벗어나 있으면 이상값 후보를 빠르게 찾을 수 있다.

🔵 Scatter Plot — 6차시

두 숫자 변수를 X축·Y축으로 놓고 점으로 흩뿌려 관계를 보여준다. 점들이 대각선 방향으로 모여 있으면 두 변수가 함께 움직인다는 뜻이다. 위젯 오른쪽 옵션에서 X축· Y축 변수를 바꿔 고를 수 있다.

📦 Box Plot — 6·7차시

그룹(예: 설비번호)별로 값이 어디에 몰려 있고 얼마나 퍼져 있는지 상자 모양으로 보여준다. 상자가 넓을수록 그 그룹의 값이 들쭉날쭉하다는 뜻이다. "Subgroups" 옵션에 설비번호 같은 범주형 열을 지정하면 그룹별로 나눠 보여준다.

📈 Distributions — 6차시

한 변수의 값이 어떤 모양으로 퍼져 있는지 히스토그램으로 보여준다. 값이 한쪽에 몰려 있는지, 두 개의 봉우리로 나뉘는지 등을 눈으로 확인할 수 있다.

📊 Bar Chart — 7차시

범주형 열(예: 설비번호, 합격여부)의 값별 개수·비율을 막대로 보여준다. 설비별 합격/불합격 막대 길이를 비교하면 어느 설비의 불량이 많아 보이는지 짐작할 수 있다.

🔗 Correlations — 8차시

데이터의 모든 숫자 변수 쌍의 상관계수를 자동으로 계산해 관계가 강한 순서대로 정렬해 보여준다. 표 안의 한 행을 클릭하면 그 두 변수의 산점도도 바로 볼 수 있다.

🌳 Tree — 9차시

클릭만으로 의사결정나무 분류 모델을 학습시키는 위젯. Target Variable(예: 검사결과)을 지정하면, 나머지 열을 특징으로 사용해 자동으로 모델을 만든다. 파이썬의 DecisionTreeClassifier와 같은 원리다.

✅ Test and Score — 9차시

Tree 같은 모델 위젯과 연결하면 정확도(Accuracy) 등 성능 지표를 자동으로 계산해 표로 보여준다. 별도의 코드 없이 "이 모델이 얼마나 잘 맞히는지"를 바로 확인할 수 있다.

🔮 Predictions — 10차시

학습된 모델과 정답을 모르는 새 데이터(CSV)를 함께 연결하면, 각 행에 대한 예측 결과(합격/불합격)와 확률을 표로 보여준다. scikit-learn의 model.predict()·predict_proba()와 같은 역할이다.

⚠️ 문제 해결 (Troubleshooting)

설치했는데 실행이 안 돼요 ① 처음 실행은 1분 가까이 걸릴 수 있으니 먼저 기다려 본다. ② 그래도 안 뜨면 컴퓨터를 다시 시작한 뒤 한 번만 실행해 본다. ③ Windows라면 설치 대신 포터블(.zip) 버전을 받아 압축을 풀어 실행해 본다. ④ Mac에서 경고 창이 뜨면 앞의 "보안 경고 창" 체크포인트를 따른다.
위젯 목록에 원하는 위젯이 안 보여요 캔버스 빈 곳을 마우스 오른쪽 클릭하면 위젯 검색 창이 뜬다. 위젯 이름(예: Box Plot)을 입력하고 Enter를 누르면 그 자리에 위젯이 놓인다.
위젯 창이 안 열려요 더블클릭이 아니라 한 번만 클릭했을 가능성이 크다. 위젯 아이콘을 정확히 두 번 빠르게 클릭한다.
Data Table이 비어 있어요 File 위젯과 연결선이 제대로 이어져 있는지 먼저 확인한다. 연결선이 없으면 데이터가 전달되지 않는다.
Tree/Test and Score에서 오류가 나요 Target Variable(정답 열, 예: 검사결과)이 지정되어 있는지 확인한다. 파이썬의 Feature/Label 나누기와 같은 개념으로, Orange3에서도 "무엇을 맞힐지" 미리 알려줘야 한다. File 위젯 창의 열 목록에서 검사결과의 Role을 target, Type을 categorical로 바꾸고 Apply를 누른다(위 "첫 워크플로" 절의 알아두기 참고). Type이 numeric으로 남아 있으면 Orange3는 합격/불합격 분류가 아니라 숫자 맞히기(회귀)로 처리한다.
작업한 워크플로를 저장하고 싶어요 Ctrl+S(Mac은 Cmd+S)로 저장하면 .ows 파일로 남는다. 다음에 그 파일을 다시 열면 위젯 배치와 연결이 그대로 복원된다.
