# 강사용 운영 가이드 (v3)

이 문서는 「반도체 및 반도체 공정 데이터 분석 10차시 과정」을 실제로 운영하는 강사를 위한 가이드다.
차시별 수업 흐름과 발문은 각 `lectures/weekXX/instructor-guide.md`에 있다. 이 문서는 과정 전체를
운영할 때 필요한 공통 정보를 담는다. 과정 설계는 [`docs/curriculum.md`](curriculum.md)(v3)를 기준으로 한다.

## 1. 과정 운영 전 준비

- **강사 PC**: `requirements.txt` 설치, Jupyter 커널 등록
  (`python -m ipykernel install --user --name python3`), **Orange 3.35** 설치.
  과정의 `.ows` 파일과 화면 설명은 Orange 3.35로 만들고 확인했다. 다른 버전이면 위젯 모양·메뉴 이름이 조금 다를 수 있다.
- **학생 준비 안내**: 첫 수업 전에 [`docs/setup.html`](setup.html)(수강 전 준비)을 안내한다. 파이썬·Jupyter·Orange3 설치,
  실습 키트 압축 풀기, 노트북과 `.ows` 열기, File 위젯 오류 대처까지 그림과 함께 들어 있다.
- **자료 배포**: 실습 키트 하나로 배포한다.
  - 전체: `dist/student_kit.zip` — 학생 노트북, 실습 데이터(`orange/*.tab` 포함), Orange 워크플로, 설치 안내
  - 차시별: `dist/weekXX_kit.zip`
  - 키트는 저장소와 같은 폴더 구조다. 노트북은 `../../data/weekly/...`로, `.ows`는 자기 폴더 기준 상대경로로 데이터를 찾으므로
    **폴더째 압축을 풀고 구조를 바꾸지 않게** 매번 강조한다.
- **사전 실행 확인**: 매 차시 수업 전 키트를 새로 풀어 다음을 확인한다.
  - `notebooks/solutions/weekXX_solution.ipynb`를 처음부터 끝까지 실행해 이상이 없는지
  - `orange3/weekXX/`의 `_start.ows` 두 개를 열어 File 위젯에 데이터가 들어오는지
  - 차시 운영안의 "오늘 데이터 핵심 수치"가 화면 숫자와 같은지

## 2. 매 차시 공통 수업 흐름

수업은 PART 1·2·3으로 나뉜다. 강의 HTML의 PART 섹션 앵커는 `#part1`·`#part2`·`#part3`이다.

| | 1~8차시 | 9·10차시 (순서 예외) |
| --- | --- | --- |
| PART 1 | 파이썬 — 생활 예제로 개념 → 반도체 데이터로 확인하기 | Orange3 — 모델을 먼저 눈으로 본다 |
| PART 2 | Orange3 — 워밍업 데이터 → 반도체 데이터 → 파이썬 결과와 비교 한 문장 | 파이썬 최소 + ChatGPT 체험 |
| PART 3 | 실습지 — 파이썬 3 + Orange 1 + 해석 문장 1 | 실습지 — 파이썬 2 + Orange 2 + 해석 문장 1 |

공통 순서:

1. 지난 시간 연결 한 문장, 오늘의 미션 소개(hero의 "오늘의 미션" — 「신입 데이터 담당자의 10일」 이야기, 정답 숫자는 말하지 않는다)
2. PART 1
3. **여기서 쉬기**
4. PART 2
5. PART 3 실습지
6. 결과 정리, 수업 마무리 질문("오늘의 반도체 이해 포인트")

- **운영안은 순서만 쓴다.** 각 차시 `instructor-guide.md`의 "수업 흐름"은 순서와 "여기서 쉬기" 표시만 있고, 단계별 시간 배분은
  적지 않는다. 학습자 수준과 현장 상황에 맞게 각 단계의 비중을 강사가 정한다.
- 노트북은 단계 번호("노트북 N단계")로, Orange는 `_start.ows` 캔버스 메모 번호로 지시한다. 강의 HTML의 step 하나는
  노트북 여러 단계를 묶은 것이며 "(노트북 N~M단계)"가 함께 적혀 있다.
- 퀴즈(`quiz.json`, 8~10문항)는 수업 후 자율 복습용이다.

## 3. Orange3 운영 — `_start` / `_done`

차시마다 `orange3/weekXX/`에 워크플로 4개가 있다.

| 파일 | 내용 | 쓰는 때 |
| --- | --- | --- |
| `weekXX_1_<주제>_start.ows` | ① 워밍업 데이터가 연결된 File 위젯 하나 + 한국어 안내 메모 | Orange 실습 시작 |
| `weekXX_1_<주제>_done.ows` | ① 완성본 | 따라잡기, 끝난 뒤 비교 |
| `weekXX_2_<주제>_start.ows` | ② 반도체 데이터 시작 파일 | 워밍업 뒤 |
| `weekXX_2_<주제>_done.ows` | ② 완성본 | 따라잡기, 느린 학습자 최소 과제 |

- **항상 `_start.ows`에서 시작**하고, 위젯을 하나씩 직접 끌어와 잇게 한다. 따라오지 못한 학생은 바로 `_done.ows`를 열어
  같은 화면에서 다시 합류시킨다. 정답을 늦게 맞히는 것보다 화면을 보며 해석하는 쪽이 이 과정의 목표다.
- Orange는 `data/weekly/weekXX/orange/*.tab`만 연다. CSV를 File에서 직접 열면 `합격여부`가 숫자로 읽혀 막대 대신
  히스토그램이 나오는 등 강의와 다른 화면이 된다. File 위젯 오류 대처는 [`docs/orange3-guide.html`](orange3-guide.html)의
  "File 위젯이 파일을 못 찾을 때"를 따른다.
- 위젯이 어느 묶음(Data·Transform·Visualize·Unsupervised·Model·Evaluate)에 있는지도 같은 부록에 표로 있다.
- Data Table 뒤에는 위젯을 잇지 않는다(행을 고르기 전에는 출력이 빌 수 있다). File에서 부채꼴로 잇는다.
- Orange는 위젯 설정을 기억해 새 위젯에 다시 적용하기도 한다. 강사 화면 숫자가 운영안과 다르면 위젯 설정(Split by, 조건 값 등)부터
  확인하고, `_done.ows`를 다시 열어 비교한다.
- 학생이 저장(`Ctrl+S`)한 `.ows`는 데이터 위치가 그 컴퓨터 기준으로 바뀔 수 있다. 다른 PC에서 열리지 않으면 키트의 원본
  `.ows`를 다시 연다.

## 4. 찾아보기 상자

강의에는 배경지식이 필요한 곳에 "찾아보기" 상자가 차시당 3~6개 있다(검색어 · ChatGPT에 물어볼 질문 · 접힌 확인 포인트).

- **선택 활동이며 평가하지 않는다.** 퀴즈·실습지에도 나오지 않는다.
- 빨리 끝낸 학생, 쉬는 시간 전후, 복습용으로 안내한다. 수업 흐름을 멈추고 전원이 함께 하지 않아도 된다.
- 찾아본 내용과 강의 내용이 다르면 접힌 "확인 포인트"를 기준으로 이야기한다. 검색 결과·AI 답이 늘 맞는 것은 아니라는 점을 함께 말한다.
- 8~10차시 찾아보기·ChatGPT 질문은 "원인"이 아니라 "원인 후보" 표현을 쓴다.

## 5. ChatGPT 체험과 대안(9·10차시 중심)

- 9차시: ChatGPT가 준 분석 코드를 실행해 숫자를 직접 확인한다. 10차시: ChatGPT가 쓴 보고 문장에서 틀린 곳을 찾아 고친다
  (응답 예시에 일부러 넣은 틀린 숫자 1개·인과 단정 1개).
- **ChatGPT를 못 쓰는 교실**(계정·네트워크·기관 정책 등): 강의에 질문과 **응답 예시**("실제 AI 응답 아님" 표기)가 실려 있고,
  노트북에 응답 예시 코드가 완성 셀로 들어 있다. 학생은 그 셀을 실행하고, 강사는 화면 시연만으로도 같은 활동을 진행할 수 있다.
- 어떤 경우든 AI가 준 숫자는 반드시 직접 실행한 결과와 대조한다. "AI 답이 오류 없이 돌았다"와 "숫자가 맞다"는 다른 이야기다.
- 개인정보나 실제 회사 데이터를 AI에 붙여 넣지 않게 안내한다(이 과정의 데이터는 모두 교육용 가상 데이터다).

## 6. 캡처 자리(빈 이미지 칸)

- 강의·실습지·설치 안내의 Orange·Jupyter 화면 그림 중 일부는 아직 실제 캡처가 없고 **자리만** 있다. 그런 `<img>`에는
  `data-shot` 속성으로 찍을 화면 설명이 붙어 있고, 브라우저에서는 그 설명이 빈자리에 보인다.
- 수업에 쓰기 전에 [`assets/images/orange3/README.md`](../assets/images/orange3/README.md)의 차시별 캡처 체크리스트를 보고 채운다.
  체크리스트에는 파일 경로, 들어갈 페이지, 찍을 화면 설명, 현재 파일이 있는지가 표로 정리되어 있다.
- 캡처가 없는 상태로 수업할 때는 그 자리에서 강사 화면으로 직접 보여 주면 된다. 캡처를 넣은 뒤에도 화면 숫자가 운영안의
  "오늘 데이터 핵심 수치"와 같은지 확인한다.
- 정합성 검사(`check_course_consistency.py`)는 캡처가 비어 있는 자리를 실패가 아니라 "캡처 대기" 경고로 표시한다.

## 7. 난이도별 학습자 대응

- **빠른 학습자**: 각 차시 `instructor-guide.md`의 "빨리 끝낸 학생용 과제"와 찾아보기 상자를 제시한다.
- **느린 학습자**: "느린 학습자용 최소 과제"를 기준으로, 파이썬은 핵심 코드 1~2줄, Orange는 `_done.ows`를 열어 화면의
  숫자 읽기, 해석 문장 한 줄만 완성해도 그 차시 목표를 달성한 것으로 인정한다.
- **결시/보강**: 강의 HTML(전체 내용) + `notebooks/solutions/`(시연·정답) + `_done.ows`(Orange 완성본)로 자기주도 학습이 가능하다.

## 8. 자주 발생하는 기술적 문제

| 문제 | 원인 | 해결 |
| --- | --- | --- |
| `FileNotFoundError` | 키트 폴더 구조가 바뀜, zip 안에서 바로 엶 | 키트를 폴더째 다시 풀고 `notebooks/student/`에서 노트북을 연다. `pd.read_csv("../../data/weekly/...")` 상대경로를 고치지 않는다 |
| `KeyError: '열이름'` | 열 이름 오타 | `df.columns`로 정확한 이름 먼저 확인(열 이름은 `온도_C`처럼 한국어 + 영문 단위) |
| 한글 깨짐 | 인코딩 문제 | 모든 CSV는 `utf-8-sig`로 저장되어 있음. `pd.read_csv(..., encoding="utf-8-sig")` 확인 |
| Jupyter 커널 연결 끊김 | 커널 종료/재시작 | Kernel → Restart Kernel and Run All Cells…로 위에서부터 다시 실행 |
| Orange File 위젯에 빨간 글씨 | `.ows`를 키트 밖으로 옮김, 폴더 구조 변경 | 키트를 다시 풀고 `_start.ows`를 다시 연다. 안 되면 File 폴더 아이콘으로 `data/weekly/weekXX/orange/*.tab`을 직접 고른다 |
| Orange 화면 숫자가 운영안과 다름 | 저장된 위젯 설정이 적용됨, CSV를 직접 엶 | 위젯 설정 확인, `.tab`으로 열었는지 확인, `_done.ows`와 비교 |
| 9·10차시 Tree/Test and Score 오류 | 합격여부가 target·categorical이 아님 | 키트의 `.tab`과 `_start.ows`를 다시 연다(처음부터 target으로 정해져 있다) |

## 9. 평가 운영

- 실습지(`worksheet.html`) 5문제의 마지막은 매 차시 "결과 해석 문장 쓰기"다. 받아쓰기가 아니라 "이 숫자만으로 ~라고 말할 수
  있을까?"를 판단하게 하고, 단순 정답 확인보다 "왜 그런지"를 말하게 한다.
- 퀴즈(`quiz.json`)는 수업 후 자율 복습용이며, 정답과 해설은 각 문항에 들어 있다.
- 10차시는 별도 미니 프로젝트 없이, 9차시 모델로 새 로트(`week09_new_lots_to_predict.csv`)를 예측하고 결과 보고 문장과
  10차시 회고 한 문단을 쓰는 것으로 평가한다. 평가 시 다음을 확인한다.
  - 파이썬 `predict()`와 Orange Predictions의 예측을 비교했는지, 확률은 Orange Predictions 표로 읽었는지
  - "정확도만으로 모델을 믿을 수 없다"(9차시 '무조건 합격' 기준선)는 관점을 10차시 예측 해석에도 이어서 적용했는지
  - ChatGPT 보고 문장의 틀린 숫자와 인과 단정을 실제 숫자로 고쳤는지, 결과를 "원인 후보"로 표현했는지

## 10. 콘텐츠 유지보수

- 데이터를 다시 생성할 때는 `python scripts/generate_weekly_data.py`(시드 고정, `.tab` 파생본 포함), 그림은
  `python scripts/generate_figures.py`, Orange 워크플로는 `python scripts/build_orange_workflows.py`를 실행한다.

  `python scripts/validate_notebooks.py`, `python scripts/validate_orange_workflows.py`, `python scripts/build_student_kit.py --check`로 검증한다.
- 새로운 기수를 운영하면서 발견한 오개념·오류 패턴은 각 차시 `instructor-guide.md`의
  "예상 오개념" 항목에 누적해서 업데이트할 것을 권장한다.
