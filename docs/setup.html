수강 전 준비 — 프로그램 설치와 실습 키트

이 페이지로 확인할 질문: "첫 수업 전에, 내 컴퓨터에서 노트북과 Orange 파일이 제대로 열릴까?"

이 페이지에서 할 일

  • 파이썬과 Jupyter Notebook을 설치한다.
  • Orange3(마우스로 데이터를 분석하는 프로그램)를 설치한다.
  • 실습 키트(student_kit.zip)를 내려받아 폴더째 압축을 푼다.
  • 1차시 노트북과 Orange 파일을 한 번씩 열어 본다.
미리 알아두기 이 과정의 실습은 Windows 기준으로 안내한다. Mac도 같은 순서로 하면 되고, 메뉴 이름만 조금 다르다. 설치 중 막히면 그 단계의 화면을 캡처해 첫 수업 때 강사에게 보여 주면 된다.
STEP 01

파이썬 설치하기

  1. python.org/downloads에서 노란색 Download Python 3.x 버튼을 눌러 설치 파일을 받는다.
  2. 설치 파일을 실행하고, 첫 화면 아래의 Add python.exe to PATH에 꼭 체크한 뒤 Install Now를 누른다.
  3. 설치가 끝나면 시작 메뉴에서 명령 프롬프트(cmd)를 열고 아래 한 줄을 실행한다. Python 3.으로 시작하는 버전이 보이면 성공이다.
명령 프롬프트 — 파이썬 버전 확인
python --version
'python'은(는) 내부 또는 외부 명령이 아닙니다 PATH 체크를 빠뜨린 경우다. 설치 파일을 다시 실행해 Modify → 다음 화면에서 Add Python to environment variables에 체크하고 마친 뒤, 명령 프롬프트를 새로 열어 다시 확인한다. Microsoft Store 창이 뜨는 경우도 같은 원인이다.
STEP 02

Jupyter Notebook과 실습 도구 설치하기

명령 프롬프트에 아래 한 줄을 붙여 넣고 Enter를 누른다. 노트북을 여는 프로그램(Jupyter)과 표·그래프·머신러닝 도구(pandas, matplotlib, scikit-learn)를 한 번에 설치한다. 글자가 많이 지나가다가 Successfully installed가 보이면 끝난 것이다.

명령 프롬프트 — 실습 도구 설치
python -m pip install jupyter pandas matplotlib scikit-learn
저장소를 통째로 받은 경우 과정 저장소 폴더에서 설치할 때는 README 5절처럼 pip install -r requirements.txt를 써도 된다. 설치되는 도구는 같다.
STEP 03

Orange3 설치하기

  1. orangedatamining.com/download에서 내 운영체제(Windows / macOS)용 설치 파일을 받는다.
  2. 설치 파일을 실행하고 기본 설정 그대로 Next를 눌러 설치한다.
  3. 시작 메뉴에서 Orange를 실행한다. 처음 실행할 때는 창이 뜰 때까지 기다린다.
버전 이 과정의 Orange 파일과 화면 설명은 Orange 3.35로 만들고 확인했다. 더 새 버전에서도 대부분 그대로 열리지만, 위젯 모양이나 메뉴 이름이 조금 다를 수 있다. 화면이 다르면 강사에게 알린다.
STEP 04

실습 키트 내려받고 압축 풀기

실습 키트 내려받기 (student_kit.zip)
  1. 내려받은 student_kit.zip을 마우스 오른쪽 클릭 → 모두 압축 풀기로 푼다(Mac은 더블클릭). 바탕화면이나 문서 폴더처럼 찾기 쉬운 곳에 둔다.
  2. 압축을 풀면 semiconductor_kit 폴더 하나가 생긴다. 안은 아래처럼 생겼다.
폴더들어 있는 것
notebooks/student/차시별 실습 노트북(week01_student.ipynb …)
data/weekly/weekXX/실습 데이터(CSV). 안의 orange/ 폴더에는 Orange가 여는 같은 데이터(.tab)가 있다
orange3/weekXX/Orange 파일. _start.ows = 시작 파일, _done.ows = 완성본
README_학생용.txt키트 사용법 요약
가장 중요한 규칙 — 폴더 구조를 바꾸지 않는다 Orange 파일은 자기 자리를 기준으로 데이터(.tab)를 찾는다. 노트북은 CSV 파일 이름만 쓰므로 CSV가 노트북과 같은 곳에 있어야 한다. 파일을 하나씩 꺼내 다른 곳으로 옮기거나, 폴더 이름을 바꾸면 데이터를 찾지 못한다. zip 파일 안에서 바로 노트북을 열지 말고, 반드시 압축을 푼 다음 연다.
STEP 05

노트북 열어 보기

  1. 파일 탐색기에서 semiconductor_kit 폴더를 연다.
  2. 위쪽 주소 표시줄을 한 번 클릭하고 cmd라고 입력한 뒤 Enter를 누른다. 그 폴더에서 명령 프롬프트가 열린다.
  3. 아래 한 줄을 실행하면 웹 브라우저에 Jupyter 화면이 열린다.
  4. notebooks → student → week01_student.ipynb를 클릭해 연다.
  5. 첫 셀을 클릭하고 Shift + Enter. 파이썬 준비 완료!가 나오면 성공이다.
명령 프롬프트 — Jupyter 열기(semiconductor_kit 폴더에서)
python -m notebook
명령 프롬프트 창은 닫지 않는다 Jupyter가 켜져 있는 동안 명령 프롬프트 창이 함께 열려 있어야 한다. 실습을 마칠 때는 브라우저 탭을 닫고, 명령 프롬프트 창에서 Ctrl + C를 눌러 끈다.
STEP 06

Orange 파일(.ows) 열어 보기

  1. week01_1_town_start.ows를 더블클릭한다. Orange가 열리며 캔버스에 File 위젯이 하나 보인다.
  2. 더블클릭으로 열리지 않으면 Orange를 먼저 실행하고 메뉴 File → Open에서 그 파일을 고른다.
  3. 캔버스의 File 위젯을 더블클릭한다. 위쪽에 파일 이름(week01_orange_town_population.tab)이 보이고, 아래 정보 칸에 30행이 들어왔다고 나오면 성공이다.

File 위젯에 "파일을 찾을 수 없다"는 오류가 날 때

File 위젯에 빨간 글씨(File not found 등)가 보이거나 파일 이름이 빨간색이면, Orange가 데이터 파일을 찾지 못한 것이다. 아래 순서로 확인한다.

  1. 압축을 풀었는가? zip 안에서 바로 연 경우 임시 폴더에서 열려 데이터를 찾지 못한다. 압축을 푼 폴더의 .ows를 다시 연다.
  2. 폴더 구조가 그대로인가? semiconductor_kit 안에 orange3와 data가 나란히 있어야 한다. .ows 파일만 다른 곳으로 옮겼다면 원래 자리로 돌려놓는다.
  3. 그래도 안 되면 직접 고른다. File 위젯 창의 폴더 아이콘을 눌러 data/weekly/weekXX/orange/ 폴더의 .tab 파일을 고른다. CSV가 아니라 orange 폴더 안의 .tab을 고른다.
  4. 처음부터 다시: 키트 zip을 새로 내려받아 다른 곳에 압축을 풀고 다시 연다.
Orange에서 저장할 때 실습한 워크플로를 저장하면(Ctrl + S) Orange가 데이터 위치를 내 컴퓨터 기준으로 바꿔 저장할 수 있다. 그 컴퓨터에서는 계속 열리지만, 폴더를 옮기면 다시 이 오류가 난다. 막히면 키트의 _done.ows나 _start.ows를 다시 열면 된다.

준비 끝 확인

세 가지가 되면 첫 수업 준비 완료
  • 명령 프롬프트에서 python --version이 버전을 보여 준다.
  • week01_student.ipynb의 첫 셀이 파이썬 준비 완료!를 출력한다.
  • week01_1_town_start.ows의 File 위젯에 데이터 30행이 들어온다.

Orange 사용법은 부록. Orange3 시작하기에 더 자세히 있다. 키트의 데이터는 모두 교육용 가상 데이터다.
