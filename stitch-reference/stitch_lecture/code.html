Step-by-Step Hands-on
STEP 01

반도체 공정에서 데이터가 왜 중요할까?

현대 메모리(DRAM, V-NAND) 및 최첨단 3nm 파운드리 공정은 700~1,000단계가 넘는 미세 패터닝 공정을 거칩니다. 이때 수율(Yield) 0.1% 상승은 공장당 연간 수백억~수천억 원의 수익 개선으로 직결됩니다.

STEP 02

파이썬 변수 선언과 데이터 타입 (int, float, str, bool)

반도체 센서 값은 물리적 성격에 따라 데이터 타입이 결정됩니다. 온도는 소수점을 포함하는 float, RF 전력이나 카운트는 int, 웨이퍼 식별 바코드는 str, 공정 통과 여부는 bool로 표현합니다.

lesson1_step2_variable.py Python 3.11 
# 1. 반도체 팹 식각(Etch) 챔버 센서 텔레메트리 변수 선언
wafer_id = "WF-2024-001"     # 문자열 (str): 웨이퍼 고유 바코드 식별자
chamber_temp = 310.45        # 부동소수점 실수 (float): 챔버 내부 온도 (°C)
rf_power = 1205              # 정수 (int): 플라즈마 고주파 RF 출력 (W)
is_pass = True               # 불리언 (bool): 현재 챔버 수율 기준 만족 여부

# 2. 파이썬 type() 함수로 메모리 타입 확인
print(type(wafer_id))         # 
print(type(chamber_temp))     # 
print(type(rf_power))         # 
print(type(is_pass))          #
STEP 03

`print()`와 `f-string`으로 공정 알림 메시지 만들기

단순한 텍스트 나열 대신 f-string (포맷 문자열, Python 3.6+) 문법을 사용하면 변수 값과 소수점 자리수 제어(`:.1f`), 조건부 상태 표기를 하나의 표준 텔레메트리 로그로 변환할 수 있습니다.

lesson1_step3_telemetry_fstring.py Terminal Stream Script 
# f-string을 활용한 실시간 팹 텔레메트리 리포트 출력
wafer_id = "WF-2024-001"
chamber_temp = 310.45
rf_power = 1205
is_pass = True

# {:.1f} 문법으로 소수점 첫째 자리까지 반올림 포맷팅 적용
status_text = "PASS" if is_pass else "DEFECT"
report = f"[FAB TELEMETRY] Wafer: {wafer_id} | Temp: {chamber_temp:.1f}°C | RF: {rf_power}W | Status: {status_text}"

print(report)

Check Your Understanding

오늘 학습한 반도체 공정 데이터와 파이썬 변수 개념을 2개의 실전 문제로 검증해보세요.

Q1. 데이터 타입 판별 배점: 50점

300mm 웨이퍼 식각 공정 센서의 실시간 측정 온도값인 310.4를 파이썬에 저장하기에 가장 적합한 데이터 타입은 무엇일까요?

Q2. 파이썬 문법 식별 배점: 50점

문자열 앞에 접두사 f를 붙이고 중괄호 안에 변수를 넣어 출력하는 print(f"Chamber: {tool_name}") 코드의 문법 명칭은 무엇일까요?

1. 따옴표 누락으로 인한 NameError wafer_id = WF-2024-001 처럼 문자열 데이터에 큰따옴표나 작은따옴표를 씌우지 않으면, 파이썬은 이를 변수명으로 착각하여 NameError: name 'WF' is not defined 에러를 발생시킵니다.
2. 대소문자 엄격 구분 (Case Sensitivity) 파이썬은 대소문자를 완전히 별개로 처리합니다. Chamber_temp와 chamber_temp는 서로 다른 메모리 위치를 가리키므로 엔지니어링 표준 네이밍인 스네이크 케이스(snake_case)로 일관되게 작성해야 합니다.
3. f 접두사 누락 print("Wafer: {wafer_id}") 처럼 문자열 앞에 f를 빼먹으면 중괄호 안의 코드가 해석되지 않고 문자 그대로 화면에 표시됩니다.
