  • 공통 CSS(assets/css/common.css, print.css)와 JS (assets/js/common.js, quiz.js) 연결: 10개 주차 전체 정상.
  • 이전/다음 주차 내비게이션: 1주차(이전 없음)와 10주차(다음 없음, "과정 완료" 표시)를 제외하고 모두 정상 연결.

5. 콘텐츠 정합성 확인

  • 모든 주차 HTML에 등장하는 통계 수치(평균, 실패율, 상관계수, 수율 등)는 실제 생성된 CSV를 pandas로 직접 계산한 값이며, 임의로 지어낸 수치가 아니다.
  • 9주차는 fab.csv 원본을 절대 수정하지 않고, 파생 파일 2종만 사용했다. 센서 별칭이 "교육용 가상 명칭"이며 실제 물리적 의미를 단정하지 않는다는 문구를 반복 명시했다.
  • 8주차·10주차는 "상관관계는 원인을 증명하지 않는다"는 메시지를 퀴즈·결과 해석에 일관되게 포함했다.
  • 합격/불합격 부호 차이(반도체_공정_샘플.csv는 1=합격/-1=불합격, fab.csv는 -1=정상/1=이상)는 1주차와 9주차, 그리고 docs/glossary.md에서 명시적으로 설명했다.
